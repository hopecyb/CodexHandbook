## 1. 目标与背景

- **业务目标：** 一句话
- **成功标准：** 可观察、可验证
- **不在范围：** 明确排除项

## 2. 准备

- 账号/权限/仓库状态
- 需要的上下文文件（`AGENTS.md`、设计稿等）
- 风险：数据、生产、密钥

## 3. 工作流（EPXV）

### 探索

- 输入提示词（摘要）
- 关键发现

### 计划

- 步骤列表
- 人工确认点

### 执行

- 实际改动范围
- 与计划的偏差及原因

### 验证

- 自动测试
- 人工检查
- 证据（截图、日志、链接）

## 4. 失败与恢复

- 遇到过什么问题
- 如何撤销或修正
- 若重来会怎么改提示词/配置

## 5. 沉淀

- 是否写入 `AGENTS.md` / Skill / Automation
- 给团队的 3 条建议

## 6. 参考来源
- 官方文档链接
- 本案例是否基于外部教程改写（仅借鉴任务类型）
