团队自动化类案例最容易让人一兴奋就做过头。更合适的理解是：把重复、规则明确的动作交给它，其他部分继续保留人工判断。

## 本组入口

- [定时文档链接检查](/cases/use-cases/team-automation/scheduled-link-check/)
- [Issue 分流建议](/cases/use-cases/team-automation/issue-triage-suggestions/)

## 这组重点

- 什么任务适合全自动，什么只适合给建议
- 失败或异常时应该怎么告警和停机
- 为什么“自动开草稿 PR”通常比“自动改主分支”更稳
