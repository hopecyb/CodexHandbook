# 制作幻灯片

## 元信息

| 字段 | 内容 |
|---|---|
| 适用读者 | 创作者 |
| 客户端 | App |
| 预估耗时 | 1–2 小时 |

## 1. 目标与背景

**目标：** 根据主题生成结构清晰的演示文稿（Markdown/HTML/PPT 等，按环境能力）。

**成功标准：** 页数与大纲一致，每页要点可讲清，无编造数据。

## 2. 推荐提示词

```text
主题：【演示主题】
受众：【听众背景】
时长：【分钟数】
请先给章节与每页标题+3 个要点，不要生成最终文件。
确认后输出到 slides/ 目录，格式：【mdx/html/pptx】。
约束：数据需标注来源或标「示例」；不要外发网络请求除非批准。
```

## 3. 验证

- 通读每页是否可在一分钟内讲完
- 核对图表与数字来源
