# 第一个任务

以下示例默认 **桌面 App**；CLI/IDE 同样可用同一段提示词。

## 元信息

| 字段 | 内容 |
|---|---|
| 适用读者 | 初学者 |
| 客户端 | 桌面 App（推荐） |
| 预估耗时 | 15–20 分钟 |

## 1. 目标与背景

**目标：** 在练习项目中完成一次安全的文件修改。

**成功标准：** 仅修改指定文件，结果符合验收描述，你能读懂 diff。

## 2. 准备

- 已安装客户端并登录
- 已创建练习项目（含 `hello.md` 或类似文件）

## 3. 推荐提示词

```text
目标：在 hello.md 末尾追加一节「今日练习」，包含三行要点列表。
约束：只修改 hello.md；不要删除已有内容；不要运行网络请求。
验收：文件末尾出现该标题与恰好三个列表项。
若信息不足请先问我，不要猜测。
```

## 4. 执行与检查

1. 先让它给出简短计划（或你主动要求计划）
2. 审批文件写入时确认路径正确
3. 完成后对照验收标准逐条检查 diff
