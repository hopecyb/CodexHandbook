# 写文章

## 元信息

| 字段 | 内容 |
|---|---|
| 适用读者 | 创作者 |
| 客户端 | App / CLI |
| 预估耗时 | 1–2 小时 |

## 1. 目标与背景

**目标：** 产出可发布的技术文章初稿。

**成功标准：** 结构完整、事实可核对、风格符合受众。

## 2. 工作流（EPXV）

### 探索

```text
主题：【文章主题】
受众：【初学者/开发者】
请先给 3 个可选角度与大纲，不要写正文。
```

### 计划

确认大纲后：

```text
按大纲第 1 节撰写，约 300 字；写完暂停等我确认语气。
```

### 执行

逐节撰写，避免一次生成全文难以修改。

### 验证

- 人工核对链接、版本号、命令是否仍有效
- 可选：用 [写作 Skill](/skills/examples/writing-skill/) 固化流程

## 3. 沉淀

重复写作可封装 `article-writer` Skill；见 [创作者路径](/guide/learning-paths/creator/)。
