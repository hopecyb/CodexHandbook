# 实战案例

实战案例展示如何从一个真实目标出发，完成提示、执行、纠偏、检查、验证和复用。案例关注过程中的判断点，而不只展示最后的产物。

## 案例格式

每个案例都应包含目标、准备材料、推荐提示词、执行过程、人工检查点、验证方式、失败处理和可复用模板。撰写新案例可参考 [案例模板](/cases/use-cases/case-study-template/)。

## 可拿走的资产

- [案例模板](/cases/use-cases/case-study-template/)：把一次任务整理成可复盘、可交接的记录。
- [第一次任务](/cases/first-task/)：用小而安全的任务跑通目标、执行和验收闭环。
- [工作流案例](/cases/workflows/)：学习如何把验证、人工确认、失败恢复和多 Agent 协作加入流程。
