# Tool Use (uso de ferramentas)

- Datas importantes:
  - Engineering inflection: 2025-03-11 (Responses API and built-in tools)
- Referências oficiais:
  - https://openai.com/index/new-tools-for-building-agents/

- Nota: Esta entrada registra o ponto de adoção e o significado atual deste conceito na engenharia de aplicações de IA.

## O Que É

Tool Use faz o modelo escolher, chamar e ler ferramentas como busca, código, navegador e bancos de dados.

## De Que Etapa para Que Etapa Isso Levou a Engenharia de Aplicações de IA

Moveu o sistema de uma função isolada para a orquestração de várias capacidades.

## Em Que Estágio Está Agora

Atualmente marco este item como `emerging`.

Está virando mainstream em APIs e frameworks de agentes.

## O Que Pode Substituir

Substitui muitos fluxos manuais de buscar, copiar, executar e verificar.

## O Que Pode Substituí-lo

Será incorporado a harnesses e runtimes de agentes com estado e recuperação.
