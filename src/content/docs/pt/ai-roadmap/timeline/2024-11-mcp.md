# MCP (protocolo de contexto de modelo)

- Datas importantes:
  - Open-source date: 2024-11-25
- Referências oficiais:
  - https://modelcontextprotocol.io/docs/getting-started/intro
- Nota: Esta entrada registra o ponto de adoção e o significado atual deste conceito na engenharia de aplicações de IA.

## O Que É

MCP padroniza como modelos e agentes se conectam a ferramentas, dados e serviços.

## De Que Etapa para Que Etapa Isso Levou a Engenharia de Aplicações de IA

Move integrações de adaptadores específicos por produto para um protocolo comum reutilizável.

## Em Que Estágio Está Agora

Atualmente marco este item como `emerging`.

É emergente e cresce rápido, embora governança e segurança ainda estejam amadurecendo.

## O Que Pode Substituir

Pode substituir integrações API e plugins específicos difíceis de reutilizar.

## O Que Pode Substituí-lo

Pode evoluir para protocolos de execução com permissões e observabilidade.
