# Casos práticos

Os casos práticos mostram como partir de um objetivo real e completar o prompt, a execução, a revisão, a verificação e a reutilização.

## Formato do caso

Cada caso deve incluir objetivo, materiais de preparação, prompt recomendado, processo de execução, pontos de controlo humanos, métodos de verificação, tratamento de falhas e modelo reutilizável. Para redigir um caso novo, consulte o [modelo de caso](/pt/cases/use-cases/case-study-template/).
