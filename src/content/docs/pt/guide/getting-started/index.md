O objetivo é completar a primeira Tarefa num **projeto de prática seguro** e aprender a verificar, aceitar, modificar ou desfazer.

O padrão é o **App desktop**. Se você prefere terminal ou editor, as páginas de instalação ainda valem; o exemplo da primeira Tarefa indica as diferenças.

Se o que mais importa agora é «como começar» e «como evitar errar de cara», este capítulo é a entrada mais direta.

## O que este capítulo inclui

- O mínimo a preparar antes do primeiro uso
- A ordem de instalar, entrar e criar o projeto de prática
- Até onde a primeira Tarefa precisa ir para contar como adequada
- Depois de fazer: como verificar e como desfazer

## Mal-entendidos comuns

### 1. Na primeira Tarefa já ir direto a um projeto importante?

Não recomendado.

Na primeira vez, uma Tarefa pequena num projeto de prática seguro é mais estável. Deixe o fluxo fluido e só então toque em conteúdo oficial.

### 2. Se a instalação deu certo, já «comecei»?

Ainda não basta.  
No mínimo isto precisa estar feito para contar como começo de verdade:

- Conseguir iniciar uma Tarefa clara
- Conseguir entender o resultado
- Conseguir decidir aceitar, modificar ou desfazer

### 3. Quanto maior a primeira Tarefa, mais se aprende?

Na maioria das vezes, só aumenta a perda de paciência.  
Quanto menor e mais fácil de verificar a primeira Tarefa, mais fácil construir o julgamento básico.

## Ordem sugerida

Dá para seguir este ciclo mínimo:

1. Escolher o cliente
2. Instalar e entrar
3. Criar um projeto de prática seguro
4. Fazer uma Tarefa bem pequena
5. Verificar o resultado
6. Aprender a desfazer ou corrigir

Depois que este ciclo fechar, aprender conteúdo mais complexo fica mais leve.
