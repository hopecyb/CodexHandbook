## Objetivo deste passo

Explica em frases completas **o que queres** e **o que não queres** — não lances só algumas palavras.

Na primeira conversa com o Codex, muita gente trata-o como uma caixa de pesquisa e só manda palavras-chave. Este passo serve para mudar esse hábito.

## Exercício

Diz ao projeto de prática:

```text
Explica em três frases que ficheiros há na pasta atual e o que cada um faz aproximadamente.
Não modifiques nenhum ficheiro.
```

## O que este passo treina

Aqui treinas duas coisas básicas — não «deixar o Prompt mais bonito»:

- Completar o objetivo
- Clarificar os limites

Mesmo numa Tarefa só de leitura, convém escrever «não modifiques nenhum ficheiro».

## O que aprendes

- Tarefas só de leitura também precisam de «não modificar»
- Pedidos vagos geram respostas vagas

## Mal-entendidos frequentes

### 1. Este exercício é demasiado simples, não vale a pena

Se nem Tarefas só de leitura ficam claras, Tarefas de alteração desviam-se ainda mais facilmente.

### 2. Só preciso de limites quando altero ficheiros

Leitura, explicação e resumo também precisam de limites.
