Na primeira vez com o Codex, o bloqueio mais comum não é «não perceber uma página», mas não saber por onde começar.

Este grupo é o caminho mais curto preparado para principiantes.

## Ordem recomendada

1. [Conversar com o Codex](/guide/learning-paths/beginner/01-talk-to-codex/)
2. [Trabalhar com ficheiros](/guide/learning-paths/beginner/02-work-with-files/)
3. [Dar Tarefas claras](/guide/learning-paths/beginner/03-give-clear-tasks/)
4. [Rever resultados](/guide/learning-paths/beginner/04-review-results/)
5. [Concluir o primeiro projeto pequeno](/guide/learning-paths/beginner/05-complete-first-project/)

## Para quem serve

- Ainda não concluíste de forma estável um ciclo completo de Tarefa
- Sabes que o Codex faz coisas, mas não sabes como treinar na primeira vez
- Queres primeiro um «método suficiente», não o glossário completo

O objetivo do percurso de principiante não é aprender tudo — é fechar o primeiro ciclo completo.
