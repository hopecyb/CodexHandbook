A App de desktop é o ponto de entrada padrão para iniciantes: permite ver projetos, Tarefas, Diff e Aprovações de forma visual.

Também é uma entrada mais fácil se você não estiver familiarizado com a linha de comando ou com plugins do IDE.

Não se limita a «poder conversar»: reúne projeto, mudanças, Aprovação e Verificação numa mesma interface visível.

## Conteúdo deste capítulo

- Quais ações convém aprender primeiro na App de desktop
- Quais funções convém usar primeiro como iniciante e quais deixar para depois
- Onde olhar quando há mudanças, Aprovações ou problemas

## Comece por reconhecer estas três coisas

Não é preciso aprender todas as funções de uma vez.  
Primeiro reconheça estas três ações centrais:

1. Onde introduzir a Tarefa
2. Onde ver as mudanças
3. Onde aprovar ou rejeitar operações

Quando dominar estes três passos, já consegue fechar um ciclo básico de Tarefa.

## Mal-entendidos frequentes

### 1. A App de desktop é só uma casca gráfica da CLI?

Ela mostra vários elos-chave do processo de colaboração:

- A Tarefa atual
- Planos e chamadas a Ferramentas
- Mudanças em ficheiros
- Ações de Aprovação
- Revisão de resultados

### 2. É preciso entender todos os botões antes de começar?

No início basta reconhecer:

- Onde introduzir a Tarefa
- Onde ver o Diff
- Onde aprovar / rejeitar

Isso já basta.

### 3. Se a App de desktop é boa para iniciantes, não serve para trabalho formal?

Muito trabalho formal também pode ser feito na App de desktop, sobretudo quando você valoriza a revisão visual e a transparência do processo.

## Ordem de aprendizagem

Na primeira vez com a App de desktop, pode seguir esta ordem:

1. Instalar e reconhecer a interface
2. Escolher o projeto certo
3. Abrir uma Tarefa pequena
4. Ver as mudanças
5. Aprender a aprovar e rejeitar
6. Só depois aprender Agents em paralelo, árvores de trabalho, Tarefas Cloud e outras capacidades avançadas

Em geral isso é mais leve do que estudar todas as funções de uma vez.
