Para a maioria das pessoas, o que trava no começo com o Codex não é o background técnico — é como dar o primeiro passo.

## O essencial

1. **Acesso utilizável ao OpenAI / Codex** (conta e plano conforme a documentação oficial)
2. **Um computador onde dá para instalar o App desktop, o CLI ou a extensão IDE**
3. **Um diretório de prática descartável** (não faça a primeira tentativa direto no repositório de produção)
4. **Disposição para verificar o resultado**: aceitar, modificar ou desfazer — em vez de mesclar às cegas

Entre os quatro, o 3 e o 4 são os mais esquecidos.

- O diretório de prática reduz muito a pressão de errar
- A disposição de verificar o resultado define se a tentativa é controlável

## O que você não precisa ter de antemão

Isto **não** é pré-requisito rígido antes de começar:

- Não precisa dominar Git
- Não precisa saber escrever muito código
- Não precisa entender de cara todos os detalhes de modelo, Contexto, Sandbox e Aprovação
- Não precisa instalar todos os clientes de uma vez

Complete a primeira Tarefa e depois vá preenchendo os conceitos — a pressão fica bem menor.

## Mal-entendidos comuns

### 1. Não precisa ler toda a documentação antes de começar

Dá para aprender enquanto usa. Muita gente começa assim:

1. Completa uma Tarefa bem pequena
2. Volta aos conceitos relacionados
3. Quando aparece um problema, consulta a documentação de novo

### 2. Não é recomendável testar no projeto oficial logo de cara

No começo, faça assim:

- Um diretório pequeno e descartável
- Uma Tarefa pequena cujo resultado você consegue entender
- Um ambiente em que errar não cause prejuízo

### 3. Não precisa aprender CLI, IDE e App de uma vez

Para a maioria dos iniciantes, começar pelo **App desktop** é mais leve: a interface é mais intuitiva e fica mais fácil ver projetos, Tarefas e mudanças.

## Uma ordem comum de início

Você pode seguir esta ordem:

1. Confirmar que tem acesso
2. Instalar um cliente
3. Preparar um diretório de prática
4. Rodar uma Tarefa bem pequena
5. Verificar o resultado e decidir o próximo passo

Antes de começar, completar a primeira Tarefa num ambiente seguro, pequeno e reversível economiza mais esforço do que acumular um monte de conceitos.
