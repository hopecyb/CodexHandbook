# Comece aqui

Este handbook é escrito principalmente para **iniciantes em IA**: não pressupõe que você saiba usar terminal, Git ou Agents, mas explica aos poucos as capacidades que você vai encontrar depois.

## Conteúdo

- Entender o que o Codex pode e não pode fazer
- Escolher uma rota de leitura por papel e Tarefa
- Completar a primeira Tarefa verificável em um projeto de prática seguro
- Aprender a escrever Prompts com objetivo, restrições e critérios de aceite, e criar o hábito de revisar

## Ordem de leitura sugerida

1. [O que é o Codex](/guide/start-here/what-is-codex/) — o que pode e o que não pode fazer
2. [Escolher o cliente](/guide/choose-your-client/) — App, CLI, IDE ou Cloud
3. [Completar a primeira Tarefa](/cases/first-task/) — uma mudança pequena com Prompt claro e revisão do resultado
4. [Permissões e Sandbox](/guide/permissions-and-sandbox/) — Aprovação, isolamento e limites de rede
5. [Contexto e arquivos](/guide/context-and-files/) — como fornecer entradas úteis
6. [Verificação](/guide/verification/) — hábitos de revisão e testes

## Mal-entendidos comuns

### 1. «Comece aqui» não explica tudo de uma vez

Esta seção esclarece as entradas e a ordem. Não tenta entregar todo o conteúdo de uma só vez.

### 2. Você pode continuar mesmo sem entender todas as palavras no início

Basta saber estas coisas por agora:

- Como o Codex colabora
- Como abrir uma Tarefa
- Como verificar o resultado

Os detalhes podem ser complementados enquanto você usa.

### 3. Só entender os conceitos ainda não basta para começar

Não basta. Entender, praticar em escala pequena e verificar o resultado precisam andar juntos.

## Rota dos primeiros 30 minutos

| Tempo | O que fazer |
|---|---|
| 0–5 min | Ler os pontos de segurança em [Permissões e Sandbox](/guide/permissions-and-sandbox/) |
| 5–10 min | Instalar e entrar no cliente escolhido (veja [App desktop](/guide/desktop-app/) e outros) |
| 10–25 min | Seguir o [caso da primeira Tarefa](/cases/first-task/) |
| 25–30 min | Percorrer [Fundamentos de Prompt](/prompts/basics/) e se preparar para escrever Tarefas mais claras |

Se travar, consulte [Solução de problemas](/guide/troubleshooting/).
