---
title: 本地与云端
description: 对比本地任务与 Cloud 任务的适用场景。
---


| | 本地任务 | Cloud 任务 |
|---|---|---|
| 运行位置 | 你的机器 / 本地环境 | 云端环境 |
| 适合 | 快速迭代、本机文件、需本机密钥的调试 | 连接远程仓库、长任务、标准化环境 |
| 注意 | 本机权限与误改风险 | 环境配置、密钥注入、网络策略 |

初学者默认从 **本地 + 桌面 App** 开始。Cloud 细节见 [Web 与 Cloud 概述](/04-product-guides/web-and-cloud/)。在 App 内切换见 [本地与云端任务](/04-product-guides/desktop-app/local-and-cloud-tasks/)。
