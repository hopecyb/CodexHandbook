Codex Dream Skin は第三者によるデスクトップテーマのプロジェクトです。プロジェクトの説明では、公式パッケージを変更せず、ローカル CDP 接続で外観を注入します。これはプロジェクト側の説明であり、本サイトは全バージョンのファイル動作、ネットワーク動作、画面の互換性を検証していません。

![テーマの外観イメージ](/theme/codex-dream-skin/article/codex-dream-skin-home.jpg)

ここに掲載している外観の画像は今回のバージョン検証の証拠ではありません。入力欄、承認ボタン、すべてのタスク画面が正常に使えることも示しません。

リリースノートでは、一部の画面修正を上流の macOS Codex 26.901.41123 で確認したとあります。ここで記録した 26.911.61220 とは異なるため、この組合せの互換性は推定できません。このページの macOS インストールリンクは v1.5.18 に固定しています。別バージョンでは対応するタグを参照してください。

クライアントのバージョンを読むだけでは環境情報にとどまり、テーマの互換性を示しません。自身の試験結果は[リソースの互換性と復元記録](/ja/guide/reference/resource-compatibility/)に残してください。

## インストール前の準備

1. リリース一覧から特定のバージョンを選び、パッケージ名、ダウンロード先、SHA-256 を記録します。公開者がチェックサムファイルを出していれば比較します。ハッシュ一致はファイルの一致を示すだけで、プログラムの安全性は保証しません。
2. クライアントと OS のバージョン、テーマ設定、使用権のあるカスタム画像のコピーを保存し、バックアップ先を記録します。
3. テーマを使う前に、ホーム、タスク画面、入力、スクロール、検索、承認画面を確認して比較基準にします。
4. 選んだリリースに対応するインストール・更新・削除手順を読みます。main ブランチの文書はインストーラーより新しい場合があります。

macOS では[プロジェクトのインストール手順](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.18/docs/install-macos.md)、Windows では[Windows 向け手順](https://github.com/Fei-Away/Codex-Dream-Skin/blob/main/docs/install-windows.md)を確認してください。「破損」警告やシステムの遮断を一律に署名不足と決めつけず、出典、パッケージの整合性、具体的なエラーを確認してから続行を判断します。

## 画像を替えた後に確認すること

プロジェクトには背景画像とテーマの管理機能があります。メニュー名はバージョンによります。利用権のある画像を使い、ライト・ダークモード、ウィンドウの拡大縮小、実際のタスク画面を確認してください。

- 入力欄、ボタン、承認情報を読み、クリックし、フォーカスできるか。
- 背景が検索結果、長い出力、コード差分、エラーを隠さないか。
- ページ切り替えや再起動後も、選んだテーマが表示されるか。
- テーマを無効にした後、元の画面が戻り、問題がなお再現するか。

内容が隠れたり操作できなくなったりしたら、テーマの使用を止めて復元してください。スタイルを重ねて問題を隠さないでください。

## アンインストールと復元

プロジェクトの macOS 文書は、テーマアプリを削除する前にメニューバーで「元に戻してアンインストール」を実行するよう求めます。ユーザーのテーマや画像は別に保持・削除できます。事前にカスタム素材をバックアップしてください。Windows では macOS のパスを流用せず、そのバージョンの文書に従います。

以下は本サイトが提案する復元の確認方法であり、実施済みの試験記録ではありません。

1. クライアント内の作業を保存し、現在のテーマと残すファイルを記録します。
2. テーマツールの復元手順を使い、成功、失敗、未確認を示すメッセージを保管します。
3. 通常の入口から Codex を再起動し、背景、文字、入力、タスクの移動を確認します。
4. テーマツールが自動起動・再注入しないことを確かめます。技術的な確認が必要なら、同名プロセスを無差別に終了せず、プロセスとデバッグ接続を調べます。
5. 確認に通ってからアプリを削除します。カスタム画像は不要と判断するまで別途保管します。

バックアップがあること、削除プログラムが終了したこと、テーマの窓が閉じたことだけでは復元成功の証拠になりません。結果が未確認ならログを保存してプロジェクトの Issue を調べ、「復元した」と書かないでください。テーマ削除のために Codex の設定ディレクトリ全体を消してはいけません。

## 適用範囲

CDP はページ内容を変更できます。「公式パッケージを変更しない」は操作に影響しないことを意味しません。画面構造の更新後は再検証が必要です。ローカル処理、ネットワークアクセス、復元機構についてのプロジェクトの説明も対象バージョンごとに確認してください。本サイトは素材が決してアップロードされないこと、全バージョンのワンクリック復元、上書き更新でのデータ無損失を保証しません。
