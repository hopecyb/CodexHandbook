## 継続的な更新

この手引きは、特定の Codex バージョンに固定されるものではありません。製品は変化し続けるため、インストール、サインイン、権限、モデル、設定、Cloud の動作も変わることがあります。

## どの情報を優先するか

現在の製品動作については、[OpenAI の Codex 公式ドキュメント](https://developers.openai.com/codex)を参照してください。この手引きは、概念の説明、学習経路の整理、実践方法の提供を目的としています。内容が食い違う場合は公式ドキュメントを優先し、ページ下部の修正リンクから問題をお知らせください。

## 内容が現在も適用できるか判断する方法

変わる可能性がある情報を読むときは、次の 3 点を確認します。

1. インストール、設定、権限、製品の入口など、変化しやすい話題か。
2. 表示されている内容の最終更新日が古くないか。
3. 引用された公式情報と現在の製品動作が一致しているか。

概念、方法、受け入れ確認の考え方は、具体的なボタン、パラメーター、画面上の経路より安定しています。最新の動作、パラメーター、価格、規則については、公式情報を改めて確認してください。

## 内容の更新と修正

[内容の更新と修正](/ja/guide/updates/)には重要な変更と影響を記録しています。ページ下部から、現在のページタイトルとパスを含む GitHub Issue の下書きを開けます。送信前に内容を確認し、機密情報を削除してください。

## 変わりやすい内容

- インストール方法とシステム要件
- サインイン、アカウント、権限の流れ
- モデル、設定項目、パラメーターの書式
- Cloud、クライアント、製品入口の動作
- 価格、割り当て、サービス上限
