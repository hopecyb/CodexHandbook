# ここから始める

このハンドブックは主に **AI 初心者** 向けに書かれています。ターミナル、Git、Agent の使用を前提としませんが、後で出会う能力は段階的に説明していきます。

## 内容

- Codex が何をできて、何ができないかを明確にする
- 役割とタスクに応じて読むルートを選ぶ
- 安全な練習プロジェクトで、最初の検証可能なタスクを完了する
- 「目標、制約、検証」でプロンプトを書き、レビューの習慣を身につける

## 推奨読書順序

1. [Codex とは](/ja/guide/start-here/what-is-codex/) — 何ができて、何ができないかを明確にする
2. [クライアントの選択](/ja/guide/choose-your-client/) — App、CLI、IDE、Cloud から選ぶ
3. [最初のタスクを完了する](/ja/cases/first-task/) — 明確なプロンプトで小さな変更を行い、結果を確認する
4. [権限とサンドボックス](/ja/guide/permissions-and-sandbox/) — 承認、隔離、ネットワーク境界を理解する
5. [コンテキストとファイル](/ja/guide/context-and-files/) — 有効な入力の提供方法を学ぶ
6. [結果の検証](/ja/guide/verification/) — レビューとテストの習慣を身につける

## よくある誤解

### 1. 「ここから始める」で全部が一度に説明されるわけではない

この章は主に入口と順序を説明するもので、すべての内容を一度に詰め込むものではありません。

### 2. 最初は用語がわからなくても、読み進められる

まず次の 3 点を知っていれば十分です。

- Codex はどう協業するか
- タスクはどう始めるか
- 結果はどう確認するか

その他の詳細は使いながら補っていけます。

### 3. 概念を理解しただけでは、すぐに使いこなせない

不十分です。理解、小規模な実践、結果の確認は一緒に行う必要があります。
