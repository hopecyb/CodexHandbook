より完全な用語集は [用語集](/guide/reference/glossary/) を参照してください。ここでは最も一般的で、読み進めに影響しやすい用語を先に挙げます。

Codex ハンドブックを初めて読むとき、つまずきやすいのは用語の密度です。単語ごとにはわかっても、つながると混乱しがちです。

よくある状況は主に 2 つです。

- 文字はわかるが、実際の操作で何を指すかわからない
- 今すぐ理解すべき用語と、後でよい用語の区別がつかない

用語試験として捉える必要はありません。おおよその意味がわかれば、本文を読み進められます。

## 最初に覚える用語

今の目標が最初のタスクを通すことだけなら、まずこの 6 つを理解してください。

| 用語 | 先に理解する理由 |
|---|---|
| **プロンプト** | タスクをどう明確に伝えるか |
| **コンテキスト** | Codex が現在何を見られるか |
| **Agent** | なぜ単なる返答ではないか |
| **承認** | なぜときどき止まって聞いてくるか |
| **差分（diff）** | 何を変更したかをどう確認するか |
| **タスク** | 1 回の完全な作業の基本単位 |

| 用語 | 簡単な説明 |
|---|---|
| **プロンプト（prompt）** | Codex に伝える目標、背景、要求 |
| **コンテキスト（context）** | モデルが現在見られるプロジェクト、ファイル、会話情報 |
| **Agent** | 目標に向けてツールを呼び出し、反復的に進める実行方式 |
| **ツール（tool）** | ファイル読み取り、コマンド実行、検索などの呼び出し可能な能力 |
| **サンドボックス（sandbox）** | ファイルシステムとネットワークへの影響範囲を制限する実行環境 |
| **承認（approval）** | 一部の操作は明示的な同意後にのみ続行 |
| **差分（diff）** | 変更前後の内容比較。レビュー用 |
| **スレッド / セッション** | 連続した会話とその蓄積コンテキスト |
| **タスク** | 目標を持つ 1 つの作業単位（複数ステップのツール呼び出しを含む場合あり） |
| **Skill** | 再利用可能な専門作業説明とリソースパッケージ（上級） |
| **MCP** | 外部ツールとデータソースを接続するプロトコル（上級） |
| **Cloud タスク** | ローカルサンドボックスではなくクラウド環境で実行されるタスク |

## もっと直感的な言い換え

- **プロンプト**：タスクを依頼するときの言葉
- **コンテキスト**：今手元にある材料
- **Agent**：返答するだけでなく、実際にタスクを前に進める
- **承認**：自分ではできないことがあり、あなたの同意が必要
- **diff**：変更前と変更後の比較
- **Skill**：固定のやり方をパッケージ化して再利用

## 使い方

他のページでこれらの用語に出会っても、毎回定義を調べる必要はありません。

- おおよその意味がわかれば、読み進める
- 何度も見てもまだ曖昧なら、ここに戻る
- フローの理解に影響するなら、対応するトピックページを読む

## グループで見る

一度に覚えすぎない場合は、次のように分けられます。

- あなたが言うこと：プロンプト
- それが見ること：コンテキスト
- それがやること：Agent、ツール
- それができるか：承認、サンドボックス
- あなたが確認すること：diff、タスク結果

## 後で見てよい用語

以下は多くが上級内容で、初回は急いで理解する必要はありません。

- Skill
- MCP
- Hook
- Plugin
- Cloud 環境の詳細

まず [最初のタスク](/guide/getting-started/run-your-first-task/) を完了し、後からこれらの用語を見ると、理解がスムーズになります。

生詞に出会ったら、ここで確認して読み進めれば十分です。

初回は、これらの用語をヒントとして捉えてください。最初から全部覚えるより、おおよその意味を知る方が実用的です。
