Codex を始めるとき、多くの人がつまずくのは技術的背景ではなく、最初の一歩の踏み出し方です。

## 必須

1. **利用可能な OpenAI / Codex アクセス権**（アカウントとプランは公式説明が基準）
2. **デスクトップ App、CLI、または IDE 拡張をインストールできるコンピュータ**
3. **捨てられる練習ディレクトリ**（本番リポジトリで初回試行しない）
4. **結果を確認する意思**：盲目的にマージするのではなく、承認、修正、取り消しを行う

この 4 項のうち、3 と 4 が最も見落とされやすいです。

- 練習ディレクトリは試行錯誤のプレッシャーを大きく減らす
- 結果を確認する意思が、試行が制御可能かどうかを決める

## 事前に必要ないもの

以下は **開始前のハードな前提条件ではありません**。

- Git を精通している必要はない
- たくさんのコードを書ける必要はない
- 最初からすべてのモデル、コンテキスト、サンドボックス、承認の詳細を理解する必要はない
- すべてのクライアントを一度にインストールする必要はない

最初のタスクを通してから、これらの概念を少しずつ補う方がプレッシャーは小さいです。

## よくある誤解

### 1. ドキュメントを全部読んでから始める必要はない

読みながら学べます。多くの人は次のように始めます。

1. とても小さなタスクを完了する
2. 関連する概念に戻って読む
3. 問題が起きたらドキュメントを参照する

### 2. 最初から本番プロジェクトで試すのはおすすめしない

最初は次のようにするとよいです。

- 捨てられる小さなディレクトリ
- 結果が理解できる小さなタスク
- 失敗しても損失がない環境

### 3. CLI、IDE、App を一度に全部学ぶ必要はない

多くの初心者にとって、**デスクトップ App** から始める方が楽です。UI が直感的で、プロジェクト、タスク、変更が見やすいからです。

## 一般的なスタート順序

次の順序で進められます。

1. アクセス権があることを確認する
2. クライアントを 1 つインストールする
3. 練習ディレクトリを用意する
4. とても小さなタスクを実行する
5. 結果を確認し、次のステップを決める

始める前に、安全で小規模、取り消し可能な環境で最初のタスクを通す方が、大量の概念を先に詰め込むより楽です。
