Codex は OpenAI が提供する **AI プログラミングと作業 Agent** です。目標を伝えると、プロジェクトファイル、ツール、あなたの承認を組み合わせて内容を読み、変更し、コマンドを実行し、結果を生成し、プロセスと変更をあなたに確認してもらいます。

ツールを使えるデジタル同僚のような存在です。あなたは目標、境界、検証基準を説明します。Codex は資料の調査、ファイルの変更、ステップの実行を担当しますが、最終判断はあなたが行います。

公式製品ドキュメントは [OpenAI Codex](https://developers.openai.com/codex) が基準です。このハンドブックはコミュニティのオープンソースガイドで、体系的な学習と実践的な利用を支援しますが、公式ドキュメントの代替ではありません。

## 普通の AI チャットとの違い

Codex を初めて見る人は、しばしば「もっと強力なチャット AI」と理解します。違いは主に実行能力にあります。

| 普段使うもの | こう理解できる |
|---|---|
| 普通のチャットボット | アドバイス、概念の説明、文章の作成 |
| Codex | 回答に加え、**ファイルの読み書き、コマンドの実行、成果物の生成** も行う場合がある |

普通のチャットツールは主に回答にとどまります。Codex は許可された範囲で直接手を動かします。

## どんなタスクに向いているか

「話す」だけでなく、資料の読み取り、変更、ステップの実行、結果の生成が必要なタスクは、Codex に任せるのに適しています。

概念を聞くだけ、ひらめきを求めるだけ、漠然としたアドバイスが欲しいだけなら、普通のチャット型 AI でも対応できます。

## どんなことに使えるか

プログラマーでなくても、次のシーンから理解できます。

- **資料の読み取りと整理**：ドキュメント、会議記録、スクリーンショット、表の要約
- **コンテンツの作成と編集**：記事の推敲、目次の追加、説明ドキュメントの修正
- **小さなプロジェクト**：ページの構築、設定の変更、テンプレートの追加
- **問題の調査と修正**：どこが間違っているか、次に何を見るべきかの特定
- **反復作業の自動化**：固定フローを一度任せる

コードが書ける人は開発フローに組み込めます。書けない人も、ステップを実行できるアシスタントとして使えます。

## できること

- **理解**：リポジトリ、ドキュメント、表、スクリーンショットの情報を要約
- **作成と変更**：原稿の執筆、コードの修正、ページと設定の生成
- **実行**：承認のもとでターミナルコマンド、検索、ブラウジングを実行
- **協業**：App、CLI、IDE、Cloud などの入口間でタスクを継続
- **拡張**：Skills、Plugins、MCP、Hooks などで反復フローと外部システムに接続（上級章で順次補完）

## できないこと（重要）

- 事実、セキュリティ、ビジネス判断に対する最終責任を代替できない
- 一度の生成で完全に正しいとは限らない。結果は必ず検証が必要
- 承認なしにサンドボックス、ネットワーク、組織ポリシーを突破できない
- 「検証不要の自動リリースパイプライン」として使うべきではない

## 使うときの基本判断

Codex をアシスタントとして使い、責任は一緒に渡さない。

先にやらせ、調べさせ、変更させても、最後は自分で確認する。

- 正しい場所を変更したか
- 目標を誤解していないか
- 提示した事実は信頼できるか
- 変更が副作用をもたらさないか

## 一般的なフロー

一般的なフローは次のとおりです。

1. 目標を伝える
2. 回答または計画を提示する
3. ファイルの変更やコマンド実行が必要な場合、承認を求めることがある
4. 完了後、何を変更したかを報告する
5. 結果が期待通りかを確認する

このフローの完全な例は [最初のタスクを実行する](/guide/getting-started/run-your-first-task/) を参照してください。

## 主な利用入口

| 入口 | 向いている人 |
|---|---|
| デスクトップ App | 初心者のデフォルト。プロジェクト、タスク、差分レビューを可視化 |
| CLI | ターミナルユーザー、スクリプト、自動化 |
| IDE 拡張 | エディタ内で開いているファイルと選択範囲と連携 |
| Web / Cloud | リポジトリ接続、クラウド環境、長期タスク |
| モバイルとリモート | 監視、承認、軽量なフォローアップ |

対照表は [機能対照](/guide/reference/feature-comparison/)。概念の関係は [能力マップ](/guide/start-here/)。

## 次に読むもの

3 点だけ押さえたい場合は、次を覚えておいてください。

1. Codex はチャットだけでなく、承認後にアクションを実行する
2. タスクには目標、境界、「完了の定義」を明確に伝える
3. すべての結果を検証し、盲信しない
