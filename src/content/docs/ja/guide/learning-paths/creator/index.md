## よくある誤解

### 1. クリエイターパスは「書いてもらう」ことだけ

それだけでは不十分です。

より重要なのは次の 3 点です。

- 目標、対象読者、スタイルをどう明確に伝えるか
- 生成されたコンテンツが使えるかどうかをどう判断するか
- 多ラウンドの創作でどう逸脱を防ぐか

### 2. プログラマーではないので検証は不要

コンテンツ作業も例外ではありません。

コンテンツ作業にも検証は必要です。重点は異なりますが、構造、トーン、事実、形式、納品効果などが該当します。
