架空のイベント資料一式を使い、ファイルの読み取りから検証可能な通知の提出まで練習する。事前に Git やプログラミングを学んだり、依存関係をインストールしたりする必要はない。

[演習パッケージ一式をダウンロード](/downloads/first-project/first-project-1.0.0.zip) · [資料の説明](/downloads/first-project/README.md)

展開後、starter を新しい work フォルダーへコピーし、Codex で work を開く。元のファイルと筆者の参考資料を残し、演習を終えてから解答と比較する。クライアントのインストールやログインで困った場合は、[クイックスタート](/ja/guide/getting-started/)と[トラブルシューティング](/ja/guide/reference/troubleshooting/)を参照する。

| ステップ | すること | 完了の証拠 |
|---|---|---|
| [1. Codex と対話する](/ja/guide/learning-paths/beginner/01-talk-to-codex/) | 3 つのファイルを読むだけにし、用途と不明点を説明する | 申込方法の確認が必要と分かり、ファイルが変わっていない |
| [2. ファイルを扱う](/ja/guide/learning-paths/beginner/02-work-with-files/) | 通知に状態の注記だけを追加する | 1 つのファイルに 1 行だけ増える |
| [3. 明確なタスクを与える](/ja/guide/learning-paths/beginner/03-give-clear-tasks/) | 事実に基づいて通知を整理する | 事実が一致し、不明点を残し、範囲が正しい |
| [4. 結果をレビューする](/ja/guide/learning-paths/beginner/04-review-results/) | 誤りのある例を確認し、自分の成果物も点検する | 4 項目の誤りを特定し、実際の点検を記録する |
| [5. 最初の小さなプロジェクトを終える](/ja/guide/learning-paths/beginner/05-complete-first-project/) | コピーで復元を練習し、引き継ぎを書く | 復元したファイルが一致し、引き継ぎを追跡できる |

## パッケージの内容

starter には事実、通知の下書き、変更してはいけない合成メモがある。references には筆者の参考資料と意図的に誤りを入れた例がある。templates には点検と引き継ぎのテンプレートがある。validation には任意の再現スクリプトと実際のファイル操作記録がある。

イベントと場所はすべて架空で、資料のライセンスは CC0-1.0。演習で扱うのはローカルファイルだけであり、実際の申込、公開、メッセージ送信は行わない。

## 検証の範囲

筆者は一時ディレクトリで、最初のコピー、単一ファイルの変更、元ファイルの保護、障害の発生、復元の照合を実行した。スクリプトはモデルを呼び出しておらず、参考通知は筆者が作成した。本サイトではモデルの成功率、学習所要時間、読者による独力での完了をまだ測定していない。完了は、自分のファイルと点検記録で示す必要がある。
