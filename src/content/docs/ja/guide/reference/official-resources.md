本ハンドブックはコミュニティのオープンガイドです。製品挙動、インストールパッケージ、プランは公式を基準にしてください。

- Codex 開発者ドキュメント：[https://developers.openai.com/codex](https://developers.openai.com/codex)
- OpenAI プラットフォームとアカウント関連ページ：OpenAI 公式サイトの現行入口を基準に

公式ドキュメントと本ハンドブックの分担：

- 本ハンドブック：概念と利用思路の説明
- 公式ドキュメント：現行バージョンと最新記法の確認

公式 URL が変わった場合は OpenAI サイトナビを基準にし、本ページ更新の PR を歓迎します。

## いつ公式を優先するか

次の問いには公式が直接的です：

- インストールとログイン
- 現行機能のサポート状況
- 設定項目やコマンドの最新記法
- プラン、権限、製品挙動の変化

## よくある誤解

### 1. 公式が最も権威ある＝コミュニティハンドブックが不要

多くの人は公式を読んでも、どこから始めるか分からず止まります。

### 2. ハンドブックに書いた＝今もそう

次は変化が速い：

- コマンドパラメータ
- 設定キー名
- サポート製品能力
- プランと権限範囲

### 3. 矛盾時の優先順位

概念と背景はハンドブック。現行挙動と最新記法は公式。

## 使い方

次はハンドブックが先：

- この概念が何を言っているか分からない
- どう始めるか分からない
- 推奨入門順序を知りたい

次は公式が信頼できる：

- 今最新で何がサポートされるか
- このパラメータの今日の名前
- この機能が現行バージョンにあるか
- 製品ルールが最近変わったか

## どちらを先に見るか迷ったら

1. ハンドブックで概念と大方向を理解
2. 設定、インストール、実行の直前に公式で最新記法を確認
3. 矛盾時は公式を優先

方向が明確になり、古い情報の踏み台を減らせます。
