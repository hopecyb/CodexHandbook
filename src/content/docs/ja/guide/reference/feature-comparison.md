この表では、**安定している主要な作業方法**だけを比較します。変化の速い細かな機能を、恒久的な約束として扱うものではありません。まず [クライアント選択ガイド](/ja/guide/choose-your-client/) で入口を決め、その後でここに戻って違いを確認してください。

## 中核となる比較

| 入口 | 作業が行われる場所 | 最も強いコンテキスト | 主なレビュー方法 | 典型的なタスク |
|---|---|---|---|---|
| ChatGPT デスクトップ App | ローカルのプロジェクト、チャット、ファイル | 開いているフォルダ、プロジェクト、タスク | タスクの要約、ファイル、diff、承認画面 | 複数プロジェクトの調整、長時間タスク、ファイルやコンピューターの操作 |
| Codex CLI | 現在のターミナルとローカルリポジトリ | 作業ディレクトリ、コマンド出力、Git の状態 | ターミナル上のコマンド、diff、結果の要約 | 調査、変更、テスト、スクリプト、CI |
| IDE 統合 | 現在のエディター | 開いているファイル、選択範囲、直近の会話 | コード付近の変更要約と diff | 局所的な説明、小刻みな変更、エディター内レビュー |
| Codex Cloud | 隔離されたリモート環境 | 接続済みリポジトリと環境設定 | Cloud のログ、要約、diff、PR | バックグラウンドの長時間タスク、並行試行、リモート協業 |

## インストールと認証

| 項目 | デスクトップ App | CLI | IDE | Cloud |
|---|---|---|---|---|
| 入口 | macOS / Windows / Linux デスクトップアプリ | ローカルのコマンドライン | VS Code 互換拡張機能。Xcode と JetBrains はそれぞれ独自の統合 | Web および対応するリモート統合 |
| ChatGPT ログイン | 対応 | 対応 | 対応 | 必須 |
| API key によるローカルログイン | 対応 | 対応 | 対応 | 非対応 |
| 主な課金との関係 | ChatGPT プランまたは API 使用量 | ChatGPT プランまたは API 使用量 | ChatGPT プランまたは API 使用量 | ChatGPT プランとワークスペース権限 |

API key でログインしたローカル作業と ChatGPT ログインでは、課金、管理、データ処理のポリシーが異なります。また API key では、ChatGPT ワークスペースや Cloud を必要とする機能を利用できません。具体的なプランと利用上限は、常に公式の最新ページを確認してください。

## よく使う組み合わせ

### 個人開発のループ

```text
IDE で局所的な問題を特定 → CLI で対象テストを実行 → デスクトップ App で長時間タスクと diff をレビュー
```

### チームのリモート作業ループ

```text
GitHub / GitLab / Linear / Slack から開始 → Cloud の隔離環境で実行 → 人が要約と diff をレビュー → PR を作成
```

### 初心者の学習ループ

```text
デスクトップ App で練習用ディレクトリを開く → 小さなタスクを依頼 → 権限要求を確認 → diff を確認 → 検証を実行
```

## 比較表だけで判断しない

Plugin、Scheduled tasks、通知、モデル、組織ポリシーは変化が速い領域です。次の点を確認するときは、現在のクライアント画面と公式ドキュメントを直接参照してください。

- 現在のアカウントに特定の機能が表示されるか
- 機能がプラン、地域、管理者ポリシーによって制限されるか
- 現在のバージョンで使うコマンド、ショートカット、UI 名称
- API key ログインで、特定の ChatGPT または Cloud 機能を利用できるか

選択の原則は単純です。**局所的なコード作業は IDE、ターミナルで完結する作業は CLI、ローカルタスクの調整はデスクトップ App、隔離されたリモート実行は Cloud** を使います。
