本表は学習と選定向きの参考です。具体能力は現行製品を基準にしてください。

各入口がどの用法に偏っているかを見る助けになります。

| 能力 | デスクトップ App | CLI | IDE | Cloud |
|---|---|---|---|---|
| 初心者向け可視化レビュー | 強 | 中 | 中 | 中 |
| ターミナル/スクリプト統合 | 中 | 強 | 中 | 中 |
| エディタ内インラインコンテキスト | 中 | 弱 | 強 | 中 |
| リモート標準化環境 | 統合次第 | 用法次第 | 用法次第 | 強 |
| 並行タスク / ワークツリー | 一般的 | ワークフロー次第 | ワークフロー次第 | 製品次第 |
| Skills / MCP / Plugin | 一般的 | 一般的 | バージョン次第 | 製品次第 |
| 移動中の承認フォロー | 通知/リモート次第 | 弱 | 弱 | 製品次第 |

選択提案：[Codex クライアント選択](/guide/getting-started/choose-your-codex-client/)

## よくある誤解

### 1. 機能が多い＝入門向き

今必要な使い方を先に見る。機能数だけを見続けない。

### 2. 四入口すべてを最初から学ぶ必要はない

一つ使える入口からで十分。

### 3. 今の働き方で選ぶ

- 最も直感的に見たい → デスクトップ App
- ターミナルに慣れている → CLI
- 常にエディタで作業 → IDE
- リモートリポジトリ、長時間タスク → Cloud

### 4. 入口を外したら後から調整できる

重く考えすぎない。まず一つで始め、後から変えてもよい。

## 選べないとき

1. 普段どこで働くか：デスクトップ、ターミナル、エディタ、ブラウザ
2. 今いちばん重視するか：見やすさ、スクリプト接続、コード接続、リモート環境
3. まず使い方を覚える段階か、継続ワークフロー段階か

多くの人は：

- デスクトップ App で基本リズムを掴む
- 習慣に応じて CLI または IDE を追加
- 本当にリモート長時間タスクが必要なら Cloud

## クイック選択表

| 現在のニーズ | 先に使う入口 |
|---|---|
| 何をしているか先に見たい | デスクトップ App |
| コマンドラインとスクリプトに慣れている | CLI |
| 主にコードを書いている | IDE |
| リモートで標準化実行したい | Cloud |

機能の多さより、利用シーンで選ぶ方が一般的に確実です。
