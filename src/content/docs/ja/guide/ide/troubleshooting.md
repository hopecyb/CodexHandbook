IDE のトラブルシューティングは CLI とは異なります。  
「プラグインが動かない」ように見えても、実際は**ワークスペース、ログイン状態、エディター自体のコンテキスト**のずれであることが多いです。

IDE で問題が出たら、まず「拡張が起動していない」のか、「起動しているがコンテキストがおかしい」のかを切り分けてください。

| 症状 | まず試すこと |
|---|---|
| 拡張が応答しない | 拡張とエディターを更新。拡張ホストのログを確認 |
| ログイン状態が失われた | 再認証 |
| コンテキストがおかしい | 開いているワークスペースのルートを確認 |

## まず 3 類に分ける

- **まったく反応しない**：多くは拡張の読み込み問題
- **開けるが使えない**：多くはログインまたは認証の問題
- **回答がずれる、誤った場所を直す**：多くはワークスペースまたはコンテキストの問題

## よくある誤解

### 1. プラグインアイコンがあれば拡張は正常か

アイコンがあるのはインストールされているだけで、現在のセッションが正常とは限りません。

### 2. コンテキストのずれはモデルの理解不足か

多くの場合、開いているルート、ファイル選択範囲、ワークスペース自体が間違っています。

### 3. 再インストールが最初の一手か

最初からそうする必要はありません。

先に次を確認してください。

- エディターのバージョン
- 拡張のバージョン
- ログイン状態
- 現在のワークスペース

ここまでで多くの問題は特定できます。

## 調査の順序

1. 拡張が応答するか確認
2. ログイン状態を確認
3. ワークスペースのルートと開いているファイルを確認
4. まだダメなら拡張ログを確認

IDE トラブルシューティングで最も多い根本原因は、ワークスペース、ログイン、コンテキストの出所のずれであり、必ずしもプラグインの破損ではありません。
