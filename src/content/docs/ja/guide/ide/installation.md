普段から主にエディターで作業しているなら、本ページではインストール先に加え、次のような疑問も扱います。

- IDE 拡張から始めるのに向いているか
- インストール後に何が見えるべきか
- プラグインは入ったのに、なぜ「使える状態」に感じないことがあるか

IDE 拡張のインストール完了とは、拡張が一覧に表示されるだけでなく、正しいエディターとワークスペースで正常に呼び出せる状態を指します。

## インストール後に最低限確認すること

1. 拡張が、今使っているエディターにインストールされている
2. ログインまたは認証が完了している
3. 開いているワークスペースが、実際に操作したいプロジェクトである
4. 拡張の入口、コマンド、サイドバーが正常に表示される

## よくある誤解

### 1. Marketplace でインストールを押せば、必ず使えるか

多くの場合、あとで次の手順が必要です。

- ログイン
- ウィンドウの再読み込み
- 正しいワークスペースを開く

### 2. IDE 拡張と CLI はまったく同じものか

基盤の能力は共通している場合がありますが、利用入口とコンテキストの取得元は異なります。  
IDE は「今どのファイルを開いているか、どのプロジェクトか」に強く依存します。

IDE 拡張が本当にインストールできたかは、現在のエディターとワークスペースで正常に呼び出せるかで判断してください。

詳細な手順は [IDE 拡張のインストール](/guide/getting-started/install-ide-extension/)。公式ドキュメントは [OpenAI Codex ドキュメント](https://developers.openai.com/codex)。
