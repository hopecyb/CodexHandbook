**Computer Use**（コンピュータ使用）は、Agent が人のように画面を見、ポインタを動かし、文字を入力できる能力です。ブラウザやターミナルに限定されません。能力は最も強力ですが、**リスクと承認要件も最も高く**なります。

Computer Use は画面、マウス、キーボードのレイヤーに直接作用します。ブラウザツールやターミナルとは別カテゴリの能力であり、慎重に有効化する必要があります。

## 本ページの内容

- Computer Use とブラウザ、ターミナルの役割分担
- どんなタスクで有効化する価値があるか
- 個人とチームでの防御策

## 能力の境界

| レイヤー | 典型的な能力 |
|---|---|
| ターミナル | Shell、スクリプト、CLI プログラム |
| ブラウザ | Web ページの DOM、限定的な操作 |
| Computer Use | デスクトップアプリ、システムダイアログ、複数ウィンドウのワークフロー |

## 他ツールとの違い

次のように区別できます。

- デスクトップ全体で作業する
- 複数ウィンドウ間を切り替える
- 実際のボタンやシステムダイアログをクリックする

そのため、接触する UI と情報の範囲は通常、より広くなります。

向いているのは：

- デモソフトで API のない反復クリックフロー（監督下）
- アプリ間でのデータコピー（コンプライアンスの範囲内）
- デスクトップ App 自体の動作検証

向いていないのは：

- 日常的なコーディング（IDE + ターミナルのほうが効率的）
- 無人の本番操作
- セキュリティソフトや DRM の回避

## よくある誤解

### 1. 能力が強いから、優先して使うべき？

次のような場合にのみ、価値がより明確になります。

- タスクがデスクトップ GUI に本当に関わる
- より軽く、より安全なツールでは完了できない

### 2. 見ていれば、リスクはない？

人がそばにいるほうが安全ですが、それでも次が起こり得ます。

- 確認ダイアログの誤クリック
- 開くべきでないウィンドウを開く
- 画面上の機密情報をフローに持ち込む

### 3. すべての GUI 自動化を代替できる？

一時的な支援、フローの検証、API のない GUI ステップの処理には向きますが、安定した長期の無人本番自動化の代替には向きません。

## リスクモデル

Computer Use は、ほぼ**キーボードとマウスを Agent に渡す**ことと同等です。

- メール、チャット、ファイルマネージャーを開ける
- 確認ダイアログを誤ってクリックする可能性がある
- 通知に機密情報が含まれる画面を共有する可能性がある

必読：[権限と承認](/guide/foundations/permissions-and-approvals/)、[サンドボックスとネットワーク](/guide/foundations/sandbox-and-network/)

## 使うべきかどうかの判断

次のような目的だけなら、通常は Computer Use を先に使う必要はありません。

- コードの変更
- テストの実行
- Web ページの確認
- 資料の調査

これらは、より軽いツールで完了できることが多いです。

次のようなタスクの場合に、有効化を検討します。

- デスクトップアプリの操作が必須
- 複数の GUI ウィンドウをまたぐ必要がある
- ブラウザとターミナルでは届かない UI を扱う必要がある

このとき初めて、本格的に検討する価値があります。

## 推奨する使い方

1. **専用環境**：仮想マシンまたはサブユーザーアカウント。画面上にプライバシー関連のウィンドウを置かない
2. **タスクの最小化**：「Calculator で式を検証」——「すべてのメールを処理して」ではなく
3. **人間がループ内にいる**：常に見える状態を保ち、いつでも中断できるようにする
4. **画面録画 / ログ**：チームの振り返り用（録画にも機密情報が含まれる点に注意）
5. **完了後の確認**：ファイルシステム、クリップボード、開いているアプリ

企業環境ではデフォルトで無効化されている場合があります。管理ポリシーに従ってください。

## ブラウザツールとの選択

```text
Web ページを見るだけ？        → ブラウザツール
IDE 以外のアプリを操作？      → Computer Use（より慎重に）
コード変更とテストだけ？      → ターミナル + ファイルツール
```

[ツール選択](/guide/tools/tool-selection/) を参照

## そのまま使える書き方

次のように書けます。

```text
Calculator とローカルテストアプリの操作のみ許可。メール、チャット、ファイルマネージャー、本番管理画面は開かないこと。
システム確認ダイアログが出たら、一旦停止して説明してから続行すること。
```

## よくあるミス

- メインデスクトップで信頼できないプロジェクトの Computer Use を実行
- 2FA、銀行、顧客データが画面上にあるのにタスクを続行
- GUI 自動化を完全なテスト戦略とみなす

## 検証チェックリスト

- [ ] 隔離環境でのみ有効化した
- [ ] プロンプトに許可操作のアプリと禁止事項を明記した
- [ ] タスク後に意図しないファイル / ネットワーク接続がないことを確認した
- [ ] 組織ポリシーがこの能力を許可している
