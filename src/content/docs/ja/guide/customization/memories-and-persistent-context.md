一部の Codex クライアントは**メモリ（Memory）**をサポートします。複数ターンで確認した好みや事実を後続セッションに残します。`AGENTS.md`、プロジェクト設定と補完関係ですが、**バージョン管理されたチーム規範の代替にはなりません**。

## 内容

- メモリに何を載せ、何を載せないか
- AGENTS.md、Memories 機能、プロジェクト指示との優先関係
- 個人とチームがメモリ内容をどう管理するか

## メモリの向き先

メモリは：**毎回繰り返すが、毎回言い直す価値はないこと**を Codex に覚えさせる仕組みと考えてください。

例：

- 日本語で説明してほしい
- 結論を先に、詳細は後
- あるプロジェクトで「バックエンド」が指すディレクトリ

「個人の長期好みと少量の安定事実」向きで、プロジェクト説明書や秘密の金庫ではありません。

## メモリに向く内容

| 向く | 向かない |
|---|---|
| 個人のコーディング好み（コメント言語、インデント） | 本番の秘密鍵、Token |
| 繰り返し説明するプロジェクト別名（「バックエンドは `services/api`」） | 変わりやすい sprint タスク状態 |
| 明示的に「覚えて」と言った非機密事実 | Git に書くべきチーム規範 |

チームレベルの規範は **`AGENTS.md` またはプロジェクト設定**へ。review と新人 onboarding のため。[スコープと優先順位](/guide/customization/agents-md/scope-and-precedence/) を参照。

## よくある誤解

### メモリは「すべてを永久に完全に覚える」わけではない

一度言ったらずっと安定して覚える、と誤解しがちです。メモリは補助層で、繰り返し説明を減らすためのもの。文書とリポジトリの正式情報の代替ではありません。

### メモリはチーム合意を載せる場所ではない

ルールが自分のアカウントのメモリだけに存在すると、他人は見えず review もできません。次へ：

- `AGENTS.md`
- プロジェクト文書
- 設定ファイル

### メモリは機密情報の保管場所ではない

クライアントがメモリをサポートしても、次は載せない：

- Token
- 顧客データ
- 内部アカウント
- 未公開のビジネス情報

## 関連仕組みとの比較

| 仕組み | 誰が見える | 変更方法 |
|---|---|---|
| 単発 prompt | 現在タスク | あなたが入力 |
| メモリ | 通常は自分のアカウント／ワークスペースのみ | 会話で確認または設定画面 |
| `AGENTS.md` | リポジトリ全協業者 | Git PR |
| プロジェクト設定 | 設定層に応じる | ファイル + マネージド方針 |

## 情報の置き場所を分ける

寿命や可視性が違う情報を同じ場所に詰めると、メモリはすぐ混乱します。

| 情報の種類 | より適した場所 |
|---|---|
| 個人的な説明の好み | メモリ |
| チーム全体のルール | `AGENTS.md` またはプロジェクト設定 |
| 特定ディレクトリの約束 | ディレクトリ単位のプロジェクト指示 |
| 一時的なタスク目標 | 現在のプロンプトまたは issue |
| 再利用する手順 | Skill またはプロンプトテンプレート |
| 自動で走る確認 | Hook |

誰が見る必要があるか、どれくらい続くか、コードレビューが必要かで判断します。チームの合意はリポジトリへ、個人の癖はメモリへ置きます。

## 推奨利用法

1. **先にリポジトリへ書く**：テストコマンド、ディレクトリ構造、push 禁止——メモリだけに置かない
2. **メモリは個人好み**：「日本語で説明」「diff コメントは英語」など
3. **定期クリーンアップ**：アーキテクチャ大変更後は古いメモリを削除
4. **機密プロジェクト**：メモリを無効化または制限し、プロジェクト間のコンテキスト漏洩を防ぐ

## メモリに載せるべきかの判断

迷ったら：

1. 個人が繰り返し言う好みか？
2. 短期間比較的安定した事実か？
3. 他人に見えなくても協業に影響しないか？

三つとも「はい」寄りならメモリ向きです。

## セキュリティ境界

- メモリを `AGENTS.md` 禁止事項を迂回する**秘密の通路**にしない
- 顧客データ、資格情報、未公開財務情報をメモリに保存しない
- 企業環境ではメモリ無効化の場合あり——マネージド方針に従う

## よくあるミス

- 「今週の epic 一覧」をメモリだけに置き、協業者が見えない
- メモリと `AGENTS.md` が矛盾したまま、どちらも更新しない
- メモリ＝「モデルがリポジトリ全体を永遠に覚える」と誤解

メモリは「繰り返す個人好みと少量の安定事実」向き。リポジトリ文書、チームルール、機密情報管理の代替ではありません。
