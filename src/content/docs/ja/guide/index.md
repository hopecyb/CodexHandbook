# Codex ガイド

ここでは、Codex とは何か、何に向いているか、そして初回利用から安定したワークフローへの移行方法を説明します。

このハンドブックを初めて開いた方は、最初から最後まで読む本として捉える必要はありません。「初回利用から慣れるまで」のロードマップとして使う方が自然です。

すべての用語、製品、ワークフローを先に理解する必要はありません。今いる段階を見つけて、順番に進めば大丈夫です。

## このセクションで扱うこと

- Codex を初めて使うとき、どこから読むべきか
- 最初にどのクライアントを選ぶべきか
- 最初のタスクを終えたあと、次に何を補うべきか
- 権限、コンテキスト、検証の問題が起きたとき、どの章に戻るべきか

## よくある誤解

### 1. ハンドブックを全部読んでから使い始めるべき

多くの人にとって、より適切なペースは次のとおりです。

- まず基本的な安全と協業の仕方を理解する
- 小さなタスクを一度通す
- 実際の問題を持って戻ってきて補足で読む

### 2. 章が多いから、まだ始めるには早い

章が多いのは、後から参照する場所を用意するためであり、最初からすべてを習得する必要があるわけではありません。

### 3. クライアントを 1 つ選べば、他の内容は関係ない

クライアントは入口が違うだけで、権限、コンテキスト、検証などの中核概念は各クライアントで繰り返し登場します。
