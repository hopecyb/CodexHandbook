CLI を初めて入れるとき、多くの人は次の点でつまずきます。

- 本当に入ったのか
- 入れたのにターミナルが `codex` を認識しない
- 更新後、今どのバージョンが動いているか確認したい

CLI のインストール完了とは、一度コマンドが走ったことではなく、**現在のターミナルが安定して見つけられること**です。

## インストール後に最低限確認すること

1. コマンドが直接実行できる
2. 現在のターミナルが `PATH` で見つけられる
3. 認証まで完了している（実行ファイルだけ入った状態ではない）

## よくある誤解

### 1. インストールスクリプトが終われば完了

スクリプト完了は「インストール手順が走った」だけです。  
次に見るべきは、**今開いているターミナルがそのコマンドを認識するか**です。

### 2. ターミナルウィンドウを変えれば直る

直ることもありますが、必ずではありません。  
`PATH` が更新されていなければ、ウィンドウを変えても同じです。

### 3. 更新は再インストールと同じ

多くの場合、先に確認したいのは次の 2 点です。

- 今のバージョンが古いのか
- どのインストールを更新しているのか

## この順で確認する

入れた直後なら、次の順で確認できます。

1. `codex` コマンドが直接実行できるか
2. 現在の shell の `PATH` にインストール先が含まれるか
3. ログインまたは認証を完了する
4. 最後にバージョン情報を確認する

実務的な合格基準は、**現在のターミナルで見つかり、認証まで完了していること**です。
