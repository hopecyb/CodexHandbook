結論が外部事実に依存する場合は、結論だけを受け取らず、出典も一緒に受け取ってください。

Agent に次を求めます。

```text
各重要事実に出典 URL または文献を付ける。不確かなものは「未確認」と明記する。
```

結果を受け取ったら、リンクを開いて再確認してください。検索機能は [Web 検索](/guide/tools/web-search/) を参照。

## よくある誤解

### 1. 自信ある表現 = 信頼できる出典

表現が流暢で自信に満ちていることと、事実が信頼できることは、もともと別の話です。

### 2. すべての文に出典が必要？

必ずしもそうではありません。  
しかし次の内容は特に出典を求める価値があります。

- 重要な事実
- 判断に影響する数値
- 時期、政策、製品差
- 対外で使う予定の言い回し

### 3. リンクが付いていても、自分で確認する

最低でも次を確認してください。

- リンクがその結論に本当に対応しているか
- 信頼できる出典か
- すでに古くなっていないか

調査系タスクでは、出典自体が結論の信頼性の一部です。
