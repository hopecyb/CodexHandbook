トラブルシューティングでは、最も可能性が高く、対処しやすい順に確認します。

| 症状 | まず試すこと |
|---|---|
| インストール／起動できない | システム要件と公式インストーラーを確認し、再起動して再試行 |
| ログインできない | ネットワーク、アカウント権限、SSO を確認し、セッションをクリアして再ログイン |
| プロジェクトファイルが見えない | 正しいフォルダが追加されているか、システムのファイル権限を確認 |
| タスクが承認待ちのまま | タスクビューに戻り、保留中の承認リクエストを処理 |
| 変更が期待と異なる | 制約を絞る、新しいスレッドを開く、コンテキストを確認 |

それでも解決しない場合：[https://developers.openai.com/codex](https://developers.openai.com/codex) と [トラブルシューティング索引](/guide/reference/troubleshooting/) を参照してください。

## よくある誤解

### 1. 問題が起きたら、重大な使い方のミスをしたのでは？

多くの問題は次のような単純な原因です。

- パスを選び間違えた
- 権限を承認していない
- タスクが確認待ち
- コンテキストが混乱している

### 2. 「ファイルが見えない」とき、最初に疑うべきことは？

モデルの能力ではなく、プロジェクトディレクトリと権限を優先的に疑いましょう。

### 3. 「変更が期待と異なる」とき、どう立て直す？

まず問題の範囲を絞ります。

- 範囲を再説明する
- どこがおかしいかを明確にする
- 必要なら新しいスレッドを開く

トラブルシューティングでは、最初から複雑に考えず、最も一般的で修正しやすい原因から確認しましょう。
