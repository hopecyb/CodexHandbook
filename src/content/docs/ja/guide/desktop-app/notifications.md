通知は「いつタスクへ戻って対応すべきか」を知らせるものであり、結果のレビューを代行するものではありません。デスクトップ App ではターン完了の通知を設定でき、権限リクエストと質問の通知も個別に制御できます。

## 推奨設定

**Settings → Notifications** を開きます。

| イベント | 推奨 | 理由 |
|---|---|---|
| Turn completion | バックグラウンド実行時に通知 | 長時間タスクを見続ける必要がない |
| Permission | 有効にする | 承認が処理されないとタスクが停止する |
| Question | 有効にする | Codex に重要なコンテキストが不足している場合、回答が必要になる |

OS 側でも ChatGPT デスクトップ App の通知を許可する必要があります。App 内で有効にしても、システム側で拒否されていると通知は届きません。

## Activity ビューで複数のチャットを処理する

Activity が利用できる場合は、サイドバーのベルを選択して、未読、実行中、回答待ちのチャットを確認します。ショートカットは次のとおりです。

- macOS：`Cmd + Option + U`
- Windows：`Ctrl + Alt + U`

フィルターは現在の画面によって変わり、Work、Chat、Pinned、Scheduled などが表示される場合があります。処理順は、権限または入力待ち、失敗、完了してレビュー待ち、実行中、を推奨します。

## 通知が表示された後にすること

- **完了**：diff と検証出力を開き、通知を検収結果だと考えない
- **権限リクエスト**：コマンド、対象リソース、影響範囲、可逆性を確認する
- **回答待ち**：必要なコンテキストだけを補い、その場でタスク範囲を広げない
- **失敗**：最初の有効なエラーを特定してから、再試行するか制約を調整するか判断する

CLI と IDE では通知の仕組みが異なります。IDE に独立した通知設定はありません。CLI では高度な設定を使い、TUI または外部プログラムによる完了通知を指定できます。デスクトップ App の設定をグローバルなスイッチだと考えないでください。
