設定ページは App の動作を個人向けに調整するためのもので、Codex の権限設定全体を扱う場所ではありません。まずはデフォルト値を維持し、影響範囲を理解してから変更してください。

macOS では `Cmd + ,`、Windows では `Ctrl + ,` を押すか、App のメニューから Settings を開きます。

## 初心者がまず確認する四項目

### General

- 複数行のプロンプトを送信するときに `Cmd + Enter` を必須にするか
- **Prevent sleep while running** を有効にし、PC から離れている間もローカルの長時間タスクを継続させるか
- Follow-up behavior で、実行中に届いた新しいメッセージを現在の処理へ直ちに反映するか、次のターンへ回すか

最後の項目は、実行中に補足した一言がどう扱われるかを変えます。緊急の軌道修正なら現在の実行を誘導し、無関係な新しい依頼なら別のチャットを開始してください。

### Keyboard shortcuts

コマンドを検索し、キー割り当てを変更したりデフォルトへ戻したりできます。オンラインの説明と手元のショートカットが異なる場合は、ここに表示される割り当てを基準にしてください。

### Notifications

ターン完了通知を表示する条件を設定し、権限リクエストや質問の通知も制御できます。詳しくは[通知とアクティビティ表示](/ja/guide/desktop-app/notifications/)を参照してください。

### Appearance

ライト、ダーク、システム設定に合わせる、の各テーマを選択できます。アクセント色、背景色、前景色、UI フォント、コードフォント、文字サイズも調整できます。長時間コードをレビューする場合は、見た目の効果だけでなく、コントラストと文字サイズを優先してください。

## ここでは解決しない設定

- リポジトリ単位のルールは `AGENTS.md` に記述する
- CLI と Agent の永続設定は主に `config.toml` に記述する
- ファイル、ネットワーク、コマンドを利用できるかどうかは、サンドボックス、承認、組織ポリシーによって決まる
- 組織の管理ポリシーにより、個人が選択できる機能が制限される場合がある

したがって、「設定画面に表示される」ことは、現在のタスクで必ず権限があることを意味しません。操作が拒否された場合は、すぐに権限を広げず、まず[権限とサンドボックス](/ja/guide/permissions-and-sandbox/)を確認してください。

## 変更後の検収

一度に変更する設定は一種類だけにし、低リスクのチャットで動作を確認してください。元の値を記録し、効果を確認してから次へ進みます。想定と異なる場合は、まずデフォルト値に戻し、App のバージョン、OS の権限、組織ポリシーを確認してください。
