設定ページの項目は多いですが、最初からすべて調整する必要はありません。安全、承認、日常の使い心地に影響する項目だけ見れば十分です。

よくある設定の方向（名称は UI 表示に準拠）：

- デフォルトモデルと推論のレベル
- 承認／サンドボックス／ネットワーク関連のオプション
- 通知
- 外観と編集の好み

チーム管理の設定が個人設定を上書きする場合があります。公式説明：[https://developers.openai.com/codex](https://developers.openai.com/codex)。概念：[権限と承認](/guide/foundations/permissions-and-approvals/)

## よくある疑問

### 1. 最初からすべての設定を調整すべき？

いいえ。まずデフォルトのままにし、各設定が何に影響するかを把握しましょう。

### 2. 最初に見るべき設定

通常は次の 3 種類で十分です。

- 承認と権限
- ネットワーク関連
- 通知

これらは次に直接影響します。

- 何ができるか
- 範囲を超えないか
- タイムリーに通知を受け取れるか

### 3. 設定を変えたのに、ドキュメントと効果が違うのはなぜ？

次のような理由が考えられます。

- バージョンの違い
- チーム管理ポリシーが個人設定を上書きしている
- 現在のタスク環境に別の制約がある

設定ページを初めて見るときは、まず安全境界と通知関連のオプションを理解し、その後で他の細部を検討しましょう。
