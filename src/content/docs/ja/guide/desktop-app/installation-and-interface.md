インストール手順は [デスクトップ App のインストール](/guide/getting-started/install-desktop-app/) と [https://developers.openai.com/codex](https://developers.openai.com/codex) を参照してください。

デスクトップ App を開いた直後は、画面上に多くの情報が同時に表示されます。

最初からすべての領域を把握する必要はありません。まず最も重要な場所を押さえましょう。

## インターフェース領域（論理区分）

具体的なラベル名はバージョンにより変わります。画面上の実際の文言と照合してください。

1. **プロジェクト／ワークスペース選択**：現在バインドされているフォルダ
2. **会話／タスク領域**：プロンプトの入力、Agent の進捗確認
3. **変更／差分ビュー**：提案された変更のレビュー
4. **ターミナルまたはログ**（有効な場合）：コマンド出力の確認
5. **設定とアカウント**：モデル、権限、通知など

最初は「どこでタスクを入力するか」「どこでファイル変更を承認するか」を見つけましょう。

## よくある誤解

### 1. 最初からすべてのパネルを理解する必要はない

次の 3 つが分かれば十分です。

- タスクを入力する場所
- 変更を確認する場所
- 承認または拒否する場所

### 2. ターミナル、差分、設定は後から学べる？

段階的に学べます。  
ただし差分ビューは早めに慣れておくとよいです。変更範囲を把握するうえで直接関係します。

### 3. 画面がドキュメントのスクリーンショットと完全一致しない場合は？

現在のバージョンの実際の文言を基準にしてください。  
ここで説明しているのは論理領域であり、具体的なボタン名ではありません。

まず「タスク入力」「変更確認」「承認」の 3 つを見つけ、使いながら慣れていきましょう。
