公式 CLI インストール説明に従って操作：[https://developers.openai.com/codex](https://developers.openai.com/codex)（通常はパッケージマネージャーまたは公式インストールスクリプト。現行ドキュメントが基準）。

普段からターミナルを使うなら、CLI の方が使いやすいです。  
初回インストールでつまずきやすいのは主に次の点です。

- インストール後、半分だけ入った状態かどうかの確認方法
- コマンドは入ったのにターミナルが見つけられない理由
- いつ PATH / 認証に戻るべきで、再インストールは不要か

CLI が正しく入ったかは、現在のターミナルが `codex` を安定して認識できるかで判断します。

## インストール後の確認

ターミナルでバージョンまたはヘルプコマンドを実行（具体的なサブコマンドは公式が基準）。次を確認：

- コマンドが実行できる
- ログインまたは認証済み状態に入れる

## よくある誤解

### 1. インストール後、どのターミナルウィンドウでもすぐコマンドが認識される

ターミナルを開き直す必要がある場合や、現在の shell の `PATH` が更新されたか確認が必要な場合があります。

### 2. インストール出力が成功なら、もう使える

現在の環境がこのコマンドを見つけられるかの方が重要です。

### 3. CLI の問題はすべて再インストールで解決する

多くの場合、本当に調べるべきは次です。

- `PATH`
- 現在の shell
- ログイン状態

## インストール後の確認手順

1. まずコマンドが実行できるか確認
2. 次に現在のセッションがログインまたはログイン済み状態に入れるか確認
3. まだダメならインストール場所と PATH を調べる

CLI をインストールしたら、現在のターミナルがそれを見つけられ、認証を続けられるはずです。

詳細な対話は [CLI 対話モード](/guide/cli/interactive-mode/)。トラブルシューティング：[CLI トラブルシューティング](/guide/cli/troubleshooting/)。
