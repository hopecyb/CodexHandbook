1. 公式 Codex ドキュメントのデスクトップアプリダウンロード説明を開く：[https://developers.openai.com/codex](https://developers.openai.com/codex)
2. 自分の OS 用インストーラーを選んでインストール
3. アプリを起動し、ログインまたはプロジェクト入口が見えることを確認

Codex を初めて使い、まずターミナルをいじりたくない場合、デスクトップ App は比較的直接的な入口です。
ここで重要なのは、インストール後にどの状態になれば使い始められるかです。

## インストール後の確認

- アプリが正常に開く
- システム権限（ファイルアクセスなど）は必要に応じて付与し、無関係なディスク権限を一度に与えない
- 画面概要は [インストールと画面](/guide/desktop-app/installation-and-interface/) を参照

## よくある誤解

### 1. App が起動すれば問題ない

次の方が確認に値します。

- 正常にログインできるか
- プロジェクトまたはタスク入口が見えるか
- 権限が正しく与えられているか

### 2. システムが権限ダイアログを出したら、すべて許可する

必要に応じて付与する方が安全で、無関係なディスクやシステム能力を一度に開かない。

### 3. インストール後すぐに大きなタスクを始めるべき

最初は次の小さなことを確認すれば十分です。

- ログインに問題がない
- ページが正常に開く
- プロジェクト入口と基本画面の場所がわかる

デスクトップ App をインストールしたら、正常に開き、ログインし、入口が見えることを確認してから最初のタスクに進んでください。

失敗時：[デスクトップ App トラブルシューティング](/guide/desktop-app/troubleshooting/)。
