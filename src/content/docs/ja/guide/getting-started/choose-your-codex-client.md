まず、普段の作業が主にどこで行われるかを確認してください。

| 主な作業場所 | ここから始める |
|---|---|
| デスクトップでプロジェクト、ファイル、複数のタスクを管理する | **ChatGPT デスクトップ App** |
| ターミナルで Git、テスト、スクリプトを実行する | **Codex CLI** |
| VS Code、互換エディタ、Xcode、JetBrains でコードを書く | **IDE 統合** |
| 接続済みのリモートリポジトリと隔離環境で作業する | **Codex Cloud** |

初めて使い、特に希望がなければ、まずデスクトップ App をインストールするとよいでしょう。タスク、ファイル、diff、承認を確認しやすいためです。入口は永続的な選択ではありません。同じワークフローを IDE で始め、CLI で検証し、デスクトップ App または Cloud で長時間タスクをフォローできます。

完全な判断図、組み合わせ例、検証手順については [Codex クライアントを選ぶ](/ja/guide/choose-your-client/) を、項目別の比較については [機能比較](/ja/guide/reference/feature-comparison/) を参照してください。

次に、該当するインストールページへ進みます。

- [CLI をインストールする](/ja/guide/getting-started/install-cli/)
