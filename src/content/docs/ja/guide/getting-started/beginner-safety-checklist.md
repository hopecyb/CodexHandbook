初回利用前に、自分にこう問いかけてください。「間違えたら、大きな代償を払うことになるか？」

このチェックリストは、初回利用のリスクを下げるためのものです。

開始前にチェック：

- [ ] 使っているのは捨てられる練習ディレクトリで、本番リポジトリではない
- [ ] ディレクトリ内に実際のキー、パスワード、顧客のプライバシー情報がない
- [ ] 高リスク操作には自分の承認が必要だと理解している
- [ ] 理解できないコマンドや外部通信リクエストは承認しない
- [ ] 差分を確認してから結果を承認するつもりである
- [ ] [取り消し](/guide/getting-started/undo-and-recover/) の方法を知っている

概念の補足：[権限と承認](/guide/foundations/permissions-and-approvals/) · [サンドボックスとネットワーク](/guide/foundations/sandbox-and-network/)。

## よくある誤解

### 1. 安全チェックリストは特に慎重な人向け

初めて使う人向けです。初回は「すべて理解できるはず」と過大評価しやすいからです。

### 2. 危険なコマンドを押さなければ十分安全

初回によくある問題は次のとおりです。

- プロジェクトを間違える
- 機密ファイルを含める
- diff を確認しない
- 取り消し方を考えていない

### 3. 使いながら学べば、事前確認は不要

使いながら学べますが、このチェックリストの項目は開始前に一通り確認する方が安定します。

Codex を初めて使うときは、まず失敗コストを下げると、その後が楽になります。
