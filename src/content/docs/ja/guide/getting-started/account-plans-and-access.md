多くの人が初めてつまずくのは、インストール前の段階です。

- OpenAI アカウントがあるのに、なぜ入れないのか
- ログインできても、すべてのクライアントが使えるのか
- 会社環境で同僚は使えるのに、自分は使えないのはなぜか

よくある誤解は、「アカウントにログインできる」＝「現在、対応製品へのアクセス権がある」と考えることです。

Codex を使うには有効な OpenAI アカウントと、現在の地域/組織ポリシーで許可された **製品アクセス権** が必要です。プラン名、クォータ、App/CLI/Cloud の包含は公式説明が基準です。

## 確認すべき 3 点

1. [OpenAI / Codex 関連入口](https://developers.openai.com/codex) にログインできる
2. プランに使いたいクライアントが含まれている
3. 会社環境の場合：SSO、デバイス管理、無効化ポリシーがあるか

## よくある誤解

### 1. アカウントがあれば App / CLI / IDE / Cloud すべて使える

入口ごとに利用可能範囲、プラン能力、組織ポリシーが異なる場合があります。

### 2. ログイン失敗は必ずパスワードの間違い

次の可能性もあります。

- 組織 SSO 制限
- 現在の地域またはデバイスポリシー制限
- 製品自体がアカウントに開放されていない

### 3. 会社環境と個人環境は同じ

会社環境では、アカウントが使えるか、どの入口が使えるかは、追加のセキュリティとデバイスポリシーの影響を受けやすいです。

## トラブルシューティング順序

問題の所在がわからない場合は、次の順序で確認してください。

1. 関連入口にログインできるか
2. 現在のプランに目的のクライアントが含まれるか
3. 所属組織に追加制限があるか

アカウントが使えることは第一歩にすぎず、その後はプランと組織アクセスポリシーも確認が必要です。

本ページは価格表を列挙しません（古くなりやすいため）。公式のアカウントと課金ページを基準にしてください。
