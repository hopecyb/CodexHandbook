実践ケースでは、実際の目標からプロンプト作成、実行、軌道修正、確認、検証、再利用までをたどります。完成物だけでなく、途中で何を判断するかに重点を置きます。

## 取り組むタスクを探す

タスクの種類やキーワードで絞り込めます。成果物と検証状況は各ケースのメタデータに基づきます。「実行例を検証済み」は、そのページに記載された環境と手順に限られ、すべてのクライアントや読者での検証を意味しません。

<CaseDirectory />

## ケースの構成

各ケースには、目標、準備資料、推奨プロンプト、実行手順、人による確認ポイント、検証方法、失敗時の対処、再利用可能なテンプレートを含めます。新しいケースを書く際は [ケーステンプレート](/ja/cases/use-cases/case-study-template/) を参照してください。

## 持ち帰って使える資料

- [ケーステンプレート](/ja/cases/use-cases/case-study-template/): タスクを、振り返りや引き継ぎに使える記録にまとめます。
- [最初のタスク](/ja/cases/first-task/): 小さく安全なタスクで、目標から実行、受け入れ確認までを一通り試します。
- [ワークフローの事例](/ja/cases/workflows/): 検証、人による承認、失敗からの復旧、複数 Agent の協働を手順に組み込む方法を学びます。
