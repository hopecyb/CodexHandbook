新しい事例ページや社内振り返りドキュメントを作るときは、このテンプレートをコピーしてください。

コピー前に、実際の読者と成果物に不要なセクションは削除してください。

## メタデータ

| 項目 | 記入 |
|---|---|
| 事例タイトル | |
| 対象読者 | 初心者 / 開発者 / クリエイター / チーム |
| 使用クライアント | App / CLI / IDE / Cloud |
| 想定時間 | |
| 検証日 | YYYY-MM-DD |

## 1. 目標とコンテキスト

- **ビジネス目標：** 一文
- **成功基準：** 観察可能で検証可能
- **範囲外：** 明示的な除外

## 2. 準備

- アカウント／権限／リポジトリ状態
- 必要なコンテキストファイル（`AGENTS.md`、デザインなど）
- リスク：データ、本番、秘密情報

## 3. ワークフロー（EPXV）

### Explore（探索）

- 入力プロンプト（要約）
- 主要な発見

### Plan（計画）

- 手順リスト
- 人の確認ポイント

### Execute（実行）

- 実際の変更範囲
- 計画からの逸脱と理由

### Verify（検証）

- 自動テスト
- 手動チェック
- 証拠（スクリーンショット、ログ、リンク）

## 4. 失敗と回復

- 何がうまくいかなかったか
- 取り消しまたは修正方法
- やり直すならプロンプト／設定で何を変えるか

## 5. 定着（キャプチャ）

- `AGENTS.md` / Skill / Automation に書くか
- チームへの推奨 3 点

## 6. 参考

- 公式ドキュメントリンク
- 外部チュートリアルの適応か（タスク種別のみ）
