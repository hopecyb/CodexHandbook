# 記事を書く

## メタ情報

| 項目 | 内容 |
|---|---|
| 対象読者 | クリエイター |
| クライアント | App / CLI |
| 所要時間の目安 | 1–2 時間 |

## 1. 目標と背景

**目標：** 公開可能な技術記事の初稿を作成する。

**成功基準：** 構成が完全であること、事実が照合可能であること、スタイルが読者に合致すること。

## 2. ワークフロー（EPXV）

### 探索

```text
テーマ：【記事テーマ】
読者：【初心者/開発者】
まず 3 つの選択肢となる切り口とアウトラインを提示してください。本文は書かないでください。
```

### 計画

アウトライン確認後：

```text
アウトライン第 1 節に沿って約 300 字で執筆してください。書き終えたらトーンの確認のため一時停止してください。
```

### 実行

一括で全文を生成せず、節ごとに執筆する。修正が困難になるのを避けるため。

### 検証

- リンク、バージョン番号、コマンドが有効か人間が照合する
- 任意：[ライティング Skill](/skills/examples/writing-skill/) でフローを固定化する

## 3. 蓄積

繰り返しのライティングは `article-writer` Skill にカプセル化できる。[クリエイターパス](/guide/learning-paths/creator/) を参照。
