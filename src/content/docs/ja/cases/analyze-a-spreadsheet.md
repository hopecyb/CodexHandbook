この演習では、売上週報、地域別集計、商品ランキング、行ごとのクレンジング台帳を作ります。入力はこのサイト用に作った架空のデータで、実際の顧客情報は不要です。

難易度は入門です。所要時間30～45分は編集上の推定で、読者による時間計測はまだ行っていません。前提はCodexにローカルファイルを渡せることです。参照結果を読むだけならプログラミング不要ですが、検証にはPython 3.10以降が必要です。

[教材一式 v1.0.0（ZIP）をダウンロード](/downloads/sales-weekly-report/sales-weekly-report-1.0.0.zip) · [売上CSVだけをダウンロード](/downloads/sales-weekly-report/sales.csv)

## 最初に成果物の目安を見る

| 指標 | 参照値 | 確認点 |
|---|---:|---|
| 当期純売上 | 4,644.75人民元 | 返金を含める |
| 華東の当期純額 | 1,281.25元 | 1,401.75 − 120.50 |
| 日付欠損の金額 | 199.99元 | 週を推測せず隔離する |

当期は2026-09-07～09-13、前期は2026-08-31～09-06です。連続する完全な暦週の前週比は87.04％です。これは架空のサンプルの結果にすぎず、実際の売上変動の理由を示すものではありません。

[参照週報を見る](/downloads/sales-weekly-report/summary.md)。まず自分で取り組み、後で参考解答と比べてください。

## 教材をダウンロードする

一式には、課題説明、データ辞書、3つのプロンプト、46行のCSV、参照週報、集計・台帳のCSV 3点、参照実装、独立した検証スクリプト、検証記録が含まれます。すべてCC0 1.0で公開され、改変や再配布が可能です。

展開後は`sales-weekly-report`フォルダーを開いてください。CSVだけをダウンロードしても、参照するほかのファイルは自動的に現れません。

## 1. ファイルと集計基準を確認する

次のタスクをCodexに渡します。ファイルの渡し方はクライアントによって異なります。まず実際に読めたことを確認してください。

```text
brief.md、starter/data-dictionary.md、starter/sales.csvを読んでください。
ファイルの存在を確認し、項目、日付範囲、レコード数、特別な処理が
必要な行番号を挙げてください。元の表は変更せず、solutionを見ないでください。
完全重複、日付欠損、負数、実際のゼロを区別してください。
辞書に従って2週間の集計基準を説明し、矛盾があれば列挙してください。
矛盾がなければ続けてください。
```

元の46行には、返金2件、完全重複1件、日付欠損1件が含まれます。完全重複は最初の1件だけ残します。同じIDで内容が異なる場合は確認を中断します。欠損日付を作らず、金額ゼロは有効とします。処理後の対象は44行です。

## 2. 週報と計算台帳を作る

続いてパック内の`prompts/02-report.md`を使い、成果物を`my-output/`へ書き出します。

| ファイル | 含める内容 |
|---|---|
| `summary.md` | 総額、前週比、地域、当期Top 3、データ品質、計算根拠 |
| `region-summary.csv` | 両週の地域別純額、増減額、前週比。地域の和と総額を照合できること |
| `top-products.csv` | 返金を含む当期の商品別純額を降順に並べる |
| `row-ledger.csv` | 元データ各行の行番号、採否、週、金額 |

入力、`solution`、`validation`は変更しません。独立した検証が項目ごとに照合できるよう、項目名と表の順序はデータ辞書に従います。西南の前期はゼロなので前週比はN/Aとし、0％や無限大の増加としないでください。

## 3. 「合っている？」だけでなく独立して照合する

展開した演習フォルダーで実行します。

```sh
python3 validation/check.py --output my-output
```

4つの成果物が揃い、基準と一致すれば`result: PASS`と表示されます。入力ハッシュの変更、返金の計上漏れ、グループ分けの誤り、台帳の不一致はエラーになります。失敗したら自分の成果物だけを直し、検証器を変更して通過させないでください。

Pythonを実行できない場合も、最低限次を手で確認してください。

1. 華東の正数7件は1,401.75元です。44行目の返金−120.50を加えると1,281.25になります。
2. 当期の3地域の和は1,281.25 + 2,101.75 + 1,261.75 = 4,644.75です。
3. 47行目のO046には日付がなく、199.99元はどちらの週にも入れません。46行目のO001は重複です。

自動検証は文章中の結論をすべて審査できません。週報を読み、根拠のない成長理由や事業判断を削除してください。

## 4. 修正演習：返金の計上漏れ

**設計された反例**：負数をすべて除外すると、当期は4,765.25元となり、120.50元多くなります。参照検証では一時的な結果を実際に変更し、検証器が誤った金額を拒否することを確認しました。架空のモデル対話ではありません。

```text
net_salesがゼロ未満の有効なレコードを確認し、計上すべきか説明してください。
返金の負符号を維持して両期の地域別・商品別集計をやり直し、修正前後の
差額を列挙してください。元のCSVや検証器を変更して失敗を消さないでください。
```

## 5. 問題が起きたら復旧する

| 症状 | まず確認すること | 次の対応 |
|---|---|---|
| ファイルが見つからない | 現在のフォルダーに`starter/sales.csv`があるか | 展開したフォルダーを開いて参照し、欠けたデータをAgentに作らせない |
| 中国語の文字化け、または1列だけ | UTF-8か、区切りがカンマか | 元のCSVを再読み込みし、金額を手で直さない |
| 数値が120.50違う | 返金R043の漏れか | 辞書どおり負数を残し、両期を再計算する |
| 前週比でゼロ除算 | 西南の前期は本当にゼロか | N/Aとし、基準値がゼロだと説明する |
| 検証器がファイル欠損を報告 | 4つの成果物が揃ったか | 辞書に従い補完して再実行する。ファイル欠損は金額の誤りとは限らない |

## 完了条件と次のステップ

- 元の表のハッシュが不変で、4つの成果物が揃っている。
- 総額、華東、日付欠損の金額を独立して照合した。
- 週報には異常、ゼロ基準、計算方法を残し、理由を捏造しない。
- 実行した検査と、人による確認がまだ必要な箇所を明示する。

自分のプロンプトと修正記録を保存してください。データを差し替える前に、項目と基準を確認し直します。この演習の固定検証器は任意の企業データには使えません。
