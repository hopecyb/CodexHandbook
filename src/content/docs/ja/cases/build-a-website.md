# ウェブサイトを構築する

## メタ情報

| 項目 | 内容 |
|---|---|
| 対象読者 | クリエイター / 開発者 |
| クライアント | App / IDE |
| 所要時間の目安 | 2–4 時間 |

## 1. 目標と背景

**目標：** シンプルな要件に基づき、ローカルでプレビュー可能な静的ページまたは小規模サイトを構築する。

**成功基準：** ブラウザで開けること、スタイルが説明に合致すること、無関係なファイルの変更がないこと。

## 2. 推奨プロンプト

```text
目標：【製品/キャンペーン】向けのシングルページランディングページを作成する。見出し、3 つの特徴、CTA ボタンを含む。
技術：HTML + CSS（またはプロジェクト既存のフレームワーク）、モバイルフレンドリー。
制約：src/ 以下のページ関連ファイルのみ変更する。承認なしに新しい依存関係を導入しない。
受け入れ基準：pnpm dev でプレビュー可能。主要ブロックのスクリーンショットを説明する。
まずワイヤーフレーム計画を提示し、確認後にコードを書く。
```

## 3. 検証

- 各ブレークポイントでローカルプレビューする
- 設定やロックファイルを誤って変更していないか確認する
