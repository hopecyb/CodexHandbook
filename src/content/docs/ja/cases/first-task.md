# 最初のタスク

以下の例は **デスクトップ App** を前提としています。CLI/IDE でも同じプロンプトが使えます。

## メタ情報

| 項目 | 内容 |
|---|---|
| 対象読者 | 初心者 |
| クライアント | デスクトップ App（推奨） |
| 所要時間の目安 | 15–20 分 |

## 1. 目標と背景

**目標：** 練習プロジェクトで安全なファイル変更を完了する。

**成功基準：** 指定ファイルのみを変更し、受け入れ基準を満たし、diff を読み解けること。

## 2. 準備

- クライアントをインストールし、ログイン済みであること
- 練習プロジェクトを作成済みであること（`hello.md` または類似ファイルを含む）

## 3. 推奨プロンプト

```text
目標：hello.md の末尾に「今日の練習」セクションを追加し、3 行の要点リストを含める。
制約：hello.md のみ変更する。既存内容は削除しない。ネットワークリクエストは実行しない。
受け入れ基準：ファイル末尾にその見出しとちょうど 3 つのリスト項目が現れること。
情報が不足している場合は先に質問し、推測しないこと。
```

## 4. 実行と確認

1. まず短い計画を出させる（または自分から計画を求める）
2. ファイル書き込みの承認時にパスが正しいか確認する
3. 完了後、受け入れ基準に照らして diff を項目ごとに確認する
