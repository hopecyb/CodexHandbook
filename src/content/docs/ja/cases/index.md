# 実践ケース

実践ケースでは、実際の目標から出発し、プロンプト、実行、確認、検証、再利用までの流れを示します。

## ケースの形式

各ケースには、目標、準備資料、推奨プロンプト、実行プロセス、人間による確認ポイント、検証方法、失敗時の対処、再利用可能なテンプレートを含めます。新しいケースを書く際は [ケーステンプレート](/ja/cases/use-cases/case-study-template/) を参照してください。
