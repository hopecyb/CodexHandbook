# スライドを作成する

## メタ情報

| 項目 | 内容 |
|---|---|
| 対象読者 | クリエイター |
| クライアント | App |
| 所要時間の目安 | 1–2 時間 |

## 1. 目標と背景

**目標：** テーマに基づき、構成が明確なプレゼン資料を生成する（Markdown/HTML/PPT など、環境の能力に応じる）。

**成功基準：** ページ数がアウトラインと一致すること、各ページの要点を説明できること、データを捏造していないこと。

## 2. 推奨プロンプト

```text
テーマ：【プレゼンテーマ】
聴衆：【聴衆の背景】
時間：【分数】
まず章立てと各ページのタイトル + 3 つの要点を提示してください。最終ファイルは生成しないでください。
確認後、slides/ ディレクトリに出力してください。形式：【mdx/html/pptx】。
制約：データには出典を明記するか「例」と表記する。承認なしに外部ネットワークリクエストを送らない。
```

## 3. 検証

- 各ページを 1 分以内で説明できるか通読する
- グラフと数値の出典を照合する
