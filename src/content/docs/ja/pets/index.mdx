# Codex ペット

Codex ペットは、Codex クライアント内に表示されるアニメーション付きの伴走要素です。モデル能力でも自動化ツールでもなく、ローカルの視覚リソースです。作業中、待機中、完了、失敗、またはユーザー入力待ちといった状態を、クライアントがアニメーションで表現できます。

<PetScienceFigure variant="anatomy" locale="ja" />

このセクションは解説目的です。Codex ペットの基本概念、よくあるファイル構成、インストール時の安全境界、作成時に素材とメタデータがどう関係するかを説明します。このサイトではペット素材リストを提供せず、外部ギャラリーを公式ソースとして扱いません。

## 通常含まれるもの

Pet は小さなローカルパッケージとして理解できます。

- `pet.json`：ID、表示名、説明、アニメーション画像のパスなどのメタデータ。
- `spritesheet.webp`：複数のアニメーションフレームをまとめた画像アトラス。
- ペットフォルダ：メタデータと素材を同じ場所に置くためのディレクトリ。

この観点では、Codex Pet はネットワークで動くプログラムではなく、テーマ素材や小さな視覚ウィジェットに近いものです。

## 構造を知る理由

Pets の構造を理解すると、次の三つを判断しやすくなります。

- インストール時：ファイルをどこに置くべきか、どのスクリプトを慎重に読むべきか。
- トラブルシュート時：ペットが表示されない理由、アニメーションが再生されない理由。
- 作成時：フレーム、透明背景、メタデータ、ライセンス説明がそれぞれ何を担うか。

## 読む順序

1. [Codex Pet をインストールする](./install/)：フォルダ、起動、セーフティチェックを理解します。
2. [Codex Pet を作成する](./create/)：素材が読み込み可能なリソースになる流れを理解します。

Pets を小さく明確なローカルパッケージとして扱うほうが、出所不明のコマンドを貼り付けるより安定し、長期的にも管理しやすくなります。
