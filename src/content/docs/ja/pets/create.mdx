このサイトでは、特定のクライアントとPetパッケージの互換性をまだ確認していません。まずバージョンと入手元を記録し、[互換性と復旧の記録](/ja/guide/reference/resource-compatibility/)で実際の結果を確かめてください。図は構造を説明するだけで、すべてのバージョンに共通する形式の仕様ではありません。


Codex Pet の作成は、単に見栄えのよい画像を作ることではありません。Codex が識別し、読み込み、再生し、状態を切り替えられるパッケージを作ることが目的です。「メタデータ + アニメーションアトラス + 出所とライセンス情報」の組み合わせとして考えると分かりやすいです。

![イラスト：手描きのスケッチからグリッド整列、スプライトシート、ペットフォルダーの完成までの制作の流れ](/illustrations/pets-create.webp)

最小構成は通常次のとおりです。

```text
<pet-id>/
  pet.json
  spritesheet.webp
```

## spritesheet とは

![イラスト：行ごとに動作を並べたスプライトシートから 1 コマを切り出し、フィルムにして画面で再生する](/illustrations/pets-spritesheet.webp)

Spritesheet は、複数のアニメーションフレームを一枚の大きな画像にまとめる方式です。クライアントは多数の小さな画像を読み込む必要がなく、行と列の座標で各フレームを切り出し、順番に再生します。

画像アトラスの仕様とバージョン項目を一緒に確認してください。このサイトの古い図は8列×9行、1フレーム192×208 px（全体1536×1872 px）を使用していますが、すべてのクライアントに共通する仕様ではありません。素材を作る前に、対象クライアントまたは制作ツールのバージョンに対応する形式の説明を入手し、行列数、動作の対応付け、バージョン項目を確認してください。

画像の高さだけを変えて古いメタデータを使い続けても、アトラスを拡張したことにはなりません。追跡可能な形式の説明がなければ、制作をいったん止めて仕様を調べ、図から互換性を推測しないでください。

## 素材を準備する

良い素材には通常、次の条件があります。

- キャラクターの輪郭が明確で、背景をきれいに抜ける。
- 各アクションで比率、視点、基準線がそろっている。
- 透明背景に色フチ、残像、余分なピクセルがない。
- 再生時に切れないよう十分な余白がある。
- 作業、待機、完了、失敗、移動、アイドルなどの状態に対応できる。

素材が二次創作、ゲーム、アニメ、ブランド、他人の作品に由来する場合は、まず出所とライセンスを確認してください。許諾のない素材を商用可能なリソースとして説明しないでください。

## `pet.json` の役割

次の例が示すのは識別情報と素材パスだけで、インストールを検証した完全なパッケージではありません。実際の形式ではバージョン項目が必要な場合もあります。

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "A focused companion for Codex sessions.",
  "spritesheetPath": "spritesheet.webp"
}
```

推奨事項：

- `id` は小文字、数字、ハイフンを使う。
- フォルダ名と `id` を一致させる。
- `spritesheetPath` は相対パスにする。
- `description` は中身が分かる説明にする。
- 作者、バージョン、出所、ライセンスを同梱のREADMEまたはLICENSEに残します。クライアントが任意の追加項目を受け入れるとは仮定しないでください。

`pet.json` はアニメーション自体を保存するものではありません。クライアントに「どのパッケージか、素材はどこにあるか、どう解釈すべきか」を伝えるものです。素材のパス、ファイル名、ディレクトリ構成が一致しないと、通常は読み込めません。

## ローカル確認

公開または共有前に、少なくとも次を確認します。

- `pet.json` が有効な JSON である。
- `spritesheetPath` が存在するファイルを指している。
- spritesheet のサイズとフレームグリッドが対象バージョンの仕様に合っている。
- 各行のアニメーションが大きく跳ねたり、ずれたり、切れたりしない。
- 透明背景がきれいである。
- パッケージに一時ファイル、元画像、公開すべきでない素材が入っていない。

## ライセンスと出所

ペット素材は、二次創作、スクリーンショット、AI 生成画像、公開素材、他人の作品などから来ることがあります。作成時は次を分けて考えてください。

- 個人利用できるか。
- 公開共有できるか。
- 他者による再配布を許可できるか。
- クレジット表記や出所リンクの保持が必要か。

元の作業ファイルと出所記録を残しておくと、後から修正、動作追加、サイズ変更、ライセンス説明の補足がしやすくなります。
