# MCP（モデルコンテキストプロトコル）

- 重要な日付:
  - Open-source date: 2024-11-25
- 公式リファレンス:
  - https://modelcontextprotocol.io/docs/getting-started/intro
- 注記: この項目は MCP が AI アプリケーションの能力接続と再利用に与えた意味を記録する。具体的な統合手順は Guide に置く。

## それは何か

MCP は、モデルや Agent が外部ツール、データ、サービスへ接続するための標準プロトコルである。各アプリが独自アダプターを書き続けるのではなく、共通の接続形式を通じて能力を公開し利用する。

## AI アプリケーション工学をどこからどこへ進めたか

AI アプリケーションは「製品ごとにツール接続層を個別実装する」段階から、「統一プロトコルを中心に能力を接続し再利用する」段階へ進んだ。

## 現在の段階

現時点では、この項目を `emerging` と見なしている。

新興だが上昇中である。概念としては急速に広がったが、ガバナンス、権限、互換性、実運用のベストプラクティスはまだ形成中である。

## 置き換える可能性があるもの

個別 API 統合、各製品専用プラグイン、再利用しにくいツールアダプターの一部を置き換える可能性がある。

## それを置き換える可能性があるもの

より厳密な Agent 実行標準、権限モデル、観測可能性を含むプロトコルに拡張または吸収される可能性がある。
