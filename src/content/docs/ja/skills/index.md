Skill は、安定した手法、参考資料、テンプレート、スクリプトを再利用可能な能力としてパッケージ化するために使います。

価値は「Codexにできることを一つ増やす」だけではありません。一連の作業に明確な入力、出力、権限の境界、テスト方法を与えられます。
