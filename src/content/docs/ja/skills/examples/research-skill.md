# 例：調査 Skill

## SKILL.md 骨組み

```md
---
name: source-backed-research
description: URL/ファイルパス引用付きの技術調査と比較表を作成する。ユーザーが選定、競合分析、文献レビューを求めたときに使用する。
---

## フロー
1. 調査問題と除外項目を明確化
2. 評価次元を列挙（3〜5 項目）
3. 各結論に出典を付ける。検証不能は「要確認」とマーク
4. 比較表 + 推奨 + 未解決問題を出力
5. コードは変更しない
```
