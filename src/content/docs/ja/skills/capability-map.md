## 比較表

| | 誰がトリガー | 永続性 | 外部システム | チーム配布 |
|---|---|---|---|---|
| AGENTS.md | 自動読み込み | 高（Git） | 容易 |
| プロンプト | あなた | 低 | 難しい |
| スラッシュコマンド | あなた | 中 | 製品依存 |
| Skill | あなたまたはモデルマッチ | 高 | 容易（ディレクトリ/Git） |
| MCP | モデルがツール呼び出し | 設定レベル | ガバナンス要 |
| Plugin | インストール後に総合的に有効 | 高 | 公式/チームチャネル |
| Hooks | システムイベント | 設定レベル | エンタープライズで一般的 |
| Automations | 時間/イベント | 設定レベル | 承認フロー要 |

## よくある対応

| ニーズ | 推奨 |
|---|---|
| コードスタイルとテストコマンドの統一 | AGENTS.md |
| 「PR レビュー」フローの標準化 | Skill |
| Jira/Linear チケットを読む | MCP |
| チーム全体に統合パックを配布 | Plugin |
| 毎コミット前に鍵スキャン | Hooks |
| 毎週月曜に週報ドラフト自動生成 | Automations（+ 人が公開） |

詳細な分岐は [拡張方式の選び方](/skills/choosing-an-extension-method/)。

## 単一 UI に縛られない

これらは**単一画面に固定されません**。CLI、デスクトップ App、IDE で Skill/MCP サポートは異なる場合があります——[機能対照](/guide/reference/feature-comparison/) と公式説明を参照。
