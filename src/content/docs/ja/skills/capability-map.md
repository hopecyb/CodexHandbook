## 比較表

| | 誰がトリガー | 永続性 | 外部システム | チーム配布 |
|---|---|---|---|---|
| AGENTS.md | 自動読み込み | 高（Git） | 容易 |
| プロンプト | あなた | 低 | 難しい |
| スラッシュコマンド | あなた | 中 | 製品依存 |
| Skill | あなたまたはモデルマッチ | 高 | 容易（ディレクトリ/Git） |
| MCP | モデルがツール呼び出し | 設定レベル | ガバナンス要 |
| Plugin | インストール後に総合的に有効 | 高 | 公式/チームチャネル |
| Hooks | システムイベント | 設定レベル | エンタープライズで一般的 |
| Automations | 時間/イベント | 設定レベル | 承認フロー要 |

## よくある対応

| ニーズ | 推奨 |
|---|---|
| コードスタイルとテストコマンドの統一 | AGENTS.md |
| 「PR レビュー」フローの標準化 | Skill |
| Jira/Linear チケットを読む | MCP |
| チーム全体に統合パックを配布 | Plugin |
| 毎コミット前に鍵スキャン | Hooks |

## 一つのタスクからチーム能力パックへ

次の流れで、どこまで仕組み化するかを判断できます。

| 段階 | 形 | 向いている状況 |
|---|---|---|
| 一度きりのプロンプト | 現在の会話内の作業指示 | 一回だけ使う、またはまだ探索中 |
| テンプレート | 目的、文脈、制約、受け入れ条件の固定構造 | 似た作業が繰り返されるが、手順はまだ動く |
| Skill | `SKILL.md` とテンプレート、参考資料、スクリプト | 手順が安定し、成功条件が明確 |
| サブエージェント | 分離された文脈の専門ロール | レビュー、テスト、デバッグ、調査など境界が明確な作業 |
| MCP | 呼び出せる外部システムツール | チケット、リポジトリ、社内システムを読む必要がある |
| Hook | イベント起点の検査やブロック | 秘密情報スキャン、整形、危険コマンドの確認 |
| Plugin | チーム向けインストールパック | Skill、MCP、Hook、テンプレート、説明をまとめて配布 |
| Automation | 定期またはイベント駆動タスク | レポート、監視、定例レビュー |

Plugin から設計を始めないでください。まず一度タスクを通し、どの手順が繰り返されるか、どの検査を自動化すべきか、どの外部権限が本当に必要かを見ます。

詳細な分岐は [拡張方式の選び方](/skills/choosing-an-extension-method/)。

## 単一 UI に縛られない

これらは**単一画面に固定されません**。CLI、デスクトップ App、IDE で Skill/MCP サポートは異なる場合があります——[機能対照](/guide/reference/feature-comparison/) と公式説明を参照。
