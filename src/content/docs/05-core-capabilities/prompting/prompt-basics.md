好提示词让 Codex 知道：做什么、在什么范围内做、怎样算做完、信息不足时是否该提问。

## 三级写法（实例库也会沿用）

- **极简版**：目标极清楚时用
- **推荐版**：含目标、背景、输入、约束、验收、权限
- **教学版**：解释每一段为什么存在

从推荐版开始练习。示例见 [运行第一次任务](/02-getting-started/run-your-first-task/)。
