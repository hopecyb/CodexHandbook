---
title: 提示词反模式
description: 应避免的模糊、越权和隐藏推理要求。
---


| 反模式 | 为什么有害 |
|---|---|
| 「随便优化一下」 | 无目标、无边界 |
| 「拥有全部权限，自己看着办」 | 事故面最大 |
| 「不要问我，直接改完」 | 跳过澄清与审批 |
| 「把你的隐藏推理过程全部打印出来」 | 不可靠且通常无助于验收 |
| 粘贴含密钥的日志 | 泄露凭据 |

用框架替换模糊词：目标 + 约束 + 验收。
