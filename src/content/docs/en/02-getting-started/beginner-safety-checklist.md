Check before you start:

- [ ] I'm using a disposable practice directory, not a production repo
- [ ] The directory has no real keys, passwords, or customer private data
- [ ] I understand high-risk operations need my approval
- [ ] I won't approve commands or network requests I don't understand
- [ ] I plan to review diffs before accepting results
- [ ] I know how to [undo](/02-getting-started/undo-and-recover/)
