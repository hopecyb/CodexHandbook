Goal: complete your first task in a **safe practice project**, and learn to inspect, accept, edit, or undo.

The default path uses the **desktop App**. If you prefer terminal or editor, installation pages still apply; the first-task example notes differences where needed.

## Steps

1. [Account, plans, and access](/02-getting-started/account-plans-and-access/)
2. [Choose your client](/02-getting-started/choose-your-codex-client/)
3. Install: [Desktop App](/02-getting-started/install-desktop-app/) · [CLI](/02-getting-started/install-cli/) · [IDE](/02-getting-started/install-ide-extension/)
4. [Sign in](/02-getting-started/sign-in-and-authentication/)
5. [Create a practice project](/02-getting-started/create-your-first-project/)
6. [Run your first task](/02-getting-started/run-your-first-task/)
7. [Review the result](/02-getting-started/review-the-result/) · [Undo and recover](/02-getting-started/undo-and-recover/)

Short on time: [First 30 minutes](/02-getting-started/first-30-minutes/) · read the [Safety checklist](/02-getting-started/beginner-safety-checklist/) first.

Installation steps change with versions—also check [https://developers.openai.com/codex](https://developers.openai.com/codex).
