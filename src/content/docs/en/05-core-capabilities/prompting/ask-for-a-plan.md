Add at the end of your prompt:

```text
First provide a brief plan and the list of files you will modify. Wait for my confirmation before executing.
```

When reviewing the plan, check: scope overreach, verifiable steps, unnecessary destructive operations. Approve before proceeding. See [Planning](/05-core-capabilities/agent-work/planning/)
