Images work well for: UI defects, design comparisons, error dialogs. Text must still state goals and constraints—images cannot replace acceptance criteria.

Note: screenshots may contain private information; crop sensitive details before sending. See [Sensitive context](/05-core-capabilities/context/sensitive-context/)
