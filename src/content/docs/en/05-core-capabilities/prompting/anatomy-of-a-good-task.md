## Recommended template

```text
Goal: … (what is the final deliverable?)
Background: … (why it matters, current state)
Inputs: … (relevant files/links/pasted content)
Constraints: … (editable scope, style, prohibitions)
Acceptance criteria: … (checkable completion conditions)
Permission boundaries: … (network access, install deps, change config)
When information is insufficient: ask first; do not guess.
```

Treat the template as a checklist, not a fill-in-the-blank ritual—remove sections irrelevant to the task, but know the consequences of removing them.
