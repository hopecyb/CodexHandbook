Getting it right the first time is luck; iteration is method.

1. Run a small step
2. Review the diff
3. Follow up with "Keep …; change …; do not touch … again"
4. Start a new thread with a handoff summary if needed

Avoid repeatedly overturning goals in the same thread—that pollutes context.
