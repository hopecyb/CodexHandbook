Constraints answer: "What must absolutely not be done?"

Common constraints:

- Only edit listed files/directories
- Do not change API contracts / do not change the database
- Do not add new dependencies
- Do not make network requests
- Keep existing formatter configuration

Write permission boundaries alongside constraints to reduce "while I'm at it" overreach.
