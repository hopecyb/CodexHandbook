When results are wrong, ask in order:

1. Is the goal checkable?
2. Are constraints clear? Did the Agent see them?
3. Is context stale or conflicting? (compaction / old thread)
4. Should you ask for a plan first?
5. Was the wrong tool chosen? (e.g., went online when it shouldn't)

Still failing: narrow to a single-file reproduction, or start a new thread restating constraints.
