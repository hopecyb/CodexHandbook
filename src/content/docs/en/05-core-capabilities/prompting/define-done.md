Acceptance criteria must be **observable**:

- Weak: "Improve code quality"
- Strong: "`npm test` passes; `Button` component supports `disabled`; Storybook screenshot matches design"

Include verification commands in your criteria so the Agent is more likely to run them: [Run tests](/05-core-capabilities/quality/run-tests/)
