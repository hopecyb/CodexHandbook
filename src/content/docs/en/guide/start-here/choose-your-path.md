## Common misconceptions

### 1. You do not need a precise role at the start

A more useful question is whether you need to learn basic operations now or solve a specific type of task.

### 2. You do not have to choose only one of the three entry points

They are different ways in, not exclusive choices. It is common to start by task and later read the product chapter.

### 3. Choosing the wrong path does not mean starting over

A path helps you avoid detours. It is not a course that must be completed in order.

## How to choose if you are unsure

Use this order:

1. Have not completed a first task? Start with the [beginner path](/en/guide/learning-paths/beginner/).
2. Already know what you want to do? Use the “By task” table.
3. Already know which product you will mainly use? Go to that product chapter.

Start from the page nearest your current question; you can adjust your route later.
