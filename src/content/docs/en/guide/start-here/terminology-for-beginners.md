For a fuller glossary, see the [Glossary](/guide/reference/glossary/). Here are the first batch:

| Term | One-line definition |
|---|---|
| **Prompt** | The goal, background, and requirements you give Codex |
| **Context** | Project, file, and conversation information the model can currently see |
| **Agent** | An execution mode that calls tools and iterates toward a goal |
| **Tool** | Callable capabilities such as reading files, running commands, and searching |
| **Sandbox** | An execution environment that limits filesystem and network impact |
| **Approval** | Your explicit consent before certain operations continue |
| **Diff** | A before-and-after comparison of changes for your review |
| **Thread / session** | A continuous conversation and its accumulated context |
| **Task** | A goal-oriented unit of work (may span multiple tool calls) |
| **Skill** | A reusable package of specialized instructions and resources (advanced) |
| **MCP** | A protocol for connecting external tools and data sources (advanced) |
| **Cloud task** | A task running in a cloud environment, not the local sandbox |

When you hit an unfamiliar term, return here or to the glossary before continuing.
