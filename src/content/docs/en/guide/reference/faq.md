For a scattered question, start with the FAQ. It does not reproduce whole chapters; it helps you find where to go next.

## When to use it

Use the FAQ when there are too many pages to choose from, a specific issue is holding you up but does not warrant a full chapter, or you want an initial direction.

**Q: Which client should I use first?**
A: The desktop app. See [Choose Your Codex Client](/en/guide/choose-your-client/).

**Q: Can I accept every change without checking it?**
A: Better not. See [Verification and Human Review](/en/guide/foundations/verification-and-human-review/).

**Q: Is there a standard prompt template?**
A: There is a framework, not magic. See [Task Anatomy](/en/prompts/task-anatomy/).

**Q: What if the handbook and official documentation conflict?**
A: Follow the [official Codex documentation](https://developers.openai.com/codex), and consider filing an issue.

**Q: How do AGENTS.md, Skills, and MCP differ?**
A: See the [Capability Map](/en/skills/capability-map/) and [Choosing an Extension Method](/en/skills/choosing-an-extension-method/).

**Q: Is there a recommended standard workflow?**
A: Start with [Explore → Plan → Execute → Verify](/en/cases/workflows/explore-plan-execute-verify/).

**Q: How does Cloud connect GitHub and open a PR?**
A: See [Connect GitHub](/en/guide/web-and-cloud/connect-github/) and [Create Pull Requests](/en/guide/web-and-cloud/create-pull-requests/).

**Q: Can the CLI run in CI?**
A: Yes. Start with [non-interactive mode](/en/guide/cli/non-interactive-mode/) and design the approvals and permissions.

**Q: What slash commands exist?**
A: Check `/` completion in your current client. For an introduction, see [Slash Commands](/en/guide/reference/slash-commands/).

**Q: Where are complete paths for creators, developers, and teams?**
A: The beginner path is written. See [use cases](/en/cases/use-cases/) for deeper examples and roadmap M6 `11-team-enterprise` for team governance.

## Common misconceptions

### 1. Is the FAQ optional?

For beginners, it can be a quick place to start.

### 2. Are FAQ answers enough to take action immediately?

They give an initial direction and link to fuller explanations.

### 3. If my question is missing, does the handbook not cover it?

The answer may be in a topic page, learning path, or hands-on case.

## How to use it

1. Look through the FAQ.
2. Find the closest question.
3. Follow its link into the relevant topic.

That is often faster than browsing the sidebar back and forth.
