This handbook is an open-source community guide. For product behavior, installers, and plans, rely on official sources:

- Codex developer documentation: [https://developers.openai.com/codex](https://developers.openai.com/codex).
- OpenAI platform and account pages: use the current entry point on the official OpenAI site.

The official documentation and this handbook serve different purposes. This handbook explains concepts and ways to work; official documentation confirms the current version and latest instructions. If an official URL changes, follow the OpenAI site's navigation and consider sending a PR to update this page.

## When to look at official documentation first

Go straight to official documentation for installation and login, whether a feature is supported now, the latest syntax of a setting or command, and changes to plans, permissions, or product behavior.

## Common misconceptions

### 1. If official sources are authoritative, is a community handbook unnecessary?

People may still need help deciding where to start even after reading the official instructions.

### 2. If this handbook said something, is it necessarily still true?

Command arguments, configuration keys, supported capabilities, and plan or permission scopes can change quickly.

### 3. What takes priority when sources conflict?

Use the handbook for concepts and background. Check official sources for current behavior and the latest syntax.

## How to use each

The handbook is a good first stop when you do not understand a concept, do not know where to start, or want a suggested learning sequence.

Official sources are more reliable when you need to know what is supported now, what a parameter is called today, whether a version has a feature, or whether product rules have changed recently.

## If you are unsure where to begin

1. Use this handbook to understand the concept and general direction.
2. Before configuring, installing, or executing, check the latest official instructions.
3. If they conflict, follow the official source.

That gives you a clearer path with less chance of relying on outdated information.
