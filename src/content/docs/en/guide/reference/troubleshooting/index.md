## Follow the logs

The [five failure recovery walkthroughs](/en/guide/reference/troubleshooting/failure-recovery-lab/) provide downloadable inputs and real command logs. They cover unintended source edits, citation numbering, binding suggestions to inputs, directory scope, and damaged state. Each case records a single-variable correction and recovery. These are designed local exercises, not client sign-in or network incidents.

## If you cannot classify the problem

Start with these questions:

1. Can you not get in?
2. Does it fail to run?
3. Does it run but produce the wrong result?
4. Are you unsure which tool or entry point to choose?

This usually leads to the relevant page more quickly.
