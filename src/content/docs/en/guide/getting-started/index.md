The goal is to complete your first task in a **safe practice project** and learn to inspect, accept, revise, or undo the result.

The default path uses the **desktop app**. If you prefer a terminal or editor, the installation pages still apply; the first-task example notes any differences.

If your main questions are “How do I begin?” and “How do I avoid mistakes at the start?”, this chapter is the most direct entry point.

## What this chapter covers

- The minimum preparation before using Codex for the first time
- The order for installation, sign-in, and creating a practice project
- What a satisfactory first task looks like
- How to inspect the result and undo changes afterward

## Common misunderstandings

### 1. Should I work on an important project for my first task?

That is not recommended.

A small task in a safe practice project is a steadier start. Learn the workflow before touching real work.

### 2. Am I ready once installation succeeds?

Not yet. To get started in practice, you should at least be able to:

- Give Codex a clear task
- Understand the result
- Decide whether to accept, revise, or undo it

### 3. Does a bigger first task teach me more?

Usually it only makes it easier to lose patience. A small task that is easy to inspect helps you develop sound judgment.

## Suggested order

Follow this short cycle:

1. Choose a client.
2. Install it and sign in.
3. Create a safe practice project.
4. Do one very small task.
5. Inspect the result.
6. Learn to undo or correct it.

Once you have completed this cycle, more complex topics will be easier to learn.
