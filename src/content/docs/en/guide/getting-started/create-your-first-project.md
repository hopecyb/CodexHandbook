## Recommended approach

1. Create a new folder, e.g. `codex-practice/`
2. Add 1–2 non-sensitive text files, e.g. `hello.md`
3. Open/add that folder as a project in Codex
4. **Do not** use a repo with production secrets, customer data, or irreplaceable history

## Why a practice project

The goal of the first task is learning the workflow—not shipping business work. Isolation keeps the cost of mistakes near zero.
