1. Open the official Codex desktop download instructions: [https://developers.openai.com/codex](https://developers.openai.com/codex)
2. Choose the installer for your OS and install
3. Launch the app and confirm you see sign-in or project entry

## Post-install checks

- The app opens normally
- Grant system permissions (e.g. file access) only as needed—don't give unrelated disk access upfront
- UI overview: [Installation and interface](/guide/desktop-app/installation-and-interface/)

If install fails: [Desktop App troubleshooting](/guide/desktop-app/troubleshooting/).
