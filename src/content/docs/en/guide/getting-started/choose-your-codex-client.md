| If you… | Choose |
|---|---|
| Are new and want clear diffs and review | **Desktop App** (recommended default) |
| Live in the terminal and want scripts | **CLI** |
| Mostly edit code in an editor | **IDE extension** |
| Need GitHub cloud environments / long tasks | **Cloud** (read overview first) |

Full comparison: [Feature comparison](/guide/reference/feature-comparison/). You can install multiple clients; **keep the same practice directory** to compare experiences.
