| Misconception | More accurate view |
|---|---|
| "It automatically guarantees correctness" | It produces candidates; you accept them |
| "Fancier prompts are always better" | Clear goals, constraints, and acceptance beat magic wording |
| "Full permissions are faster" | Broader permissions broaden accident surface |
| "One endless session solves everything" | Old context pollutes new tasks |
| "Cloud is always safer than local" | Safety depends on policy, secrets, and review—not location |
| "If the handbook says it, it's official" | OpenAI docs are authoritative; the handbook helps you learn |
