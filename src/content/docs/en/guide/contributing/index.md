## Quick checklist (English)

1. Source locale for new guides: **zh-CN** under `src/content/docs/`
2. Every new sidebar slug needs a matching `.md` file and `astro.config.mjs` entry
3. Run `npm run build` before opening a PR
4. Prompt examples live in `examples/prompts/` with YAML metadata and acceptance criteria
5. Do not copy external tutorials verbatim; see the integration plan in `docs/planning/`
