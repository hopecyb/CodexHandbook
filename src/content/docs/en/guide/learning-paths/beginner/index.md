Use one set of fictional event materials to practice going from reading files to delivering a verifiable notice. You do not need to learn Git or programming or install dependencies first.

[Download the complete exercise package](/downloads/first-project/first-project-1.0.0.zip) · [Materials guide](/downloads/first-project/README.md)

After extracting the archive, copy starter into a new work folder and open work with Codex. Keep the originals and the author reference; finish the exercise before comparing your work with the answer. If you have trouble installing or signing in to a client, see [Quick start](/en/guide/getting-started/) and [Troubleshooting](/en/guide/reference/troubleshooting/).

| Step | What to do | Evidence of completion |
|---|---|---|
| [1. Talk to Codex](/en/guide/learning-paths/beginner/01-talk-to-codex/) | Read only the three files; explain their purpose and what remains unknown | Identify that the registration method needs confirmation; files remain unchanged |
| [2. Work with files](/en/guide/learning-paths/beginner/02-work-with-files/) | Add only a status note to the notice | Only one file gains one line |
| [3. Give clear tasks](/en/guide/learning-paths/beginner/03-give-clear-tasks/) | Prepare the notice from the established facts | Facts match, unknowns remain, scope is correct |
| [4. Review results](/en/guide/learning-paths/beginner/04-review-results/) | Find errors in the faulty sample and review your own result | Locate four errors and record an actual review |
| [5. Complete your first small project](/en/guide/learning-paths/beginner/05-complete-first-project/) | Practice recovery in a copy and write a handoff | Restored files match; the handoff can be traced back |

## What is in the package

starter contains the facts, a draft notice, and a synthetic note that must not be changed; references contains the author reference and an intentionally faulty sample; templates contains review and handoff templates; validation contains an optional reproduction script and a record of real file operations.

All events and places are fictional, and the materials use CC0-1.0. The exercise handles only local files; it does not actually register anyone, publish anything, or send messages.

## What has been validated

The author ran the initial copy, single-file modification, original-file protection, deliberate failure, and recovery checks in a temporary directory. The script did not call a model, and the reference notice was written by the author. This site has not yet measured model success rates, learning time, or independent reader completion. Your completion should be demonstrated by your own files and review record.
