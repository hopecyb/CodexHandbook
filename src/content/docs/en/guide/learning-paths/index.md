## Advanced operator path

For people who already finish small Codex tasks and want to combine features into repeatable workflows:

| Step | Topic | Read |
|---|---|---|
| 1 | Fast entry points | [Slash commands and quick entry](/guide/reference/slash-commands/) |
| 2 | Durable project context | [AGENTS.md](/guide/customization/agents-md/) and [Memories and persistent context](/guide/customization/memories-and-persistent-context/) |
| 3 | Reusable task behavior | [Skills overview](/skills/overview/) and [Skill anatomy](/skills/skill-anatomy/) |
| 4 | Isolated work | [Subagents](/guide/agent-work/subagents/) and [Multi-agent coordination](/cases/workflows/multi-agent-coordination/) |
| 5 | External systems | [MCP overview](/skills/mcp/mcp-overview/) |
| 6 | Automatic guardrails | [Hooks overview](/skills/hooks/hooks-overview/) |
| 7 | Team distribution | [Plugins overview](/skills/plugins/plugins-overview/) |
| 8 | Recovery and review | [Undo and recover](/guide/getting-started/undo-and-recover/) and [Review diffs](/guide/quality/review-diffs/) |

Use this path when the goal is not "learn one feature," but "turn a recurring workflow into a small operating system": instructions define the norm, Skills define the method, MCP provides tools, subagents split work, Hooks guard the edges, and Plugins package the result for others.
