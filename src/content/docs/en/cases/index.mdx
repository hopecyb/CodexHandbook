Case studies show how to start with a real goal and work through prompting, execution, course correction, review, verification, and reuse. They focus on decisions made along the way, not just the final artifact.

## Find the task you want to do

Filter by task type or keyword. Outputs and verification status come from each case’s metadata. “Example run tested” covers only the environment and steps listed on that page; it does not mean every client or reader has been tested.

## Case format

Each case should include a goal, preparation materials, a suggested prompt, the execution process, human checkpoints, a verification method, failure handling, and a reusable template. To write a new case, see the [case study template](/en/cases/use-cases/case-study-template/).

## Reusable materials

- [Case study template](/en/cases/use-cases/case-study-template/): Turn a task into a record that others can review and pick up.
- [First task](/en/cases/first-task/): Practice the full goal, execution, and acceptance loop with a small, safe task.
- [Workflow examples](/en/cases/workflows/): Learn to add verification, human approval, failure recovery, and collaboration among multiple Agents.
