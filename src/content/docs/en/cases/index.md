# Case studies

Case studies show how to go from a real goal through prompting, execution, review, verification, and reuse.

## Case format

Each case should include goal, preparation materials, recommended prompts, execution process, human checkpoints, verification methods, failure handling, and reusable templates. To write a new case, see [Case study template](/en/cases/use-cases/case-study-template/).
