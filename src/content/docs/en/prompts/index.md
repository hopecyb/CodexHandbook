The prompts section explains how to state a task so Codex knows its goal, context, boundaries, and completion criteria. A useful prompt also lets uncertainty surface during execution, makes room for necessary confirmation, and asks for a result you can inspect.

## Fixed-input comparison

[Three prompt comparisons](/en/prompts/comparison-lab/) provide A/B materials and shared scoring dimensions for a weekly report, an article, and a bug fix. These are experimental designs; they do not yet establish conclusions about model effectiveness or elapsed time.
