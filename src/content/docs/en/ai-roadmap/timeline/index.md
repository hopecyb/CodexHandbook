This map separates verifiable public events from learning advice. **A date refers only to the paper, announcement, or article named in its row; it does not automatically mark the birth of a concept, industry adoption, or a mature capability.** Different techniques can be used together, and chronological order is not a required sequence of upgrades or study.

Each topic page provides primary sources, applicability limits, and an exercise on this site. Checking sources is not the same as running software. Existing URLs are retained, so the year and month in a URL may differ from the corrected event date; use the date in the article text.
