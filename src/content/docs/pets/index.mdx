# Codex 宠物

Codex 宠物是一类出现在 Codex 客户端里的动态陪伴元素。它不是模型能力，也不是自动化工具，而是一组本地视觉资源：客户端在工作、等待、完成、出错或需要你介入时，可以用不同动画状态表达当前氛围。

<PetScienceFigure variant="anatomy" locale="zh" />

这个栏目定位为科普：解释 Codex 宠物的基本概念、常见文件结构、安装时的安全边界，以及制作一个 Pet 时需要理解的素材和元数据关系。本站不提供宠物资源列表，也不把任何外部资源站作为官方来源。

## 它通常由什么组成

一个 Pet 通常可以理解成一个小型资源包：

- `pet.json`：描述宠物身份、展示名称、说明、动画图路径等元数据。
- `spritesheet.webp`：把多帧动画合并到一张图里，客户端按固定网格读取。
- 宠物目录：把元数据和素材放在同一个可识别的文件夹中。

从这个角度看，Codex Pet 更接近“主题资源”或“小组件素材包”，而不是一段需要联网运行的程序。

## 为什么需要了解它

了解 Pets 的结构可以帮你判断三件事：

- 安装时：知道文件应该放在哪里，哪些脚本值得警惕。
- 排错时：知道为什么宠物没有出现、动画为什么不播放。
- 制作时：知道图片帧、透明背景、元数据和授权说明分别负责什么。
