当前最可复现的制作路径是：准备一个符合 Web 上传要求的透明 sprite sheet 文件，或在桌面 App 的 **Settings → Pets → Create pet** 中让内置 `hatch-pet` Skill 创建。官方公开文档没有给出可供手工维护的通用 `pet.json` schema，因此本站不再提供看似可安装、实际未验证的元数据示例。

![插画：从草图、透明背景和尺寸检查，到产品内创建宠物的流程](/illustrations/pets-create.webp)

## Web sprite sheet 规格

| 项目 | 当前要求（核验于 2026-11-19） |
|---|---|
| 画布 | 1536 × 1872 px |
| 背景 | 透明 |
| 格式 | PNG 或 WebP |
| 大小 | ≤ 20 MiB |

上传入口：**Settings → Personalization → Pet → Upload pet**。产品限制会变化，制作和上传前再次查看界面提示。

## 准备素材

- 角色轮廓清楚，四周保留足够留白。
- 透明背景没有彩边、残影或意外的半透明像素。
- 缩小预览后仍能辨认主体，不把重要细节贴到画布边缘。
- 导出后检查像素尺寸、格式、alpha 通道和文件大小，不只看扩展名。

## 桌面 App 内创建

打开 **Settings → Pets → Create pet** 后，App 会安装内置 `hatch-pet` Skill、重新加载 Skills 并打开新聊天。描述想要的 Pet；任务完成后回到设置选择 **Refresh** 和新 Pet。完成后至少检查：

1. 普通、等待、完成或需要介入等状态下是否显示正常；
2. 缩放和裁切是否遮住主体；
3. 切回默认宠物后能否恢复；
4. 重启客户端后设置是否仍符合预期。

本站没有用真实账号记录所有平台的创建流程，因此按钮、状态和可用性以当前客户端为准。

## 不要推断私有格式

旧示意曾使用 8 × 9 帧、单帧 192 × 208 px（整图恰为 1536 × 1872 px），并配合 `pet.json`。当前公开资料确认 Web 接受指定尺寸的 sprite sheet，但**不能据此推出某个手写 JSON schema 或私有目录约定**。桌面端优先让官方内置 Skill 生成，只有目标版本给出可追溯契约时才手工维护资源包。

## 授权和来源

素材来自二创、游戏、动漫、品牌、图库或他人作品时，分别确认个人使用、公开分享、二次分发和署名条件。AI 生成素材也要保留输入、生成工具、日期和后续编辑记录；生成不等于自动拥有第三方角色或商标的权利。
