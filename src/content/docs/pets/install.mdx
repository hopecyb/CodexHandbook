当前公开流程是在产品界面中创建、上传或选择 Pet。不要先去创建 `~/.codex/pets/<id>/pet.json`：官方公开文档没有把这个目录结构作为通用安装契约。

![插画：先用放大镜检查资源包，再放入抽屉式目录，刷新后宠物出现在笔记本屏幕上](/illustrations/pets-install.webp)

## 桌面 App

macOS 和 Windows 桌面 App 当前流程是：

1. 打开 **Settings → Pets → Create pet**；
2. App 安装内置 `hatch-pet` Skill、重新加载 Skills，并打开新聊天；
3. 描述想要的 Pet 并发送；
4. 任务完成后回到 **Settings → Pets**，选择 **Refresh**，再选择新 Pet。

桌面创建的自定义 Pet 保存在本机，不会自动同步到 ChatGPT Web。入口、按钮和开放范围仍可能随版本、账号与组织策略变化；如果看不到入口，先更新客户端并检查工作区设置，不要用未知脚本“强制安装”。

## ChatGPT Web

1. 打开 **Settings → Personalization → Pet**。
2. 选择 **Upload pet**。
3. 上传符合当前要求的单个透明 sprite sheet 文件：
   - 1536 × 1872 px；
   - 透明背景；
   - PNG 或 WebP；
   - 不超过 20 MiB。
4. 保存后在界面中检查缩放、裁切和透明边缘。

上传前以界面给出的限制为最终依据；如果产品拒绝文件，不要仅通过改扩展名绕过校验。

## CLI

在交互式 Codex CLI 中，先输入 `/` 查看补全：

- `/pets` 或 `/pet`：打开 picker；
- `/pets <name>`：直接选择；
- `/pets off`：关闭终端 Pet。

终端需要 iTerm2 3.6 或更新版本，或支持 Kitty graphics / Sixel；tmux 与 Zellij 中不可用。命令不可见时，检查 CLI 版本和终端支持。IDE 扩展没有 Pet picker 或浮动 Pet。

## 安全与恢复

- 不运行来源不明的 `curl | sh`、安装器或修改客户端目录的脚本。
- 上传前检查文件中是否含姓名、账号、工作画面或其他不应公开的信息。
- 保留原图、来源、许可与修改记录；切换宠物前记录当前设置。
- 如果显示异常，先在产品界面切回内置/默认选项，再移除上传内容。

历史或社区教程可能使用 `pet.json + spritesheet.webp`。在目标版本没有公开 schema 和恢复说明时，只能把它视为未核实格式，不能作为本站主路径。
