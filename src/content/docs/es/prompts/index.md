La sección de prompts explica cómo expresar una tarea para que Codex conozca el objetivo, el contexto, los límites y los criterios de finalización. Un buen prompt también permite señalar incertidumbres durante la ejecución, pedir confirmación cuando sea necesaria y entregar un resultado comprobable.

## Comparación con entradas fijas

Las [tres comparaciones de prompts](/es/prompts/comparison-lab/) ofrecen materiales A/B y criterios de puntuación comunes para un informe semanal, un artículo y una corrección de bug. Son diseños experimentales; todavía no permiten concluir nada sobre la eficacia del modelo o el tiempo empleado.
