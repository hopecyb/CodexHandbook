# Tool Use (uso de herramientas)

- Fechas clave:
  - Engineering inflection: 2025-03-11 (Responses API and built-in tools)
- Referencias oficiales:
  - https://openai.com/index/new-tools-for-building-agents/
  - https://platform.openai.com/docs/guides/tools
- Nota: Esta entrada registra el punto de adopción y el significado actual de este concepto en la ingeniería de aplicaciones de IA.

## Qué Es

Tool Use hace que el modelo elija, invoque y lea herramientas como búsqueda, código, navegador o bases de datos.

## De Qué Paso a Qué Paso Movió la Ingeniería de Aplicaciones de IA

Movió el sistema desde llamar una función aislada hacia orquestar varias capacidades para completar tareas.

## En Qué Etapa Está Ahora

Actualmente lo marco como `emerging`.

Está pasando a mainstream en APIs y frameworks de agentes.

## Qué Podría Reemplazar

Reemplaza muchos flujos manuales de buscar, copiar, ejecutar y verificar.

## Qué Podría Reemplazarlo

Se integrará en harnesses y runtimes de agentes con estado y recuperación.
