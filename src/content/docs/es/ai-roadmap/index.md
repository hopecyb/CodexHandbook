## Elige una práctica según la tarea actual

- Primera vez: empieza por la [ruta para principiantes](/es/guide/learning-paths/); no hace falta estudiar toda la cronología antes.
- Mejorar instrucciones: usa los [materiales de comparación de prompts](/es/prompts/comparison-lab/) para guardar resultados y puntuaciones. El sitio aún no tiene una conclusión medida sobre la eficacia de los modelos.
- Necesitas fuentes: practica la correspondencia entre afirmaciones y pruebas con el [artículo con fuentes](/es/cases/write-an-article/).
- Necesitas reutilización estable: elige un [ejemplo de Skill](/es/skills/examples/) y comprueba entradas, límites y registro de verificación.
- La ejecución falla repetidamente: usa el [laboratorio de recuperación](/es/guide/reference/troubleshooting/failure-recovery-lab/) para leer registros y cambiar una variable cada vez.

El valor de un tema para aprender depende de tu tarea. Esta sección ya no usa etiquetas como «rising» o «emerging» para dividir a toda la industria en etapas sin una base de medición común.
