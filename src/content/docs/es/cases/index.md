# Casos prácticos

Los casos prácticos muestran cómo partir de un objetivo real y completar el prompt, la ejecución, la revisión, la verificación y la reutilización.

## Formato del caso

Cada caso debe incluir objetivo, materiales de preparación, prompt recomendado, proceso de ejecución, puntos de control humanos, métodos de verificación, manejo de fallos y plantilla reutilizable. Para redactar un caso nuevo, consulta la [plantilla de caso](/es/cases/use-cases/case-study-template/).
