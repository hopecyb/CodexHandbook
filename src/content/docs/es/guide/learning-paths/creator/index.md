> Estado MVP: esta página es un resumen. Los cinco pasos completos (investigación, escritura, imágenes y presentaciones, prototipos web, flujos reutilizables) se completarán en hitos posteriores.

Si quieres usar Codex sobre todo para contenido, y no para cambiar código, puedes empezar por esta ruta.

## Casos adecuados

- Quien escribe artículos, documentación o guiones
- Quien necesita piezas visuales, presentaciones o prototipos de página
- Quien quiere dominar el método de «formular bien la demanda creativa + aceptar claramente el resultado»

## Qué puedes leer ahora

- [Prompts](/es/prompts/): formular con claridad las Tareas de creación
- [Verificar artefactos](/es/guide/quality/verify-artifacts/): revisar textos y páginas
- [App de escritorio](/es/guide/desktop-app/): entrada principal para quien no usa terminal

## Malentendidos frecuentes

### 1. La ruta para creadores es «que me escriba»

Eso no basta.

Más importante es:

- Cómo formular objetivo, audiencia y estilo
- Cómo juzgar si el contenido generado sirve
- Cómo evitar que varias rondas creativas se desvíen

### 2. No soy programador, así que no necesito Verificación

El trabajo de contenido tampoco es una excepción.

También necesita Verificación; lo que cambia es el foco: estructura, tono, hechos, formato y efecto de entrega.
