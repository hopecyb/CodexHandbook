## Four types of readers

| Reader | How you'll use this handbook |
|---|---|
| AI beginners | From "what is it" to your first safe task; terms are explained |
| Creators | Research, writing, presentations, and prototypes; start with overviews, then link to capability topics |
| Developers | Code understanding, implementation, testing, review, and automation |
| Teams | Shared guidance, permissions, quality, and governance (deeper content in later milestones) |

## Default perspective

The main text is written for **readers unfamiliar with the terminal and Agents**. Developer and team chapters don't get watered down—professional content enters through learning paths layer by layer.

## What this handbook is not

- A complete official changelog for a single product
- A script repository you can ship to production without verification
- A replacement for your organization's internal security and compliance policies
