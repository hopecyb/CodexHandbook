Antes del primer uso, pregúntate: «Si se equivoca, ¿pagaré un precio demasiado alto?»

Esta lista existe para bajar el riesgo del primer uso.

Marca antes de empezar:

- [ ] Uso un directorio de práctica descartable, no un repositorio de producción
- [ ] En el directorio no hay claves reales, contraseñas ni privacidad de clientes
- [ ] Entiendo que las operaciones de alto riesgo requieren mi Aprobación
- [ ] No aprobaré comandos o peticiones de red que no entienda
- [ ] Revisaré el Diff antes de aceptar el resultado
- [ ] Sé cómo [deshacer](/guide/getting-started/undo-and-recover/)

Conceptos de apoyo: [Permisos y Aprobaciones](/guide/foundations/permissions-and-approvals/) · [Sandbox y red](/guide/foundations/sandbox-and-network/).

## Malentendidos frecuentes

### 1. La lista de seguridad solo es para gente especialmente cautelosa

Está pensada para quien empieza: la primera vez es fácil sobreestimar que «debería entenderlo todo».

### 2. Si no pulso comandos peligrosos, ya es suficiente

Los problemas más frecuentes la primera vez son:

- Usar el proyecto equivocado
- Incluir archivos sensibles
- No revisar el Diff
- No haber pensado cómo deshacer

### 3. Puedo aprender sobre la marcha sin confirmar esto antes

Puedes aprender usándolo, pero pasar por estos puntos antes de empezar es más seguro.

La primera vez con Codex, baja primero el coste de equivocarte; después todo será más fácil.
