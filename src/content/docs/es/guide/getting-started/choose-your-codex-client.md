Empieza por identificar dónde realizas la mayor parte del trabajo:

| Trabajas principalmente | Empieza aquí |
|---|---|
| En el escritorio, gestionando proyectos, archivos y varias tareas | **Aplicación de escritorio de ChatGPT** |
| En la terminal, ejecutando Git, pruebas y scripts | **Codex CLI** |
| En VS Code, un editor compatible, Xcode o JetBrains | **Integración con IDE** |
| En un repositorio remoto conectado y un entorno aislado | **Codex Cloud** |

Si es tu primera vez y no tienes una preferencia clara, puedes empezar por la aplicación de escritorio. Facilita ver las tareas, los archivos, los diffs y las solicitudes de aprobación. La elección no es definitiva: un mismo flujo puede comenzar en el IDE, verificarse con la CLI y continuar una tarea larga en la aplicación de escritorio o en Cloud.

Para consultar el diagrama de decisión completo, los ejemplos de combinación y los pasos de verificación, lee [Elegir un cliente de Codex](/es/guide/choose-your-client/). Para comparar cada función, consulta la [comparación de funcionalidades](/es/guide/reference/feature-comparison/).

Después, elige la página de instalación correspondiente:

- [Instalar la aplicación de escritorio](/es/guide/getting-started/install-desktop-app/)
- [Instalar la CLI](/es/guide/getting-started/install-cli/)
- [Instalar la integración con IDE](/es/guide/getting-started/install-ide-extension/)
- [Conocer Codex Cloud](/es/guide/web-and-cloud/)
