## Cómo usarla

Hay tres tipos de contenido:

- **Completar conceptos**: glosario, FAQ, comparación de funciones
- **Consultar reglas concretas**: comandos, configuración, Permisos, variables de entorno

Aquí conviene venir con una pregunta; no hace falta leerlo todo de una vez.
