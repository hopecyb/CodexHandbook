Codex should not perform high-risk operations without consent. **Approval** is a key gate in human–Agent collaboration.

## What you usually need to watch

- Whether read/write is allowed outside the current project paths
- Whether network access is allowed
- Whether specific shell commands may run
- Whether the team enforces managed policy (managed configuration)
