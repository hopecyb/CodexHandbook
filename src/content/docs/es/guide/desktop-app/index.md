La App de escritorio es el punto de entrada por defecto para principiantes: permite ver proyectos, Tareas, diferencias y Aprobaciones de forma visual.

También es una entrada más fácil de usar si no estás familiarizado con la línea de comandos o con los plugins del IDE.

No se limita a «poder chatear»: reúne proyecto, cambios, Aprobación y Verificación en una misma interfaz visible.

## Contenido de este capítulo

- Qué acciones conviene aprender primero en la App de escritorio
- Qué funciones conviene usar primero como principiante y cuáles dejar para después
- Dónde mirar cuando hay cambios, Aprobaciones o problemas

## Empieza por reconocer estas tres cosas

No hace falta aprender todas las funciones de una vez.  
Primero reconoce estas tres acciones centrales:

1. Dónde introducir la Tarea
2. Dónde ver los cambios
3. Dónde aprobar o rechazar operaciones

Cuando domines estos tres pasos, ya puedes cerrar un ciclo básico de Tarea.

## Malentendidos frecuentes

### 1. ¿La App de escritorio es solo una carcasa gráfica de la CLI?

Te muestra varios eslabones clave del proceso de colaboración:

- La Tarea actual
- Planes y llamadas a herramientas
- Cambios en archivos
- Acciones de Aprobación
- Revisión de resultados

### 2. ¿Hay que entender todos los botones antes de empezar?

Al principio basta con reconocer:

- Dónde introducir la Tarea
- Dónde ver el diff
- Dónde aprobar o rechazar

### 3. Si es buena para principiantes, ¿no sirve para trabajo serio?

Mucho trabajo formal también se puede hacer en la App de escritorio, sobre todo si te importa la revisión visual y la transparencia del proceso.

## Orden recomendado

La primera vez que uses la App de escritorio, sigue este orden:

1. Instálala y reconoce la interfaz
2. Elige el proyecto correcto
3. Abre una Tarea pequeña
4. Revisa sus cambios
5. Aprende a aprobar y rechazar
6. Después, capacidades avanzadas como Agents en paralelo, worktrees y Tareas Cloud

Así suele resultar más fácil que empezar investigando todas las funciones.
