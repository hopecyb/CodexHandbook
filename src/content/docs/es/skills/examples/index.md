Comprueba el estado de los materiales antes de elegir un ejemplo. Los paquetes completos incluyen entradas, referencias y scripts de validación. Un esqueleto aún necesita recursos y comprobaciones reales; por sí solo no es un flujo de trabajo verificado.

| Ejemplo | Estado del material | Qué se comprobó |
|---|---|---|
| [Skill de escritura](/es/skills/examples/writing-skill/) | Paquete source-backed-writer completo para descargar | Pasaron ocho pruebas de regresión estructural; el autor revisó hechos y estilo, pero no se midió la calidad del modelo. |
| [Skill de revisión](/es/skills/examples/review-skill/) | Paquete scoped-review completo para descargar | Pasaron siete pruebas de alcance del diff; no se midieron el enrutamiento del modelo ni la tasa de detección. |
| [Skill de investigación](/es/skills/examples/research-skill/) | Paquete evidence-research completo para descargar | Pasaron ocho pruebas de estructura de fuentes y evidencias; no se midió la calidad investigadora del modelo. |
| [Skill de automatización](/es/skills/examples/automation-skill/) | Paquete quiet-link-monitor completo para descargar | Pasaron ocho pruebas de estado; no se probaron la programación ni la entrega reales. |

Página relacionada: [Crea tu primer Skill](/es/skills/create-your-first-skill/).

Usa el [método de evaluación de flujos de trabajo](/es/guide/quality/workflow-evaluation/) para registrar por separado activación, límites, formato, calidad y tiempo. Que pasen los scripts de ejemplo no demuestra una tasa general de éxito del modelo.
