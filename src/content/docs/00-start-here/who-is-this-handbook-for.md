## 四类读者

| 读者 | 你会怎样用这本手册 |
|---|---|
| AI 初学者 | 从「是什么」到第一次安全任务；术语都有解释 |
| 创作者 | 研究、写作、演示与原型；先走概览，再链到能力专题 |
| 开发者 | 代码理解、实现、测试、评审与自动化 |
| 团队 | 共享说明、权限、质量与治理（深度内容在后续里程碑） |

## 默认视角

正文默认写给 **不熟悉终端与 Agent 的读者**。开发者与团队章节不会因此变浅：专业内容通过学习路径逐层进入。

## 不适合把手册当成什么

- 单一产品的完整官方 changelog
- 不经核验即可上生产的脚本仓库
- 替代你们组织内部的安全与合规政策
