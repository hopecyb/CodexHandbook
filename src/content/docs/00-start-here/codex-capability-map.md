把 Codex 想成多层能力，而不是一个聊天框：

```text
目标与提示词
  → 上下文（项目 / 文件 / 对话）
    → 工具（文件、终端、搜索、浏览器…）
      → Agent 工作（计划、执行、引导、交接）
        → 质量验证与人工审批
          → 扩展与自动化（Skills / MCP / Hooks…，进阶）
            → 团队治理（后续里程碑）
```
