欢迎来到 Codex 指南手册。本手册以 **AI 初学者** 为默认读者：不假设你会用终端、Git 或 Agent，但会一路把专业能力讲清楚。

## 你将得到什么

- 弄清 Codex 能做什么、不能做什么
- 按角色与任务选择阅读路线
- 在安全练习项目中完成第一次可检查的任务
- 学会用「目标、约束、验收」写提示词，并养成审查习惯
