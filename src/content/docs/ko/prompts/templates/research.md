# 연구 템플릿

연구류 작업과 일반 Q&A의 차이는, 답이 필요할 뿐 아니라 답이 어디서 왔는지도 필요하다는 점입니다.

## 템플릿

```text
연구 질문: 【한 문장】
평가 차원: 【3–5개 나열】
제약:
- 각 결론에 출처 URL 또는 @저장소 내 경로를 붙일 것
- 검증할 수 없는 항목은 「확인 대기」로 표시
- 코드를 수정하지 말 것
출력: 대비표 + 권장 + 열린 질문
```

## 언제 이 템플릿이 맞는가

- 제품·방안을 비교할 때
- 최신 기능, 규칙, 차이를 조사할 때
- 결론을 나중에 다시 검증할 수 있어야 할 때

## 흔한 오해

### 1. 연구는 그럴듯하게 요약만 하면 된다

연구에서 더 중요한 것은 출처, 경계, 확인 대기 항목입니다.

### 2. 못 찾아도 확정 답을 줘야 한다

연구류 작업에서는 “확인 대기”를 분명히 표시하는 편이, 확정인 척하는 것보다 가치 있습니다.

연구 템플릿의 핵심 제약은, 형식 완성도보다 각 핵심 결론이 출처로 추적 가능해야 한다는 점입니다.
