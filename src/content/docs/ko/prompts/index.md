## 고정 입력으로 비교하기

[세 가지 프롬프트 비교](/ko/prompts/comparison-lab/)는 주간 보고서, 기사, 버그 수정의 A/B 자료와 공통 채점 항목을 제공합니다. 현재는 실험 설계이며 모델의 효과나 소요 시간에 관한 결론은 아직 없습니다.

## 재사용할 수 있는 자료

- [프롬프트 템플릿 모음](/ko/prompts/templates/): 작업 유형을 고른 뒤 변수를 바꿉니다.
- [작업 구조 점검표](/ko/prompts/task-anatomy/): 목표, 배경, 입력, 제약, 완료 기준이 모두 있는지 확인합니다.
- [프롬프트 문제 해결 방법](/ko/prompts/prompt-debugging/): 결과가 불안정하면 원인이 목표, 맥락, 범위 중 어디에 있는지 찾습니다.
