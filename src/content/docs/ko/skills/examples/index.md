예시를 고르기 전에 자료 상태를 확인하세요. 완성된 패키지에는 입력, 참고 자료, 검증 스크립트가 들어 있습니다. 뼈대만 있는 경우에는 자료와 실제 확인을 추가해야 하며, 그대로 검증된 워크플로로 사용할 수 없습니다.

| 예시 | 자료 상태 | 확인한 범위 |
|---|---|---|
| [글쓰기 Skill](/ko/skills/examples/writing-skill/) | 완전한 source-backed-writer 다운로드 패키지 | 구조 회귀 검사 8개를 통과했습니다. 사실과 문체는 작성자가 직접 확인했으며 모델 품질은 측정하지 않았습니다. |
| [검토 Skill](/ko/skills/examples/review-skill/) | 완전한 scoped-review 다운로드 패키지 | diff 범위 회귀 검사 7개를 통과했습니다. 모델 라우팅과 탐지율은 측정하지 않았습니다. |
| [조사 Skill](/ko/skills/examples/research-skill/) | 완전한 evidence-research 다운로드 패키지 | 출처와 근거 구조 검사 8개를 통과했습니다. 모델의 조사 품질은 측정하지 않았습니다. |
| [자동화 Skill](/ko/skills/examples/automation-skill/) | 완전한 quiet-link-monitor 다운로드 패키지 | 상태 테스트 8개를 통과했습니다. 실제 예약 실행과 전달은 시험하지 않았습니다. |
