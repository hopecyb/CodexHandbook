# 예시: 연구 Skill

## SKILL.md 골격

```md
---
name: source-backed-research
description: URL/파일 경로 인용이 있는 기술 조사와 비교표를 만듭니다. 사용자가 선정, 경쟁 분석, 문헌 리뷰를 할 때 사용합니다.
---

## 절차
1. 연구 질문과 제외 항목 명확화
2. 평가 차원 나열(3–5개)
3. 각 결론에 출처 첨부. 검증 불가 시 「확인 필요」 표시
4. 비교표 + 추천 + 열린 질문 출력
5. 코드를 수정하지 말 것
```
