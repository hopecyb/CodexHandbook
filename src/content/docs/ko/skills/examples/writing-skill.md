# 예시: 글쓰기 Skill

## SKILL.md 골격

```md
---
name: article-writer
description: 개요에 따라 기술 글을 작성합니다. 연구, 원고, 윤문을 포함합니다. 사용자가 블로그, 튜토리얼, 공중 계정 글을 쓸 때 사용합니다.
---

## 절차
1. 독자, 길이, 어조, 금지 항목 확인
2. 자료가 부족하면 먼저 개요를 쓰고 보완할 점 표시
3. 절별로 작성. 필요하면 핵심 단락 뒤 방향 확인
4. 전문 완성 후 사실과 링크 검사
5. 최종 원고를 지정 경로에 출력

## 금지
- 인용이나 데이터를 지어내지 말 것
- 승인 없이 외부 플랫폼에 게시하지 말 것
```
