Skills는 안정된 방법, 참고 자료, 템플릿, 스크립트를 재사용 가능한 능력으로 패키징하는 데 씁니다.

가치는 Codex에 기능을 하나 더하는 데 그치지 않습니다. 작업 흐름의 입력과 출력, 권한 경계, 테스트 방법을 분명하게 할 수 있습니다.
