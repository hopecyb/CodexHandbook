확장 메커니즘이 많고, 실제로도 혼동하기 쉽습니다. 이 페이지는 설치 단계를 펼치지 않고 관계만 설명합니다.

## 관계 도식

```text
                    ┌─────────────────┐
                    │   당신의 작업 목표   │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         ▼                   ▼                   ▼
   ┌───────────┐      ┌─────────────┐     ┌──────────────┐
   │ AGENTS.md │      │  프롬프트/템플릿  │     │ 슬래시 명령      │
   │ 지속 규칙   │      │  이번 작업     │     │ 당신이 능동 트리거    │
   └───────────┘      └─────────────┘     └──────────────┘
         │                   │                   │
         └───────────────────┼───────────────────┘
                             ▼
                    ┌─────────────────┐
                    │      Skill       │
                    │ 재사용 워크플로 패키지    │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌──────────┐  ┌──────────┐  ┌─────────────┐
        │   MCP    │  │  Hooks   │  │  Scripts    │
        │ 외부 도구  │  │ 감사·검증  │  │ Skill 내 스크립트 │
        └──────────┘  └──────────┘  └─────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │     Plugin       │
                    │ 배포·조합 패키징    │
                    └────────┬────────┘
                             ▼
                    ┌─────────────────┐
                    │  Automations     │
                    │ 무인/예약     │
                    └─────────────────┘
```

## 비교표

| | 누가 트리거 | 지속성 | 외부 시스템 연결 | 팀 배포 |
|---|---|---|---|---|
| AGENTS.md | 자동 로드 | 높음(Git) | 쉬움 |
| 프롬프트 | 당신 | 낮음 | 어려움 |
| 슬래시 명령 | 당신 | 중간 | 제품에 따름 |
| Skill | 당신 또는 모델 매칭 | 높음 | 쉬움(디렉터리/Git) |
| MCP | 모델이 도구 호출 | 설정 수준 | 거버넌스 필요 |
| Plugin | 설치 후 종합 적용 | 높음 | 공식/팀 채널 |
| Hooks | 시스템 이벤트 | 설정 수준 | 기업에서 흔함 |
| Automations | 시간/이벤트 | 설정 수준 | 승인 흐름 필요 |

## 흔한 대응 관계

| 요구 | 권장 선택 |
|---|---|
| 코드 스타일·테스트 명령 통일 | AGENTS.md |
| 「PR 검토」 절차 표준화 | Skill |
| Jira/Linear 티켓 읽기 | MCP |
| 팀 전체에 통합 세트 설치 | Plugin |
| 커밋마다 비밀 스캔 | Hooks |
| 매주 월요일 주간 보고 초안 자동 생성 | Automations(+ 사람 게시) |

상세 분기 논리는 [확장 방식 고르기](/skills/choosing-an-extension-method/)를 참고하세요.

## 제품 입구와 무관

이 메커니즘들은 단일 UI에 **묶이지 않습니다**. CLI, 데스크톱 App, IDE의 Skill/MCP 지원 수준은 다를 수 있으니 [기능 대조](/guide/reference/feature-comparison/)와 공식 설명을 기준으로 하세요.
