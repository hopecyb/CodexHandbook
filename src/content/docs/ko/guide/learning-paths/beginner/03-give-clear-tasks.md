## 사전 조건

먼저 두 번째 단계를 완료하세요. `facts.md`에는 번호가 매겨진 사실 일곱 가지가 있고, `notice.md`에는 미게시 상태를 나타내는 주석이 이미 있습니다.

## 명확한 기준으로 안내문 정리하기

```text
이 디렉터리의 facts.md만 근거로 notice.md를 행사 안내문으로 정리하세요.
상태 주석 <!-- 状态：练习草稿，未发布 -->을 원문 그대로 유지하세요.
시간, 장소, 정원, 비용, 준비 사항, “확인 필요” 부분을 포함하세요.
각 사실에 해당하는 F 번호를 표시하세요. 불확실한 정보는 미확정으로 두고,
QR 코드, 전화번호, 신청 링크를 추가하지 마세요.
notice.md만 수정하세요. facts.md와 private-note.md는 수정하지 말고 새 파일을 만들거나,
네트워크에 접속하거나 내용을 게시 또는 전송하지 마세요.
완료 후 변경 사항과 근거를 나열하세요. 자료가 충돌하면 충돌을 설명하고 확인 필요로 남기세요.
```

목표는 검증 가능한 안내문이고 배경은 가상의 학습용 행사입니다. 입력은 `facts.md`, 경계는 `notice.md`만 수정하는 것입니다. 완료 기준은 내용과 파일을 구체적으로 지정하며 “전문적으로 써 줘” 같은 표현으로 대신하지 않습니다.

## 완료 조건

시간은 2026-10-17 14:00~15:30, 장소는 자료에 나오는 가상의 열람실, 정원은 18명, 참가비는 무료이고 책 지참은 선택 사항입니다. 신청 방법은 확인 필요로 남깁니다. 인용한 각 F 번호가 해당 문장을 실제로 뒷받침하는지 하나씩 확인하세요.

먼저 직접 확인한 뒤 [작성자의 참고 안내문](/downloads/first-project/references/notice.md)을 보세요. 문체는 달라도 되지만 사실, 미확정 항목, 수정 범위는 일치해야 합니다. 오류가 있다면 그 부분만 고치고 결과에 맞추려고 모델이 사실 파일을 다시 쓰게 하지 마세요.
