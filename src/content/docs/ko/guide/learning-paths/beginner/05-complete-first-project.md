## 사전 조건

안내문을 항목별로 검토했고 facts.md와 private-note.md는 원본 그대로이며 records에 자신의 검토 기록이 저장되어 있다.

## 복원을 한 번 연습하기

1. `work` 폴더 전체를 새 `backup-final` 폴더에 복사하고 파일 세 개가 모두 있는지 확인한다.
2. 다시 새 `recovery-drill` 폴더에 복사한다. 이 연습용 복사본에서만 notice.md를 “복원 연습용 잘못된 버전”으로 바꾼다. 실제 work는 그대로 둔다.
3. 연습용 파일을 열어 실제로 바뀌었는지 확인한 다음 backup-final의 올바른 notice.md를 복사해 덮어쓴다.
4. recovery-drill의 파일 세 개를 백업과 하나씩 비교해 내용이 일치하는지 확인한다. work도 변경되지 않았는지 확인한다.

파일 관리자와 편집기만으로 할 수 있다. 대상 경로가 연습용 복사본인지 먼저 확인한다. 같은 이름의 폴더가 이미 있다면 다른 이름을 사용해 기존 내용을 덮어쓰지 않는다. 복원 결과를 확인할 수 없다면 기록에 “미확인”으로 남긴다.

## 인계 가능한 결과물 저장하기

`templates/handoff.md`를 records에 복사한다. 실제 내용에 맞춰 클라이언트 버전, 최종 파일, 근거, 검토 증거, 미해결 신청 방법, 복원 결과를 채운다. 다음에 자료를 교체할 수 있도록 이번에 사용한 작업 지시도 보관한다.

제출물은 최종 notice.md, 원본 facts.md, 자신이 작성한 review.md와 handoff.md, 재사용 가능한 작업 지시를 포함한다. 교육용 파일이므로 실제 게시 권한을 주지 않는다.

## 완료 판단 기준

안내문에 사실 근거가 있고 미확인 정보를 지어내지 않았으며, 변경 범위가 올바르고, 오류 예시의 문제를 식별했고, 복원 연습을 실제 수행하여 기록했으며, 인계 내용으로 다른 사람이 근거와 미해결 사항을 찾을 수 있어야 한다. “작업 세 번 성공”이라고만 적어서는 완료를 증명할 수 없다.
