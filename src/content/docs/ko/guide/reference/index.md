짧고, 정확하고, 검색 가능하게. 이 구역은 주로 빠른 조회와 색인이며, 깊은 설명은 각 특집 장에 둡니다.

“참고 자료” 페이지 내용이 많으니, 도구 상자와 색인으로 쓰는 편이 맞고, 처음부터 끝까지 읽을 필요는 없습니다.

## 사용법

여기에는 주로 세 종류가 있습니다.

- **개념 먼저**：용어, FAQ, 기능 대조
- **구체 규칙 조회**：명령, 설정, 권한, 환경 변수
- **문제 날 때 조회**：오류 안내, 장애 분석, 공식 리소스

질문을 들고 찾는 데 맞고, 한숨에 전부 읽을 필요는 없습니다.
