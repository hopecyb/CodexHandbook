|---|---|

| Cloud 작업 | 클라우드 환경에서 실행하는 작업 |

## 사용 방식

여기는 빠른 조회 사전이지 완전한 튜토리얼이 아닙니다.  
다른 페이지에서 단어를 보고 뜻이 잠깐 기억나지 않으면 여기로 돌아와 찾으세요.

이 단어들이 대부분 아직 낯설다면, 먼저 [초보자를 위한 용어](/guide/start-here/terminology-for-beginners/)를 읽는 편이 더 수월합니다.

## 흔한 오해

### 1. 처음부터 끝까지 외울 필요 없다

더 흔한 쓰임은 이렇습니다.

- 다른 페이지를 읽다 단어를 만남
- 돌아와 한 번 찾음
- 원문으로 돌아가 계속 읽음

### 2. 짧은 정의를 이해했다고 이미 쓸 줄 아는 것은 아니다

용어집은 먼저 짝을 맞춰 주고, 어떻게 쓰는지는 대응 특집 페이지의 구체 시나리오를 봐야 합니다.

### 3. 용어가 많다고 계속 배우기 어려운 것은 아니다

Codex 관련 내용에는 원래 새 단어가 있습니다. 대략 뜻을 먼저 알고, 세부사항은 천천히 보완하면 됩니다.

## 모르는 단어를 만났을 때

이렇게 처리하세요.

1. 짧은 정의를 먼저 찾음
2. 대략 어느 종류의 개념인지만 확인
3. 대응 특집 페이지에서 전체 설명을 봄

한 용어 때문에 페이지 전체의 읽기 리듬이 오래 끊기지 않게 합니다.
