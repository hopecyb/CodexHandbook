본 핸드북은 커뮤니티 오픈소스 가이드입니다. 제품 동작, 설치 패키지, 플랜은 공식을 따릅니다.

- Codex 개발자 문서：[https://developers.openai.com/codex](https://developers.openai.com/codex)
- OpenAI 플랫폼과 계정 관련 페이지：OpenAI 공식 사이트의 현재 입구를 따름

공식 문서와 이 핸드북의 역할은 다릅니다.

- 이 핸드북은 개념과 사용 관점을 설명
- 공식 문서는 현재 버전과 최신 서술을 확인

공식 URL이 바뀌면 OpenAI 사이트 내비를 따르고, 이 페이지를 갱신하는 PR도 환영합니다.

## 언제 공식을 우선하나

다음 문제면 공식 문서로 바로 가는 편이 더 직접적입니다.

- 설치와 로그인
- 현재 기능 지원 여부
- 설정 항목이나 명령의 최신 서술
- 플랜, 권한, 제품 동작 변화

## 흔한 오해

### 1. 공식이 가장 권위적이라고 커뮤니티 핸드북이 필요 없는 것은 아니다

많은 사람이 막히는 이유는, 공식 설명을 읽어도 어디서부터 시작할지 모르는 경우입니다.

### 2. 핸드북에 적혀 있다고 지금 그대로인 것은 아니다

다음 내용은 더 빨리 바뀝니다.

- 명령 파라미터
- 설정 키 이름
- 지원하는 제품 능력
- 플랜과 권한 범위

### 3. 충돌할 때 우선순위를 분명히 하세요

간단히 나누면, 개념과 배경은 핸드북, 현행 동작과 최신 서술은 공식입니다.

## 사용 방식

이런 질문은 핸드북을 먼저 보세요.

- 이 개념이 무엇을 말하는지 모르겠음
- 어떻게 시작할지 모르겠음
- 권장 입문 순서를 알고 싶음

이런 질문은 공식이 더 믿을 만합니다.

- 지금 최신으로 무엇을 지원하는지
- 이 파라미터가 오늘 정확히 무엇인지
- 이 기능이 현재 버전에 있는지
- 제품 규칙이 최근에 바뀌었는지

## 어느 쪽을 먼저 볼지 헷갈릴 때

1. 핸드북으로 개념과 큰 방향을 이해
2. 설정·설치·실행 직전에는 공식에서 최신 서술을 확인
3. 둘이 충돌하면 공식을 따름

방향이 더 분명해지고, 오래된 정보를 덜 밟게 됩니다.
