슬래시 명령을 처음 보면, 외워야 할 은어처럼 보이기 쉽습니다. 능동적으로 이름을 불러 쓰는 빠른 입구 묶음으로 보면 더 수월합니다.

보통 어떤 고정 모드나 내장 흐름에 빨리 들어갈 때 씁니다. 슬래시 명령(`/command`)은 [Skill](/skills/overview/)의 `$name` 호출과 관련되지만 같은 것은 아닙니다. 구체 목록은 **제품과 버전에 따라 바뀌므로**, 쓰기 전에 클라이언트 안 `/` 자동완성과 공식 문서를 기준으로 하세요.

## 개념 구분

| 입구 | 누가 시작 | 전형 용도 |
|---|---|---|
| `/review` 등 슬래시 명령 | 당신이 `/`를 입력 | 내장 또는 설정의 고정 흐름 |
| `$skill-name` | 당신 또는 모델 | 프로젝트 또는 사용자 Skill |
| 자연어 | 당신 | 일반 작업 |

## 셋을 직접 구분하기

- `/명령`：채팅에서 빠른 입구를 직접 고름
- `$skill`：당신 또는 모델이 특정 Skill을 이름으로 사용
- 자연어：요구를 바로 말하고, 모델이 어떻게 할지 판단

이미 아는 흐름에 더 빨리 들어가고 싶다면 `/명령`이 더 직접적입니다.

## 무엇인가

- 터미널 명령이 아님
- 신비한 은어가 아님
- 채팅 UI의 “빠른 버튼 입구”로 보면 됨

다음 시나리오에 잘 맞습니다.

- 이미 어떤 흐름에 들어갈지 알고 있음
- 같은 의도를 매번 다시 말하고 싶지 않음

## 흔한 오해

### 1. 슬래시 명령은 터미널 명령이다

채팅 UI의 빠른 입구이지, shell에서 실행하는 `codex ...` 명령이 아닙니다.

### 2. 슬래시 명령 목록은 고정이다 않다

제품, 버전, 환경마다 사용 가능한 명령이 다를 수 있습니다. 현재 환경의 **자동완성 목록**을 보는 편이 더 믿을 만합니다.

### 3. 슬래시 명령을 쓰면 승인·샌드박스의 영향을 받지 않는다

뒤에 파일 쓰기, 명령 실행, 네트워킹이 있으면, 현재 정책의 제약을 그대로 받습니다.

### 4. 슬래시 명령을 모르면 Codex를 잘 못 쓴다

자연어만으로도 대부분의 작업을 끝낼 수 있습니다. 슬래시 명령은 조금 익숙해진 뒤, 속도를 내고 고정 입구를 탈 때 더 유용합니다.

## 흔한 범주(예시)

아래 이름은 버전에 따라 늘거나 줄 수 있으며, **학습용 분류일 뿐입니다**.

### 세션과 모드

- 계획 모드 전환, 컨텍스트 압축, 도움말 보기
- [계획](/guide/agent-work/planning/)과 함께

### 검토와 품질

- 현재 diff 또는 PR 검토
- [diff 검토](/guide/quality/review-diffs/)와 결합

### 워크스페이스와 Git

- 상태 보기, 커밋 설명 생성(커밋 여부는 여전히 확인)
- [사람 승인 패턴](/cases/workflows/human-approval-patterns/)을 따름

### 확장

- Skill 설치 또는 목록(환경에 `skill-installer` 등이 있으면)

## 쓸 때 주의

1. **먼저 `/`로 한눈** 현재 환경이 무엇을 지원하는지 보고, 낡은 목록을 외우지 마세요
2. 팀의 고정 흐름은 **Skill + 문서**로 만들어, 「고수만 명령 이름을 아는」 상황을 줄이세요
3. 슬래시 명령이 트리거하는 쓰기 동작도 샌드박스와 승인의 제약을 받습니다

## 바로 써 보는 방법

이렇게 해보세요.

1. `/`를 입력
2. 현재 환경에 무엇이 있는지 봄
3. 이름과 용도를 이해할 수 있는 것부터 시도

## 처음에는 이렇게

처음 시도할 때 이 순서로:

1. 먼저 `/`를 입력해 현재 환경이 무엇을 제공하는지 봄
2. 용도를 이해할 수 있는 명령을 한 번 시도
3. “모드 전환”에 가까운지 “흐름 실행”에 가까운지 관찰
4. 팀이 오래 재사용할 흐름이면 Skill로 쌓을지 고려

둘의 역할이 더 잘 보입니다. 슬래시 명령은 빠른 입구에, Skill은 장기 재사용 흐름에 가깝습니다.

## CLI 명령과의 차이

| | 채팅 안 `/` | 터미널 `codex …` |
|---|---|---|
| 컨텍스트 | 현재 세션과 @ 파일 | `--cwd`로 지정한 디렉터리 |
| 적합 | 대화형 탐색 | 스크립트, CI |

슬래시 명령은 채팅의 빠른 입구로 보면 됩니다. 현재 환경이 실제로 제공하는 것을 먼저 보는 편이, 명령 이름을 외우는 것보다 유용합니다.

CLI 하위 명령은 [CLI 대화형 모드](/guide/cli/interactive-mode/)와 [비대화형 모드](/guide/cli/non-interactive-mode/)를 보세요. 완전한 파라미터 표는 [CLI 명령 참고](/guide/reference/commands/)를 보세요.
