슬래시 명령을 처음 보면 모두 외워야 하는 낯선 용어처럼 느껴질 수 있습니다. 필요한 기능을 이름으로 바로 불러오는 빠른 실행 메뉴라고 생각하면 이해하기 쉽습니다.

대개 정해진 모드나 내장된 절차를 빠르게 시작할 때 사용합니다. 슬래시 명령(`/command`)과 [Skill](/ko/skills/overview/)의 `$name` 호출은 관련은 있지만 같은 것은 아닙니다. 구체적인 명령 목록은 **제품과 접근 권한에 따라 달라지고**, 데스크톱 App, CLI, IDE, ChatGPT Web이 제공하는 목록도 서로 다릅니다. 사용하기 전에 현재 composer에서 `/` 자동 완성과 공식 문서를 확인하세요.

## 개념 구분

| 시작 방법 | 누가 시작하나 | 일반적인 용도 |
|---|---|---|
| `/review` 같은 슬래시 명령 | 사용자가 `/` 입력 | 내장되거나 설정된 고정 절차 |
| `$skill-name` | 사용자 또는 모델 | 프로젝트 또는 사용자 Skill |
| 자연어 | 사용자 | 일반적인 작업 |

## 세 가지를 바로 구분하기

- `/명령`: 채팅에서 빠른 실행 메뉴를 사용자가 직접 선택합니다.
- `$skill`: 사용자 또는 모델이 특정 Skill을 이름으로 지정합니다.
- 자연어: 요구 사항을 직접 설명하고 모델이 수행 방법을 판단하게 합니다.

이미 알고 있는 절차를 빠르게 시작하고 싶다면 `/명령`을 사용하는 편이 간단합니다.

## 슬래시 명령이란

- 터미널 명령이 아닙니다.
- 외워야 하는 비밀 용어가 아닙니다.
- 채팅 화면의 “바로가기 버튼”과 비슷하다고 생각하면 됩니다.

특히 다음 상황에 적합합니다.

- 시작하려는 절차를 이미 알고 있습니다.
- 매번 같은 의도를 처음부터 다시 설명하고 싶지 않습니다.

## 흔한 오해

### 1. 슬래시 명령은 터미널 명령이다

슬래시 명령은 채팅 화면의 바로가기이며, shell에서 실행하는 `codex ...` 명령이 아닙니다.

### 2. 슬래시 명령 목록은 언제나 같다

제품, 버전, 환경에 따라 사용 가능한 명령이 달라질 수 있습니다. 현재 환경의 **자동 완성 목록**을 확인하는 편이 정확합니다.

### 3. 슬래시 명령을 쓰면 승인과 샌드박스의 영향을 받지 않는다

명령이 파일 쓰기, 명령 실행, 네트워크 접근 등을 일으킨다면 현재 정책의 제한을 그대로 받습니다.

### 4. 슬래시 명령을 모르면 Codex를 잘 사용할 수 없다

대부분의 작업은 자연어만으로도 처리할 수 있습니다. 슬래시 명령은 어느 정도 익숙해진 뒤 속도를 높이고 정해진 진입점을 사용할 때 더 유용합니다.

## 현재 자주 쓰이는 진입점

### 데스크톱 App / IDE

- `/plan`: 여러 단계의 계획 모드로 전환
- `/review`: 커밋되지 않은 변경 또는 기준 브랜치와의 차이 검토
- `/status`: chat ID, 컨텍스트 사용량, rate limits 확인
- `/mcp`: MCP 연결 상태 확인
- `/init`: 현재 프로젝트의 `AGENTS.md` 기본 구조 생성

### CLI 전용 세션 제어

- `/permissions`: 현재 세션의 권한 방식 조정
- `/agent`: Agent 스레드 확인 또는 전환
- `/model`: 현재 모델 선택
- `/status`: 현재 세션 설정 확인

ChatGPT Web에는 자체 composer 명령 메뉴가 있습니다. 데스크톱 App이나 CLI의 명령을 Web에서 같은 이름으로 쓸 수 있다고 가정하지 마세요.

## 사용할 때 주의할 점

1. 먼저 `/`를 입력해 **현재 환경에서 지원하는 명령을 확인**하세요. 오래된 목록을 외우지 마세요.
2. 팀이 반복해서 쓰는 고정 절차는 **Skill과 문서**로 만들어, 이름을 아는 숙련자만 사용할 수 있는 상황을 줄이세요.
3. 슬래시 명령이 일으키는 쓰기 작업도 샌드박스와 승인 정책의 적용을 받습니다.

## 바로 시험하는 방법

다음처럼 바로 시험할 수 있습니다.

1. `/`를 입력합니다.
2. 현재 환경에 무엇이 있는지 확인합니다.
3. 이름과 용도를 이해할 수 있는 항목 하나를 골라 사용해 봅니다.

## 처음이라면 이렇게 시험하세요

처음 시도할 때는 다음 순서가 좋습니다.

1. `/`를 입력해 현재 환경이 제공하는 명령을 확인합니다.
2. 용도를 이해한 명령 하나를 선택해 사용합니다.
3. 이 명령이 “모드 전환”에 가까운지 “절차 실행”에 가까운지 살펴봅니다.
4. 팀이 오래 반복해 사용할 절차라면 Skill로 정리할지 고려합니다.

이렇게 하면 두 기능의 역할이 드러납니다. 슬래시 명령은 빠른 진입점에, Skill은 오래 재사용할 절차에 가깝습니다.

## CLI 명령과의 차이

| | 채팅 안의 `/` | 터미널의 `codex …` |
|---|---|---|
| 컨텍스트 | 현재 세션과 첨부 파일 | `--cd` / `-C`로 지정한 디렉터리 |
| 적합한 용도 | 상호작용하며 탐색 | 스크립트와 CI |

슬래시 명령을 채팅의 빠른 진입점으로 생각하세요. 명령 이름을 무작정 외우기보다 현재 환경에서 실제로 제공하는 항목을 확인하는 편이 유용합니다.

CLI 하위 명령은 [CLI 대화형 모드](/ko/guide/cli/interactive-mode/)와 [비대화형 모드](/ko/guide/cli/non-interactive-mode/)를 참고하세요. 전체 인수 표는 [CLI 명령 참조](/ko/guide/reference/commands/)에 있습니다.
