단축키는 **클라이언트와 버전**에 따라 차이가 큽니다. 이 페이지는 **조작 의도**로 분류해, 더 빠른 방법이 있는지 판단하기 쉽게 합니다. 구체 키는 제품 안 도움말이나 설정에서 확인하세요.

단축키를 한숨에 다 외울 필요는 없습니다. 조작 리듬을 가장 자주 끊는 몇 가지 동작만 익혀도 이미 충분히 유용합니다.

:::caution
아래 표는 **예시**이며 완전한 바인딩 표가 아닙니다. 업그레이드 후 키가 바뀔 수 있습니다.
:::

## 일반 의도 색인

| 의도 | 데스크톱 App(예시) | CLI TUI(예시) | IDE 확장(예시) |
|---|---|---|---|
| 새 작업/세션 | `Cmd/Ctrl+N` 또는 사이드바 | 종료 후 재진입 / 새 스레드 명령 | 명령 팔레트 「Codex」 |
| 메시지 보내기 | `Enter` / `Cmd+Enter` | 제품 설명 따름 | 패널 안 전송 |
| 줄바꿈만(전송 안 함) | `Shift+Enter` | TUI에 따름 | 패널에 따름 |
| 명령 팔레트 열기 | `Cmd/Ctrl+K`류 | `/` 슬래시 명령 | `Cmd/Ctrl+Shift+P` |
| 이력 검색 | 사이드바 검색 | 세션 안 검색(있으면) | 채팅 이력 |
| 도구 호출 승인 | 패널 버튼 | `y` / 방향 키(TUI에 따름) | 알림 또는 인라인 버튼 |
| 거부 | 패널 버튼 | `n` | 인라인 거부 |

**설치한 버전의 UI를 기준으로 하세요.**

## 어떤 동작을 먼저 익힐까

단축키의 가치는 이런 막힘을 줄이는 데 있습니다.

- 메시지를 보낼 때 버튼을 찾아야 함
- 줄바꿈하려다 잘못 전송
- 동작을 승인할 때 허둥댐
- 새 작업을 열 입구를 모름

전체 세트를 외우기보다, 먼저 이 4종류를 익히는 편이 낫습니다.

- 전송 / 줄바꿈
- 새 작업
- 명령 팔레트
- 승인 / 거부

## 슬래시 명령 vs 키보드

- **슬래시 명령**：`/review`, `/help` 등——[슬래시 명령 빠른 조회](/guide/reference/slash-commands/)
- **단축키**：글자를 치지 않고 UI 동작을 바로 트리거

둘을 조합할 수 있습니다. 먼저 `Cmd+K`로 입력에 포커스한 뒤 `/review`.

## CLI 터미널 사용자

- **Ctrl+C**로 폭주하는 출력을 중단하는 법을 익히세요(저장되지 않은 상태를 끊는지 주의)
- 터미널 멀티플렉서(tmux)분할：한쪽은 Codex, 한쪽은 `git diff`
- 자주 쓰는 `codex exec`를 shell alias로——[명령과 단축키](/guide/cli/commands-and-shortcuts/)

## 흔한 오해

### 1. 단축키를 다 외워야 쓰기 시작하는 것은 아니다

가장 자주 트리거하는 동작 몇 가지만 익히면 비용이 훨씬 낮아집니다.

### 2. 남이 능숙하다고 지금 내가 서툰 것은 아니다

단축키는 익숙해진 뒤 생기는 근육 기억이지, 입문 문턱이 아닙니다.

### 3. 모든 클라이언트를 같은 키로 억지로 통일할 필요 없다

더 중요한 것은 다음을 아는 것입니다.

- 이 동작에 단축키가 있는지
- 어디서 보고 바꿀 수 있는지
- 어느 동작을 먼저 바인딩할 가치가 있는지

## 처음에는 이것부터

처음 쓸 때 이 동작을 먼저 익히세요.

1. 어떻게 보내는지
2. 어떻게 줄바꿈만 하는지
3. 어떻게 명령 팔레트를 여는지
4. 어떻게 승인하거나 거부하는지
5. 어떻게 새 작업을 여는지

이 5가지가 익숙해지면, 나머지 단축키는 쓰면서 보완하면 됩니다.

## IDE 사용자

- 「Codex로 선택한 코드 설명」을 편한 키에 바인딩
- 에디터 네이티브 diff, 정의 점프와 함께 써 복붙을 줄임

[IDE 설정](/guide/ide/settings/) · [선택한 코드와 연 파일](/guide/ide/selected-code-and-open-files/)

## 접근성과 커스텀

대부분 클라이언트는 설정에서 키를 바꿀 수 있습니다. 팀은 **권장 바인딩**을 문서화할 수 있지만, 전원이 같아야 할 필요는 없습니다.

단축키는 시험 범위가 아닙니다. 가장 자주 리듬을 끊는 동작만 익히면 보통 충분합니다.
