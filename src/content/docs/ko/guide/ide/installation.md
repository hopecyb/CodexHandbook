평소 주로 에디터에서 일한다면, 이 페이지는 설치 위치뿐 아니라 다음도 다룹니다.

- IDE 확장으로 시작해도 되는지
- 설치 후 무엇을 봐야 하는지
- 확장은 설치됐는데도 “쓸 수 있는 상태”처럼 느껴지지 않는 이유

IDE 확장이 준비됐다는 것은, 목록에 나타나기만 한 상태가 아니라, 올바른 에디터와 워크스페이스에서 정상적으로 호출할 수 있다는 뜻입니다.

## 설치 후 최소한 확인할 것

1. 지금 쓰는 에디터에 확장이 설치됐는지
2. 로그인 또는 인증이 끝났는지
3. 연 워크스페이스가 실제로 다룰 프로젝트인지
4. 확장 진입점·명령·사이드바가 정상적으로 나타나는지

## 흔한 오해

### 1. Marketplace에서 설치만 누르면 바로 쓸 수 있나요

이후에도 종종 몇 단계가 더 필요합니다.

- 로그인
- 창 다시 로드
- 올바른 워크스페이스 열기

### 2. IDE 확장과 CLI는 완전히 같은 것인가요

하위 능력은 통할 수 있지만, 사용 입구와 컨텍스트 출처가 다릅니다.  
IDE는 “지금 어떤 파일·어떤 프로젝트를 열었는지”에 더 의존합니다.

IDE 확장이 정말 준비됐는지는, 현재 에디터와 워크스페이스에서 정상적으로 호출할 수 있는지로 판단합니다.
