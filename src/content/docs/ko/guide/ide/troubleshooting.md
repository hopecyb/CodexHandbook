IDE 문제 해결은 CLI와 다릅니다.  
많은 문제가 “확장이 안 된다”처럼 보이지만, 실제로는 **워크스페이스·로그인 상태·에디터 자체의 컨텍스트**가 어긋난 경우가 많습니다.

IDE에 문제가 생기면, “확장이 안 떴는지”와 “확장은 떴지만 받은 컨텍스트가 틀렸는지”를 먼저 구분하세요.

| 증상 | 먼저 시도 |
|---|---|
| 확장이 응답 없음 | 확장과 에디터 업데이트; 확장 호스트 로그 확인 |
| 로그인 상태 소실 | 다시 인증 |
| 컨텍스트가 틀림 | 연 워크스페이스 루트 확인 |

## 먼저 3가지로 나눕니다

- **완전 무반응**: 대개 확장 로드 문제
- **열리지만 쓸 수 없음**: 대개 로그인·인증 문제
- **답이 틀리거나 잘못된 곳을 수정**: 대개 워크스페이스·컨텍스트 문제

## 흔한 오해

### 1. 확장 아이콘이 있으면 확장이 정상인가요

아이콘이 있다는 것은 설치됐다는 뜻일 뿐입니다. 현재 세션이 정상인지는 보장하지 않습니다.

### 2. 컨텍스트가 틀리면 모델 이해가 부족한가요

많은 경우 이해가 부족한 게 아니라, 연 루트·파일 선택 범위·워크스페이스 자체가 틀린 것입니다.

### 3. 확장을 다시 설치하는 게 첫 단계인가요

처음부터 그렇게 할 필요는 없습니다.

먼저 확인하세요.

- 에디터 버전
- 확장 버전
- 로그인 상태
- 현재 워크스페이스

여기까지면 많은 문제를 짚을 수 있습니다.

## 점검 순서

1. 확장이 응답하는지 봅니다
2. 로그인 상태를 확인합니다
3. 현재 워크스페이스 루트와 열린 파일을 확인합니다
4. 그래도 안 되면 확장 로그를 봅니다

IDE 문제의 가장 흔한 원인은 워크스페이스·로그인 상태·컨텍스트 출처가 틀린 경우이며, 확장이 망가진 경우는 상대적으로 적습니다.

공식 설명은 [OpenAI Codex 문서](https://developers.openai.com/codex)를 보세요.
