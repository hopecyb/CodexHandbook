Codex는 속도를 높여 주지만, 최종 확인 책임을 대신하지 않습니다.

Codex는 속도를 높이되, **수락을 면제하지 않습니다**. 최소한 아래를 재검토하세요.

1. [차이](/ko/guide/quality/review-diffs/)를 읽기: 어떤 파일을 고쳤는지, 범위를 넘었는지
2. 당신이 정의한 완료 기준으로 확인
3. 테스트를 돌릴 수 있으면 돌리기: [테스트 실행](/ko/guide/quality/run-tests/)
4. 대외 사실은 출처를 확인: [출처 확인](/ko/guide/quality/validate-sources/)

## 사람 검토가 보는 것

「사람 검토」는 모든 일을 다시 하라는 뜻이 아닙니다. 인도를 책임지는 관점에서 아래만 확인하면 됩니다.

- 맞게 고쳤는지
- 너무 많이 고치지 않았는지
- 핵심 조건을 빠뜨리지 않았는지
- 이 결과를 정말 넘길 수 있는지

## 흔한 오해

### 1. 결과가 「그럴듯해 보이면」 끝내도 되나?

「맞을 것 같아 보인다」는 종종:

- 문장은 자연스럽지만 사실이 틀릴 수 있음
- 페이지는 멀쩡해 보이지만 핵심 흐름을 안 써 봄
- 코드는 돌아가지만 경계 조건을 안 테스트함

### 2. 사람 검토는 AI가 가치 없다는 뜻인가?

AI는 속도를, 당신은 기준과 최종 관문을 맡습니다.

### 3. 검토는 코드 작업만 필요한가?

아래도 마찬가지입니다.

- 조사 결론
- 문서 내용
- 표와 집계
- 데모 자료
- 설정과 스크립트

## 검토할 때 이 순서

시간이 부족하면:

1. 범위가 넘치지 않았는지
2. 원래 원한 것을 충족하는지
3. 자동 검증할 수 있으면 우선 자동으로
4. 남은 가장 핵심 한 단계를 사람 관점으로

사람 검토의 역할은 최종 결정을, 결과에 책임지는 사람에게 남기는 것입니다.
