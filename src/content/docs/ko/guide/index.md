# Codex 가이드

여기에서는 Codex가 무엇인지, 어디에 잘 맞는지, 그리고 첫 사용에서 안정적인 워크플로로 어떻게 넘어가는지를 안내합니다.

이 핸드북을 처음 열었다면, 처음부터 끝까지 읽어야 하는 책처럼 대하지 않아도 됩니다. 「첫 사용부터 점점 익숙해지기」까지의 로드맵으로 보는 편이 자연스럽습니다.

모든 용어·제품·워크플로를 먼저 다 알 필요는 없습니다. 지금 있는 단계를 찾은 뒤, 순서대로 앞으로 나아가면 됩니다.

## 이 파트에서 다루는 내용

- Codex를 처음 접할 때 어디를 보면 되는지
- 어떤 클라이언트를 먼저 고를지
- 첫 작업을 마친 뒤 다음에 어떤 역량을 보완할지
- 권한·컨텍스트·검증 문제가 생겼을 때 어느 장으로 돌아갈지

## 흔한 오해

### 1. 핸드북 전체를 읽고 나서야 써야 한다

대부분의 사람에게 더 맞는 리듬은 다음과 같습니다.

- 가장 기본적인 안전과 협업 방식을 먼저 이해합니다
- 작은 작업을 한 번 끝까지 돌려 봅니다
- 실제 문제를 들고 돌아와 필요한 부분을 보충 읽습니다

### 2. 장이 많으니 지금은 시작할 때가 아니다

장이 많은 이유는 나중에 되찾아볼 곳이 있도록 한 것이지, 처음부터 전부 익혀야 한다는 뜻이 아닙니다.

### 3. 클라이언트만 고르면 나머지는 나와 무관하다

클라이언트는 입구가 다를 뿐입니다. 권한·컨텍스트·검증 같은 핵심 개념은 모든 입구에서 반복적으로 등장합니다.
