**Computer Use**는 Agent가 사람처럼 화면을 보고, 포인터를 움직이고, 글자를 입력하게 합니다. 브라우저나 터미널에 한정되지 않습니다. 능력이 가장 강하고, **위험과 승인 요구도 가장 높습니다**.

Computer Use는 화면·마우스·키보드 층에서 직접 동작하며, 브라우저 도구·터미널과 다른 종류의 능력입니다. 그만큼 신중히 켜야 합니다.

## 이 페이지 내용

- Computer Use와 브라우저·터미널의 역할 분담
- 어떤 작업이 켤 가치가 있는지
- 개인과 팀이 어떻게 방비하는지

## 능력 경계

| 계층 | 전형 능력 |
|---|---|
| 터미널 | Shell, 스크립트, CLI 프로그램 |
| 브라우저 | 웹 DOM, 제한된 상호작용 |
| Computer Use | 데스크톱 앱, 시스템 대화상자, 다중 창 워크플로 |

## 다른 도구와 무엇이 다른가

다른 도구와 이렇게 구분하세요.

- 데스크톱 전체에서 일함
- 여러 창을 오감
- 실제 버튼과 시스템 팝업을 누름

그래서 닿는 인터페이스와 정보 범위도 보통 더 큽니다.

적합:

- API가 없는 소프트웨어의 반복 클릭 흐름(당신이 감독)
- 앱 간 데이터 복사(컴플라이언스 전제)
- 데스크톱 App 자체의 동작 검증

부적합:

- 일상 코딩(IDE + 터미널이 더 효율)
- 무인 프로덕션 조작
- 보안 소프트웨어나 DRM 우회

## 흔한 오해

### 1. 능력이 강하니 우선 써야 하나?

다음일 때만 가치가 더 분명합니다.

- 작업이 정말 데스크톱 GUI를 다룸
- 더 가볍고 안전한 도구로 끝낼 수 없음

### 2. 옆에서 보면 위험이 없나?

사람이 있으면 더 안전하지만 여전히:

- 확인 상자를 잘못 누름
- 열면 안 되는 창을 염
- 화면의 민감 정보를 흐름에 끌어들임

### 3. 모든 GUI 자동화를 대체하나?

임시 지원, 흐름 검증, API 없는 GUI 단계에 맞고, 안정·장기·무인 프로덕션 자동화 방안으로는 맞지 않습니다.

## 위험 모델

Computer Use는 거의 **키보드·마우스를 Agent에 넘기는 것**과 같습니다.

- 메일, 채팅, 파일 관리자를 열 수 있음
- 확인 대화상자를 잘못 누를 수 있음
- 화면에 알림의 민감 정보가 있을 수 있음

필독: [권한과 승인](/guide/foundations/permissions-and-approvals/), [샌드박스와 네트워크](/guide/foundations/sandbox-and-network/)

## 쓸지 말지 판단하기

목표가 다음뿐이면 Computer Use를 먼저 쓸 필요는 보통 없습니다.

- 코드 수정
- 테스트 실행
- 웹페이지 보기
- 자료 조회

대부분 더 가벼운 도구로 끝납니다.

다음이면 켜기를 고려하세요.

- 데스크톱 앱을 반드시 조작
- 여러 GUI 창을 반드시 오감
- 브라우저와 터미널이 닿지 못하는 인터페이스를 처리

그때 진지하게 고려할 가치가 있습니다.

## 권장 사용법

1. **전용 환경**: 가상머신 또는 보조 사용자 계정, 화면에 프라이버시 창 없음
2. **작업 최소화**: 「Calculator에서 수식 검증」 — 「모든 메일 처리」가 아님
3. **사람이 루프에**: 보이게 두고, 언제든 중단 준비
4. **녹화/로그**: 팀 회고용(녹화에도 민감 정보)
5. **끝난 뒤 점검**: 파일시스템, 클립보드, 열린 앱

기업 환경은 기본 비활성일 수 있습니다. 호스팅 정책을 따릅니다.

## 브라우저 도구와의 선택

```text
웹페이지만 보면?        → 브라우저 도구
IDE 밖 앱을 조작?  → Computer Use(더 신중)
코드만 고치고 테스트?  → 터미널 + 파일 도구
```

[도구 선택](/guide/tools/tool-selection/)을 보세요.

## 바로 쓸 수 있는 쓰기

이렇게 쓰세요.

```text
Calculator와 로컬 테스트 앱만 조작하고, 메일·채팅·파일 관리자·프로덕션 백오피스는 열지 마세요.
시스템 확인 상자가 나오면 먼저 멈추고 설명한 뒤 계속하세요.
```

## 흔한 실수

- 주 데스크톱에서 신뢰하지 않는 프로젝트의 Computer Use를 돌림
- 화면에 2FA·은행·고객 데이터가 있는데 작업을 계속
- GUI 자동화를 완전한 테스트 전략으로 둠

## 검증 체크리스트

- [ ] 격리 환경에서만 켬

- [ ] 조직 정책이 해당 능력을 허용
