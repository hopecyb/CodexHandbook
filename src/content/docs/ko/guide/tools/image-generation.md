Codex는 일부 장면에서 **이미지 생성** 능력을 호출할 수 있습니다. 일러스트, 아이콘 초안, UI 컨셉, 도식. 생성 결과는 **검증 대기 산출물**로 보고, 바로 올릴 브랜드 자산으로 보지 마세요.

시각 초안을 먼저 내기에 맞고, 최종 완성품으로 바로 두기엔 맞지 않습니다.

## 이 페이지 내용

- 언제 Codex에서 이미지를 만들고, 언제 전문 도구를 쓰는지
- 이미지 prompt와 제약을 어떻게 쓰는지
- 저작권, 브랜드, 파일 관리

## 적용 장면

| 적합 | 부적합 |
|---|---|
| 블로그 삽화 초안, 내부 문서 도식 | 엄격한 브랜드 핸드북이 있는 대외 자료 |
| UI 레이아웃 분위기의 빠른 탐색 | 픽셀 단위 재현이 필요한 디자인 납품 |
| 튜토리얼 예시 아이콘 | 승인되지 않은 실물 초상 |

[이미지 프롬프트](/prompts/prompting-with-images/)와 보완 관계입니다. 그 페이지는 **입력** 이미지, 이 페이지는 **출력** 이미지입니다.

## 이미지 생성이 잘 맞는 일

다음에 더 맞습니다.

- 방향을 빠르게 냄
- 시각 개념을 보게 함
- 글·문서·프로토타입에 쓸 수 있는 스케치를 먼저 맞춤

다음은 생성 결과에 바로 맡기면 안 됩니다.

- 정식 브랜드 자료인 척
- 정밀 디자인 시안인 척
- 바로 대외 배포할 최종 시각인 척

## 권장 워크플로

1. 용도, 화면비, 스타일 키워드를 설명(침해성 스타일명 나열 피함)
2. 출력 형식(PNG/SVG 지원 시)과 저장 경로를 요구
3. 생성 후 [산출물 검증](/guide/quality/verify-artifacts/): 파일 열기, 해상도·가독성 점검
4. 대외 배포 전 디자인 또는 법무 재검토

## 흔한 오해

### 1. 화면이 예쁘면 쓸 수 있다?

다음도 봐야 합니다.

- 장면이 용도에 맞는지
- 세부가 기이하지 않은지
- 글자가 깨지지 않았는지
- 스타일이 내용과 맞는지

### 2. “그림 하나 만들어 줘” 한 줄이면 되나?

보통 부족합니다.  
최소한:

- 용도
- 가로·세로·정사각
- 스타일 방향
- 글자 포함 여부
- 파일 형식

### 3. 이미지 생성이 디자이너를 대체하나?

다음에 가깝습니다.

- 전기 탐색 도구
- 콘텐츠 삽화 도구
- 개념 스케치 도구

엄격한 디자인 납품의 대체품은 아닙니다.

## 어떻게 쓸 수 있나

이 구조로 요청하세요.

1. 이 그림을 어디에 쓰는지
2. 가로·세로·정사각이 필요한지
3. 어떤 분위기와 배색을 원하는지
4. 글자가 나와도 되는지
5. 출력 후 어떻게 검증할지

## 파일과 저장소

- 큰 그림은 `assets/` 또는 CDN, Git 용량을 평가
- PR에 생성 prompt와 모델 버전을 적음(내부 감사)
- [이미지와 스크린샷](/guide/files-and-artifacts/images-and-screenshots/) 참고

## 보안과 컴플라이언스

- 민감 표식, 가짜 신분증, 타인 초상의 오도 콘텐츠를 생성하지 않음
- 기업 정책이 일부 소재를 금지할 수 있음 — [acceptable use](https://openai.com/policies/)와 내부 규정을 따름

## 참고 출처

- OpenAI Help Center: Images in ChatGPT
- OpenAI Academy: Creating images with ChatGPT

## 흔한 실수

- 압축하지 않은 4K 그림을 바로 저장소에 커밋
- 생성 그림으로 실사나 공식 logo를 가장
- prompt에 「글자 없음」을 제약하지 않아 깨진 자막이 생김

이미지 생성은 방향과 초안을 먼저 내기에 맞고, 대외 납품 시에는 여전히 정식 산출물 기준으로 검증해야 합니다.
