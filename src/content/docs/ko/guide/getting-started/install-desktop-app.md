1. 공식 Codex 문서의 데스크톱 앱 다운로드 안내를 엽니다: [https://developers.openai.com/codex](https://developers.openai.com/codex)
2. 운영체제에 맞는 설치 패키지를 골라 설치합니다
3. 앱을 실행하고, 로그인이나 프로젝트 입구가 보이는지 확인합니다

Codex를 처음 쓰고 터미널을 먼저 다루고 싶지 않다면, 데스크톱 App이 비교적 직접적인 입구입니다.
여기서 더 중요한 것은, 설치 후 어떤 상태여야 「쓰기 시작한」 것으로 볼 수 있는지입니다.

## 설치 후 확인

- 앱이 정상적으로 열림
- 시스템 권한(파일 접근 등)은 필요에 따라 부여. 무관한 디스크 권한을 한꺼번에 주지 마세요
- 인터페이스 개요는 [설치와 인터페이스](/guide/desktop-app/installation-and-interface/)

## 흔한 오해

### 1. App이 실행되면 문제없다

더 확인할 가치가 있는 것:

- 정상 로그인 가능한지
- 프로젝트나 작업 입구가 보이는지
- 권한이 맞게 주어졌는지

### 2. 시스템이 권한 창을 띄우면 전부 허용한다

필요에 따라 부여하는 편이 안전합니다. 무관한 디스크나 시스템 능력을 한 번에 열지 마세요.

### 3. 설치 직후 바로 큰 작업을 해야 한다

처음에는 작은 것부터 확인하세요.

- 로그인에 문제 없음
- 페이지가 정상으로 열림
- 프로젝트 입구와 기본 인터페이스 위치를 앎

데스크톱 App을 설치한 뒤에는, 정상 열기·로그인·입구 확인을 한 뒤 첫 작업을 하세요.

실패 시: [데스크톱 App 문제 해결](/guide/desktop-app/troubleshooting/).
