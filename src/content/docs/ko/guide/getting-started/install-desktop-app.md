이 핸드북에서 말하는 ‘데스크톱 App’은 현재 **ChatGPT 데스크톱 App 안의 Codex 작업 공간**을 뜻합니다. 공식적으로 macOS, Windows, Linux 버전이 제공됩니다.

## 설치 단계

1. [ChatGPT 데스크톱 App 공식 안내](https://learn.chatgpt.com/docs/app)를 엽니다.
2. 공식 경로에서 운영체제에 맞는 설치 파일을 다운로드합니다.
3. ChatGPT를 설치하고 실행한 뒤 ChatGPT 계정이나 사용 가능한 다른 방식으로 로그인합니다.
4. 새 채팅을 시작하거나 프로젝트를 만들거나 연습용 폴더를 엽니다.
5. Codex로 이동해 새 작업을 만들고 원하는 결과를 설명합니다.

검색 결과에 나오는 제삼자 다운로드 사이트에서 설치 파일을 받지 마세요. 회사 장치에 관리자가 일괄 배포한다면 조직의 소프트웨어 배포 및 업데이트 정책을 따르세요.

## 설치 후 최소 점검

비밀 키가 없는 연습용 디렉터리를 준비하고 다음을 확인합니다.

- App이 정상적으로 열리고 현재 계정 또는 작업 공간이 표시됩니다.
- 해당 디렉터리를 열거나 프로젝트에 파일을 추가할 수 있습니다.
- Codex 작업을 만들고 응답을 받을 수 있습니다.
- 파일 접근 권한이 이번 작업에 필요한 범위에만 적용됩니다.
- 작업 결과, 파일 변경 사항, 승인 요청을 어디에서 확인하는지 알 수 있습니다.

다음 읽기 전용 작업으로 기본 동작을 시험할 수 있습니다.

```text
이 디렉터리만 읽고 파일은 수정하지 마세요. 어떤 파일이 있는지, 어떤 프로젝트로 보이는지 알려 주고 그렇게 판단한 파일 이름을 설명해 주세요.
```

## 자주 묻는 문제

### App은 열리지만 Codex가 보이지 않음

먼저 현재 계정, 작업 공간, 요금제의 접근 권한을 확인하고 조직에서 해당 기능을 비활성화했는지 살펴보세요. 계정이나 관리자 정책을 우회하려고 반복해서 재설치하지 마세요.

### 시스템에서 파일, 손쉬운 사용 또는 앱 제어 권한을 요청함

현재 작업에 정말 필요한 권한인지 먼저 확인하세요. 연습용 디렉터리만 열 때는 관련 없는 디스크나 시스템 기능까지 함께 허용할 필요가 없습니다. 판단 방법은 [권한과 샌드박스](/ko/guide/permissions-and-sandbox/)를 참고하세요.

### 설치 후 화면이 스크린샷과 다름

데스크톱 App은 자주 업데이트됩니다. 특정 버튼의 고정된 위치에 의존하지 말고 ‘로그인할 수 있는가, 작업 위치를 선택할 수 있는가, 작업을 시작할 수 있는가, 결과를 검토할 수 있는가’를 성공 기준으로 삼으세요.

자세한 화면 설명은 [설치와 화면 구성](/ko/guide/desktop-app/installation-and-interface/)에서, 문제가 생겼을 때는 [데스크톱 App 문제 해결](/ko/guide/desktop-app/troubleshooting/)에서 확인하세요.
