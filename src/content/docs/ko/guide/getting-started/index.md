목표는 **안전한 연습 프로젝트**에서 첫 작업을 마치고, 확인·수락·수정·철회를 익히는 것입니다.

기본은 **데스크톱 App**입니다. 터미널이나 편집기가 더 익숙해도 설치 페이지는 그대로 쓰며, 첫 작업 예시는 차이를 적습니다.

「어떻게 시작할지」「처음에 어떻게 실수하지 않을지」가 가장 궁금하다면, 이 장이 가장 직접적인 입구입니다.

## 이 장에 포함된 것

- 첫 시작 전에 최소한 무엇을 준비할지
- 설치·로그인·연습 프로젝트 생성 순서
- 첫 작업이 어느 정도여야 「합격」인지
- 끝난 뒤 어떻게 확인하고 철회할지

## 흔한 오해

### 1. 첫 작업부터 중요 프로젝트를?

권하지 않습니다.

첫 번째는 안전한 연습 프로젝트에서 작은 작업이 더 안전합니다. 흐름을 익힌 뒤 정식 내용에 손대세요.

### 2. 설치만 되면 이미 익숙해진 것인가?

충분하지 않습니다.  
적어도 아래까지 해야 진짜로 「익숙해진」 것입니다.

- 명확한 작업을 시작할 수 있음
- 결과를 이해할 수 있음
- 수락·수정·철회를 결정할 수 있음

### 3. 첫 작업이 클수록 학습 가치가 큰가?

대개는 오히려 인내를 잃기 쉽습니다.  
첫 작업이 작고 확인하기 쉬울수록 기본 판단을 쌓기 쉽습니다.

## 권장 순서

이 최소 루프로 가세요.

1. 클라이언트 고르기
2. 설치하고 로그인
3. 안전한 연습 프로젝트 만들기
4. 아주 작은 작업 하나
5. 결과 확인
6. 철회나 수정 익히기

이 루프가 통하면, 더 복잡한 내용을 배우기가 수월해집니다.
