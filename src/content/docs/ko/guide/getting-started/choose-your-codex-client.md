먼저 작업이 주로 어디에서 이뤄지는지 살펴보세요.

| 주로 작업하는 곳 | 시작할 곳 |
|---|---|
| 데스크톱에서 프로젝트, 파일, 여러 작업을 관리함 | **ChatGPT 데스크톱 App** |
| 터미널에서 Git, 테스트, 스크립트를 실행함 | **Codex CLI** |
| VS Code, 호환 편집기, Xcode, JetBrains에서 코드를 작성함 | **IDE 통합** |
| 연결된 원격 저장소와 격리된 환경에서 작업함 | **Codex Cloud** |

처음 사용하고 뚜렷한 선호가 없다면 데스크톱 App부터 설치해 볼 수 있습니다. 작업, 파일, diff, 승인 요청을 쉽게 확인할 수 있습니다. 처음 선택한 진입점에 계속 머물 필요는 없습니다. 하나의 작업 흐름을 IDE에서 시작하고 CLI에서 검증한 뒤, 데스크톱 App이나 Cloud에서 긴 작업을 이어갈 수 있습니다.

전체 선택 흐름도, 클라이언트 조합 예시, 검증 단계는 [Codex 클라이언트 선택 가이드](/ko/guide/choose-your-client/)에서 확인하세요. 기능을 항목별로 비교하려면 [기능 비교](/ko/guide/reference/feature-comparison/)를 참고하세요.

다음으로 해당 설치 페이지를 선택하세요.

- [CLI 설치](/ko/guide/getting-started/install-cli/)
