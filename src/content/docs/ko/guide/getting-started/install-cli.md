공식 CLI 설치 안내에 따르세요: [https://developers.openai.com/codex](https://developers.openai.com/codex)(보통 패키지 관리자나 공식 설치 스크립트. 현재 문서 기준).

평소 터미널을 자주 쓰면 CLI가 더 손에 익습니다.  
처음 설치할 때 막히기 쉬운 지점은 대개:

- 설치 후 「반만」 된 것이 아닌지 어떻게 확인하는지
- 명령은 설치했는데 터미널이 못 찾는 이유
- 언제 PATH / 인증으로 돌아가고, 언제 재설치하지 말아야 하는지

CLI가 잘 설치됐는지는, 현재 터미널이 `codex`를 안정적으로 인식하는지가 핵심입니다.

## 설치 후 확인

터미널에서 버전이나 도움 명령을 실행합니다(구체 서브커맨드는 공식 기준). 확인:

- 명령을 실행할 수 있음
- 로그인 또는 이미 인증된 상태에 들어갈 수 있음

## 흔한 오해

### 1. 설치 후 모든 터미널 창이 즉시 명령을 안다

터미널을 다시 열거나, 현재 shell의 `PATH`가 갱신됐는지 확인해야 할 때가 있습니다.

### 2. 설치 출력이 성공이면 이미 쓸 수 있다

더 확인할 것은 현재 환경이 그 명령을 찾을 수 있는지입니다.

### 3. CLI 문제는 모두 재설치해야 한다

많은 경우 진짜로 볼 것은:

- `PATH`
- 현재 shell
- 로그인 상태

## 설치 후 점검 방법

1. 먼저 명령을 실행할 수 있는지
2. 다음으로 현재 세션이 로그인·이미 로그인 상태에 들어갈 수 있는지
3. 그래도 안 되면 설치 위치와 PATH를 확인

CLI를 설치한 뒤, 현재 터미널이 그것을 찾고, 인증도 이어갈 수 있어야 합니다.

상세 상호작용은 [CLI 대화형 모드](/guide/cli/interactive-mode/). 문제 해결: [CLI 문제 해결](/guide/cli/troubleshooting/).
