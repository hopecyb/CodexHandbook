설치 단계는 [데스크톱 App 설치](/guide/getting-started/install-desktop-app/)와 [https://developers.openai.com/codex](https://developers.openai.com/codex)를 참고하세요.

데스크톱 App을 처음 열면 화면에 정보가 한꺼번에 나타납니다.

처음부터 모든 영역을 파악할 필요는 없습니다. 가장 위치만 먼저 구분하면 됩니다.

## 화면 영역(논리적 구분)

구체적 라벨 이름은 버전에 따라 달라지므로, 화면의 실제 문구를 기준으로 하세요.

1. **프로젝트 / 워크스페이스 선택**: 현재 연결된 폴더
2. **대화 / 작업 영역**: 프롬프트 입력, Agent 진행 상황 확인
3. **변경 / diff 뷰**: 제안된 변경 검토
4. **터미널 또는 로그**(사용 시): 명령 출력 확인
5. **설정과 계정**: 모델, 권한, 알림 등

시작할 때는 “어디에 작업을 입력하는지”와 “어디에서 파일 변경을 승인하는지”를 먼저 찾으세요.

## 흔한 오해

### 1. 처음부터 모든 패널을 이해할 필요는 없습니다

다음 세 영역만 구분하면 충분합니다.

- 작업을 입력하는 곳
- 변경을 보는 곳
- 승인하거나 거부하는 곳

### 2. 터미널, diff, 설정은 나중에 배워도 되나요?

단계적으로 배워도 됩니다.  
다만 diff 뷰는 변경 범위를 이해하는 데 직결되므로 일찍 익히는 편이 좋습니다.

### 3. 화면이 문서 스크린샷과 다르면 어떻게 하나요?

현재 버전의 실제 문구를 기준으로 하세요.  
여기서 말하는 것은 논리 영역이지, 구체적 버튼 이름이 아닙니다.

“작업 입력”, “변경 확인”, “승인” 세 가지를 먼저 찾은 뒤, 쓰면서 익히면 됩니다.
