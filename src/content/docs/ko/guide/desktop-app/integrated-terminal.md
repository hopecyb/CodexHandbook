통합 터미널은 Agent가 실행한 명령 출력을 보거나, 직접 검증 명령을 실행하기에 편리합니다.

데스크톱 App을 벗어나지 않고도 명령 실행 과정과 결과를 볼 수 있습니다.

처음에는 다음을 살피세요.

- 실제로 무엇을 실행했는지
- 왜 검증 통과라고 말하는지
- 어느 단계에서 실패했는지

## 사용할 때 주의

- 「검증 명령」을 프롬프트의 완료 기준에 넣습니다
- 통합 터미널에 프로덕션 키를 붙여넣지 않습니다
- 이해하지 못한 명령을 프로덕션 환경에서 수동으로 다시 실행하지 않습니다

## 흔한 오해

### 1. 터미널을 써야만 데스크톱 App을 쓸 수 있나요?

많은 기본 작업은 직접 명령을 칠 필요가 없습니다.  
다만 터미널 영역이 무엇을 하는지 알아 두면, 확인할 때 완전히 막히지 않습니다.

### 2. 출력이 길면 무엇을 봐야 하나요?

다음을 살피세요.

- 명백한 오류가 있는지
- 어떤 명령을 실행했는지
- 최종이 성공·실패·부분 완료 중 무엇인지

### 3. 그 명령을 복사해 직접 다시 실행해도 되나요?

가능합니다. 단, 무엇을 하는지 이해한 뒤에만, 특히 프로덕션에서는 맹목적으로 다시 실행하지 마세요.

통합 터미널은 검증 과정을 그대로 보여 주므로, 명령줄이 하는 일을 단계적으로 익히기에도 좋습니다.
