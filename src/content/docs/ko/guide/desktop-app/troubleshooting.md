문제를 해결할 때는 가장 가능성 높고 다루기 쉬운 순서부터 점검합니다.

| 증상 | 먼저 시도 |
|---|---|
| 설치/실행 불가 | 시스템 요구사항과 공식 설치 패키지 확인; 재시작 후 재시도 |
| 로그인 불가 | 네트워크·계정 권한·SSO 확인; 세션을 지우고 다시 로그인 |
| 프로젝트 파일이 안 보임 | 올바른 폴더 추가와 시스템 파일 권한 확인 |
| 작업이 계속 승인 대기 | 작업 뷰로 돌아가 대기 중인 요청을 처리 |
| 변경이 기대와 다름 | 제약을 조이고, 새 스레드를 열고, 컨텍스트를 점검 |

그래도 실패하면: [https://developers.openai.com/codex](https://developers.openai.com/codex)와 [문제 해결 색인](/guide/reference/troubleshooting/).

## 흔한 오해

### 1. 문제가 나면 어딘가 크게 잘못 쓴 건가요?

많은 문제는 다음뿐입니다.

- 경로를 잘못 고름
- 권한을 승인하지 않음
- 작업이 확인을 기다림
- 컨텍스트가 이미 섞임

### 2. “파일이 안 보인다”면 무엇을 먼저 의하나요?

프로젝트 디렉터리와 권한을 먼저 의하세요. 모델 능력부터 의심할 필요는 없습니다.

### 3. “변경이 기대와 다르다”면 어떻게 하나요?

범위를 먼저 좁히세요.

- 범위를 다시 설명합니다
- 어디가 틀린지 분명히 합니다
- 필요하면 새 스레드를 엽니다

문제 해결은 가장 흔하고 고치기 쉬운 원인부터 보며, 처음부터 과도하게 복잡하게 생각할 필요는 없습니다.
