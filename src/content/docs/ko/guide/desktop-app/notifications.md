알림은 작업 상태를 알려, 백그라운드 작업이 멈추거나 승인을 기다리거나 이미 끝났는데 놓치는 일을 줄입니다.

알림 용도:

- 긴 작업 완료
- 승인 대기
- 실패 또는 후속 조치 필요

시스템 설정에서 필수 알림은 남겨 두는 편이 좋습니다. 백그라운드 작업이 막힌 뒤 아무도 처리하지 않게 됩니다. 자동화 관련 알림은 이후 장에서 다루며, 여기서는 App 내 작업 알림에 초점을 둡니다.

## 흔한 질문

### 1. App을 계속 켜 두어도 알림이 필요한가요?

대부분 경우 필요합니다. 작업이 길거나 중간에 승인을 기다릴 때, 알림이 있으면 화면을 계속 쳐다보지 않아도 됩니다.

### 2. 어떤 알림을 남기는 게 좋나요?

다음을 우선합니다.

- 작업 완료
- 승인 대기
- 실행 실패

### 3. 전부 끄면 어떻게 되나요?

당장 문제가 나지 않을 수도 있지만, 다음이 더 쉬워집니다.

- 작업이 이미 멈춘 줄 모름
- 승인을 기다리고 있음
- 결과가 이미 나왔는데 놓침

알림을 모두 끄면 이런 상태 변화를 놓치기 쉽습니다.
