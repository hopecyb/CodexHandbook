데스크톱 App은 초보자의 기본 진입점입니다. 프로젝트, 작업, 차이, 승인을 시각적으로 다룰 수 있습니다.

명령줄이나 IDE 확장에 익숙하지 않은 사람에게도 비교적 접근하기 쉬운 입구입니다.

단순히 “채팅할 수 있다”는 수준이 아니라, 프로젝트·변경·승인·검증을 같은 화면에서 볼 수 있게 모아 둡니다.

## 이 장의 내용

- 데스크톱 App에서 먼저 익혀야 할 동작
- 초보자가 먼저 쓸 기능과, 나중에 배워도 되는 기능
- 변경·승인·문제 해결 시 어디를 볼지

## 먼저 이 세 가지를 구분하세요

모든 기능을 한 번에 배울 필요는 없습니다.  
먼저 다음 세 가지 핵심 동작을 구분하세요.

1. 작업을 입력하는 곳
2. 변경을 확인하는 곳
3. 작업을 승인하거나 거부하는 곳

이 세 단계를 통과하면 기본 작업의 한 사이클을 완료할 수 있습니다.

## 흔한 오해

### 1. 데스크톱 App은 CLI의 GUI 껍데기에 불과하다?

협업 과정의 핵심 단계를 다음과 같이 펼쳐 보여 줍니다.

- 현재 작업
- 계획과 도구 호출
- 파일 변경
- 승인 동작
- 결과 검토

### 2. 모든 버튼을 이해해야 시작할 수 있다?

처음에는 이것만 알면 충분합니다.

- 작업을 입력하는 위치
- diff를 보는 위치
- 승인/거부하는 위치

### 3. 초보자용이라 실무에는 맞지 않다?

많은 실무 작업도 데스크톱 App에서 처리할 수 있습니다. 특히 시각적 검토와 과정 투명성을 중시할 때 그렇습니다.

## 시작 순서

데스크톱 App을 처음 쓸 때는 다음 순서를 권합니다.

1. 설치하고 화면을 익힌다
2. 올바른 프로젝트를 고른다
3. 작은 작업을 시작한다
4. 변경을 확인한다
5. 승인·거부를 익힌다
6. 그다음에 병렬 Agent, 작업 트리, Cloud 작업 같은 고급 기능을 배운다

처음부터 모든 기능을 파고드는 것보다 보통 더 수월합니다.
