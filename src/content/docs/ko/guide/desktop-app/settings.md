설정 항목은 많지만, 처음부터 전부 조정할 필요는 없습니다. 보안·승인·일상 경험에 영향을 주는 항목만 보면 됩니다.

흔한 설정 방향(이름은 UI 기준):

- 기본 모델과 추론 등급
- 승인 / 샌드박스 / 네트워크 관련 옵션
- 알림
- 외관과 편집 선호

팀 관리형 설정이 개인 설정을 덮어쓸 수 있습니다. 공식 설명: [https://developers.openai.com/codex](https://developers.openai.com/codex). 개념: [권한과 승인](/guide/foundations/permissions-and-approvals/)

## 흔한 질문

### 1. 처음부터 모든 설정을 다 바꿔야 하나요?

아닙니다. 기본값을 유지한 채, 각 설정이 무엇을 바꾸는지 먼저 이해하세요.

### 2. 처음에는 어떤 설정을 보나요

보통 다음 세 종류면 충분합니다.

- 승인과 권한
- 네트워크 관련
- 알림

이 항목들이 가장 직접적으로 영향을 줍니다.

- 무엇을 할 수 있는지
- 경계를 넘는지
- 알림을 제때 받는지

### 3. 설정을 바꿨는데 문서와 다르면?

가능한 이유는 다음과 같습니다.

- 버전이 다름
- 팀 관리형 정책이 개인 설정을 덮어씀
- 현재 작업 환경에 다른 제약이 있음

설정 페이지를 처음 볼 때는 보안 경계와 알림 관련 옵션을 먼저 이해한 뒤, 다른 세부 항목을 보세요.
