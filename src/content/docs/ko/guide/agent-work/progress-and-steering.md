실행 중간의 흔한 반응은 보통 둘뿐입니다.

- 아무 말도 안 하고 빗나간 채 계속 달리게 둠
- “멈춰, 전부 다시” 한 마디

더 흔한 실천은 실행 중에 계속 **유도**하여, 이미 맞는 부분은 남기고 빗나간 곳만 고치는 것입니다.

## 유도가 하는 일

여기서 “유도”는 지금 이 단계를 어떻게 갈지 보완하는 일입니다. 예:

- 어느 부분이 맞으니 유지
- 어느 부분이 빗나가기 시작했으니 그만
- 다음에 어느 단계를 우선

## “유도”란

유도는 현재 실행 상태에 대한 **국소 방향 조정**입니다.

보통 이런 때에 필요합니다.

- 목표는 맞았지만 단계 순서가 이상함
- 이미 반이 맞아서 전부 뒤집고 싶지 않음
- 방금 새 정보를 보강해 이후 동작을 조정해야 함
- 불필요한 리팩터나 확장에 들어가려는 것을 발견함

## 가장 자주 쓰는 템플릿 하나

중간 유도는 매우 짧아도 됩니다.

```text
현재 단계에서 멈추세요. A와 B는 유지하고, C에 대한 변경 방향은 철회하세요. 다음은 D만 하세요. E는 시작하지 마세요.
```

이런 지시에는 네 핵심 부품이 있습니다.

1. 어디서 멈출지
2. 무엇을 유지할지
3. 무엇을 포기할지
4. 다음에 무엇만 할지

## 흔한 함정

### 1. 빗나감을 발견하면 전부 멈추고 다시?

이미 반이 맞다면 전부 뒤집는 것은 보통:

- 배경을 다시 설명해야 함
- 이미 정렬된 부분도 함께 잃음
- 새 라운드에서 또 빗나갈 수 있음

### 2. “틀렸어”만 말하면 어디가 틀린지 알까?

보통은 부족합니다.

더 효과적인 것은 명시하는 것입니다.

- 무엇을 유지
- 무엇을 포기
- 지금 무엇을 우선

### 3. 유도와 재계획은 같은가?

- **유도**: 경로는 대체로 맞고, 국소만 수정
- **재계획**: 목표·전제·영향 범위가 이미 바뀜

## 왜 작은 걸음 궤도 수정이 더 효과적인가

| 작은 걸음 궤도 수정 | 전부 뒤집기 |
|---|---|
| 이미 정렬된 작업을 유지 | 앞에 맞았던 것도 함께 버림 |
| 컨텍스트를 더 아낌 | 배경을 다시 설명해야 함 |
| 범위를 더 쉽게 통제 | 다시 드리프트하기 쉬움 |
| 실제 협업에 가까움 | 주문을 반복하는 느낌 |

## 언제 먼저 유도하고, 언제 계획으로 돌아가나

이렇게 판단하세요.

- **순서만 틀리거나, 범위가 크거나, 출력 형식만 틀림**: 먼저 유도
- **목표·전제·영향면이 바뀜**: 계획으로 복귀

## 세 가지 흔한 유도 방식

### 1. 범위 축소

너무 크게 하기 시작할 때:

```text
먼저 로그인 페이지만 처리하고, 회원가입·비밀번호 찾기 흐름까지 확장하지 마세요.
```

### 2. 순서 조정

하는 일 자체는 맞지만 선후가 맞지 않을 때:

```text
먼저 검증과 테스트를 보완한 뒤, 구현을 계속 고치세요.
```

### 3. 출력 형식 변경

바로 착수하지 않고 분석을 먼저 보고 싶을 때:

```text
먼저 파일은 고치지 마세요. 현재 방안과 제안 방안의 차이를 비교표로 주세요.
```

## 좋은 유도에 되도록 넣을 것

- 지금 멈출 위치
- 유지할 부분
- 계속하면 안 되는 방향
- 새 우선순위
- 계속 실행을 허용하는지

다음 문장이 비교적 분명합니다.

```text
원인 판단은 유지하되, 리팩터에는 아직 들어가지 마세요. 다음은 최소 수정 방안과 검증 단계만 보완하세요.
```

## 언제 “재계획”으로 돌아가야 하나

유도는 국소 이탈에 맞고, 다음은 [계획](/guide/agent-work/planning/)으로 돌아가는 편이 낫습니다.

- 작업 목표 자체가 바뀜
- 새 정보가 원래 전제를 뒤집음
- 영향 범위가 분명히 커짐
- 궤도 수정을 두세 번 연속 했는데도 여전히 떠다님

이미 국소 이탈이 아니면 바로 계획 단계로 돌아가세요.

## 흔한 실수

- “틀렸어”만 말하고 어디가 틀린지 말하지 않음
- “알아서 고쳐”라고만 하고 우선순위를 주지 않음
- 한 단계만 멈추고 싶은데 전부 재실행을 유발하는 말을 씀
- 이미 새 작업인데 보완 설명 한 줄로 억지로 이어 붙임

실행 중 이탈을 발견하면, 짧은 지시로 “무엇을 유지·무엇을 중단·다음에 무엇만”을 말하세요.
