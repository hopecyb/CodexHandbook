“설정” 그룹을 처음 보면 파라미터 이름 나열이라고 생각하기 쉽습니다.

실제로 푸는 문제는 하나입니다. Codex가 기본으로 어떻게 일하게 할지 — 매번 임시로 다시 말하지 않게.

## 권장 순서

1. [설정 기초](/guide/customization/configuration/config-basics/)
2. [Profiles](/guide/customization/configuration/profiles/)

## 이 그룹이 푸는 문제

- 어떤 선호를 설정 파일에 쓰기 좋은지
- 언제 여러 profile로 나눌지
- 왜 어떤 제한은 설정 메모가 아니라 규칙·승인에 넘겨야 하는지

설정은 기본 동작과 안정적 선호에 맞고, 승인·규칙·프로젝트 설명을 대체하기엔 맞지 않습니다.
