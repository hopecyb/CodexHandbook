원칙만 보면 다 알겠는데, 자기 저장소에 내려놓으려면 막히는 경우가 많습니다.

이 그룹의 역할은 “남들이 어떻게 썼는지”를 보여 주어, 추상 규칙을 더 구체적인 쓰기로 바꾸는 데 돕습니다.

## 이 그룹 진입점

- [Monorepo의 AGENTS.md](/ko/guide/customization/examples/monorepo-agents-md/)

## 언제 보면 좋은가

- AGENTS.md가 무엇인지 알지만 아직 쓰기 시작할 수 없을 때
- 규칙을 둬야 한다는 건 알지만 디렉터리 계층·범위를 어떻게 쓸지 모를 때
- 실제 샘플을 먼저 보고 자기 프로젝트 버전으로 바꾸고 싶을 때

예시 페이지는 아이디어 참고용이지, 그대로 복붙용이 아닙니다.
