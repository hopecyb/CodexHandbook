여러 `AGENTS.md`, 설정 파일, 현재 대화가 동시에 있을 때 **어느 규칙이 적용되는지**를 분명히 해야 합니다.

여기서 말하는 것은, 두 규칙이 달라 보일 때 누구 말을 들을지입니다.

## 우선순위 개요

```text
호스팅 조직 정책 > nearer 디렉터리의 AGENTS.md > 저장소 루트 AGENTS.md > 사용자 설정 > 현재 대화
```

「nearer」는 **현재 작업 경로에 더 가까운** 하위 디렉터리 파일을 뜻합니다. 예: `packages/web/AGENTS.md` 아래에서 일할 때 해당 파일과 루트 파일이 병합되며, 충돌 시 **하위 디렉터리가 우선**합니다.

## “가까운 쪽이 우선”을 이해하기

이렇게 보면 됩니다.

- 루트 규칙은 “전 저장소 기본법”
- 하위 디렉터리 규칙은 “이 국소 영역의 특별 설명”

그래서 현재 작업 위치에 가까울수록 보통 더 구체적이고, 더 우선해야 합니다.

## 대화 프롬프트와의 관계

| 출처 | 지속성 | 쓰기 좋은 내용 |
|---|---|---|
| AGENTS.md | 세션 간, 버전 관리 가능 | 팀 합의, 빌드 명령, 금지구역 |
| 작업 프롬프트 | 이번 세션만 | 이번 목표, 범위, 마감 |
| @ 파일 참조 | 이번 세션 컨텍스트 강화 | 구체 구현 파일, 디자인 |

대화에 전체 `AGENTS.md`를 **반복 붙여 넣지 마세요**. 어떤 조항을 강조해야 하면 한 문장으로 인용하세요. 「AGENTS.md의 테스트 요구를 지키고, 이번엔 `legacy/` 디렉터리는 추가로 건드리지 마세요.」

## Monorepo 패턴

```text
repo/
├── AGENTS.md              # 전 저장소 공통: 패키지 매니저, CI, 보안
├── apps/
│   └── web/
│       └── AGENTS.md      # 프론트: 컴포넌트 라이브러리, E2E 명령
└── packages/
    └── api/
        └── AGENTS.md      # 백엔드: DB 마이그레이션 규약
```

원칙:

- **루트 파일**: 전 저장소가 공유하는 10–20개 하드 규칙
- **서브패키지 파일**: 해당 패키지 고유 명령·디렉터리만
- 세 파일이 80% 중복되지 않게 — 중복은 루트에, 서브패키지는 증분만

## 개인 선호와의 경계

개인 습관(테마, 기본 모델, 로컬 경로)은 **사용자 설정**에 두고, 팀 저장소 `AGENTS.md`에 쓰지 마세요. 협업자가 피해를 봅니다.

## 흔한 오해

### 1. 현재 대화의 말이 최신이니 우선순위도 가장 높다?

대화는 “이번 추가 요구”를 보완하기에 맞지만, 팀·조직급 하드 규칙을 마음대로 덮는 것과는 다릅니다.

### 2. 하위 `AGENTS.md`는 루트 규칙을 한 번 더 복사하는 것?

그렇게 하면 안 됩니다.

더 맞는 방식은 다음과 같습니다.

- 루트에 공통 규칙
- 하위에 증분과 예외만

### 3. 순서만 기억하면 충분하다?

충분하지 않습니다.

더 중요한 것은 다음을 아는 것입니다.

- 어떤 정보가 어느 계층에 가야 하는지
- 충돌 시 왜 어느 계층이 기준이 되는지

## 충돌 시 판단하기

두 규칙이 충돌해 보이면 이 순서로 보세요.

1. 어느 쪽이 현재 작업 디렉터리에 더 가까운가
2. 어느 쪽이 장기 프로젝트 규칙이고, 어느 쪽이 이번 임시 보완인가
3. 더 위 계층의 조직·호스팅 정책이 직접 제한하는가

규칙이 충돌하면 보통 더 가깝고, 더 단단하고, 더 명확한 계층을 우선하며, “가장 최신 한 문장”이 무조건 이긴다고 가정하지 마세요.

## 흔한 실수

- 하위 `AGENTS.md`와 루트가 모순인데 어느 쪽이 기준인지 밝히지 않음
- 민감 키를 `AGENTS.md`에 써 Git에 커밋 — 키 관리와 환경 변수를 써야 함
- 대화의 「임시 완화」가 팀 호스팅 정책을 덮기를 기대(보통 불가)

## 검증 체크리스트

- [ ] 루트 `AGENTS.md`와 서브패키지 파일의 역할 분담이 분명함
- [ ] 충돌 시 「하위 디렉터리 우선」 의식이 있음
- [ ] 작업 프롬프트는 증분만 쓰고, 프로젝트 핸드북 전체를 복사하지 않음
