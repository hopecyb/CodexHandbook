Codex는 OpenAI가 제공하는 **AI 프로그래밍·업무 Agent**입니다. 목표를 주면 프로젝트 파일·도구·승인을 바탕으로 내용을 읽고 고치고, 명령을 실행하고, 결과를 만든 뒤, 과정과 변경을 당신에게 검토하도록 넘깁니다.

도구를 쓰는 디지털 동료에 가깝습니다. 목표·경계·수락 기준은 당신이 정하고, 자료 조사·파일 수정·단계 실행은 맡기되, 최종 결정은 당신이 합니다.

공식 제품 문서는 [OpenAI Codex](https://developers.openai.com/codex)를 기준으로 합니다. 이 핸드북은 체계적 학습과 실습을 위한 커뮤니티 오픈소스 가이드이며, 공식 문서를 대체하지 않습니다.

## 일반 AI 채팅과 무엇이 다른가

많은 사람이 Codex를 처음 보면 「조금 더 강한 채팅 AI」로 이해합니다. 차이는 주로 실행 능력에 있습니다.

| 평소 쓰는 것 | 이렇게 이해하면 |
|---|---|
| 일반 챗봇 | 조언, 개념 설명, 문장 작성 |
| Codex | 답변뿐 아니라 **파일 읽기·수정·명령 실행·산출물 생성**까지 할 수 있음 |

일반 채팅 도구는 주로 답변에 머무릅니다. Codex는 허용된 범위 안에서 직접 손을 댑니다.

## 어떤 작업에 맡기기 좋은가

「이야기만」이 아니라 자료를 읽고, 무언가를 고치고, 단계를 실행하고, 결과를 내야 한다면 Codex와 함께하기 좋습니다.

개념 질문·짧은 영감·막연한 조언만 필요하면 일반 채팅형 AI로도 충분할 수 있습니다.

## 어디에 쓸 수 있나

프로그래머가 아니어도 이런 장면으로 이해할 수 있습니다.

- **읽고 정리하기**: 문서·회의록·스크린샷·표 요약
- **쓰고 고치기**: 글 다듬기, 목차 보완, 설명 문서 수정
- **작은 프로젝트**: 페이지 만들기, 설정 수정, 템플릿 보완
- **문제 찾고 고치기**: 어디가 틀렸는지, 다음에 무엇을 볼지
- **반복 작업 자동화**: 고정 흐름을 먼저 한 번 돌려 보기

코드를 쓰는 사람은 개발 흐름에 넣을 수 있고, 코드를 못 써도 단계를 실행하는 조수로 쓸 수 있습니다.

## 할 수 있는 일

- **이해**: 저장소·문서·표·스크린샷 정보 요약
- **생성·수정**: 원고 작성, 코드 수정, 페이지·설정 생성
- **실행**: 권한 아래 터미널 명령·검색·브라우징
- **협업**: App, CLI, IDE, Cloud 등 입구 사이에서 작업 이어가기
- **확장**: Skills, Plugins, MCP, Hooks 등으로 반복 흐름·외부 시스템 연결(고급 장은 이후 보완)

## 할 수 없는 일(중요)

- 사실·안전·업무 결정에 대한 최종 책임을 대신하지 않습니다
- 한 번에 완전히 올바른 결과를 보장하지 않습니다. 결과는 반드시 확인할 수 있어야 합니다
- 승인 없이 샌드박스·네트워크·조직 정책을 넘지 않습니다
- 「검증 없는 자동 배포 파이프라인」으로 쓰면 안 됩니다

## 사용할 때의 기본 판단

Codex를 조수로 쓰면 됩니다. 책임까지 넘기지 마세요.

먼저 시키고, 먼저 조사하고, 먼저 고치게 한 뒤, 마지막에는 직접 확인하세요.

- 올바른 곳을 고쳤는지
- 목표를 잘못 이해하지 않았는지
- 제시한 사실이 믿을 만한지
- 변경이 부작용을 만들지 않는지

## 일반적인 흐름

일반적인 흐름은 대략 이렇습니다.

1. 당신이 목표를 말합니다
2. 답하거나 계획을 제시합니다
3. 파일 수정이나 명령 실행이 필요하면 승인을 요청할 수 있습니다
4. 끝나면 무엇을 바꿨는지 알려 줍니다
5. 결과가 기대에 맞는지 확인합니다

이 흐름의 전체 예시는 [첫 작업 실행](/guide/getting-started/run-your-first-task/)을 보세요.

## 주요 사용 입구

| 입구 | 적합한 경우 |
|---|---|
| 데스크톱 App | 초보자 기본값. 프로젝트·작업·diff 검토를 시각적으로 |
| CLI | 터미널 사용자, 스크립트·자동화 |
| IDE 확장 | 편집기 안에서 열린 파일·선택 영역과 함께 |
| Web / Cloud | 저장소 연결, 클라우드 환경, 장기 작업 |
| 모바일·원격 | 모니터링, 승인, 가벼운 추적 |

대조표는 [기능 비교](/guide/reference/feature-comparison/)를 보세요. 개념 관계는 [능력 지도](/guide/start-here/)를 보세요.

## 이어서 보기

세 가지만 기억한다면:

1. Codex는 채팅만이 아니라, 승인 후 동작을 실행합니다
2. 작업은 목표·경계·「완료 기준」을 분명히 말해야 합니다
3. 어떤 결과든 확인하고, 맹신하지 마세요
