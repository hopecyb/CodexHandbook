## 지속적인 업데이트

이 핸드북은 하나의 Codex 버전에 장기간 고정되지 않습니다. 제품은 계속 바뀌므로 설치, 로그인, 권한, 모델, 설정, Cloud 동작도 시간이 지나면서 달라질 수 있습니다.

## 어떤 정보를 우선할지

현재 제품 동작은 [OpenAI의 공식 Codex 문서](https://developers.openai.com/codex)를 기준으로 하세요. 이 핸드북은 개념을 설명하고 경로를 정리하며 실용적인 방법을 제공합니다. 내용이 충돌하면 공식 문서를 따르고 페이지 아래의 수정 링크로 문제를 알려 주세요.

## 내용이 여전히 적용되는지 판단하는 방법

변경될 수 있는 정보를 읽을 때는 세 가지를 확인하세요.

1. 설치, 설정, 권한, 제품 진입점처럼 자주 바뀌는 주제인지 확인합니다.
2. 화면에 표시된 최근 콘텐츠 업데이트 날짜가 오래되었는지 확인합니다.
3. 인용한 공식 자료가 현재 제품 동작과 여전히 일치하는지 확인합니다.

개념, 방법, 검수 원칙은 구체적인 버튼, 파라미터, 화면 경로보다 대체로 안정적입니다. 최신 동작, 파라미터, 가격, 규칙은 공식 자료를 다시 확인하세요.

## 콘텐츠 업데이트와 수정

[콘텐츠 업데이트와 수정](/ko/guide/updates/)에는 중요한 변경 사항과 영향이 기록됩니다. 페이지 아래에서 현재 페이지 제목과 경로가 포함된 GitHub Issue 초안을 열 수 있습니다. 제출하기 전에 내용을 확인하고 민감한 정보를 삭제하세요.

## 자주 바뀌는 내용

- 설치 방법과 시스템 요구 사항
- 로그인, 계정, 권한 흐름
- 모델, 설정 옵션, 파라미터 표기
- Cloud, 클라이언트, 제품 진입점 동작
- 가격, 할당량, 서비스 제한
