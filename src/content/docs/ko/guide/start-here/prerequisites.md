대부분의 사람이 Codex를 처음 쓸 때 막히는 지점은 기술 배경이 아니라, 첫 단계를 어떻게 시작하느냐입니다.

## 필수

1. **사용 가능한 OpenAI / Codex 접근 권한**(계정·플랜은 공식 안내 기준)
2. **데스크톱 App, CLI 또는 IDE 확장을 설치할 수 있는 컴퓨터**
3. **버려도 되는 연습 디렉터리**(프로덕션 저장소에서 첫 시도를 하지 마세요)
4. **결과를 확인할 의지**: 수락·수정·철회. 맹목적인 merge는 피합니다

네 가지 중 3번과 4번이 가장 쉽게 놓칩니다.

- 연습 디렉터리가 있으면 시행착오 부담이 훨씬 줄어듭니다
- 결과를 확인하려는 태도가, 이번 시도가 통제 가능한지를 가릅니다

## 시작 전에 꼭 갖출 필요는 없는 것

아래는 **시작의 하드 게이트가 아닙니다**.

- Git을 먼저 통달할 필요 없음
- 코드를 많이 쓸 줄 알 필요 없음
- 모델·컨텍스트·샌드박스·승인 세부까지 처음부터 이해할 필요 없음
- 모든 클라이언트를 한 번에 설치할 필요 없음

첫 작업을 끝까지 돌린 뒤 개념을 천천히 보완하는 편이 부담이 훨씬 적습니다.

## 흔한 오해

### 1. 문서를 다 읽고 나서야 시작할 필요는 없습니다

보며 배워도 됩니다. 많은 사람이 이렇게 시작합니다.

1. 아주 작은 작업을 하나 마칩니다
2. 관련 개념을 다시 봅니다
3. 문제가 생기면 문서를 찾아봅니다

### 2. 처음부터 정식 프로젝트로 시험하지 않는 편이 좋습니다

처음에는 이렇게 하세요.

- 버려도 되는 작은 디렉터리
- 결과를 눈으로 확인할 수 있는 작은 작업
- 실수해도 손실이 없는 환경

### 3. CLI·IDE·App을 한 번에 다 배울 필요는 없습니다

대부분의 초보자에게는 **데스크톱 App**부터가 더 쉽습니다. 인터페이스가 직관적이고, 프로젝트·작업·변경을 보기 쉽기 때문입니다.

## 제안

- 먼저 [초보자 안전 체크리스트](/guide/getting-started/beginner-safety-checklist/)를 읽으세요
- [권한과 승인](/guide/foundations/permissions-and-approvals/)과 [샌드박스와 네트워크](/guide/foundations/sandbox-and-network/)를 알아 두세요
- 공식 설치·제품 변경은 [https://developers.openai.com/codex](https://developers.openai.com/codex)를 기준으로 합니다

## 흔한 시작 순서

이 순서로 가면 됩니다.

1. 접근 권한을 확인합니다
2. 클라이언트를 하나 설치합니다
3. 연습 디렉터리를 준비합니다
4. 아주 작은 작업을 돌립니다
5. 결과를 확인한 뒤 다음을 정합니다

시작 전에는 안전하고 작은 범위·되돌릴 수 있는 환경에서 첫 작업을 끝내는 편이, 개념을 한꺼번에 채우는 것보다 수월합니다.
