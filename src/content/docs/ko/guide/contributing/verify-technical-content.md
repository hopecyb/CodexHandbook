명령, 권한, 가격, 제품 기능은 버전에 따라 바뀔 수 있습니다. 기술 정보 확인은 어떤 설명이 현재 근거를 갖는지, 어떤 환경에 적용되는지, 독자가 무엇을 추가로 확인해야 하는지 명확히 하는 과정입니다.

## 확인 목표

문장을 읽기 좋게 다듬는 것만으로는 충분하지 않습니다. 핵심 사실이 현재 제품과 일치하고, 명시한 환경에서 단계를 수행할 수 있으며, 결론이 근거가 뒷받침하는 범위를 넘지 않는지 확인합니다.

## 근거 우선순위

1. 제품 동작, 파라미터, 제한은 OpenAI 공식 문서를 우선합니다.
2. “실행됨”이라고 설명하는 예시에는 실제 결과와 환경 정보가 있어야 합니다.
3. 커뮤니티 글은 주제를 찾는 데 도움이 되지만 공식 자료나 실제 실행을 대신하지 않습니다.
4. 링크가 열린다는 사실만으로 설명이 뒷받침되지는 않습니다. 원문을 읽어야 합니다.
5. 확인할 수 없는 정보는 추측으로 채우지 말고 불확실성을 직접 밝힙니다.

## 기록할 범위

- 적용 제품: App, CLI, IDE 또는 Cloud
- 운영체제, 클라이언트, 주요 의존성 버전
- 실제로 수행한 단계와 결과 확인 방법
- 다루지 않은 플랫폼, 진입점, 경계 조건
- 웹사이트 첫 화면이 아닌 구체적인 출처 페이지

## 확인 순서

1. 페이지가 다루는 제품, 진입점, 사용 상황을 확인합니다.
2. 자주 바뀌는 사실을 현재 공식 문서와 대조합니다.
3. 실행할 수 있다고 설명한 단계는 깨끗한 환경에서 처음부터 수행합니다.
4. 시험하지 않았거나 불확실한 주장은 범위를 좁히고 한계를 본문에 밝힙니다.
5. 내부 링크, 외부 링크, 독자에게 필요한 사전 조건을 확인합니다.

## 자주 바뀌는 정보

주요 제품 업데이트 후에는 다음을 우선 확인합니다.

- 명령, 하위 명령, flags
- 기본 권한과 샌드박스 동작
- 요금제, 모델 이름, 가격, 할당량, 지역별 제공 여부
- MCP, Hooks, 기타 통합 인터페이스
- 메뉴 위치, 버튼 이름, 제품 진입점

## 확인할 수 없을 때

추론을 사실처럼 쓰지 마세요. 오래된 세부 정보를 삭제하거나 안정적인 방법 중심으로 다시 쓰거나 PR 또는 issue에 미확인 질문을 기록합니다. 현재 동작, 가격, 정책은 공식 자료를 기준으로 합니다.
