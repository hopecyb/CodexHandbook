# 실전 사례

실전 사례는 실제 목표에서 출발해 프롬프트, 실행, 검사, 검증, 재사용까지 완료하는 방법을 보여 줍니다.

## 사례 형식

각 사례에는 목표, 준비 자료, 권장 프롬프트, 실행 과정, 사람 검사 지점, 검증 방법, 실패 처리, 재사용 가능한 템플릿이 포함되어야 합니다. 새 사례를 작성할 때는 [사례 템플릿](/cases/use-cases/case-study-template/)을 참고하세요.
