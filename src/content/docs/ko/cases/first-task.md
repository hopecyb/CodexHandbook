# 첫 번째 작업

아래 예시는 기본값이 **데스크톱 App**입니다. CLI/IDE에서도 같은 프롬프트를 사용할 수 있습니다.

## 메타 정보

| 필드 | 내용 |
|---|---|
| 대상 독자 | 초보자 |
| 클라이언트 | 데스크톱 App(권장) |
| 예상 소요 시간 | 15–20분 |

## 1. 목표와 배경

**목표:** 연습 프로젝트에서 안전한 파일 수정을 한 번 완료합니다.

**성공 기준:** 지정한 파일만 수정하고, 결과가 인수 설명과 맞으며, diff를 읽을 수 있어야 합니다.

## 2. 준비

- 클라이언트를 설치하고 로그인한 상태
- 연습 프로젝트를 만든 상태(`hello.md` 또는 유사 파일 포함)

## 3. 권장 프롬프트

```text
목표：hello.md 끝에 「오늘의 연습」 절을 추가하고, 세 줄 요점 목록을 포함하세요.
제약：hello.md만 수정하세요. 기존 내용을 삭제하지 마세요. 네트워크 요청을 실행하지 마세요.
인수：파일 끝에 해당 제목과 목록 항목이 정확히 세 개 있어야 합니다.
정보가 부족하면 추측하지 말고 먼저 질문하세요.
```

## 4. 실행과 검사

1. 먼저 짧은 계획을 내놓게 합니다(또는 직접 계획을 요청합니다)
2. 파일 쓰기 승인 시 경로가 맞는지 확인합니다
3. 완료 후 인수 기준에 맞춰 diff를 항목별로 검사합니다
