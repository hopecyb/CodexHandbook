# 슬라이드 만들기

## 메타 정보

| 필드 | 내용 |
|---|---|
| 대상 독자 | 창작자 |
| 클라이언트 | App |
| 예상 소요 시간 | 1–2시간 |

## 1. 목표와 배경

**목표:** 주제에 따라 구조가 명확한 발표 자료(Markdown/HTML/PPT 등, 환경 능력에 따름)를 생성합니다.

**성공 기준:** 페이지 수가 개요와 일치하고, 각 페이지 요점을 설명할 수 있으며, 날조된 데이터가 없어야 합니다.

## 2. 권장 프롬프트

```text
주제：【발표 주제】
독자：【청중 배경】
시간：【분】
먼저 장과 각 페이지 제목+요점 3개를 주세요. 최종 파일은 생성하지 마세요.
확인 후 slides/ 디렉터리로 출력하세요. 형식：【mdx/html/pptx】.
제약：데이터는 출처를 표시하거나 「예시」로 표시하세요. 승인 없이는 외부 네트워크 요청을 하지 마세요.
```

## 3. 검증

- 각 페이지를 1분 안에 말할 수 있는지 통독
- 차트와 숫자 출처를 대조
