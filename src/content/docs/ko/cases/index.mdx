실전 사례는 실제 목표에서 시작해 프롬프트 작성, 실행, 방향 수정, 검토, 검증, 재사용까지의 과정을 보여줍니다. 최종 결과물뿐 아니라 진행 중의 판단에 초점을 맞춥니다.

import CaseDirectory from '/src/components/CaseDirectory.astro';

## 할 작업 찾기

작업 유형이나 키워드로 필터링하세요. 결과물과 검증 상태는 각 사례의 메타데이터에서 가져옵니다. “예제 실행 검증”은 해당 페이지에 적힌 환경과 단계에만 적용되며, 모든 클라이언트나 독자에 대한 검증을 뜻하지 않습니다.

<CaseDirectory />

## 사례 구성

각 사례에는 목표, 준비 자료, 권장 프롬프트, 실행 과정, 사람의 확인 지점, 검증 방법, 실패 대응, 재사용 가능한 템플릿이 포함되어야 합니다. 새 사례를 작성할 때는 [사례 템플릿](/ko/cases/use-cases/case-study-template/)을 참고하세요.

## 재사용할 수 있는 자료

- [사례 템플릿](/ko/cases/use-cases/case-study-template/): 한 번의 작업을 검토하고 인계할 수 있는 기록으로 정리합니다.
- [첫 작업](/ko/cases/first-task/): 작고 안전한 작업으로 목표, 실행, 인수 확인의 전 과정을 연습합니다.
- [워크플로 사례](/ko/cases/workflows/): 검증, 사람의 승인, 실패 복구, 여러 Agent의 협업을 절차에 추가하는 방법을 배웁니다.
