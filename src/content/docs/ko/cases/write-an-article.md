# 글 쓰기

## 메타 정보

| 필드 | 내용 |
|---|---|
| 대상 독자 | 창작자 |
| 클라이언트 | App / CLI |
| 예상 소요 시간 | 1–2시간 |

## 1. 목표와 배경

**목표:** 게시 가능한 기술 글 초고를 만듭니다.

**성공 기준:** 구조가 완전하고, 사실을 대조할 수 있으며, 스타일이 독자에 맞아야 합니다.

## 2. 워크플로(EPXV)

### 탐색

```text
주제：【글 주제】
독자：【초보자/개발자】
먼저 선택 가능한 각도 3개와 개요를 주세요. 본문은 쓰지 마세요.
```

### 계획

개요를 확인한 뒤:

```text
개요 1절에 따라 약 300자로 작성하세요. 쓴 뒤 멈추고 어조를 확인해 주세요.
```

### 실행

절 단위로 작성해, 한 번에 전체 글을 만들어 수정하기 어렵게 만들지 마세요.

### 검증

- 링크, 버전 번호, 명령이 아직 유효한지 사람이 확인
- 선택: [글쓰기 Skill](/skills/examples/writing-skill/)로 흐름을 고정

## 3. 정착

반복 글쓰기는 `article-writer` Skill로 패키징할 수 있습니다. [창작자 경로](/guide/learning-paths/creator/)를 참고하세요.
