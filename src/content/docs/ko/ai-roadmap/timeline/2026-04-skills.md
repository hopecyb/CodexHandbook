# Skills(스킬)

- 주요 날짜:
  - Verified OpenAI Academy publication date: 2026-04-10
- 공식 참고 자료:
  - https://openai.com/academy/skills/
  - https://help.openai.com/en/articles/20001066-skills-in-chatgpt
- 참고: 이 항목은 Skills가 AI 애플리케이션 엔지니어링 메커니즘으로 공식 도입된 시점과 의미를 기록한다. 구체적 설계와 작성법은 Guide에서 다룬다.

## 무엇인가

Skills는 특정 작업 유형을 완료하는 방법을 패키징하는 메커니즘이다. 지시, 단계, 예시, 코드, 의존 리소스를 포함할 수 있으며 같은 작업을 더 일관되게 수행하게 하는 재사용 가능한 워크플로가 된다.

## AI 애플리케이션 엔지니어링을 어디에서 어디로 옮겼나

AI 애플리케이션은 “매번 프롬프트와 요구사항을 다시 설명하는” 단계에서 “전문성과 절차를 재사용 가능한 실행 단위로 포장하는” 단계로 이동했다.

## 현재 단계

현재 이 항목은 `emerging` 단계로 본다.

신흥 단계다. 제품 기능으로 제시되고 ChatGPT, Codex, API 생태계와 관련되지만 플랜, 조직 설정, 거버넌스 패턴은 아직 형성 중이다.

## 대체할 수 있는 것

흩어진 프롬프트 템플릿, 내부 프롬프트 문서, 재사용하기 어려운 구전 워크플로 일부를 대체한다.

## 그것을 대체할 수 있는 것

권한, 상태, 체크포인트, 관측 가능성을 직접 담는 더 엄격한 실행 단위 표준이나 Agent 워크플로 형식으로 발전하거나 흡수될 수 있다.
