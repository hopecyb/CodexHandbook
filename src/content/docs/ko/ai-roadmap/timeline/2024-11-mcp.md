# MCP(모델 컨텍스트 프로토콜)

- 주요 날짜:
  - Open-source date: 2024-11-25
- 공식 참고 자료:
  - https://modelcontextprotocol.io/docs/getting-started/intro
- 참고: 이 항목은 MCP가 AI 애플리케이션의 능력 연결과 재사용에 준 의미를 기록한다. 구체적 통합 절차는 Guide에서 다룬다.

## 무엇인가

MCP는 모델이나 Agent가 외부 도구, 데이터, 서비스에 연결하기 위한 표준 프로토콜이다. 각 애플리케이션이 별도 어댑터를 계속 작성하는 대신 공통 형식으로 능력을 공개하고 사용하게 한다.

## AI 애플리케이션 엔지니어링을 어디에서 어디로 옮겼나

AI 애플리케이션은 “제품마다 도구 연결층을 따로 만드는” 단계에서 “통일된 프로토콜을 중심으로 능력을 연결하고 재사용하는” 단계로 이동했다.

## 현재 단계

현재 이 항목은 `emerging` 단계로 본다.

신흥 단계지만 상승세다. 개념은 빠르게 확산됐지만 거버넌스, 권한, 호환성, 운영 모범 사례는 아직 형성 중이다.

## 대체할 수 있는 것

개별 API 통합, 제품 전용 플러그인, 재사용하기 어려운 도구 어댑터의 일부를 대체할 수 있다.

## 그것을 대체할 수 있는 것

더 엄격한 Agent 실행 표준, 권한 모델, 관측 가능성을 포함한 프로토콜로 확장되거나 흡수될 수 있다.
