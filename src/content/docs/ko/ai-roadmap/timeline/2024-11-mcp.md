## 확인 가능한 사건과 범위

**날짜: 2024-11-25 · 유형: 프로토콜 공개.** Anthropic은 AI 어시스턴트를 외부 데이터 및 도구와 연결하기 위해 Model Context Protocol을 오픈소스로 공개한다고 발표했습니다.

출처: [MCP 공개 발표](https://www.anthropic.com/news/model-context-protocol). 확인일은 2026-09-18입니다. 출처의 발표일과 이 페이지의 확인일은 의미가 다릅니다.

## 어떤 문제를 해결하나

MCP는 클라이언트와 서버가 도구와 리소스 같은 기능을 교환하는 프로토콜입니다. 프로토콜 연결은 접근 문제를 해결하지만, 서비스의 신뢰성, 계정 권한, 작업 승인 여부는 각각 별도로 다뤄야 합니다.

## 학습 조언과 적용 범위

다음은 이 사이트의 교육적 판단이며, 업계 보급률이나 효과를 측정한 결과가 아닙니다.

먼저 범위가 분명한 읽기 전용 기능 하나를 연결해 입력과 반환값을 확인한 뒤 쓰기 작업을 검토하세요. 같은 프로토콜을 지원한다고 모든 클라이언트가 모든 기능을 지원하거나 동일한 권한 경험을 제공하는 것은 아닙니다.
