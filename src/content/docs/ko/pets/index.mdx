# Codex 펫

Codex 펫은 Codex 클라이언트 안에 표시되는 애니메이션 동반 요소입니다. 모델 기능도 자동화 도구도 아니며, 로컬 시각 리소스입니다. 클라이언트는 작업 중, 대기 중, 완료, 실패, 사용자 입력 대기 같은 상태를 서로 다른 애니메이션으로 표현할 수 있습니다.

<PetScienceFigure variant="anatomy" locale="ko" />

이 섹션은 교육용입니다. Codex 펫의 기본 개념, 일반적인 파일 구조, 설치 시의 안전 경계, 그리고 Pet을 만들 때 이미지와 메타데이터가 어떻게 연결되는지 설명합니다. 이 사이트는 펫 리소스 목록을 제공하지 않으며, 외부 갤러리를 공식 출처로 취급하지 않습니다.

## 보통 무엇으로 구성되나

Pet은 보통 작은 로컬 패키지로 이해할 수 있습니다.

- `pet.json`: ID, 표시 이름, 설명, 애니메이션 이미지 경로 같은 메타데이터.
- `spritesheet.webp`: 여러 애니메이션 프레임을 담은 이미지 아틀라스.
- 펫 폴더: 메타데이터와 애셋을 함께 보관하는 디렉터리.

이 관점에서 Codex Pet은 네트워크 프로그램보다 테마 리소스나 작은 시각 위젯에 가깝습니다.

## 구조를 알아야 하는 이유

Pets 구조를 알면 세 가지를 판단하기 쉽습니다.

- 설치할 때: 파일을 어디에 두어야 하는지, 어떤 스크립트를 조심해서 봐야 하는지.
- 문제를 해결할 때: 펫이 보이지 않거나 애니메이션이 재생되지 않는 이유.
- 만들 때: 프레임, 투명 배경, 메타데이터, 라이선스 설명이 각각 무엇을 담당하는지.

## 읽는 순서

1. [Codex Pet 설치하기](./install/): 폴더, 활성화, 안전 점검을 이해합니다.
2. [Codex Pet 만들기](./create/): 이미지가 로드 가능한 리소스가 되는 과정을 이해합니다.

Pets를 작고 명확한 로컬 패키지로 관리하면 출처가 불분명한 명령을 붙여 넣는 것보다 안정적이고, 장기 유지보수도 쉽습니다.
