이 사이트는 특정 클라이언트와 Pet 패키지의 호환성을 아직 시험하지 않았습니다. 먼저 버전과 출처를 기록하고 [호환성 및 복구 기록](/ko/guide/reference/resource-compatibility/)으로 실제 결과를 확인하세요. 그림은 구조를 설명할 뿐이며 모든 버전에 적용되는 형식 계약은 아닙니다.


Codex Pet을 만드는 목표는 단순히 예쁜 이미지를 얻는 것이 아닙니다. Codex가 식별하고, 로드하고, 재생하고, 상태를 전환할 수 있는 리소스 패키지를 만드는 것입니다. “메타데이터 + 애니메이션 아틀라스 + 출처와 라이선스 설명”의 조합으로 생각하면 됩니다.

![일러스트: 손그림 스케치에서 격자 정렬, 스프라이트 시트, 완성된 펫 폴더까지 이어지는 제작 흐름](/illustrations/pets-create.webp)

최소 구조는 보통 다음과 같습니다.

```text
<pet-id>/
  pet.json
  spritesheet.webp
```

## spritesheet란 무엇인가

![일러스트: 행마다 동작이 배열된 스프라이트 시트에서 한 프레임을 잘라 필름으로 이어 화면에서 재생하는 모습](/illustrations/pets-spritesheet.webp)

Spritesheet는 여러 애니메이션 프레임을 하나의 큰 이미지로 합치는 방식입니다. 클라이언트는 수십 개의 작은 파일을 로드하지 않고, 큰 이미지에서 행과 열 좌표로 각 프레임을 잘라 순서대로 재생합니다.

아틀라스 규격과 버전 필드를 함께 확인하세요. 이 사이트의 이전 그림은 8열 × 9행, 프레임당 192 × 208 px(전체 1536 × 1872 px)를 사용하지만 모든 클라이언트에 공통으로 적용되는 규격은 아닙니다. 제작 전에 대상 클라이언트나 제작 도구 버전에 맞는 형식 문서를 확보하고 행과 열의 수, 동작 매핑, 버전 필드를 확인한 뒤 소재를 생성하세요.

이미지 높이만 바꾸고 이전 메타데이터를 그대로 두는 것으로 아틀라스를 확장할 수는 없습니다. 출처를 추적할 수 있는 형식 문서가 없다면 제작을 멈추고 규격을 확인하세요. 그림만 보고 호환성을 추론하지 마세요.

## 애셋 준비

좋은 소재는 보통 다음 조건을 만족합니다.

- 캐릭터 윤곽이 뚜렷하고 배경을 깨끗하게 제거할 수 있습니다.
- 각 동작의 비율, 시점, 기준선이 일관됩니다.
- 투명 배경에 색 번짐, 잔상, 불필요한 픽셀이 없습니다.
- 재생 중 잘리지 않도록 가장자리에 붙지 않습니다.
- 작업, 대기, 완료, 실패, 이동, 유휴 상태 등에 대응할 수 있습니다.

소재가 팬 창작, 게임, 애니메이션, 브랜드, 타인 작품에서 왔다면 먼저 출처와 라이선스를 확인하세요. 허가받지 않은 소재를 상업적으로 사용할 수 있는 리소스로 설명하지 마세요.

## `pet.json`의 역할

다음 예시는 식별 정보와 에셋 경로 필드만 보여 줍니다. 설치가 검증된 완전한 패키지가 아니며 실제 형식에는 버전 필드도 필요할 수 있습니다.

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "A focused companion for Codex sessions.",
  "spritesheetPath": "spritesheet.webp"
}
```

권장 사항:

- `id`는 소문자, 숫자, 하이픈을 사용합니다.
- 폴더 이름과 `id`를 일치시킵니다.
- `spritesheetPath`는 상대 경로를 사용합니다.
- `description`에는 펫이 무엇인지 분명히 씁니다.
- 작성자, 버전, 출처, 라이선스는 패키지의 README 또는 LICENSE에 남기세요. 클라이언트가 임의의 추가 필드를 받아들인다고 가정하지 마세요.

`pet.json`은 애니메이션 자체를 저장하지 않습니다. 클라이언트에게 “이 패키지가 누구인지, 소재가 어디 있는지, 어떻게 해석해야 하는지” 알려줍니다. 소재 경로, 파일 이름, 디렉터리 구조가 일치하지 않으면 클라이언트가 보통 로드할 수 없습니다.

## 로컬 점검

공개하거나 공유하기 전에 최소한 다음을 확인합니다.

- `pet.json`이 유효한 JSON입니다.
- `spritesheetPath`가 존재하는 파일을 가리킵니다.
- spritesheet 크기와 프레임 그리드가 현재 계약에 맞습니다.
- 각 행의 애니메이션이 크게 튀거나 밀리거나 잘리지 않습니다.
- 투명 배경이 깨끗합니다.
- 패키지에 임시 파일, 원본 이미지, 공개하면 안 되는 소재가 없습니다.

## 라이선스와 출처

펫 소재는 팬 창작, 스크린샷, AI 생성 이미지, 공개 이미지 라이브러리, 타인 작품에서 올 수 있습니다. 만들 때는 다음을 구분하세요.

- 개인적으로 사용할 수 있는지.
- 공개적으로 공유할 수 있는지.
- 다른 사람의 재배포를 허용할 수 있는지.
- 출처 표시나 링크 보존이 필요한지.

원본 작업 파일과 출처 기록을 보관하면 이후 테두리 수정, 동작 변경, 크기 조정, 라이선스 설명 보완이 쉬워집니다.
