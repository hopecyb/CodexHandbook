| Begriff | Definition |
|---|---|
| Agent | Ausführungsweise, die Werkzeuge aufruft und iterativ auf ein Ziel hinarbeitet |
| Freigabe | Menschliche Bestätigung vor risikoträchtigen Operationen |
| Diff / Differenz | Vergleichsansicht vor/nach der Änderung |
| Cloud-Aufgabe | Aufgabe, die in einer Cloud-Umgebung ausgeführt wird |
| Kontext | Informationsmenge, die dem Modell aktuell zur Verfügung steht |
| Komprimierung | Langer Kontext wird zusammengefasst, um das Fenster zu schonen |
| Hook | Benutzerdefinierte Logik an Lebenszykluspunkten (fortgeschritten) |
| MCP | Protokoll zur Anbindung externer Werkzeuge und Daten (fortgeschritten) |
| Prompt | Text mit Ziel und Anforderungen an den Agenten |
| Sandbox | Ausführungsisolation, die den Wirkungsbereich begrenzt |
| Skill | Wiederverwendbares Spezialpaket aus Anweisungen und Ressourcen (fortgeschritten) |
| Thread | Fortlaufendes Gespräch und akkumulierten Kontext |
| Token | Maßeinheit für Textverarbeitung im Modell |
| Arbeitsbaum | Isoliertes Arbeitsverzeichnis für parallele Experimente |

Einsteigerfassung: [Terminologie für Einsteiger](/guide/start-here/terminology-for-beginners/)

## Nutzung

Nachschlage-Wörterbuch, kein vollständiges Tutorial.  
Taucht auf einer anderen Seite ein Wort auf, das Sie nicht einordnen können — hier nachschlagen.

Sind die meisten Begriffe noch fremd, zuerst [Terminologie für Einsteiger](/guide/start-here/terminology-for-beginners/).

## Häufige Missverständnisse

### 1. Nicht von vorn bis hinten auswendig lernen

Üblich:

- Beim Lesen auf ein Wort stoßen
- Hier nachschlagen
- Zurück zum Text

### 2. Kurze Definition verstehen ≠ beherrschen

Das Glossar hilft beim Einordnen; die Anwendung steht in den Fachseiten.

### 3. Viele Begriffe ≠ ungeeignet zum Weiterlernen

Codex bringt neue Wörter mit. Zuerst ungefähre Bedeutung, Details später.

## Bei unbekannten Wörtern

1. Kurze Definition nachschlagen
2. Nur die Konzeptklasse bestätigen
3. Zur Fachseite für die volle Erklärung

So unterbricht ein einzelner Begriff den Lesefluss weniger lange.
