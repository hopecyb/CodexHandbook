## Wenn die Kategorie unklar ist

Zuerst einordnen:

1. „Komme nicht rein“?
2. „Läuft nicht“?
3. „Läuft, aber Ergebnis falsch“?
4. „Weiß nicht, welches Werkzeug/welchen Einstieg“?

So landet man schneller auf der richtigen Seite.
