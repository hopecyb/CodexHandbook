Vollständigere Einträge findest du im [Glossar](/guide/reference/glossary/). Hier stehen zuerst die häufigsten Wörter, die das Lesen am meisten beeinflussen.

Beim ersten Lesen des Codex-Handbooks stocken viele an der Begriffsdichte. Jedes Wort allein kennt man — zusammen wirken sie schnell überfordernd.

Zwei typische Situationen:

- Du verstehst jedes Wort, weißt aber nicht, worauf es in der Praxis zeigt
- Du weißt nicht, welche Wörter jetzt nötig sind und welche später reichen

Das ist keine Terminologie-Prüfung. Es reicht, ungefähr zu wissen, wovon die Rede ist — damit du beim Lesen nicht ständig hängenbleibst.

## Die ersten Wörter, die du kennen solltest

Wenn dein Ziel gerade nur die erste Aufgabe ist, reichen zunächst diese 6:

| Begriff | Warum zuerst |
|---|---|
| **Prompt** | Wie du eine Aufgabe klar formulierst |
| **Kontext** | Welche Informationen Codex gerade sehen kann |
| **Agent** | Warum es mehr als eine Textantwort liefert |
| **Freigabe** | Warum es manchmal innehält und dich fragt |
| **Diff** | Wie du prüfst, was wirklich geändert wurde |
| **Aufgabe** | Die Grundeinheit einer abgeschlossenen Arbeit |

| Begriff | Kurze Erklärung |
|---|---|
| **Prompt** | Ziel, Hintergrund und Anforderungen, die du Codex gibst |
| **Kontext (Context)** | Projekt-, Datei- und Gesprächsinformationen, die das Modell gerade sehen kann |
| **Agent** | Ausführungsweise, die Werkzeuge um ein Ziel herum aufruft und iterativ vorgeht |
| **Werkzeug (Tool)** | Aufrufbare Fähigkeiten wie Dateien lesen, Befehle ausführen, suchen |
| **Sandbox** | Ausführungsumgebung, die Dateisystem- und Netzwerkeinfluss begrenzt |
| **Freigabe (Approval)** | Manche Operationen brauchen deine ausdrückliche Zustimmung |
| **Diff** | Vergleich vor/nach einer Änderung — zum Überprüfen |
| **Thread / Sitzung** | Ein durchgängiges Gespräch und sein angesammelter Kontext |
| **Aufgabe** | Eine zielgerichtete Arbeitseinheit (kann mehrere Werkzeugaufrufe umfassen) |
| **Skill** | Wiederverwendbares Paket aus Spezialanweisungen und Ressourcen (fortgeschritten) |
| **MCP** | Protokoll zum Anbinden externer Werkzeuge und Datenquellen (fortgeschritten) |
| **Cloud-Aufgabe** | Aufgabe, die in einer Cloud-Umgebung läuft — nicht in der lokalen Sandbox |

## Noch direkter gesagt

- **Prompt**: Was du sagst, wenn du eine Aufgabe gibst
- **Kontext**: Das Material, das es gerade in den Händen hat
- **Agent**: Es antwortet nicht nur — es treibt die Aufgabe wirklich voran
- **Freigabe**: Manches darf es nicht allein entscheiden — du musst zustimmen
- **Diff**: Vergleich vorher/nachher
- **Skill**: Eine feste Vorgehensweise als wiederverwendbares Paket

## So nutzt du die Liste

Triffst du diese Wörter auf anderen Seiten, musst du nicht jedes Mal anhalten:

- Ungefähr klar → weiterlesen
- Immer noch unscharf → hierher zurück
- Es blockiert das Verständnis des Ablaufs → zur passenden Themenseite

## In Gruppen denken

Wenn du nicht alles auf einmal merken willst:

- Was du sagst: Prompt
- Was es sieht: Kontext
- Wie es handelt: Agent, Werkzeug
- Ob es darf: Freigabe, Sandbox
- Wie du prüfst: Diff, Aufgabenergebnis

## Das kann später kommen

Das Folgende ist meist fortgeschritten — beim ersten Mal nicht zwingend durchdringen:

- Skill
- MCP
- Hook
- Plugin
- Details zur Cloud-Umgebung

Zuerst die [erste Aufgabe](/guide/getting-started/run-your-first-task/) abschließen und die Begriffe danach nachschlagen — dann sitzt das Verständnis meist besser.

Bei unbekannten Wörtern kurz nachschlagen und weiterlesen.

Beim ersten Lesen reichen diese Wörter als Hinweise. Ungefähr wissen, worauf sie zeigen, ist praktischer als alles sofort auswendig zu lernen.
