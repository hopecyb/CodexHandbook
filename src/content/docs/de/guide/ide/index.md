Die IDE-Erweiterung eignet sich für **Schreiben und Diff gleichzeitig sehen**: Datei öffnen, Code auswählen, Aufgabe in der Seitenleiste beschreiben. Dieses Kapitel deckt den Weg von Auswahl bis Überprüfung ab.

Arbeitest du ohnehin im Editor an Code oder Dokumenten, ist die IDE oft der natürlichste Einstieg.

Sie nimmt geöffnete Dateien und die Auswahl direkt mit — deshalb lassen sich viele „kleine Änderungs“-Aufgaben leichter eingrenzen.

## Diese Punkte zuerst beachten

Beim ersten Einsatz vor allem drei Dinge:

1. Es bezieht sich auf die aktuell geöffneten Dateien
2. Mit Auswahl kannst du den Rahmen enger setzen
3. Nach Änderungen musst du das Diff selbst prüfen

Die IDE-Erweiterung passt zu „kleinem Umfang, ändern und gleichzeitig sehen“ — Rahmenkontrolle und Überprüfung bleiben trotzdem Pflicht.
