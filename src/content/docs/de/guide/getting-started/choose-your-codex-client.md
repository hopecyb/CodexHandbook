Orientiere dich zuerst daran, wo die Arbeit hauptsächlich stattfindet:

| Du arbeitest hauptsächlich hier | Beginne hier |
|---|---|
| Projekte, Dateien und mehrere Aufgaben auf dem Desktop verwalten | **ChatGPT-Desktop-App** |
| Git, Tests und Skripte im Terminal ausführen | **Codex CLI** |
| Code in VS Code, einem kompatiblen Editor, Xcode oder JetBrains schreiben | **IDE-Integration** |
| In einem verbundenen Remote-Repository und einer isolierten Umgebung arbeiten | **Codex Cloud** |

Wenn du Codex zum ersten Mal verwendest und keine klare Präferenz hast, kannst du mit der Desktop-App beginnen. Aufgaben, Dateien, Diffs und Genehmigungen sind dort besonders gut sichtbar. Diese Wahl ist nicht dauerhaft. Ein Workflow kann in der IDE beginnen, in der CLI verifiziert und für eine Langzeitaufgabe in der Desktop-App oder Cloud fortgesetzt werden.

Eine vollständige Entscheidungsgrafik, Kombinationsbeispiele und Verifikationsschritte findest du unter [Den passenden Codex-Client auswählen](/de/guide/choose-your-client/). Für einen Vergleich einzelner Funktionen lies den [Funktionsvergleich](/de/guide/reference/feature-comparison/).

Wähle anschließend die entsprechende Installationsseite:

- [Desktop-App installieren](/de/guide/getting-started/install-desktop-app/)
- [CLI installieren](/de/guide/getting-started/install-cli/)
- [IDE-Integration installieren](/de/guide/getting-started/install-ide-extension/)
- [Codex Cloud kennenlernen](/de/guide/web-and-cloud/)
