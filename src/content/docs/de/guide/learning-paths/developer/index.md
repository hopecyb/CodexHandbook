## Häufige Missverständnisse

### 1. Entwicklerpfad = sofort Code schreiben lassen

Ergebnisqualität hängt oft stärker ab von:

- Versteht es den Umfang?
- Haben Sie Fertigkriterien definiert?
- Haben Sie Diff und Verifikation ernst genommen?

### 2. Ich kann code — Grundlagen überspringbar

Besser nicht ganz.

Codex arbeitet anders als Editor-Autocomplete; Berechtigung, Kontext und Werkzeugaufrufe wirken direkt aufs Ergebnis.

## Empfohlene Leseordnung

Für den Einsatz in der Entwicklung:

1. [Erste Schritte](/guide/getting-started/)
2. [CLI](/guide/cli/) oder [IDE](/guide/ide/)
3. [Agent-Arbeit](/guide/agent-work/)

Diese Route betont kontrollierte Änderungen und prüfbare Ergebnisse — nicht nur „erstmal schreiben lassen“.
