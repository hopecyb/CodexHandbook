Codex speeds you up—it **does not** remove acceptance. Minimum review:

1. Read the [diff](/guide/quality/review-diffs/): which files changed, any out-of-scope edits
2. Check against your definition of done
3. Run tests when you can: [Run tests](/guide/quality/run-tests/)
4. Verify external facts: [Validate sources](/guide/quality/validate-sources/)

"Looks right" is not an acceptance criterion.
