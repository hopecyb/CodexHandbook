<section class="home-section home-section-lead" aria-label="手册定位">
	<p>Codex 不只是一个能改代码的工具。它可以帮助你理解资料、生成内容、搭建原型、处理文档、审查变更、自动化重复工作，也可以成为个人和团队的 AI Agent 执行伙伴。</p>
	<p>本手册不追求堆积功能说明，而是关注一条可复用的工作链：明确目标，提供上下文，设置边界，让 Agent 执行，检查结果，再把经验沉淀成模板、Skill 或案例。</p>
</section>

		<section aria-labelledby="evidence-teams">

		</section>
