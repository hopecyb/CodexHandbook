使用 Codex 前需要有效的 OpenAI 账号，以及当前地区/组织策略允许的 **产品访问权限**。套餐名称、额度与是否包含 App/CLI/Cloud 以官方说明为准。

## 你要确认的三件事

1. 能登录 [OpenAI / Codex 相关入口](https://developers.openai.com/codex)
2. 你的计划包含打算使用的客户端
3. 若在公司环境：是否有 SSO、设备管理或禁用策略

本页不罗列价格表（易过时）。以官方账号与计费页为准。
