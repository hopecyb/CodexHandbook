---
title: 安装桌面 App
description: 安装并打开 Codex 桌面应用。
---


1. 打开官方 Codex 文档的桌面应用下载说明：[https://developers.openai.com/codex](https://developers.openai.com/codex)
2. 选择你的操作系统安装包并安装
3. 启动应用，确认能看到登录或项目入口

## 安装后检查

- 应用能正常打开
- 系统权限（如文件访问）按需授予，不要一次性给无关磁盘权限
- 界面总览见 [安装与界面](/04-product-guides/desktop-app/installation-and-interface/)

若失败：见 [桌面 App 排障](/04-product-guides/desktop-app/troubleshooting/)。
