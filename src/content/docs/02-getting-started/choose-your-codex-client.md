---
title: 选择 Codex 客户端
description: 在 App、CLI、IDE、Cloud 之间做第一次选择。
---


| 若你… | 选 |
|---|---|
| 第一次用、想看清差异与审查 | **桌面 App**（推荐默认） |
| 习惯终端、要写脚本 | **CLI** |
| 主要在编辑器里改代码 | **IDE 扩展** |
| 要连 GitHub 云端环境 / 长任务 | **Cloud**（先读概述） |

完整对照：[功能对照](/12-reference/feature-comparison/)。可以装多个客户端；**练习项目保持同一目录**，便于对照体验。
