## Flux
1. Clarifier la question de recherche et les exclusions
2. Lister 3–5 dimensions d'évaluation
3. Chaque conclusion avec source ; marquer « à confirmer » si non vérifiable
4. Sortie : tableau comparatif + recommandation + questions ouvertes
5. Ne pas modifier le code
