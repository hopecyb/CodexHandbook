Dans le contexte Codex, la gouvernance est principalement deux choses : ce que l'équipe autorise, et qui gère les problèmes quand ils arrivent.

Cela affecte :

- Quelles extensions peuvent se connecter
- Quelles tâches peuvent être automatisées
- Quand l'approbation humaine est obligatoire

## Entrée de section

- [Politique d'usage acceptable](/guide/team-enterprise/governance/acceptable-use/)

## Ce que ces pages répondent

- Comment écrire les frontières org comme règles claires
- Ce qui ne devrait pas être laissé au jugement individuel
- Pourquoi « tout le monde sait » ne suffit généralement pas

Les pages de gouvernance existent pour énoncer les frontières à haut risque dès le départ — pas laisser les équipes deviner.
