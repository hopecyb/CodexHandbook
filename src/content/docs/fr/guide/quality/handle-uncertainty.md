Indiquez dans votre Prompt :

```text
Lorsque l'information est insuffisante, demandez d'abord ; n'inventez pas de chemins de fichiers, d'API ou de règles métier.
```

Si une fabrication apparaît : arrêtez, corrigez les faits, démarrez un nouveau Fil si nécessaire.
