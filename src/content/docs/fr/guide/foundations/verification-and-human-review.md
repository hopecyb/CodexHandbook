Codex vous accélère — il **ne supprime pas** l'acceptation. Revue minimale :

1. Lire le [Diff](/guide/quality/review-diffs/) : quels fichiers ont changé, modifications hors portée
2. Vérifier par rapport à votre définition de terminé
3. Exécuter des tests quand possible : [Exécuter des tests](/guide/quality/run-tests/)
4. Vérifier les faits externes : [Valider les sources](/guide/quality/validate-sources/)

« Ça a l'air correct » n'est pas un critère d'acceptation.
