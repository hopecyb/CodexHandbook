| Terme | Définition |
|---|---|
| Agent | Approche d'exécution qui appelle des outils et itère vers un objectif |
| Approval | Confirmation humaine avant opérations à haut risque |
| Diff | Vue avant/après des changements |
| Tâche Cloud | Tâche exécutée dans un environnement cloud |
| Contexte | Ensemble d'informations que le modèle peut utiliser actuellement |
| Compaction | Processus de résumer un long contexte pour gagner de l'espace dans la fenêtre |
| Hook | Logique personnalisée exécutée aux nœuds du cycle de vie (avancé) |
| MCP | Protocole pour connecter outils et données externes (avancé) |
| Prompt | Texte d'objectif et d'exigences donné à un Agent |
| Sandbox | Isolation d'exécution qui limite le rayon d'explosion |
| Skill | Paquet réutilisable d'instructions et ressources spécialisées (avancé) |
| Thread | Conversation continue et son contexte accumulé |
| Token | Unité utilisée pour mesurer le texte traité par le modèle |
| Worktree | Répertoire de travail isolé pour expériences parallèles |

Version débutant : [Terminologie pour débutants](/guide/start-here/terminology-for-beginners/)
