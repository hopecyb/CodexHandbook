Ce manuel est un guide communautaire open source. Pour le comportement du produit, les programmes d'installation et les offres, fiez-vous aux sources officielles :

- Documentation Codex pour les développeurs : [https://developers.openai.com/codex](https://developers.openai.com/codex).
- Pages relatives à la plateforme et au compte OpenAI : utilisez les accès actuels sur le site officiel d'OpenAI.

La documentation officielle et ce manuel ont des rôles différents. Le manuel explique les notions et méthodes de travail ; la documentation officielle confirme la version actuelle et les dernières instructions. Si une URL officielle change, suivez la navigation du site OpenAI et proposez, si possible, une PR pour corriger cette page.

## Quand consulter d'abord la documentation officielle

Allez directement à la source officielle pour l'installation et la connexion, la disponibilité actuelle d'une fonction, la syntaxe récente d'un réglage ou d'une commande, et les changements d'offre, de permissions ou de comportement.

## Idées reçues

### 1. Si l'officiel fait autorité, le manuel communautaire est-il inutile ?

Après avoir lu des instructions officielles, on peut encore ignorer par où commencer. Le manuel aide à se repérer.

### 2. Ce qui figure dans le manuel est-il toujours vrai aujourd'hui ?

Les paramètres de commandes, clés de configuration, fonctions disponibles et limites des offres ou permissions peuvent changer vite.

### 3. Quelle source prime en cas de contradiction ?

Utilisez le manuel pour les notions et le contexte. Pour le comportement actuel et la syntaxe récente, consultez l'officiel.

## Utiliser les deux types de ressources

Consultez d'abord le manuel si vous ne comprenez pas un concept, ne savez pas comment commencer ou cherchez un ordre d'apprentissage.

Les sources officielles sont plus fiables pour savoir ce qui est pris en charge aujourd'hui, le nom actuel d'un paramètre, la disponibilité d'une fonction dans une version ou un changement récent des règles du produit.

## Si vous hésitez sur le point de départ

1. Utilisez le manuel pour comprendre les notions et l'orientation générale.
2. Avant de configurer, installer ou exécuter, vérifiez les dernières instructions officielles.
3. Si les deux divergent, suivez la source officielle.

Cette démarche clarifie la direction et réduit le risque d'utiliser une information périmée.
