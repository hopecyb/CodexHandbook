Pour une question ponctuelle, commencez par la FAQ. Elle ne remplace pas les chapitres complets : elle vous aide à trouver la prochaine page utile.

## Quand la consulter

Ouvrez-la si vous ne savez pas quelle page lire, si une question précise vous bloque sans justifier tout un chapitre, ou si vous voulez une première orientation.

**Q : Quel client utiliser pour commencer ?**
R : L'application de bureau. Voir [Choisir son client Codex](/fr/guide/choose-your-client/).

**Q : Puis-je accepter tous les changements sans les examiner ?**
R : Mieux vaut éviter. Voir [Vérification et revue humaine](/fr/guide/foundations/verification-and-human-review/).

**Q : Existe-t-il un modèle de consigne standard ?**
R : Il existe un cadre, pas de formule magique. Voir [Structure d'une tâche](/fr/prompts/task-anatomy/).

**Q : Que faire si le manuel contredit la documentation officielle ?**
R : Suivez la [documentation officielle de Codex](https://developers.openai.com/codex) et, si possible, ouvrez une issue.

**Q : Quelle différence entre AGENTS.md, Skills et MCP ?**
R : Voir la [Carte des capacités](/fr/skills/capability-map/) et [Choisir une méthode d'extension](/fr/skills/choosing-an-extension-method/).

**Q : Y a-t-il un flux standard recommandé ?**
R : Commencez par [Explorer → Planifier → Exécuter → Vérifier](/fr/cases/workflows/explore-plan-execute-verify/).

**Q : Comment Cloud se connecte-t-il à GitHub et ouvre-t-il une PR ?**
R : Voir [Connecter GitHub](/fr/guide/web-and-cloud/connect-github/) et [Créer des pull requests](/fr/guide/web-and-cloud/create-pull-requests/).

**Q : Peut-on utiliser la CLI dans la CI ?**
R : Oui. Commencez par le [mode non interactif](/fr/guide/cli/non-interactive-mode/) et définissez les approbations et permissions.

**Q : Quelles commandes à barre oblique existent ?**
R : Consultez la complétion de `/` dans votre client actuel. Pour apprendre, voir [Commandes à barre oblique](/fr/guide/reference/slash-commands/).

**Q : Où trouver les parcours complets pour créateurs, développeurs et équipes ?**
R : Le parcours débutant est disponible. Pour des cas approfondis, voir les [cas d'usage](/fr/cases/use-cases/) ; pour la gouvernance d'équipe, voir l'étape M6 `11-team-enterprise` de la feuille de route.

## Idées reçues

### 1. Peut-on ignorer la FAQ ?

Pour un débutant, elle peut être un point de départ rapide.

### 2. Ses réponses suffisent-elles pour agir directement ?

Elles donnent une première direction, puis renvoient vers des explications plus complètes.

### 3. Si ma question n'y figure pas, le manuel n'en parle-t-il pas ?

Elle peut se trouver dans une page thématique, un parcours d'apprentissage ou un cas pratique.

## Comment l'utiliser

1. Parcourez la FAQ.
2. Repérez la question la plus proche de la vôtre.
3. Suivez le lien vers le chapitre correspondant.

C'est souvent plus rapide que de parcourir la barre latérale en tous sens.
