|---|---|
| command not found | Vérifier l'installation et le PATH |
| Authentication failed | Se reconnecter ; vérifier la politique d'organisation |
| Permission denied | Revoir le mode d'Approbation et les paramètres du Bac à sable |
| Édition de fichiers dans le mauvais répertoire | Confirmer le répertoire de travail actuel |
