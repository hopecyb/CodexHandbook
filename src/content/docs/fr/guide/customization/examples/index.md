Beaucoup de principes font sens isolément mais sont difficiles à appliquer dans votre propre dépôt.

Ce groupe montre « comment d'autres l'ont écrit » pour transformer des règles abstraites en modèles concrets.

## Entrées dans ce groupe

- [AGENTS.md dans un monorepo](/fr/guide/customization/examples/monorepo-agents-md/)

## Quand lire ce groupe

- Vous comprenez ce qu'est AGENTS.md mais ne savez pas comment commencer à écrire
- Vous savez qu'il faut des règles mais hésitez sur les couches de répertoires et la portée
- Vous voulez d'abord un exemple réel, puis l'adapter à votre projet

Les pages d'exemple servent de référence de réflexion — pas pour copier-coller aveuglément.
