Le groupe règles est facile à confondre pour les débutants avec « écrire quelques rappels supplémentaires pour Codex ».

Plus précisément, les règles répondent : quelles actions sont autorisées par défaut, quelles bloquer et quelles imposer uniformément comme standard d'équipe.

## Ordre recommandé

1. [Modèles Allow et Deny](/guide/customization/rules/allow-and-deny-patterns/)
2. [Règles de commandes](/guide/customization/rules/command-rules/)
3. [Règles d'équipe](/guide/customization/rules/team-rules/)

## Ce que ce groupe vous aide à résoudre

- Quelles actions devraient être bloquées directement
- Quelles limites appartiennent aux règles explicites plutôt qu'aux rappels verbaux
- Comment les équipes gardent les mêmes frontières pour des risques similaires

Les règles existent pour fixer les frontières afin que le système s'exécute contre elles.
