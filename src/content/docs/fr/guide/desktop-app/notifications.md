Les notifications servent à :

- Fin des longues Tâches
- Attente de votre Approbation
- Échecs ou suivi nécessaire

Autorisez les notifications nécessaires dans les paramètres système pour que les Tâches ne restent pas bloquées en arrière-plan sans être remarquées. Les capacités de notification pour l'automatisation s'étendront dans les chapitres ultérieurs ; cette page couvre uniquement les alertes de Tâche dans l'App.
