## Flux de revue

1. Ouvrez la vue Diff et parcourez fichier par fichier
2. Confirmez que les changements restent dans la portée convenue
3. Posez des questions de suivi ou commentez les points suspects (si l'interface le permet)
4. Acceptez, rejetez ou demandez des modifications

Méthode : [Examiner les Diff](/guide/quality/review-diffs/)
