Ce choix détermine si une tâche lancée dans l'application de bureau s'exécute sur votre ordinateur ou dans un environnement distant.

Choisissez le lieu d'exécution :

- **Local** : utilise les fichiers et l'environnement de votre ordinateur pour itérer rapidement
- **Cloud** : utilise un environnement distant adapté aux dépôts distants et aux tâches plus longues

Pour les notions, voir [Local et cloud](/fr/guide/foundations/local-vs-cloud/). Pour une vue d'ensemble, voir [Web et cloud](/fr/guide/web-and-cloud/).

Avant de changer de mode, vérifiez si des secrets doivent se trouver dans l'environnement choisi et si les règles réseau autorisent cet accès.

## Idées reçues

### 1. Si j'utilise l'application de bureau, pourquoi distinguer local et cloud ?

L'application est un point d'entrée ; elle ne signifie pas que toutes les tâches s'exécutent sur votre ordinateur.

### 2. Quel mode choisir par défaut ?

Dans la plupart des cas, commencez en local, surtout parce que :

- Les fichiers sont déjà sur votre ordinateur.
- Le résultat est plus facile à examiner.
- Il est plus simple d'annuler une erreur.

### 3. Quand envisager le cloud ?

Cela peut être utile si :

- La tâche est longue.
- Vous devez accéder à un environnement de dépôt distant.
- Vous avez besoin d'un environnement uniforme.
- Vous ne voulez pas mobiliser votre ordinateur.

Si la tâche peut être menée à bien localement dans l'application, le mode local est généralement le plus simple. Envisagez le cloud pour les travaux longs ou distants, ou pour disposer d'un environnement uniforme.
