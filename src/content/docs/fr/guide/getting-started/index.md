Objectif : réaliser votre première Tâche dans un **projet d'entraînement sécurisé**, et apprendre à inspecter, accepter, modifier ou annuler.

Le parcours par défaut utilise l'**App de bureau**. Si vous préférez le terminal ou l'éditeur, les pages d'installation s'appliquent toujours ; l'exemple de première Tâche note les différences si nécessaire.

## Étapes

1. [Compte, forfaits et accès](/fr/guide/getting-started/account-plans-and-access/)
2. [Choisir votre client](/fr/guide/getting-started/choose-your-codex-client/)
3. Installation : [App de bureau](/fr/guide/getting-started/install-desktop-app/) · [CLI](/fr/guide/getting-started/install-cli/) · [IDE](/fr/guide/getting-started/install-ide-extension/)
4. [Connexion](/fr/guide/getting-started/sign-in-and-authentication/)
5. [Créer un projet d'entraînement](/fr/guide/getting-started/create-your-first-project/)
6. [Exécuter votre première Tâche](/fr/guide/getting-started/run-your-first-task/)
7. [Examiner le résultat](/fr/guide/getting-started/review-the-result/) · [Annuler et récupérer](/fr/guide/getting-started/undo-and-recover/)

Peu de temps : [Les 30 premières minutes](/fr/guide/getting-started/first-30-minutes/) · lisez d'abord la [Liste de contrôle sécurité](/fr/guide/getting-started/beginner-safety-checklist/).

Les étapes d'installation évoluent avec les versions — consultez aussi [https://developers.openai.com/codex](https://developers.openai.com/codex).
