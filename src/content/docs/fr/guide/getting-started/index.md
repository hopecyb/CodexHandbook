Objectif : réaliser votre première Tâche dans un **projet d'entraînement sécurisé**, et apprendre à inspecter, accepter, modifier ou annuler.

Le parcours par défaut utilise l'**App de bureau**. Si vous préférez le terminal ou l'éditeur, les pages d'installation s'appliquent toujours ; l'exemple de première Tâche note les différences si nécessaire.

## Étapes

1. [Compte, forfaits et accès](/guide/getting-started/account-plans-and-access/)
2. [Choisir votre client](/guide/getting-started/choose-your-codex-client/)
3. Installation : [App de bureau](/guide/getting-started/install-desktop-app/) · [CLI](/guide/getting-started/install-cli/) · [IDE](/guide/getting-started/install-ide-extension/)
4. [Connexion](/guide/getting-started/sign-in-and-authentication/)
5. [Créer un projet d'entraînement](/guide/getting-started/create-your-first-project/)
6. [Exécuter votre première Tâche](/guide/getting-started/run-your-first-task/)
7. [Examiner le résultat](/guide/getting-started/review-the-result/) · [Annuler et récupérer](/guide/getting-started/undo-and-recover/)

Peu de temps : [Les 30 premières minutes](/guide/getting-started/first-30-minutes/) · lisez d'abord la [Liste de contrôle sécurité](/guide/getting-started/beginner-safety-checklist/).

Les étapes d'installation évoluent avec les versions — consultez aussi [https://developers.openai.com/codex](https://developers.openai.com/codex).
