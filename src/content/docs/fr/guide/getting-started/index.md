L'objectif est d'accomplir une première tâche dans un **projet d'entraînement sûr**, puis d'apprendre à examiner, accepter, corriger ou annuler le résultat.

Le parcours par défaut utilise l'**application de bureau**. Si vous préférez le terminal ou un éditeur, les pages d'installation restent adaptées ; l'exemple de première tâche précise les différences éventuelles.

Si vos premières questions sont « Comment commencer ? » et « Comment éviter les erreurs dès le départ ? », ce chapitre est l'entrée la plus directe.

## Idées reçues

### 1. Dois-je commencer par une tâche dans un projet important ?

Ce n'est pas conseillé.

Une petite tâche dans un projet d'entraînement sûr est un meilleur départ. Maîtrisez le déroulement avant de toucher au travail réel.

### 2. L'installation réussie signifie-t-elle que je sais déjà utiliser Codex ?

Pas encore. Pour avoir réellement commencé, vous devez au moins pouvoir :

- Donner une tâche claire à Codex
- Comprendre le résultat
- Décider de l'accepter, de le corriger ou de l'annuler

### 3. Une première tâche plus grande est-elle plus instructive ?

Le plus souvent, elle risque surtout de décourager. Une petite tâche facile à contrôler aide davantage à développer les bons réflexes.

## Ordre conseillé

Suivez ce cycle minimal :

1. Choisissez un client.
2. Installez-le et connectez-vous.
3. Créez un projet d'entraînement sûr.
4. Réalisez une toute petite tâche.
5. Examinez le résultat.
6. Apprenez à annuler ou corriger.

Une fois ce cycle maîtrisé, les sujets plus complexes seront plus faciles à aborder.
