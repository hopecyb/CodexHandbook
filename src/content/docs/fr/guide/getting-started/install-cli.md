Suivez l'installation officielle de la CLI : [https://developers.openai.com/codex](https://developers.openai.com/codex) (généralement un gestionnaire de paquets ou un script d'installation officiel — voir la doc actuelle).

## Vérifications post-installation

Dans un terminal, exécutez la commande de version ou d'aide (sous-commandes exactes selon la doc officielle) et confirmez :

- La commande s'exécute
- Vous pouvez vous connecter ou êtes déjà authentifié

Détails : [Mode interactif CLI](/guide/cli/interactive-mode/). Dépannage : [Dépannage CLI](/guide/cli/troubleshooting/).
