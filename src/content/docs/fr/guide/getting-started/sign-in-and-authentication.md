Connectez-vous via votre client choisi selon les invites à l'écran. Vous pouvez voir :

- Autorisation par redirection navigateur
- Compte SSO / organisation
- Code appareil ou Token (scénarios CLI)

## Après connexion, confirmez

- Le compte ou l'organisation affiché est le vôtre
- Vous pouvez créer ou ouvrir un projet
- Pas d'erreurs du type « pas de Permission pour utiliser Codex »

Les détails d'authentification et les conseils de sécurité suivent la doc officielle : [https://developers.openai.com/codex](https://developers.openai.com/codex). En cas d'échec, consultez l'[index de dépannage](/guide/reference/troubleshooting/).
