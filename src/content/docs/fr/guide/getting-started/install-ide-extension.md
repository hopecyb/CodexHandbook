1. Confirmez que votre éditeur figure sur la liste officielle de support (voir [https://developers.openai.com/codex](https://developers.openai.com/codex))
2. Recherchez l'extension Codex officielle sur la marketplace et installez
3. Redémarrez l'éditeur si nécessaire et ouvrez le panneau d'extension
