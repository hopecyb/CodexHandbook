1. Ouvrez les instructions officielles de téléchargement de l'App de bureau Codex : [https://developers.openai.com/codex](https://developers.openai.com/codex)
2. Choisissez l'installateur pour votre OS et installez
3. Lancez l'application et confirmez que vous voyez la connexion ou l'entrée projet

## Vérifications post-installation

- L'application s'ouvre normalement
- Accordez les Permissions système (ex. accès aux fichiers) uniquement si nécessaire — ne donnez pas d'accès disque non lié dès le départ
- Aperçu de l'interface : [Installation et interface](/guide/desktop-app/installation-and-interface/)

Si l'installation échoue : [Dépannage App de bureau](/guide/desktop-app/troubleshooting/).
