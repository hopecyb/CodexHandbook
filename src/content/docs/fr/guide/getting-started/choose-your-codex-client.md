La première fois que vous voyez `App / CLI / IDE / Cloud`, la question habituelle est : lequel utiliser ?

Ne réfléchissez pas trop au premier choix. Commencez par un point d'entrée facile et ajoutez les autres plus tard.

## Choix directs

Si vous n'avez pas de préférence marquée :

- **Première fois** : choisissez l'App de bureau
- **Vous vivez dans le terminal** : choisissez la CLI
- **Vous codez surtout dans VS Code / JetBrains** : choisissez l'extension IDE
- **Vous avez déjà besoin de dépôts GitHub cloud ou de Tâches de longue durée** : regardez Cloud

## Ce qu'est chaque point d'entrée

| Point d'entrée | Pensez-y comme |
|---|---|
| App de bureau | Une console graphique pour Tâches, Diff et Approbations |
| CLI | Codex dans le terminal, pour les utilisateurs en ligne de commande |
| Extension IDE | Un assistant dans l'éditeur, pour modifier en lisant |
| Cloud | Exécution de Tâches à distance pour collaboration sur dépôt et longs travaux |

## Choisir selon votre situation

| Si vous… | Choisissez |
|---|---|
| Êtes nouveau et voulez des Diff et une revue clairs | **App de bureau** |
| Vivez dans le terminal et voulez des scripts | **CLI** |
| Modifiez surtout du code dans un éditeur | **Extension IDE** |
| Avez besoin d'environnements cloud GitHub / Tâches longues | **Cloud** (lisez d'abord l'aperçu) |

## Pourquoi les débutants commencent souvent par l'App de bureau

Pour les nouveaux utilisateurs, l'App de bureau présente des avantages clairs :

- Plus facile de voir ce qu'elle a fait
- Clair quand elle demande des Permissions
- Tâches, projets et Diff plus concrets
- Plus facile de faire une pause et d'inspecter en cas de problème

Si vous ne préférez pas fortement le terminal, l'App de bureau est généralement le démarrage le plus léger.

## Idées reçues courantes

### 1. Ces quatre points d'entrée sont quatre produits complètement différents

Ils partagent les mêmes capacités principales. Les différences portent surtout sur le style d'interaction et l'adéquation au scénario.

### 2. Je dois choisir le parfait dès la première fois ou je le regretterai

Le premier choix est un point de départ, pas une décision à vie.

### 3. Je ne peux utiliser qu'un seul point d'entrée

Beaucoup de personnes les combinent ensuite :

- App de bureau pour examiner Tâches et changements au quotidien
- CLI pour les opérations par lot
- Extension IDE quand on code principalement

## Ordre de démarrage suggéré

1. Installez l'[App de bureau](/guide/getting-started/install-desktop-app/)
2. Passez par [votre première Tâche](/guide/getting-started/run-your-first-task/)
3. Une fois à l'aise, envisagez CLI ou IDE

Comparaison complète : [Comparaison des fonctionnalités](/guide/reference/feature-comparison/). Vous pouvez installer plusieurs clients ; **gardez le même répertoire d'entraînement** pour comparer facilement les expériences.

Ne vous précipitez pas pour décider lequel est « plus professionnel ». Choisissez l'entrée où processus et résultats sont les plus faciles à comprendre.
