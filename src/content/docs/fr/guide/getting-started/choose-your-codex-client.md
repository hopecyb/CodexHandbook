Commencez par déterminer où se déroule l'essentiel de votre travail :

| Vous travaillez surtout dans | Commencez ici |
|---|---|
| L'environnement de bureau, pour gérer des projets, des fichiers et plusieurs tâches | **App de bureau ChatGPT** |
| Un terminal, pour exécuter Git, des tests et des scripts | **Codex CLI** |
| VS Code, un éditeur compatible, Xcode ou JetBrains | **Intégration IDE** |
| Un dépôt distant connecté et un environnement isolé | **Codex Cloud** |

S'il s'agit de votre première utilisation et que vous n'avez pas de préférence marquée, commencez par l'App de bureau. Elle permet de visualiser plus facilement les tâches, les fichiers, les différences et les demandes d'autorisation. Ce choix n'est pas définitif : un même workflow peut débuter dans l'IDE, utiliser la CLI pour les vérifications, puis se poursuivre dans l'App de bureau ou dans Cloud pour une tâche longue.

Pour consulter le diagramme de décision complet, les workflows combinés et les étapes de vérification, lisez [Choisir un client Codex](/fr/guide/choose-your-client/). Pour une comparaison fonctionnalité par fonctionnalité, consultez la [Comparaison des fonctionnalités](/fr/guide/reference/feature-comparison/).

Passez ensuite à la page de configuration correspondante :

- [Installer l'App de bureau](/fr/guide/getting-started/install-desktop-app/)
- [Installer la CLI](/fr/guide/getting-started/install-cli/)
- [Installer une intégration IDE](/fr/guide/getting-started/install-ide-extension/)
- [Découvrir Codex Cloud](/fr/guide/web-and-cloud/)
