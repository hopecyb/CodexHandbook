Placez les conventions stables dans les instructions de projet (par ex. `AGENTS.md` ou directives de projet fournies par le produit) : structure des répertoires, commands, style de code, interdictions.

Les Prompts de Tâche ne doivent indiquer que le **delta de cette session** ; le long arrière-plan répété appartient au niveau projet. La couverture approfondie de la configuration arrive dans le jalon ultérieur `06-customization`.
