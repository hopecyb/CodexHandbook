## Objectif de cette étape

Utilisez un cadre stable pour écrire un Prompt « recommandé ».

Voir le cadre : [Anatomie d'une bonne Tâche](/prompts/task-anatomy/)

## Exercice

Choisissez un petit changement (par exemple, ranger une liste dans `hello.md`) et écrivez un Prompt qui inclut : objectif, Contexte, entrées, contraintes, critères d'acceptation et limites de Permission. Demandez d'abord un plan, puis autorisez l'exécution.

Suite : [Examiner les résultats](/guide/learning-paths/beginner/04-review-results/)
