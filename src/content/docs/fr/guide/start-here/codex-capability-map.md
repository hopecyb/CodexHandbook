Pensez à Codex comme des couches de capacité, pas seulement une boîte de chat :

```text
Objectifs et Prompts
  → Contexte (projet / fichiers / conversation)
    → Outils (fichiers, terminal, recherche, navigateur…)
      → Travail Agent (planifier, exécuter, orienter, transmettre)
        → Vérification qualité et Approbation humaine
          → Extensions et automatisation (Skills / MCP / Hooks…, avancé)
            → Gouvernance d'équipe (jalons ultérieurs)
```
