## Mises à jour continues

Ce handbook **n'est pas** figé de façon permanente sur un numéro de version Codex unique. Le produit évolue ; les pages utilisent le statut et les dates de vérification pour signaler la fiabilité.

## Statut des pages

| Statut | Signification |
|---|---|
| planned | Planifié, pas encore rédigé |
| draft | En cours |
| review | Contenu complet, en attente de revue |
| verified | Vérifié par rapport aux sources citées |
| outdated | Nécessite une mise à jour après des changements produit |
| archived | Conservé pour l'historique, hors navigation principale |

## Trois lignes de pied de page

Pendant le MVP, chaque page se termine par : **Statut / Produits concernés / Dernière vérification**. Le contenu qui vieillit rapidement (installation, comptes, Permissions, modèles) doit renvoyer vers la documentation officielle.
