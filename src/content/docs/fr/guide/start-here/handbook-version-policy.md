## Mises à jour continues

Ce manuel n’est pas figé durablement sur une seule version de Codex. Le produit continue d’évoluer : l’installation, la connexion, les autorisations, les modèles, la configuration et le comportement de Cloud peuvent donc changer.

## Quelle source suivre

Pour le comportement actuel du produit, référez-vous à la [documentation Codex officielle d’OpenAI](https://developers.openai.com/codex). Ce manuel explique les notions, propose des parcours et présente des méthodes pratiques. En cas de conflit, la documentation officielle prévaut ; vous pouvez signaler le problème avec le lien de correction en bas de page.

## Comment savoir si un contenu s’applique encore

Pour les informations susceptibles d’évoluer, examinez trois points :

1. Le sujet change-t-il souvent, comme l’installation, la configuration, les autorisations ou les points d’entrée du produit ?
2. La date de mise à jour du contenu affichée est-elle ancienne ?
3. Les sources officielles citées correspondent-elles encore au comportement actuel du produit ?

Les notions, les méthodes et les pratiques de validation sont généralement plus stables que les boutons, paramètres et chemins d’interface précis. Pour le comportement actuel, les paramètres, les tarifs ou les règles, consultez de nouveau les sources officielles.

## Mises à jour et corrections

La page [Mises à jour et corrections](/fr/guide/updates/) consigne les changements importants et leurs effets. Le pied de page peut ouvrir un brouillon d’Issue GitHub contenant le titre et le chemin de la page actuelle. Vérifiez-le et retirez les données sensibles avant l’envoi.

## Sujets qui changent souvent

- Méthodes d’installation et configuration requise
- Connexion, comptes et autorisations
- Modèles, options de configuration et syntaxe des paramètres
- Comportement de Cloud, des clients et des points d’entrée du produit
- Tarifs, quotas et limites du service
