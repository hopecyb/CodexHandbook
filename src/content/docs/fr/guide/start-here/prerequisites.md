Pour la plupart des personnes qui découvrent Codex, la difficulté n'est pas leur bagage technique, mais le premier pas.

## Le nécessaire

1. **Un accès valide à OpenAI / Codex** (consultez les indications officielles concernant le compte et la formule)
2. **Un ordinateur capable d'utiliser l'application de bureau, la CLI ou l'extension IDE**
3. **Un dossier d'exercice que vous pouvez supprimer** (évitez de commencer dans un dépôt de production)
4. **La volonté de vérifier les résultats :** les accepter, les modifier ou les annuler, sans les fusionner aveuglément

Les troisième et quatrième points sont les plus faciles à oublier.

- Un dossier d'exercice rend les erreurs moins stressantes
- La vérification du résultat rend l'essai maîtrisable

## Ce dont vous n'avez pas besoin avant de commencer

Ces éléments **ne sont pas des prérequis** :

- Vous n'avez pas besoin de maîtriser Git
- Vous n'avez pas besoin de savoir beaucoup coder
- Vous n'avez pas besoin de comprendre d'emblée tous les détails des modèles, du contexte, du bac à sable et des approbations
- Vous n'avez pas besoin d'installer tous les clients à la fois

Terminez une première tâche, puis apprenez ces notions progressivement.

## Idées reçues

### 1. Inutile de lire toute la documentation avant de commencer

Vous pouvez apprendre en pratiquant. Un ordre fréquent :

1. Terminer une toute petite tâche
2. Revenir aux notions liées
3. Consulter la documentation en cas de problème

### 2. Ne commencez pas avec un véritable projet

Pour débuter, choisissez :

- Un petit dossier sans importance
- Une tâche simple dont vous comprenez le résultat
- Un environnement où une erreur ne causera pas de dommage

### 3. Inutile d'apprendre la CLI, l'IDE et l'App d'un seul coup

Pour beaucoup de débutants, l'**application de bureau** est un point de départ plus simple : son interface aide à voir les projets, les tâches et les changements.

## Un ordre courant pour commencer

1. Vérifiez que vous avez accès au service.
2. Installez un client.
3. Préparez un dossier d'exercice.
4. Exécutez une toute petite tâche.
5. Vérifiez le résultat avant de décider de la suite.

Réussir une première tâche dans un environnement sûr, limité et réversible demande moins d'effort que d'apprendre d'abord toutes les notions.
