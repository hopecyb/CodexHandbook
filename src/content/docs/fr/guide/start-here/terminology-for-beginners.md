Pour un glossaire plus complet, consultez le [Glossaire](/guide/reference/glossary/). Voici le premier lot :

| Terme | Définition en une ligne |
|---|---|
| **Prompt** | L'objectif, le contexte et les exigences que vous donnez à Codex |
| **Contexte** | Les informations de projet, fichier et conversation que le modèle peut actuellement voir |
| **Agent** | Un mode d'exécution qui appelle des outils et itère vers un objectif |
| **Outil** | Capacités appelables telles que la lecture de fichiers, l'exécution de commands et la recherche |
| **Bac à sable** | Un environnement d'exécution qui limite l'impact sur le système de fichiers et le réseau |
| **Approbation** | Votre consentement explicite avant que certaines opérations ne continuent |
| **Diff** | Une comparaison avant/après des modifications pour votre revue |
| **Fil / session** | Une conversation continue et son Contexte accumulé |
| **Tâche** | Une unité de travail orientée objectif (peut couvrir plusieurs appels d'outils) |
| **Skill** | Un paquet réutilisable d'instructions et de ressources spécialisées (avancé) |
| **MCP** | Un protocole pour connecter des outils et sources de données externes (avancé) |
| **Tâche Cloud** | Une Tâche s'exécutant dans un environnement cloud, pas dans le Bac à sable local |

Lorsque vous rencontrez un terme inconnu, revenez ici ou au glossaire avant de continuer.
