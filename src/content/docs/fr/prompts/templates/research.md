# Modèle de recherche

La recherche n'est pas une Q&R simple : vous voulez la réponse **et** d'où elle vient.

## Modèle

```text
Question de recherche : 【une phrase】
Dimensions d'évaluation : 【3 à 5 critères】
Contraintes :
- chaque conclusion avec URL source ou chemin @dans le dépôt
- ce qui n'est pas vérifiable : marquer « à confirmer »
- ne pas modifier le code
Sortie : tableau comparatif + recommandation + questions ouvertes
```

## Quand l'utiliser

- comparer produits ou approches
- capacités, règles ou écarts récents
- conclusions auditables

## Idées reçues

### 1. Recherche = bien rédiger un résumé

Ici : sources, limites, points à confirmer.

### 2. Mieux une fausse certitude que « je ne sais pas »

« À confirmer » vaut mieux qu'un faux positif.

Règle clé : chaque conclusion importante doit être **traçable** — pas seulement bien formatée.
