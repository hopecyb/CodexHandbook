ตัวอย่างต่อไปนี้ใช้ **แอปเดสก์ท็อป** เป็นค่าเริ่มต้น แต่ CLI/IDE ก็ใช้พรอมป์เดียวกันได้

## ข้อมูลเมตา

| ฟิลด์ | เนื้อหา |
|---|---|
| ผู้อ่านที่เหมาะสม | ผู้เริ่มต้น |
| ไคลเอนต์ | แอปเดสก์ท็อป (แนะนำ) |
| เวลาโดยประมาณ | 15–20 นาที |

## 1. เป้าหมายและบริบท

**เป้าหมาย:** แก้ไขไฟล์ในโปรเจกต์ฝึกอย่างปลอดภัยหนึ่งครั้ง

**เกณฑ์ความสำเร็จ:** แก้เฉพาะไฟล์ที่กำหนด ผลลัพธ์ตรงตามคำอธิบายการยอมรับ และคุณอ่าน diff เข้าใจ

## 2. การเตรียมพร้อม

- ติดตั้งไคลเอนต์และเข้าสู่ระบบแล้ว
- สร้างโปรเจกต์ฝึกแล้ว (มี `hello.md` หรือไฟล์ลักษณะเดียวกัน)

## 3. พรอมป์ที่แนะนำ

```text
เป้าหมาย: เพิ่มหัวข้อ “แบบฝึกวันนี้” ต่อท้าย hello.md พร้อมรายการหัวข้อย่อยสามบรรทัด
ข้อจำกัด: แก้เฉพาะ hello.md ห้ามลบเนื้อหาเดิม และห้ามส่งคำขอผ่านเครือข่าย
การยอมรับ: ท้ายไฟล์มีหัวข้อนี้และมีรายการย่อยสามรายการพอดี
ถ้าข้อมูลไม่พอ ให้ถามฉันก่อน อย่าคาดเดา
```

## 4. ลงมือทำและตรวจสอบ

1. ให้ระบบเสนอแผนสั้น ๆ ก่อน (หรือคุณขอแผนเอง)
2. เมื่ออนุมัติการเขียนไฟล์ ให้ตรวจว่าพาธถูกต้อง
3. เมื่อเสร็จแล้ว ตรวจ diff เทียบกับเกณฑ์ยอมรับทีละข้อ
