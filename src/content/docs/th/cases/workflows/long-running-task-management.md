ปัญหาที่พบบ่อยในงานยาวคือ **บริบทเต็ม** **คนต้องออกไป** **ทิศทางค่อย ๆ เปลี่ยน** และ **ไม่รู้ว่าเมื่อใดควรหยุด** หน้านี้นำ [สำรวจ—วางแผน—ลงมือ—ยืนยันผล](/th/cases/workflows/explore-plan-execute-verify/) มาใช้กับสถานการณ์ที่กินเวลาหลายชั่วโมงหรือหลาย session

## ประเด็นสำคัญของหน้านี้

- เมื่อใดควรแยกงาน และเมื่อใดควรมอบหมายให้ Cloud
- จุดตรวจและบันทึกสถานะควรเขียนอะไร
- เงื่อนไขออกของงานอัตโนมัติระยะยาว

เนื้อหาที่เกี่ยวข้อง: [มอบหมายและติดตาม](/th/guide/web-and-cloud/delegate-and-follow-up/) · [Automations](/th/skills/automations/scheduled-tasks/)

## สัญญาณว่าเป็นงานระยะยาว

- คาดว่าใช้เวลาประมวลผลเกิน 30 นาที
- เกี่ยวข้องกับหลาย subsystem หรือมากกว่า 20 ไฟล์
- ต้องรอข้อเสนอแนะจากคนหรือ API ภายนอก
- ต้องรัน E2E / performance test ทั้งชุด

หากตรงข้อใดข้อหนึ่ง ควรเขียนแผนก่อนเสมอ อย่าคุยต่อไปเรื่อย ๆ จนจบ

## การจัดการสามช่วง

### 1. ตรึงแผน

สร้างแผนลายลักษณ์อักษร ได้แก่ ขอบเขต สิ่งที่ไม่ทำ milestone และคำสั่งยอมรับ ให้คนยืนยันก่อนลงมือครั้งใหญ่

[การวางแผน](/th/guide/agent-work/planning/) · [Agent ย่อย](/th/guide/agent-work/subagents/)

### 2. จุดตรวจ

เมื่อจบแต่ละ milestone:

- commit หรือ stash ส่วนเพิ่มที่ตรวจได้
- อัปเดต `PROGRESS.md` หรือ comment ใน issue ว่าทำอะไรแล้ว ขั้นถัดไป และสิ่งที่ขวาง
- เมื่อบริบทเต็ม ให้ใช้ [การบีบอัด](/th/guide/context/compaction/) หรือเปิด session ใหม่พร้อมลิงก์ไฟล์ความคืบหน้า

### 3. ปิดงานหรือมอบหมาย

- เครื่อง local รองรับไม่ไหว → [มอบหมายให้ Cloud](/th/guide/web-and-cloud/delegate-and-follow-up/)
- ต้องติดตามต่อเนื่อง → Automation + กำหนด **max iterations / เวลาสิ้นสุด** ชัดเจน

## เงื่อนไขออก (จำเป็นสำหรับระบบอัตโนมัติ)

| เงื่อนไข | คำอธิบาย |
|---|---|
| เวลาสูงสุด | แจ้งเตือนหากไม่มีความคืบหน้า 4h |
| จำนวนรอบสูงสุด | หยุดหากการทดสอบเดียวกันล้มเหลว 3 ครั้ง |
| ประตูกำกับโดยคน | ต้อง @ คนก่อนแก้การตั้งค่า production |
| เงื่อนไขสำเร็จ | การทดสอบเขียว + เปิด PR แล้ว |

## ข้อผิดพลาดที่พบบ่อย

- ไม่มีไฟล์ PROGRESS ทำให้เปลี่ยน session แล้วทำงานซ้ำ
- ไม่กำหนดสิ่งที่ไม่ทำในงานยาว Agent จึงถือโอกาส “จัดทั้ง repository”
- ปล่อยงาน Cloud ค้างข้ามคืนโดยไม่มีคนอนุมัติ

- [ ] รู้วิธีหยุดชั่วคราว ทำต่อ หรือส่งต่องาน
