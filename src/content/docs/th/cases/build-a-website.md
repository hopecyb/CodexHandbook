นำข้อมูลกิจกรรมมาทำเป็นเว็บไซต์หน้าเดียวที่เปิดในเบราว์เซอร์ได้ งานที่ส่งคือหน้าเว็บ static ในเครื่องและบันทึกการยอมรับ กิจกรรมและสถานที่เป็นเรื่องสมมติ และยังไม่กำหนดวิธีสมัคร

[ดาวน์โหลดชุดฝึกฉบับเต็ม](/downloads/reading-event/reading-event-1.0.0.zip) · [เปิดผลงานอ้างอิง](/downloads/reading-event/solution/index.html) · [คำอธิบายสื่อ](/downloads/reading-event/README.md)

## เป้าหมายและการเตรียมพร้อม

หน้าเว็บต้องมีคำอธิบายกิจกรรม เวลา สถานที่ จำนวนที่รับ ค่าใช้จ่าย สิ่งที่ต้องเตรียม และข้อมูลที่รอยืนยัน ปุ่มหลักให้เลื่อนไปยังคำอธิบายการเข้าร่วมในหน้าเดียวกันเท่านั้น ห้ามทำให้ดูเหมือนสมัครได้

หลังแตกไฟล์ ให้คัดลอก starter เป็นไดเรกทอรี work ใหม่ และให้โมเดลแก้เฉพาะ work/index.html ใช้ facts.md, brief.md และ prompt.md ที่รากของชุดฝึกเป็นอินพุตแบบอ่านอย่างเดียว แล้วค่อยดูคำตอบใน solution หลังทำเสร็จ เปิด HTML โดยตรงในเบราว์เซอร์ได้ ไม่ต้องติดตั้ง dependency ฝั่ง frontend

หากต้องการใช้เซิร์ฟเวอร์ในเครื่อง ให้ทำตามคำสั่ง Python ทางเลือกใน README หากพอร์ตถูกใช้งาน ให้เปลี่ยนเป็นพอร์ตว่าง อย่าหยุดบริการที่ไม่ทราบที่มา

## มอบหมายงาน

```text
ใช้ facts.md และ brief.md เติม index.html ปัจจุบันให้เป็นเว็บไซต์หน้าเดียวสำหรับกิจกรรมแลกเปลี่ยนการอ่าน
แก้เฉพาะ index.html ใช้ HTML และ inline CSS ห้ามเพิ่ม dependency ห้ามเชื่อมต่ออินเทอร์เน็ต ห้าม deploy หรือส่งออก
คงวิธีสมัครไว้เป็นข้อมูลรอยืนยัน และให้ปุ่มหลักเลื่อนไปยังคำอธิบายการเข้าร่วมในหน้าเท่านั้น
เมื่อเสร็จแล้ว ให้ตรวจเดสก์ท็อป จอแคบ 375px focus จากแป้นพิมพ์ และลิงก์ภายในหน้า
แสดงผลการตรวจที่รันจริงและรายการที่ยังไม่เสร็จ ห้ามเขียนว่าส่วนที่ไม่ได้รันผ่านแล้ว
```

[เลย์เอาต์อ้างอิง](/downloads/reading-event/wireframe.md) อธิบายลำดับการอ่านแบบสองคอลัมน์บนเดสก์ท็อปและคอลัมน์เดียวบนมือถือ สีและองค์ประกอบตกแต่งเปลี่ยนได้ แต่ข้อเท็จจริงของกิจกรรม รายการที่ยังไม่ทราบ และเงื่อนไขยอมรับห้ามเปลี่ยน

## ตรวจผลงาน

| รายการตรวจ | เกณฑ์เสร็จสมบูรณ์ |
|---|---|
| ข้อเท็จจริง | 2026-10-17 14:00—15:30, ห้องอ่านหนังสือสมมติ, 18 คน, ฟรี และนำหนังสือมาได้ตามสมัครใจ ต้องตรงกับสื่อ |
| ข้อมูลที่ยังไม่ทราบ | คงวิธีสมัครไว้เป็นรอยืนยัน ห้ามแต่ง QR code หมายเลขโทรศัพท์ หรือลิงก์ |
| มือถือ | อ่านได้บนจอแคบ 375px และหน้าไม่ล้นแนวนอน |
| การใช้งาน | กด Tab ไปถึงปุ่มหลักได้ focus มองเห็นชัด และกด Enter หรือคลิกแล้วไปยังคำอธิบายการเข้าร่วมได้ |
| ขอบเขต | แก้เฉพาะ work/index.html ไม่มี dependency ใหม่ การเก็บข้อมูลผ่านฟอร์ม หรือการเผยแพร่ภายนอก |

คัดลอก[เทมเพลตการยอมรับ](/downloads/reading-event/review-template.md) ไปไว้นอกไดเรกทอรี work แล้วกรอกผลของคุณ ผลงานอ้างอิงเขียนโดยผู้เขียน จึงใช้บันทึกของผู้เขียนแทนการยอมรับผลงานโมเดลครั้งนี้ไม่ได้

## ลองแก้ปัญหาปุ่มหนึ่งครั้ง

ปุ่มใน fixtures/broken.html ชี้ไปที่ #signup ผิด แต่ section จริงในหน้าคือ #participation หน้าดูเหมือนสมบูรณ์ แต่ปุ่มไปยังปลายทางที่ถูกต้องไม่ได้

เลือกที่จะรันได้:

```sh
python3 validation/reproduce.py
```

ตัวทำซ้ำจะตรวจหน้าที่ผิดในไดเรกทอรีชั่วคราว ออกด้วยสถานะ 1 และรายงาน missing-fragment หลังแก้เฉพาะ href แล้วตรวจอีกครั้ง จะออกด้วยสถานะ 0 fixture ต้นฉบับต้องไม่เปลี่ยน [บันทึกที่เก็บไว้](/downloads/reading-event/validation/recovery.json) มีเอาต์พุตของการตรวจทั้งสองรอบ

อย่า “แก้” ด้วยการลบปุ่มหรือเพิกเฉยต่อการตรวจ ให้แก้เฉพาะลิงก์ปลายทางแล้วคลิกตรวจจริง สคริปต์ตรวจลิงก์ไม่เข้าใจงานออกแบบ ข้อเท็จจริง หรือประสบการณ์ใช้แป้นพิมพ์ เรื่องเหล่านี้ยังต้องตรวจแยกต่างหาก

## การแก้ภาพจริงและขอบเขตการยืนยัน

ระหว่างการตรวจมือถือครั้งแรก ผู้เขียนพบว่าข้อความรูปหนังสือตกแต่งล้นออกจากการ์ด จึงปรับขนาดตัวอักษรและ padding สำหรับจอแคบแล้วตรวจใหม่ บันทึกการสังเกตหน้าเดสก์ท็อปและมือถือ focus จากแป้นพิมพ์ ปุ่มหลัก และข้อเท็จจริง F1—F7 อยู่ใน[การตรวจด้วยเบราว์เซอร์](/downloads/reading-event/validation/browser-review.md)

ครั้งนี้ไม่ได้ทดสอบทุกเบราว์เซอร์ โทรศัพท์จริง การใช้งาน screen reader แบบครบถ้วน หรือการทำงานสำเร็จของผู้อ่านอิสระ ไม่ได้เผยแพร่เว็บไซต์ และไม่ได้วัดอัตราความสำเร็จของโมเดล หากต้องเผยแพร่ ต้องยืนยันตำแหน่งโฮสต์ เนื้อหาสาธารณะ และสิทธิ์ deploy แยกต่างหาก
