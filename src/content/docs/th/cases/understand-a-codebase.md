## ข้อมูลเมตา

| ฟิลด์ | เนื้อหา |
|---|---|
| ผู้อ่านที่เหมาะสม | นักพัฒนา |
| ไคลเอนต์ | CLI / IDE |
| เวลาโดยประมาณ | 30–60 นาที |

## 1. เป้าหมายและบริบท

**เป้าหมาย:** เข้าใจขอบเขตโมดูล จุดเข้า และพื้นที่เสี่ยงก่อนเปลี่ยนแปลง

**เกณฑ์ความสำเร็จ:** อธิบายเส้นทางหลัก “จาก request ถึง response” หรือ “จากคำสั่งถึงเอาต์พุต” ให้ผู้อื่นเข้าใจได้

## 2. พรอมป์ที่แนะนำ

```text
ยังไม่ต้องแก้โค้ด อ่าน @src/ และ @README แล้วสรุปไม่เกิน 8 ข้อ:
1. วัตถุประสงค์และ tech stack ของโปรเจกต์
2. หน้าที่ของไดเรกทอรีหลัก
3. จุดเริ่มต้นสำหรับรัน/ทดสอบ
4. ไฟล์ 3 ไฟล์ที่เกี่ยวข้องกับ 【เป้าหมายของฉัน】 มากที่สุด
5. คำถาม 3 ข้อที่ต้องให้ฉันยืนยัน
```

## 3. การยืนยันผล

- สุ่มตรวจเทียบกับ `package.json` / ไฟล์จุดเข้าใช้งานจริง
- เขียนข้อสรุปลงใน issue หรือบทสรุปใน `AGENTS.md`
