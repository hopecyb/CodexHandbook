กรณีระบบอัตโนมัติของทีมทำให้เผลอทำเกินขอบเขตได้ง่ายเมื่อเริ่มตื่นเต้น มุมมองที่เหมาะกว่าคือ มอบเฉพาะงานซ้ำที่มีกติกาชัดเจนให้ระบบ ส่วนที่เหลือยังให้คนใช้วิจารณญาณ

## ทางเข้าของกลุ่มนี้

- [ตรวจลิงก์เอกสารตามกำหนดเวลา](/th/cases/use-cases/team-automation/scheduled-link-check/)
- [ข้อเสนอแนะคัดแยก Issue](/th/cases/use-cases/team-automation/issue-triage-suggestions/)

## ประเด็นสำคัญของกลุ่มนี้

- งานใดเหมาะกับระบบอัตโนมัติเต็มรูปแบบ และงานใดควรให้เพียงคำแนะนำ
- เมื่อผิดพลาดหรือเกิดความผิดปกติ ควรแจ้งเตือนและหยุดอย่างไร
- เหตุใด “เปิด draft PR อัตโนมัติ” จึงมักปลอดภัยกว่า “แก้ main branch อัตโนมัติ”
