ก่อนคัดลอก ให้ลบหัวข้อที่ไม่จำเป็นตามผู้อ่านและผลงานจริง

## 1. เป้าหมายและบริบท

- **เป้าหมายทางธุรกิจ:** หนึ่งประโยค
- **เกณฑ์ความสำเร็จ:** สังเกตและตรวจสอบได้
- **นอกขอบเขต:** ระบุสิ่งที่ตัดออกอย่างชัดเจน

## 2. การเตรียมพร้อม

- บัญชี/สิทธิ์/สถานะ repository
- ไฟล์บริบทที่ต้องใช้ (`AGENTS.md`, แบบออกแบบ ฯลฯ)
- ความเสี่ยง: ข้อมูล production และ secret

## 3. เวิร์กโฟลว์ (EPXV)

### สำรวจ

- พรอมป์อินพุต (สรุป)
- สิ่งสำคัญที่ค้นพบ

### วางแผน

- รายการขั้นตอน
- จุดยืนยันโดยคน

### ลงมือ

- ขอบเขตการเปลี่ยนแปลงจริง
- สิ่งที่ต่างจากแผนและเหตุผล

### ยืนยันผล

- การทดสอบอัตโนมัติ
- การตรวจด้วยคน
- หลักฐาน (ภาพหน้าจอ log ลิงก์)

## 4. ความล้มเหลวและการกู้คืน

- พบปัญหาอะไร
- ย้อนกลับหรือแก้ไขอย่างไร
- หากเริ่มใหม่ จะเปลี่ยนพรอมป์/การตั้งค่าอย่างไร

## 5. เก็บเป็นความรู้ใช้ซ้ำ

- เขียนลง `AGENTS.md` / Skill / Automation หรือไม่
- คำแนะนำ 3 ข้อสำหรับทีม

## 6. แหล่งอ้างอิง
- ลิงก์เอกสารทางการ
- กรณีศึกษานี้ดัดแปลงจากบทเรียนภายนอกหรือไม่ (ยืมเฉพาะประเภทงาน)
