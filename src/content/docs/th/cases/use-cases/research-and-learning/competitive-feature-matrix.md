| ฟิลด์ | เนื้อหา |

| ไคลเอนต์ | App หรือ CLI |
| เวลาโดยประมาณ | 45 นาที |
| วันที่ยืนยัน | 2026-07-25 |

## 1. เป้าหมายและบริบท

**เป้าหมาย:** สร้างตารางเปรียบเทียบคู่แข่ง 3–5 ราย (ความสามารถ เบาะแสราคา สถานการณ์ที่เหมาะสม) โดยทุกข้อสรุปมีแหล่งข้อมูล

**เกณฑ์ความสำเร็จ:**

- ตาราง Markdown + ป้าย “รอยืนยัน”
- ไม่แต่งราคาหรือหมายเลขเวอร์ชัน
- ไม่เขียนข้อมูลลับภายในลงเอกสารภายนอก

## 2. การเตรียมพร้อม

- กำหนดมิติเปรียบเทียบให้ชัด (เขียนไว้ล่วงหน้าในพรอมป์หรือ `@brief.md`)
- เปิดใช้ [การค้นเว็บ](/th/guide/tools/web-search/) (หากผลิตภัณฑ์รองรับ)

## 3. เวิร์กโฟลว์

ทำตาม [การวิจัยพร้อมแหล่งอ้างอิง](/th/cases/workflows/research-with-sources/):

```text
เปรียบเทียบความสามารถ “การทำงานร่วมกันเป็นทีม” ของ A/B/C:
แต่ละมิติมีคำอธิบาย 1–2 ประโยคพร้อม URL แหล่งข้อมูล
ให้ความสำคัญกับเอกสารทางการมากกว่าบล็อก
หากยืนยันราคาไม่ได้ ให้ระบุ “รอยืนยัน”
ส่งออกเป็นตาราง markdown และห้ามแก้ไฟล์อื่นใน repository
```

**การยืนยัน:** ให้คนเปิด URL 3 รายการ ตรวจวันที่และ [นโยบายการยืนยัน](/th/guide/start-here/handbook-version-policy/)

## 4. ความล้มเหลวและการกู้คืน

- แหล่งข้อมูลขัดกัน: ให้แสดงสองคำอธิบายคู่กัน ห้ามบังคับให้เป็นข้อสรุปเดียว
- บริบทยาวเกินไป: แยกเป็น “A เทียบ B ก่อน แล้วค่อยเพิ่ม C”

## 5. เก็บเป็นความรู้ใช้ซ้ำ

- เก็บเทมเพลตตารางเปรียบเทียบในไดเรกทอรีเทมเพลตหรือฐานความรู้ที่ทีมตกลง
- เปลี่ยนเป็น Skill ได้: `source-backed-research`
