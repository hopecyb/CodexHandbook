เว็บไซต์นี้ยังไม่ได้ทดสอบความเข้ากันได้กับไคลเอนต์และแพ็กเกจ Pet ที่เฉพาะเจาะจง โปรดบันทึกเวอร์ชันและแหล่งที่มาก่อน แล้วใช้[บันทึกความเข้ากันได้และการกู้คืน](/th/guide/reference/resource-compatibility/)เพื่อตรวจสอบผลลัพธ์จริง ภาพประกอบมีไว้เพื่ออธิบายโครงสร้างเท่านั้น ไม่ได้หมายความว่าเป็นข้อกำหนดรูปแบบสำหรับทุกเวอร์ชัน


เป้าหมายของการสร้าง Codex Pet ไม่ใช่เพียงการได้ภาพสวย ๆ หนึ่งภาพ แต่คือการได้แพ็กเกจทรัพยากรที่ Codex รู้จัก เล่นได้ และสลับสถานะได้ คุณสามารถมองว่าเป็นการรวมกันของ “เมทาดาทา + ชุดภาพแอนิเมชัน + ข้อมูลสิทธิ์การใช้งาน”

![ภาพประกอบ: ขั้นตอนการสร้างตั้งแต่สเก็ตช์ด้วยมือ จัดแนวกริด สร้างชุดภาพแอ็กชัน จนถึงการจัดเป็นแพ็กเกจในโฟลเดอร์ Pet](/illustrations/pets-create.webp)

โครงสร้างขั้นต่ำโดยทั่วไปคือ:

```text
<pet-id>/
  pet.json
  spritesheet.webp
```

## spritesheet คืออะไร

![ภาพประกอบ: ภาพชุดหนึ่งจัดวางแอ็กชันหลายแบบเป็นแถวและคอลัมน์ จากนั้นตัดแต่ละเฟรมมาต่อเป็นแถบฟิล์มแล้วเล่นบนหน้าจอ](/illustrations/pets-spritesheet.webp)

spritesheet คือการรวมแอนิเมชันหลายเฟรมไว้ในภาพขนาดใหญ่ภาพเดียว ไคลเอนต์จึงไม่ต้องโหลดภาพขนาดเล็กหลายสิบภาพ แต่จะตัดแต่ละเฟรมจากภาพขนาดใหญ่ตามพิกัดแถวและคอลัมน์ แล้วเล่นต่อเนื่องกัน

ต้องตรวจสอบข้อกำหนดของชุดภาพควบคู่กับฟิลด์เวอร์ชันเสมอ ภาพตัวอย่างเก่าของเว็บไซต์นี้ใช้ 8 คอลัมน์ × 9 แถว โดยแต่ละเฟรมมีขนาด 192 × 208 px (ภาพทั้งชุด 1536 × 1872 px) แต่ไม่สามารถใช้เป็นข้อกำหนดทั่วไปสำหรับไคลเอนต์ทุกตัวได้ ก่อนสร้าง ควรหาเอกสารรูปแบบของเวอร์ชันที่ตรงกับไคลเอนต์หรือเครื่องมือสร้างเป้าหมาย ตรวจสอบจำนวนแถวและคอลัมน์ การแมปแอ็กชัน และฟิลด์เวอร์ชัน แล้วจึงสร้างแอสเซ็ต

สำหรับชุดภาพแบบขยาย ห้ามเปลี่ยนเพียงความสูงของภาพแล้วยังคงใช้เมทาดาทาเก่า เมื่อไม่มีเอกสารรูปแบบที่ตรวจสอบย้อนกลับได้ ให้หยุดการสร้างไว้ก่อนและค้นหาข้อกำหนดให้ชัดเจน อย่าอนุมานความเข้ากันได้จากภาพตัวอย่าง

## การเตรียมแอสเซ็ต

แอสเซ็ตควรมีคุณสมบัติดังนี้:

- รูปร่างของตัวละครชัดเจน และสามารถตัดพื้นหลังออกได้อย่างสะอาด
- สัดส่วน มุมมอง และเส้นฐานของตัวละครในแต่ละแอ็กชันสอดคล้องกัน
- พื้นหลังโปร่งใสไม่มีขอบสี ภาพซ้อนตกค้าง หรือพิกเซลส่วนเกิน
- ตัวละครไม่ชิดขอบ เพื่อป้องกันการถูกตัดระหว่างเล่น
- แอ็กชันสอดคล้องกับสถานะ เช่น ทำงาน รอ เสร็จสิ้น ล้มเหลว เคลื่อนที่ หรือไม่ได้ใช้งาน

หากแอสเซ็ตมาจากผลงานแฟนเมด เกม อนิเมะ แบรนด์ หรือผลงานของผู้อื่น ต้องตรวจสอบแหล่งที่มาและสิทธิ์การใช้งานก่อน อย่าระบุว่าแอสเซ็ตที่ไม่ได้รับอนุญาตสามารถนำไปใช้เชิงพาณิชย์ได้

## `pet.json` ทำหน้าที่อะไร

ตัวอย่างต่อไปนี้แสดงเฉพาะฟิลด์ระบุตัวตนและพาธของแอสเซ็ต ไม่ใช่แพ็กเกจฉบับสมบูรณ์ที่ผ่านการตรวจสอบแล้วว่าสามารถติดตั้งได้ รูปแบบจริงอาจต้องมีฟิลด์เวอร์ชันเพิ่มเติม:

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "A focused companion for Codex sessions.",
  "spritesheetPath": "spritesheet.webp"
}
```

คำแนะนำ:

- `id` ใช้ตัวอักษรพิมพ์เล็ก ตัวเลข และขีดกลาง
- ชื่อโฟลเดอร์ต้องตรงกับ `id`
- `spritesheetPath` ใช้พาธแบบสัมพัทธ์
- `description` อธิบายให้ชัดเจนว่า Pet นี้คืออะไร ไม่ใช้คำบรรยายกว้าง ๆ ที่ไม่มีสาระ
- เก็บชื่อผู้สร้าง เวอร์ชัน แหล่งที่มา และใบอนุญาตไว้ใน README หรือ LICENSE ที่มาพร้อมแพ็กเกจ อย่าคาดว่าไคลเอนต์จะรองรับฟิลด์ส่วนขยายใด ๆ ก็ได้

`pet.json` ไม่ได้ทำหน้าที่เก็บแอนิเมชัน แต่ใช้บอกไคลเอนต์ว่า “แพ็กเกจนี้คืออะไร แอสเซ็ตอยู่ที่ไหน และควรตีความอย่างไร” เมื่อพาธของแอสเซ็ต ชื่อไฟล์ หรือโครงสร้างไดเรกทอรีไม่สอดคล้องกัน โดยทั่วไปไคลเอนต์จะโหลดแพ็กเกจไม่ได้

## การตรวจสอบในเครื่อง

ก่อนเผยแพร่หรือแชร์ อย่างน้อยให้ตรวจสอบว่า:

- `pet.json` เป็น JSON ที่ถูกต้อง
- `spritesheetPath` ชี้ไปยังไฟล์ที่มีอยู่จริง
- ขนาดของ spritesheet และกริดเฟรมเป็นไปตามข้อกำหนดปัจจุบัน
- แอนิเมชันในแต่ละแถวไม่มีอาการข้ามเฟรม เลื่อนตำแหน่ง หรือถูกตัดอย่างเห็นได้ชัด
- พื้นหลังโปร่งใสสะอาด
- ภายในแพ็กเกจไม่มีไฟล์ชั่วคราว ภาพต้นฉบับ หรือแอสเซ็ตที่ไม่ควรเผยแพร่

## สิทธิ์การใช้งานและแหล่งที่มา

แอสเซ็ต Pet มักมาจากผลงานแฟนเมด ภาพหน้าจอ ภาพที่สร้างด้วย AI คลังภาพสาธารณะ หรือผลงานของผู้อื่น ระหว่างการสร้างต้องแยกให้ออกว่า:

- คุณสามารถใช้เป็นการส่วนตัวได้หรือไม่
- คุณสามารถแชร์ต่อสาธารณะได้หรือไม่
- คุณสามารถอนุญาตให้ผู้อื่นเผยแพร่ต่อได้หรือไม่
- คุณต้องระบุชื่อเจ้าของผลงานหรือเก็บลิงก์แหล่งที่มาไว้หรือไม่

การเก็บไฟล์โปรเจกต์ต้นฉบับและบันทึกแหล่งที่มาไว้ จะช่วยให้การเก็บขอบภาพ ปรับแอ็กชัน เปลี่ยนขนาด และเพิ่มเติมข้อมูลสิทธิ์การใช้งานในภายหลังทำได้ง่ายขึ้น
