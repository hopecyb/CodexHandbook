Codex Dream Skin เป็นโครงการธีมเดสก์ท็อปจากบุคคลที่สาม ตามคำอธิบายของโครงการ ธีมนี้เชื่อมต่อผ่าน CDP ภายในเครื่องเพื่อแทรกรูปลักษณ์ โดยไม่แก้ไขแพ็กเกจติดตั้งอย่างเป็นทางการ นี่เป็นวิธีทำงานตามคำอธิบายของผู้พัฒนา เว็บไซต์นี้ยังไม่ได้ใช้ข้อมูลดังกล่าวเพื่อยืนยันพฤติกรรมของไฟล์ พฤติกรรมเครือข่าย หรือความเข้ากันได้ของอินเทอร์เฟซในทุกเวอร์ชัน

![ตัวอย่างรูปลักษณ์ของธีม](/theme/codex-dream-skin/article/codex-dream-skin-home.jpg)

ภาพตัวอย่างรูปลักษณ์ที่มีอยู่ในเว็บไซต์นี้ไม่ถือเป็นหลักฐานการทดสอบเวอร์ชันครั้งนี้ และไม่สามารถยืนยันได้ว่าช่องป้อนข้อมูล ปุ่มอนุมัติ และมุมมองงานทั้งหมดทำงานเป็นปกติ

## สถานะเวอร์ชันและการตรวจสอบ

| รายการ | ผลการตรวจสอบครั้งนี้ |
|---|---|
| แหล่งที่มา | [repository ของโครงการ](https://github.com/Fei-Away/Codex-Dream-Skin) และ [หน้า Releases](https://github.com/Fei-Away/Codex-Dream-Skin/releases) |
| ผลการตรวจสอบหน้า Releases | ตรวจสอบ [v1.5.18](https://github.com/Fei-Away/Codex-Dream-Skin/releases/tag/v1.5.18) เมื่อ 2026-09-18, commit `34335d27d54300eccb325cc652f6c93fef428b84`; ยังไม่ได้ติดตั้ง |
| ข้อมูลไคลเอนต์ในเครื่อง | อ่าน Info.plist แบบอ่านอย่างเดียว: 26.911.61220, build 9647, identifier คือ com.openai.codex |

บันทึกประจำรุ่นระบุว่าการแก้ไขอินเทอร์เฟซบางส่วนได้รับการตรวจสอบกับ Codex สำหรับ macOS รุ่น upstream 26.901.41123 ซึ่งต่างจาก 26.911.61220 ที่เว็บไซต์นี้บันทึกไว้แบบอ่านอย่างเดียว จึงไม่สามารถอนุมานต่อได้ว่าชุดเวอร์ชันนี้เข้ากันได้ ลิงก์ติดตั้งสำหรับ macOS ในหน้านี้ตรึงไว้ที่ v1.5.18 แล้ว หากใช้เวอร์ชันอื่นให้ตรวจสอบ tag ที่ตรงกัน

เวอร์ชันไคลเอนต์ที่อ่านได้เป็นเพียงข้อมูลสภาพแวดล้อม ไม่ใช่หลักฐานความเข้ากันได้ของธีม คุณสามารถใช้[บันทึกความเข้ากันได้และการกู้คืนทรัพยากร](/th/guide/reference/resource-compatibility/)เพื่อบันทึกผลการทดสอบจริง

## การเตรียมพร้อมก่อนติดตั้ง

1. เลือกเวอร์ชันที่ระบุชัดเจนจากหน้า Releases ของโครงการ แล้วบันทึกชื่อแพ็กเกจ URL ดาวน์โหลด และ SHA-256 หากผู้เผยแพร่มีไฟล์ checksum ให้ตรวจเทียบกับแพ็กเกจที่ดาวน์โหลด ค่าแฮชตรงกันพิสูจน์ได้เพียงว่าไฟล์ตรงกัน ไม่ได้พิสูจน์ว่าโปรแกรมปลอดภัย
2. บันทึกเวอร์ชันไคลเอนต์ เวอร์ชันระบบ การกำหนดค่าธีม และสำเนารูปภาพกำหนดเองที่คุณมีสิทธิ์ใช้งานในปัจจุบัน พร้อมบันทึกตำแหน่งข้อมูลสำรอง
3. ตรวจสอบหน้าแรก หน้างาน การป้อนข้อมูล การเลื่อน การค้นหา และอินเทอร์เฟซการอนุมัติในรูปลักษณ์เดิมก่อน เพื่อใช้เป็นข้อมูลเปรียบเทียบ
4. อ่านคำแนะนำการติดตั้ง อัปเดต และถอนการติดตั้งที่ตรงกับเวอร์ชันเผยแพร่ เอกสารบน branch `main` ของ repository อาจใหม่กว่าแพ็กเกจติดตั้ง

สำหรับ macOS โปรดอ่าน[คำแนะนำการติดตั้งของโครงการ](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.18/docs/install-macos.md) และสำหรับ Windows โปรดอ่าน[คำแนะนำการติดตั้งของโครงการ](https://github.com/Fei-Away/Codex-Dream-Skin/blob/main/docs/install-windows.md) เว็บไซต์นี้จะไม่สรุปว่าอาการ “เสียหาย” หรือการถูกระบบบล็อกทั้งหมดเกิดจากไม่มีลายเซ็น ควรตรวจสอบแหล่งที่มา ความสมบูรณ์ของแพ็กเกจ และข้อผิดพลาดที่เกิดขึ้นจริงก่อน แล้วจึงตัดสินใจว่าจะดำเนินการต่อหรือไม่

## สิ่งที่ต้องตรวจสอบหลังเปลี่ยนรูปภาพ

โครงการมีฟังก์ชันจัดการภาพพื้นหลังและธีม ชื่อเมนูให้ยึดตามเวอร์ชันที่ใช้งาน ใช้เฉพาะรูปภาพที่คุณมีสิทธิ์ใช้ และตรวจสอบทั้งโหมดสว่าง โหมดมืด การปรับขนาดหน้าต่าง และหน้างานจริง

- ช่องป้อนข้อมูล ปุ่ม และข้อมูลการอนุมัติยังมองเห็น คลิก และโฟกัสได้ชัดเจนหรือไม่
- ผลการค้นหา เอาต์พุตยาว code diff และข้อความแสดงข้อผิดพลาดถูกพื้นหลังบดบังหรือไม่
- หลังสลับหน้าและเริ่มแอปใหม่ ธีมที่แสดงยังตรงกับธีมที่เลือกหรือไม่
- หลังปิดธีม อินเทอร์เฟซเดิมกลับคืนมาหรือไม่ และยังทำให้ปัญหาเดิมเกิดซ้ำได้หรือไม่

หากมีส่วนใดถูกบดบังหรือใช้งานไม่ได้ ให้หยุดใช้ธีมนั้นและดำเนินการกู้คืนก่อน อย่าพยายามซ่อนปัญหาด้วยการซ้อนสไตล์เพิ่มเติม

## การถอนการติดตั้งและการกู้คืน

เอกสาร macOS ของโครงการกำหนดให้เลือก “คืนสภาพเดิมและถอนการติดตั้ง” จากแถบเมนูก่อน แล้วจึงนำแอปธีมออก ส่วนธีมและรูปภาพของผู้ใช้ให้เก็บไว้หรือล้างแยกต่างหาก สำรองทรัพยากรกำหนดเองก่อนดำเนินการ สำหรับ Windows ให้ทำตามเอกสารของเวอร์ชันที่ใช้งาน และอย่านำ path ของ macOS ไปใช้

ต่อไปนี้เป็นวิธีตรวจรับการกู้คืนที่เว็บไซต์นี้แนะนำ ไม่ใช่บันทึกผลการทำงานที่ดำเนินการเสร็จแล้ว:

1. บันทึกงานในไคลเอนต์ รวมถึงธีมปัจจุบันและไฟล์ที่ต้องการเก็บไว้
2. ใช้กระบวนการกู้คืนที่เครื่องมือธีมมีให้ และเก็บข้อความแจ้งว่าสำเร็จ ล้มเหลว หรือยังยืนยันสถานะไม่ได้
3. เปิดแอปใหม่จากทางเข้าไคลเอนต์ตามปกติ แล้วตรวจสอบพื้นหลัง ข้อความ การป้อนข้อมูล และการนำทางงาน
4. ยืนยันว่าเครื่องมือธีมไม่เริ่มทำงานอัตโนมัติหรือแทรกตัวเองอีก หากต้องตรวจสอบทางเทคนิค ให้ตรวจสอบ process และการเชื่อมต่อ debugging โดยไม่ยุติ process ที่ใช้ชื่อเหมือนกันโดยพลการ
5. นำแอปออกหลังผ่านการตรวจรับแล้วเท่านั้น เก็บรูปภาพกำหนดเองไว้ก่อน และจัดการแยกต่างหากเมื่อยืนยันว่าไม่ต้องการใช้อีก

การมีข้อมูลสำรอง การที่โปรแกรมถอนการติดตั้งปิดตัวลง หรือการที่หน้าต่างธีมปิดลง ไม่สามารถยืนยันว่ากู้คืนสำเร็จได้เพียงลำพัง หากยังยืนยันผลไม่ได้ ให้เก็บ log แล้วตรวจสอบ Issue ของโครงการ และอย่าเขียนว่า “กู้คืนแล้ว” อย่าลบไดเรกทอรีการกำหนดค่า Codex ทั้งหมดเพื่อถอนการติดตั้งธีม

## ขอบเขตการใช้งาน

CDP สามารถเปลี่ยนเนื้อหาของหน้าได้ ดังนั้น “ไม่แก้ไขแพ็กเกจติดตั้งอย่างเป็นทางการ” จึงไม่ได้หมายความว่าจะไม่ส่งผลต่อการใช้งาน เมื่อโครงสร้างอินเทอร์เฟซเปลี่ยน ควรตรวจสอบใหม่ คำอธิบายของโครงการเกี่ยวกับการประมวลผลภายในเครื่อง การเข้าถึงเครือข่าย และกลไกการกู้คืนก็ต้องตรวจสอบตามแต่ละเวอร์ชันเช่นกัน เว็บไซต์นี้ไม่รับรองว่าสื่อทั้งหมดจะไม่ถูกอัปโหลด ทุกเวอร์ชันจะกู้คืนได้ด้วยคลิกเดียว หรือการอัปเดตแบบทับจะไม่ทำให้ข้อมูลสูญหายเสมอไป
