ตรวจสถานะวัสดุก่อนเลือกตัวอย่าง แพ็กเกจเต็มมีอินพุต เอกสารอ้างอิง และสคริปต์ตรวจสอบ ส่วนโครงร่างต้องเพิ่มทรัพยากรและการตรวจจริงเอง จึงนำไปใช้เป็น workflow ที่ตรวจสอบแล้วโดยตรงไม่ได้

| ตัวอย่าง | สถานะวัสดุ | ขอบเขตที่ตรวจแล้ว |
|---|---|---|
| [Skill งานเขียน](/th/skills/examples/writing-skill/) | แพ็กเกจดาวน์โหลด source-backed-writer ฉบับเต็ม | การทดสอบโครงสร้างย้อนหลังแปดรายการผ่าน ข้อเท็จจริงและสไตล์ตรวจโดยผู้เขียนเอง ยังไม่ทดสอบคุณภาพโมเดล |
| [Skill ตรวจทาน](/th/skills/examples/review-skill/) | แพ็กเกจดาวน์โหลด scoped-review ฉบับเต็ม | การทดสอบย้อนหลังขอบเขต diff เจ็ดรายการผ่าน ยังไม่ทดสอบการ route โมเดลและอัตราการตรวจพบ |
| [Skill วิจัย](/th/skills/examples/research-skill/) | แพ็กเกจดาวน์โหลด evidence-research ฉบับเต็ม | การทดสอบย้อนหลังโครงสร้างแหล่งข้อมูลและหลักฐานแปดรายการผ่าน ยังไม่ทดสอบคุณภาพงานวิจัยของโมเดล |
| [Skill ทำงานอัตโนมัติ](/th/skills/examples/automation-skill/) | แพ็กเกจดาวน์โหลด quiet-link-monitor ฉบับเต็ม | การทดสอบสถานะแปดรายการผ่าน ยังไม่ทดสอบการกำหนดเวลาจริงและการส่งผลลัพธ์ |

หน้าที่เกี่ยวข้อง: [สร้าง Skill แรก](/th/skills/create-your-first-skill/)

ใช้ [วิธีประเมิน workflow](/th/guide/quality/workflow-evaluation/) บันทึกการทริกเกอร์ ขอบเขต รูปแบบ คุณภาพ และเวลาที่ใช้แยกกัน การที่สคริปต์ตัวอย่างผ่านไม่ได้หมายถึงอัตราความสำเร็จโดยรวมของโมเดล
