Skills ใช้บรรจุวิธีทำงานที่เสถียร เอกสารอ้างอิง เทมเพลต และสคริปต์ให้เป็นความสามารถที่นำกลับมาใช้ได้ คุณค่าของ Skills ไม่ใช่เพียง “ทำให้ Codex ทำได้อีกอย่าง” แต่คือทำให้ workflow หนึ่งชุดมีอินพุต ผลลัพธ์ ขอบเขตสิทธิ์ และวิธีทดสอบที่ชัดเจน

![ภาพประกอบ: ขั้นบันไดเรืองแสงหกระดับ เริ่มจากกระดาษโน้ตพรอมป์ ไปยังโฟลเดอร์ Skill, Agent ย่อย, การเชื่อมต่อ MCP, ประตูเฝ้าระวัง Hook และสุดท้ายคือแพ็กเกจความสามารถที่แจกให้ทีมและรันตามกำหนดเวลา](/illustrations/skills-capability-ladder.webp)
