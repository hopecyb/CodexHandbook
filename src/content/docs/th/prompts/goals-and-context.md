พรอมป์จำนวนมากดูเหมือนมีข้อมูลเยอะ แต่กลับไม่ชัดเจนในสองเรื่องนี้:

- คุณต้องการผลลัพธ์อะไร
- เหตุใดงานนี้จึงต้องทำเช่นนั้น

เป้าหมายมีหน้าที่บอกว่า “ต้องทำให้เป็นแบบใด” ส่วนบริบทบอกว่า “ทำไมจึงต้องทำแบบนี้”

**เป้าหมาย** ควรระบุสิ่งส่งมอบสุดท้าย ไม่ใช่ความต้องการคลุมเครือ  
“ทำให้เว็บไซต์ดีขึ้น” → “เปลี่ยนข้อความปุ่มหลักบนหน้าแรกเป็น……โดยคงชื่อคลาสสไตล์เดิม”

**บริบท** ควรเติมสภาพปัจจุบันที่ผู้อ่านไม่รู้แต่ Agent ต้องใช้ เช่น tech stack กลุ่มเป้าหมาย เหตุผลของกำหนดส่ง และข้อควรระวังที่ทราบแล้ว

## ทำไม “เป้าหมาย” กับ “บริบท” จึงไม่ควรปะปนกัน

หากมีแต่บริบท ไม่มีเป้าหมาย Codex อาจมองว่าเป็นเพียงคำอธิบายสถานการณ์และไม่รู้ว่าคุณต้องการสิ่งส่งมอบใด  
หากมีแต่เป้าหมาย ไม่มีบริบท Codex อาจเลือกวิธีที่ “ทำได้ในทางเทคนิค แต่ไม่เหมาะกับสถานการณ์ของคุณ”

## ความเข้าใจผิดที่พบบ่อย

### 1. เป้าหมายคือ “ฉันอยากปรับให้ดีขึ้นหน่อย”

นี่คล้ายความปรารถนามากกว่าเป้าหมาย

เป้าหมายที่ชัดกว่ามักระบุว่า:

- แก้อะไร
- ให้เป็นสภาพใด
- ต้องคงอะไรไว้

### 2. บริบทไม่ใช่ยิ่งมากยิ่งดี

ส่วนที่มีคุณค่าจริงในบริบทคือข้อมูลที่ **คุณรู้ แต่ Codex ไม่รู้** และมีผลต่อการตัดสินใจ

### 3. มีเพียงบริบททางเทคนิคเท่านั้นที่นับเป็นบริบท

ไม่ใช่แค่บริบททางเทคนิค

ข้อมูลต่อไปนี้ก็อาจเป็นบริบทสำคัญ:

- ผู้อ่านคือใคร
- เหตุผลของกำหนดส่ง
- ข้อควรระวังที่ทราบแล้ว
- ข้อจำกัดของทีม

## รูปแบบที่เพียงพอ

หากต้องการเริ่มจากเวอร์ชันที่ใช้ได้ ให้เขียนดังนี้:

```text
เป้าหมาย: เปลี่ยนอะไรให้เป็นแบบใด
บริบท: ทำไมต้องเปลี่ยน ทำให้ใครดู และตอนนี้ติดปัญหาที่ใด
```

ตัวอย่าง:

```text
เป้าหมาย: ปรับข้อความส่วนแรกของหน้าแรก docs ให้ผู้เริ่มต้นเข้าใจง่ายขึ้น โดยคงโครงสร้างเดิม
บริบท: ข้อความปัจจุบันตั้งสมมติฐานว่าผู้อ่านรู้ศัพท์หลายคำอยู่แล้ว จึงเข้าใจยากเมื่อเข้าชมครั้งแรก
```

## ตรวจอย่างไรว่าชัดเจนเพียงพอ

เมื่อตรวจเป้าหมาย ให้ดูสองเรื่อง:

- มองเห็นผลลัพธ์ได้หรือไม่
- รับรู้ขอบเขตได้หรือไม่

เมื่อตรวจบริบท ให้ดูอีกหนึ่งเรื่อง:

- ข้อมูลเหล่านี้มีผลต่อวิธีทำงานจริงหรือไม่

เป้าหมายกำหนดว่าจะส่งมอบอะไร บริบทอธิบายว่าทำไมจึงต้องทำเช่นนั้น

เรื่องที่เกี่ยวข้อง: เก็บบริบทระดับโปรเจกต์ไว้ใน [บริบทของโปรเจกต์](/th/guide/context/project-context/) เพื่อไม่ต้องใส่คำอธิบายยาวซ้ำในทุกพรอมป์
