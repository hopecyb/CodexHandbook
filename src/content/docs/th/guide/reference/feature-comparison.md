ตารางนี้เปรียบเทียบเฉพาะ**รูปแบบการทำงานหลักที่มีความเสถียร** โดยไม่นำฟีเจอร์ย่อยที่เปลี่ยนแปลงรวดเร็วมาทำเป็นคำมั่นถาวร ให้ใช้ [แผนภาพเลือกไคลเอนต์](/th/guide/choose-your-client/) เพื่อตัดสินใจก่อน แล้วจึงตรวจสอบความแตกต่างที่นี่

## การเปรียบเทียบหลัก

| ช่องทาง | ตำแหน่งที่ทำงาน | บริบทที่เด่นที่สุด | วิธีตรวจทานหลัก | งานทั่วไป |
|---|---|---|---|---|
| ChatGPT App เดสก์ท็อป | โปรเจกต์ในเครื่อง แชต และไฟล์ | โฟลเดอร์ โปรเจกต์ และงานที่เปิดอยู่ | สรุปงาน ไฟล์ diff และหน้าจออนุมัติ | ประสานงานหลายโปรเจกต์ งานระยะยาว และการทำงานกับไฟล์และคอมพิวเตอร์ |
| Codex CLI | เทอร์มินัลปัจจุบันและ repository ในเครื่อง | ไดเรกทอรีทำงาน ผลลัพธ์คำสั่ง และสถานะ Git | คำสั่ง diff และสรุปผลในเทอร์มินัล | สำรวจ แก้ไข ทดสอบ เขียนสคริปต์ และ CI |
| การผสานรวมกับ IDE | เอดิเตอร์ปัจจุบัน | ไฟล์ที่เปิด ส่วนที่เลือก และบทสนทนาล่าสุด | สรุปการเปลี่ยนแปลงและ diff ข้างโค้ด | อธิบายเฉพาะจุด แก้ไขทีละน้อย และตรวจทานในเอดิเตอร์ |
| Codex Cloud | สภาพแวดล้อมระยะไกลที่แยกออกจากกัน | repository ที่เชื่อมต่อและการกำหนดค่าสภาพแวดล้อม | บันทึกบน Cloud สรุป diff และ PR | งานเบื้องหลังระยะยาว การลองหลายแนวทางพร้อมกัน และการทำงานร่วมกันจากระยะไกล |

## การติดตั้งและข้อมูลประจำตัว

| รายการ | App เดสก์ท็อป | CLI | IDE | Cloud |
|---|---|---|---|---|
| ช่องทาง | แอปเดสก์ท็อปสำหรับ macOS / Windows / Linux | บรรทัดคำสั่งในเครื่อง | ส่วนขยายที่เข้ากันได้กับ VS Code รวมถึงการผสานรวมเฉพาะสำหรับ Xcode และ JetBrains | เว็บและการผสานรวมระยะไกลที่รองรับ |
| เข้าสู่ระบบด้วย ChatGPT | รองรับ | รองรับ | รองรับ | จำเป็น |
| เข้าสู่ระบบในเครื่องด้วย API key | รองรับ | รองรับ | รองรับ | ไม่รองรับ |
| รูปแบบการเรียกเก็บเงินหลัก | แพ็กเกจ ChatGPT หรือการใช้งาน API | แพ็กเกจ ChatGPT หรือการใช้งาน API | แพ็กเกจ ChatGPT หรือการใช้งาน API | แพ็กเกจ ChatGPT และสิทธิ์ของ workspace |

งานในเครื่องที่เข้าสู่ระบบด้วย API key ใช้นโยบายด้านการเรียกเก็บเงิน การจัดการ และการประมวลผลข้อมูลต่างจากการเข้าสู่ระบบด้วย ChatGPT อีกทั้ง API key ไม่รองรับความสามารถที่ต้องใช้ workspace ของ ChatGPT หรือ Cloud สำหรับแพ็กเกจและโควตา ให้ยึดหน้าทางการแบบเรียลไทม์เสมอ

## รูปแบบการใช้งานร่วมกันที่พบบ่อย

### วงจรการพัฒนาสำหรับบุคคล

```text
IDE ระบุตำแหน่งปัญหาเฉพาะจุด → CLI รันการทดสอบที่เจาะจง → App เดสก์ท็อปตรวจทานงานระยะยาวและ diff
```

### วงจรการทำงานระยะไกลสำหรับทีม

```text
เริ่มจาก GitHub / GitLab / Linear / Slack → Cloud รันในสภาพแวดล้อมแยก → มนุษย์ตรวจทานสรุปและ diff → สร้าง PR
```

### วงจรการเรียนรู้สำหรับผู้เริ่มต้น

```text
App เดสก์ท็อปเปิดไดเรกทอรีแบบฝึกหัด → มอบหมายงานเล็ก ๆ → ดูคำขอสิทธิ์ → ดู diff → รันการตรวจสอบ
```

## อย่าใช้ตารางแทนการตรวจสอบจากระบบจริง

Plugin, Scheduled tasks, การแจ้งเตือน โมเดล และนโยบายองค์กรเปลี่ยนแปลงรวดเร็ว เมื่อพบคำถามต่อไปนี้ ให้ดูหน้าจอของไคลเอนต์ปัจจุบันและเอกสารทางการโดยตรง:

- บัญชีปัจจุบันมีฟีเจอร์นั้นหรือไม่
- ความสามารถนั้นถูกจำกัดด้วยแพ็กเกจ ภูมิภาค หรือนโยบายผู้ดูแลระบบหรือไม่
- คำสั่ง แป้นพิมพ์ลัด หรือชื่อ UI ในเวอร์ชันปัจจุบัน
- การเข้าสู่ระบบด้วย API key รองรับฟีเจอร์ของ ChatGPT หรือ Cloud นั้นหรือไม่

หลักการเลือกใช้ควรเรียบง่าย: **ใช้ IDE กับโค้ดเฉพาะจุด ใช้ CLI เพื่อทำวงจรงานในเทอร์มินัลให้ครบ ใช้ App เดสก์ท็อปประสานงานในเครื่อง และใช้ Cloud เพื่อรันงานระยะไกลในสภาพแวดล้อมแยก**
