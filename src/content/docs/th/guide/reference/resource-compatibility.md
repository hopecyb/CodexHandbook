ความเข้ากันได้ต้องผูกกับชุดเวอร์ชันที่เฉพาะเจาะจง โครงสร้างแพ็กทรัพยากรถูกต้อง ขนาดภาพถูกต้อง หรือเปิดหน้าจอได้ ล้วนไม่อาจยืนยันได้ด้วยตัวเองว่าสถานะแอนิเมชันหรือการกู้คืนหลังถอนการติดตั้งทำงานตามปกติ

## หลักฐานปัจจุบัน

เมื่อ 2026-09-18 มีการตรวจสอบ Info.plist ของแอปภายในเครื่องแบบอ่านอย่างเดียว พบว่าตัวระบุไคลเอนต์คือ com.openai.codex เวอร์ชัน 26.911.61220 และ build 9647 การตรวจสอบนี้ไม่ได้โหลดสัตว์เลี้ยงหรือธีม และไม่ได้เปลี่ยนการกำหนดค่าไคลเอนต์ **ชุดเวอร์ชันที่ทดสอบการติดตั้ง การเล่น การสลับ และการกู้คืนเสร็จแล้ว: ยังไม่มี**

ขั้นตอนใน [การติดตั้งสัตว์เลี้ยง](/th/pets/install/), [การสร้างสัตว์เลี้ยง](/th/pets/create/) และ [สกินธีม](/th/theme/) ควรใช้ร่วมกับทรัพยากรและเวอร์ชันไคลเอนต์ที่ตรงกัน คำกล่าวอ้างของโปรเจกต์ภายนอกต้องระบุแหล่งที่มาแยกต่างหาก และห้ามเขียนใหม่ให้ดูเหมือนเป็นผลทดสอบจริงของเว็บไซต์นี้

รายการที่ยังไม่ได้รันให้เว้นว่างหรือระบุว่ายังไม่ได้รัน ห้ามกรอกเวลาที่ใช้เป็นศูนย์ ระบุว่าผ่าน หรือใส่เวอร์ชันจากการคาดเดา บันทึกที่เผยแพร่ควรใช้พาธและภาพทดสอบที่ลบข้อมูลสำคัญแล้ว เพื่อหลีกเลี่ยงการเปิดเผยเนื้อหางานจริง

## การตรวจสอบสัตว์เลี้ยง

ตรวจ JSON และพาธทรัพยากรก่อน จากนั้นตรวจการเลือก การโหลด พื้นหลังโปร่งใส การสลับท่าทาง และการปรับขนาดหน้าต่างในไคลเอนต์ หาก sprite sheet มีฟิลด์เวอร์ชัน ให้ยืนยันว่าฟิลด์นั้นตรงกับข้อตกลงเรื่องแถวและคอลัมน์ การเปิดภาพได้ไม่ได้แปลว่าไคลเอนต์จะแปลผลตามเวอร์ชันที่ถูกต้อง

เมื่อต้องการปิดใช้ ให้สลับกลับไปใช้ทรัพยากรในตัวหรือปิดสัตว์เลี้ยงก่อน ย้ายแพ็กแบบกำหนดเองไปยังตำแหน่งสำรองนอกไดเรกทอรีที่ระบบสแกน แล้วรีเฟรชหรือรีสตาร์ตเพื่อยืนยันว่าแพ็กไม่ปรากฏอีก หากต้องการกู้คืน ให้วางแพ็กเดิมกลับเข้าไปแล้วตรวจการโหลดอีกครั้ง อย่าเพียงเปลี่ยนชื่อภายในไดเรกทอรีที่ระบบสแกน และอย่าลบไดเรกทอรีการกำหนดค่าทั้งหมด

## การตรวจสอบธีม

บันทึกลักษณะและการโต้ตอบของหน้าเดียวกันทั้งก่อนและหลังเปิดใช้ อย่างน้อยต้องครอบคลุมหน้าแรก งาน ช่องป้อนข้อมูล การค้นหา ข้อความผิดพลาด และหน้าจออนุมัติที่เข้าถึงได้ สำหรับหน้าจอที่เรียกให้แสดงไม่ได้ ให้ระบุว่ายังไม่ได้ทดสอบ และอย่าสร้างการทำงานความเสี่ยงสูงจริงเพียงเพื่อทดสอบปุ่ม

หลังจากกู้คืน ให้เปิดไคลเอนต์ปกติอีกครั้งและยืนยันว่าลักษณะกับการทำงานเป็นปกติ รวมทั้งธีมไม่เริ่มทำงานใหม่หรือฉีดเข้าไปอีกโดยอัตโนมัติ ควรตรวจการคืนค่าหน้าจอและการปิดการเชื่อมต่อดีบักแยกกัน หากยืนยันข้อใดไม่ได้ ให้คงรายการนั้นไว้เป็นประเด็นที่ยังไม่ปิด

## เมื่อใดต้องตรวจสอบใหม่

เมื่อไคลเอนต์ ระบบ เอนจินธีม รูปแบบสัตว์เลี้ยง หรือแพ็กทรัพยากรเปลี่ยนแปลง ให้นำขั้นตอนทดสอบเดิมกลับมาใช้ เก็บบันทึกเก่าไว้และเพิ่มชุดเวอร์ชันใหม่ ห้ามเพียงอัปเดตวันที่ตรวจสอบ หากล้มเหลว ให้กู้คืนการกำหนดค่าที่ทราบว่าใช้ได้ก่อน แล้วจึงแยกวิเคราะห์ความเปลี่ยนแปลงใหม่
