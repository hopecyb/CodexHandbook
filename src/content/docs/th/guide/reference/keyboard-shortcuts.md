แป้นพิมพ์ลัดเปลี่ยนแปลงตามแพลตฟอร์ม ไคลเอนต์ และการตั้งค่าที่กำหนดเอง หน้านี้รวบรวมเฉพาะชุดแป้นที่เอกสารทางการปัจจุบันระบุไว้อย่างชัดเจน สำหรับรายการทั้งหมดให้ยึด **Keyboard Shortcuts** ภายในแอปเป็นหลัก

## แอปเดสก์ท็อป

| การทำงาน | macOS | Windows |
|---|---|---|
| เปิด Settings | `Cmd + ,` | `Ctrl + ,` |
| เปิด/ปิด Activity | `Cmd + Option + U` | `Ctrl + Alt + U` |
| เปิดเทอร์มินัลในตัว | `Ctrl` + ปุ่มแบ็กทิก | `Ctrl` + ปุ่มแบ็กทิก |
| เปิดแผงคำสั่งของแอป | `Cmd + K` | ให้ยึด Keyboard Shortcuts เป็นหลัก |
| ล้างการแสดงผลในเทอร์มินัล | `Ctrl + L` | `Ctrl + L` |

`Cmd + K` ใช้เปิดแผงคำสั่งของแอป ไม่ได้ล้างเทอร์มินัล

Keyboard Shortcuts ใน Settings รองรับการค้นหาด้วยชื่อคำสั่ง ค้นย้อนกลับด้วยชุดแป้น แก้ไขการผูกแป้น และคืนค่าเริ่มต้น เมื่อกำหนดค่าเองแล้ว การตั้งค่าในเครื่องจะมีลำดับความสำคัญเหนือคู่มืออ้างอิงด่วนบนอินเทอร์เน็ต

## IDE

การตั้งค่า `chatgpt.composerEnterBehavior` ในเอดิเตอร์ตระกูล VS Code กำหนดว่า Enter และ `Cmd/Ctrl + Enter` จะส่งพรอมต์หลายบรรทัดอย่างไร อย่าคิดว่าทุกเครื่องใช้ปุ่มส่งแบบเดียวกัน

ขณะที่ Codex กำลังทำงาน `chatgpt.followUpQueueMode` จะกำหนดว่าข้อความใหม่ถูกจัดคิวหรือใช้ steer ทันที สำหรับการส่งเพียงครั้งเดียว กด `Cmd/Ctrl + Shift + Enter` เพื่อกลับค่าพฤติกรรมเริ่มต้นปัจจุบัน

หากหาแถบด้านข้าง Codex ไม่พบ ให้รันคำสั่งต่อไปนี้จากแผงคำสั่งของเอดิเตอร์:

```text
Codex: Open Codex Sidebar
```

## CLI

ควรดูวิธีใช้งาน TUI ของ CLI จาก `/help` และข้อความแนะนำบนหน้าจอของเวอร์ชันปัจจุบัน หน้านี้จะไม่คาดเดาปุ่มอนุมัติอย่าง `y` หรือ `n` เพราะเทอร์มินัล โหมด และเวอร์ชันอาจเปลี่ยนรูปแบบการโต้ตอบ

สัญญาณเทอร์มินัลทั่วไป `Ctrl + C` อาจขัดจังหวะคำสั่งหรือเซสชันที่กำลังทำงาน โปรดตรวจสอบสถานะปัจจุบันก่อน และอย่าถือว่าเป็นปุ่ม “ย้อนกลับ” ที่ไม่มีผลข้างเคียง

## ลำดับการเรียนรู้

เริ่มจากเรียนรู้วิธีเปิดการตั้งค่า ดู Activity เปิดเทอร์มินัล และส่งพรอมต์หลายบรรทัด ส่วนการทำงานอื่นให้ค้นหาภายในแอปตามความถี่ที่ใช้งานจริง เอกสารของทีมควรระบุชื่อการทำงาน โดยไม่บังคับให้ทุกคนใช้ชุดแป้นที่กำหนดเองเหมือนกัน
