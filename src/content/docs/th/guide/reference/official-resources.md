คู่มือนี้เป็นแนวทางโอเพนซอร์สจากชุมชน สำหรับพฤติกรรมผลิตภัณฑ์ แพ็กเกจติดตั้ง และแพ็กเกจบริการ ให้ยึดข้อมูลทางการเป็นหลัก:

- เอกสารสำหรับนักพัฒนา Codex: [https://developers.openai.com/codex](https://developers.openai.com/codex)
- หน้าที่เกี่ยวข้องกับแพลตฟอร์มและบัญชี OpenAI: ให้ยึดทางเข้าปัจจุบันบนเว็บไซต์ทางการ OpenAI

เอกสารทางการกับคู่มือนี้มีหน้าที่ต่างกัน:

- คู่มือนี้อธิบายแนวคิดและแนวทางการใช้งาน
- เอกสารทางการใช้ยืนยันเวอร์ชันปัจจุบันและวิธีเขียนล่าสุด

หาก URL ทางการเปลี่ยนแปลง ให้ยึดการนำทางบนเว็บไซต์ OpenAI และยินดีรับ PR เพื่ออัปเดตหน้านี้

## เมื่อใดควรดูข้อมูลทางการก่อน

เมื่อพบคำถามต่อไปนี้ ให้กลับไปดูเอกสารทางการโดยตรง:

- การติดตั้งและเข้าสู่ระบบ
- ฟีเจอร์นั้นรองรับอยู่ในปัจจุบันหรือไม่
- วิธีเขียนตัวเลือกการกำหนดค่าหรือคำสั่งล่าสุด
- การเปลี่ยนแปลงของแพ็กเกจ สิทธิ์ และพฤติกรรมผลิตภัณฑ์

## ความเข้าใจผิดที่พบบ่อย

### 1. ข้อมูลทางการน่าเชื่อถือที่สุด ไม่ได้แปลว่าไม่จำเป็นต้องอ่านคู่มือชุมชน

หลายคนติดขัดเพราะแม้อ่านคำอธิบายทางการแล้ว ก็ยังไม่รู้ว่าควรเริ่มจากตรงไหน

### 2. คู่มือเคยเขียนไว้อย่างไร ไม่ได้แปลว่าปัจจุบันยังเป็นเช่นนั้นเสมอ

เนื้อหาต่อไปนี้เปลี่ยนแปลงเร็วกว่า:

- อาร์กิวเมนต์ของคำสั่ง
- ชื่อคีย์การกำหนดค่า
- ความสามารถของผลิตภัณฑ์ที่รองรับ
- ขอบเขตแพ็กเกจและสิทธิ์

### 3. เมื่อข้อมูลขัดแย้งกัน ต้องแยกลำดับความสำคัญให้ชัดเจน

กล่าวอย่างง่ายคือ ใช้คู่มือเพื่อทำความเข้าใจแนวคิดและบริบท ส่วนพฤติกรรมปัจจุบันกับวิธีเขียนล่าสุดให้ดูข้อมูลทางการ

## วิธีใช้

คำถามประเภทต่อไปนี้ดูจากคู่มือก่อนได้:

- ฉันไม่เข้าใจว่าแนวคิดนี้หมายถึงอะไร
- ฉันไม่รู้ว่าควรเริ่มอย่างไร
- ฉันต้องการทราบลำดับเริ่มต้นที่แนะนำ

คำถามประเภทต่อไปนี้ดูข้อมูลทางการจะน่าเชื่อถือกว่า:

- ตอนนี้รองรับอะไรล่าสุด
- วันนี้อาร์กิวเมนต์นี้ชื่ออะไรกันแน่
- เวอร์ชันปัจจุบันมีฟีเจอร์นี้หรือไม่
- กฎของผลิตภัณฑ์เปลี่ยนแปลงไปเมื่อเร็ว ๆ นี้หรือไม่

## เมื่อไม่แน่ใจว่าควรดูแหล่งใดก่อน

1. ใช้คู่มือเพื่อทำความเข้าใจแนวคิดและทิศทางโดยรวม
2. ก่อนเริ่มกำหนดค่า ติดตั้ง หรือดำเนินการจริง ให้ไปยืนยันวิธีเขียนล่าสุดจากข้อมูลทางการ
3. หากข้อมูลทั้งสองแหล่งขัดแย้งกัน ให้ยึดข้อมูลทางการ

วิธีนี้ช่วยให้เห็นทิศทางชัดเจนขึ้น และลดโอกาสพบข้อมูลที่ล้าสมัย
