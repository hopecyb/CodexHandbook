หน้านี้อธิบายว่างานใน Desktop App ทำงานบนเครื่องของคุณหรือในสภาพแวดล้อมระยะไกล

เลือกตำแหน่งทำงานใน App:

- **ในเครื่อง**: ใช้ไฟล์และสภาพแวดล้อมบนเครื่อง วนแก้ได้เร็ว
- **Cloud**: ใช้สภาพแวดล้อม Cloud เหมาะสำหรับเชื่อม repository ระยะไกลและงานที่ใช้เวลานาน

แนวคิด: [ในเครื่องกับ Cloud](/th/guide/foundations/local-vs-cloud/) · ภาพรวม: [Web และ Cloud](/th/guide/web-and-cloud/)

ก่อนสลับ ให้ตรวจว่า secret ควรอยู่ในสภาพแวดล้อมนั้นหรือไม่ และนโยบายเครือข่ายอนุญาตหรือไม่

## ความเข้าใจผิดที่พบบ่อย

### 1. เมื่ออยู่ใน Desktop App ทำไมยังต้องแยกงานในเครื่องกับ Cloud

เพราะ App เป็นเพียงจุดเข้า ไม่ได้หมายความว่าทุกงานจะทำบนเครื่องของคุณ

### 2. ควรเลือกอะไรเป็นค่าเริ่มต้น

กรณีส่วนใหญ่ให้เริ่มจากในเครื่อง เพราะ:

- ไฟล์อยู่บนคอมพิวเตอร์ของคุณ
- ตรวจผลลัพธ์ได้ง่ายกว่า
- ย้อนกลับเมื่อผิดพลาดได้ง่ายกว่า

### 3. เมื่อใดจึงควรพิจารณา Cloud

กรณีทั่วไป ได้แก่:

- งานใช้เวลานาน
- ต้องเชื่อมสภาพแวดล้อมของ repository ระยะไกล
- ต้องใช้สภาพแวดล้อมมาตรฐานเดียวกัน
- ไม่ต้องการใช้ทรัพยากรของเครื่อง

หากทำงานในเครื่องผ่าน Desktop App ได้ ก็มักควรทำในเครื่องก่อน เมื่อเป็นงานยาว งานระยะไกล หรือจำเป็นต้องใช้สภาพแวดล้อมเดียวกัน จึงค่อยพิจารณา Cloud
