หน้าการตั้งค่าใช้ปรับพฤติกรรมของแอป ไม่ใช่การกำหนดสิทธิ์ทั้งหมดของ Codex เริ่มจากค่าเริ่มต้น และแก้เฉพาะเมื่อเข้าใจขอบเขตผลกระทบแล้ว

บน macOS กด `Cmd + ,` บน Windows กด `Ctrl + ,` หรือเปิด Settings จากเมนูแอป

## สี่ส่วนที่ผู้เริ่มต้นควรดูก่อน

### General

- ต้องกด `Cmd + Enter` เพื่อส่งพรอมต์หลายบรรทัดหรือไม่
- **Prevent sleep while running** อนุญาตให้งานยาวในเครื่องทำต่อเมื่อคุณไม่ได้อยู่หน้าเครื่องหรือไม่
- Follow-up behavior กำหนดว่าข้อความใหม่ระหว่างทำงานจะชี้นำการทำงานปัจจุบันทันที หรือเข้าคิวรอบถัดไป

ข้อสุดท้ายเปลี่ยนผลของการ “เสริมอีกประโยค” หากต้องแก้ทิศทางเร่งด่วน ให้ชี้นำการทำงานปัจจุบัน แต่ requirement ใหม่ที่ไม่เกี่ยวข้องควรเปิดแชตใหม่

### Keyboard shortcuts

ค้นหาคำสั่ง เปลี่ยนปุ่ม หรือคืนค่าเริ่มต้นได้ หากปุ่มลัดจากอินเทอร์เน็ตไม่ตรงกับเครื่อง ให้ยึด binding ที่แสดงในส่วนนี้

### Notifications

กำหนดว่าเมื่อใดจะแจ้งเตือนเมื่อจบรอบ และควบคุมการแจ้งคำขอสิทธิ์กับคำถาม ดูคำแนะนำทั้งหมดที่ [การแจ้งเตือนและมุมมอง Activity](/th/guide/desktop-app/notifications/)

### Appearance

เลือกธีมสว่าง มืด หรือตามระบบ และปรับสีเน้น สีพื้นหลัง สีตัวอักษร ฟอนต์อินเทอร์เฟซ ฟอนต์โค้ด และขนาดตัวอักษร เมื่อตรวจโค้ดยาว ให้ความสำคัญกับ contrast และขนาดตัวอักษรก่อนความสวยของธีม

## สิ่งที่แก้ไม่ได้จากหน้านี้

- กฎระดับ repository เขียนใน `AGENTS.md`
- การตั้งค่าถาวรของ CLI และ Agent ส่วนใหญ่อยู่ใน `config.toml`
- การเข้าถึงไฟล์ เครือข่าย และคำสั่งกำหนดร่วมกันโดย sandbox การอนุมัติ และนโยบายองค์กร
- นโยบายที่องค์กรจัดการอาจจำกัดความสามารถที่บุคคลเลือกได้

ดังนั้น “มองเห็นในการตั้งค่า” ไม่ได้หมายความว่างานปัจจุบันมีสิทธิ์นั้นเสมอ เมื่อถูกปฏิเสธ ให้อ่าน [สิทธิ์และ sandbox](/th/guide/permissions-and-sandbox/) ก่อน อย่าขยายสิทธิ์ทันที

## ตรวจรับหลังแก้การตั้งค่า

เปลี่ยนครั้งละหนึ่งประเภท และใช้แชตความเสี่ยงต่ำหนึ่งรายการตรวจผล จดค่าเดิมไว้ ยืนยันผลแล้วจึงทำต่อ หากพฤติกรรมไม่เป็นไปตามคาด ให้คืนค่าเริ่มต้นก่อน แล้วตรวจเวอร์ชันแอป สิทธิ์ของระบบปฏิบัติการ และนโยบายองค์กร
