การแจ้งเตือนช่วยบอกว่า “ต้องกลับมาจัดการงานเมื่อไร” แต่ไม่ได้แทนการตรวจทานผลลัพธ์ Desktop App ตั้งค่าการแจ้งเตือนเมื่อจบรอบ และควบคุมการแจ้งคำขอสิทธิ์กับคำถามแยกกันได้

## การตั้งค่าที่แนะนำ

เปิด **Settings → Notifications**:

| เหตุการณ์ | คำแนะนำ | เหตุผล |
|---|---|---|
| Turn completion | แจ้งเมื่อทำงานเบื้องหลัง | ไม่ต้องเฝ้างานยาวตลอดเวลา |
| Permission | เปิด | คำขออนุมัติที่ยังไม่จัดการจะหยุดงานไว้ |
| Question | เปิด | คุณต้องตอบเมื่อ Codex ขาดบริบทสำคัญ |

ระบบปฏิบัติการต้องอนุญาตให้ ChatGPT Desktop App ส่งการแจ้งเตือนด้วย หากเปิดในแอปแต่ระบบปฏิเสธ คุณก็จะไม่ได้รับการแจ้งเตือน

## จัดการหลายแชตด้วยมุมมอง Activity

เมื่อ Activity ใช้งานได้ ให้เลือกไอคอนกระดิ่งในแถบด้านข้างเพื่อดูแชตที่ยังไม่ได้อ่าน กำลังทำงาน หรือรอคำตอบ ปุ่มลัดคือ:

- macOS: `Cmd + Option + U`
- Windows: `Ctrl + Alt + U`

ตัวกรองอาจเปลี่ยนตามอินเทอร์เฟซปัจจุบัน และอาจมี Work, Chat, Pinned และ Scheduled ลำดับจัดการที่แนะนำคือ รอสิทธิ์หรือข้อมูล → ล้มเหลว → เสร็จแล้วรอตรวจ → ยังทำงานอยู่

## ทำอะไรหลังได้รับการแจ้งเตือน

- **เสร็จสิ้น**: เปิด diff และ output การตรวจสอบ อย่าใช้การแจ้งเตือนเป็นข้อสรุปการตรวจรับ
- **คำขอสิทธิ์**: ยืนยันคำสั่ง ทรัพยากรเป้าหมาย ขอบเขตผลกระทบ และความสามารถในการย้อนกลับ
- **รอคำตอบ**: เพิ่มเฉพาะบริบทที่จำเป็น อย่าขยายงานโดยไม่ตั้งใจ
- **ล้มเหลว**: หา error ที่มีความหมายรายการแรก แล้วค่อยตัดสินใจว่าจะลองใหม่หรือปรับข้อจำกัด

CLI และ IDE ใช้กลไกแจ้งเตือนต่างกัน IDE ไม่มีการตั้งค่าการแจ้งเตือนแยก ส่วน CLI ใช้การตั้งค่าขั้นสูงกำหนดการแจ้งเตือนเมื่อ TUI หรือโปรแกรมภายนอกทำงานเสร็จ อย่าถือว่าการตั้งค่าบนเดสก์ท็อปเป็นสวิตช์ส่วนกลาง
