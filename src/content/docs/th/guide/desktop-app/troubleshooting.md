แก้ปัญหาตามลำดับจากสาเหตุที่เป็นไปได้มากที่สุดและจัดการง่ายที่สุด

| อาการ | ลองทำสิ่งนี้ก่อน |
|---|---|
| ติดตั้งหรือเปิดไม่ได้ | ตรวจข้อกำหนดระบบและแพ็กเกจติดตั้งทางการ แล้วรีสตาร์ตและลองใหม่ |
| ลงชื่อเข้าใช้ไม่ได้ | ตรวจเครือข่าย สิทธิ์บัญชี และ SSO จากนั้นล้าง session แล้วลงชื่อเข้าใช้อีกครั้ง |
| มองไม่เห็นไฟล์โปรเจกต์ | ยืนยันว่าเพิ่มโฟลเดอร์ถูกต้องและระบบอนุญาตให้เข้าถึงไฟล์ |
| งานรออนุมัติไม่สิ้นสุด | กลับไปยังมุมมองงานและจัดการคำขอที่รออนุมัติ |
| การเปลี่ยนแปลงไม่ตรงคาด | จำกัดขอบเขตให้แคบลง เปิด thread ใหม่ และตรวจบริบท |

หากยังไม่สำเร็จ ดู [https://developers.openai.com/codex](https://developers.openai.com/codex) และ [ดัชนีการแก้ปัญหา](/th/guide/reference/troubleshooting/)

## ความเข้าใจผิดที่พบบ่อย

### 1. เมื่อเกิดปัญหา แปลว่าใช้งานผิดร้ายแรงหรือไม่

ปัญหาจำนวนมากเกิดจาก:

- เลือกพาธผิด
- ยังไม่อนุมัติสิทธิ์
- งานกำลังรอการยืนยัน
- บริบทในแชตปะปนแล้ว

### 2. เมื่อ “มองไม่เห็นไฟล์” ควรสงสัยอะไรก่อน

ให้ตรวจไดเรกทอรีโปรเจกต์และสิทธิ์ก่อน ไม่ต้องเริ่มจากสงสัยความสามารถของโมเดล

### 3. จะแก้ “การเปลี่ยนแปลงไม่ตรงคาด” อย่างไร

จำกัดขอบเขตปัญหาก่อน:

- ระบุขอบเขตอีกครั้ง
- บอกให้ชัดว่าส่วนใดผิด
- เปิด thread ใหม่เมื่อจำเป็น

เริ่มแก้จากสาเหตุที่พบบ่อยและแก้ง่ายที่สุด ไม่จำเป็นต้องคิดว่าปัญหาซับซ้อนตั้งแต่แรก
