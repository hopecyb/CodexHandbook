หน้านี้บันทึกว่าคู่มือเปลี่ยนอะไร ส่งผลต่อขั้นตอนใด และตรวจสอบถึงระดับไหน วันที่คือวันที่เรียบเรียงเนื้อหา ส่วนสถานะเผยแพร่จริงให้ยึดเวอร์ชันของเว็บไซต์ที่คุณกำลังเข้าชม สำหรับความเปลี่ยนแปลงของผลิตภัณฑ์ ให้ดูแหล่งข้อมูลทางการในบทสอนที่เกี่ยวข้อง

## 2026-09-18: การกรองกรณีศึกษาและการนำทางตามเส้นทาง

[สารบัญกรณีศึกษา](/th/cases/) รองรับประเภทงาน คำค้น และ URL ตัวกรองที่แชร์ได้ การ์ดอ่านผลลัพธ์และสถานะการตรวจสอบจาก metadata ของกรณีศึกษา แถบด้านข้างของเส้นทางการเรียนรู้ภาษาจีนตัวย่อและตัวเต็มแสดงเฉพาะเส้นทางปัจจุบัน ขั้นตอน และความช่วยเหลือที่เกี่ยวข้อง ภาพรวมสำหรับผู้เริ่มต้นอยู่บนสุด และห้าขั้นเรียงหมายเลขตามลำดับ เมื่อกรองแล้วไม่พบผลลัพธ์สามารถรีเซ็ตได้ และยังอ่านกรณีศึกษาทั้งหมดได้เมื่อไม่ได้เปิดใช้สคริปต์

## 2026-09-18: การรันเปรียบเทียบพรอมต์ 12 ครั้ง

[การเปรียบเทียบพรอมต์สามชุด](/th/prompts/comparison-lab/) เพิ่มผลลัพธ์จริง เวลา และคะแนนรายข้อจากการรัน A/B อย่างละสองครั้งสำหรับรายงานยอดขายรายสัปดาห์ บทความที่อิงแหล่งข้อมูล และการแก้บั๊ก [แพ็กเกจผลลัพธ์](/downloads/prompt-comparison-results/prompt-comparison-results-1.0.0.zip) เก็บข้อผิดพลาดของเครื่องมือ รายการ log ที่ขาด และ hash ของพาธที่ลบข้อมูลอ่อนไหว Agent หลักตรวจซ้ำแบบไม่ปิดบังผล ป้ายกำกับโมเดลไม่ทราบ และไม่มีการสรุปอัตราความสำเร็จหรือเวลาที่ประหยัดได้โดยทั่วไป

## 2026-09-18: แบบฝึกหัดสร้างเว็บไซต์ครบชุด

[สร้างเว็บไซต์](/th/cases/build-a-website/) เพิ่มข้อกำหนดคงที่ หน้าเริ่มต้น HTML ผลงานอ้างอิง template ตรวจรับ และข้อผิดพลาดของ anchor ปุ่ม หน้าตัวอย่างผ่านการตรวจบนเดสก์ท็อปและหน้าจอแคบ 375px พร้อมบันทึกการแก้จริงและ log ลิงก์ โดยไม่มีการอ้างว่า deploy แล้ว มีผู้สมัคร หรือมีผลด้านประสิทธิภาพของโมเดล

## 2026-09-18: ปรับทางเข้าภาษาจีนให้กระชับ

หน้าแรกจัดเนื้อหาตามการทำงาน เส้นทางตามบทบาท การค้นหาปัญหา และสื่อที่นำกลับมาใช้ซ้ำ พร้อมตัดคำอธิบายตำแหน่งและความสามารถที่ซ้ำกัน เมนูหลักภาษาจีนตัวย่อและตัวเต็มเน้นงาน เส้นทางการเรียนรู้ และสารบัญอ้างอิง ส่วนแผนงานย้ายไปเมนูทรัพยากร และอุปกรณ์เคลื่อนที่ใช้ทางเข้าชุดเดียวกัน

## 2026-09-18: สื่อคงที่และแบบฝึกกู้คืนสำหรับผู้เริ่มต้น

[เส้นทางห้าขั้นสำหรับผู้เริ่มต้น](/th/guide/learning-paths/beginner/) มีชุดข้อมูลกิจกรรมสังเคราะห์เดียวกัน ตัวอย่างประกาศ ตัวอย่างข้อผิดพลาดสี่รายการ และ template สำหรับตรวจซ้ำกับส่งต่องาน แบบฝึกเริ่มจากอ่านอย่างเดียว แก้ไฟล์เดียว แล้วไปถึงการกู้คืนสำเนาจริง สคริปต์ของผู้เขียนยืนยันเฉพาะขั้นตอนจัดการไฟล์ ยังไม่มีข้อสรุปอิสระเกี่ยวกับโมเดลหรืออัตราที่ผู้อ่านทำผ่าน

## 2026-09-18: วันที่ในแผนงานและทางเข้าฝึกปฏิบัติ

[แผนงานแอปพลิเคชัน AI](/th/ai-roadmap/) แยกงานวิจัย การเปิดตัวผลิตภัณฑ์ บทความวิศวกรรม และหัวข้อโครงการที่ไม่ได้เรียงตามวันเปิดตัวครั้งแรก แต่ละหัวข้อมีแหล่งข้อมูลและทางเข้าฝึกที่ชัดเจน ไม่ใช้วันที่ของบทความเดียวแทนวันที่เทคโนโลยีแพร่หลายในอุตสาหกรรม และไม่ถือว่าการตรวจโครงสร้างแพ็กเกจ Skill คือการทดสอบ trigger ในไคลเอนต์ URL เดิมยังคงอยู่ และปีเดือนในอดีตไม่ถือเป็นวันที่ของเหตุการณ์ปัจจุบัน แต่ละหัวข้อระบุลิงก์แหล่งข้อมูลและข้อจำกัดการใช้ไว้ในเนื้อหา

## 2026-09-18: ปรับคำอธิบายที่อาจทำให้เข้าใจผิด

- เปลี่ยนทางเข้าราคาเป็น “ข้อมูลอ้างอิงราคา” แยก snapshot สกุลเงินเดิมที่มีแหล่งข้อมูลออกจากข้อมูลที่ไม่ทราบ และไม่ใช้ค่าประมาณเปรียบเทียบราคาสูงต่ำทั่วโลกอีกต่อไป ก่อนซื้อยังต้องตรวจราคาที่ช่องทางจริงแสดง
- หน้าที่เกี่ยวข้องจะอธิบายแหล่งข้อมูล ขอบเขตการใช้ และขอบเขตการรันจริงไว้ในเนื้อหาโดยตรง “การรันจริง” ครอบคลุมเฉพาะสคริปต์และสภาพแวดล้อมที่ระบุ ไม่ได้หมายถึงอัตราความน่าเชื่อถือของผลลัพธ์โมเดล
- [ลำดับชั้นคำสั่ง](/th/guide/context/context-priority/) แยกบทบาทข้อความ กฎการค้นพบคำแนะนำของโปรเจกต์ และสิทธิ์ในการดำเนินการ เพื่อหลีกเลี่ยงคำอ้างแบบเหมารวมว่า “สิ่งที่ใหม่กว่าหรือเข้มงวดกว่าจะมีลำดับสูงกว่าเสมอ”
- [SDK](/th/guide/developer-platform/sdk-overview/) และ [Webhook](/th/guide/developer-platform/webhooks/overview/) แยกการรันในเครื่อง บริการที่โฮสต์เอง และการออกแบบ callback โดยไม่เขียน interface เชิงออกแบบให้ดูเป็นสัญญาทางการ
- [การแบ่งระดับงาน](/th/prompts/ask-for-a-plan/) แยกการลงมือโดยตรง การวางแผนก่อน และการอนุมัติการดำเนินการ เพื่อไม่ให้หยุดรอทุกขั้นโดยไม่จำเป็น

หน้าที่เกี่ยวข้องอธิบายแหล่งข้อมูลและข้อจำกัดไว้ในเนื้อหา อย่าใช้สรุปการอัปเดตนี้แทนเอกสาร interface ฉบับเต็ม

## เมื่อพบปัญหาในหน้า

ทุกหน้าในคู่มือมีลิงก์รายงานปัญหาแบบภาษาท้องถิ่นที่ส่วนท้าย ลิงก์จะใส่เฉพาะชื่อหน้าและเส้นทางในเว็บไซต์ แล้วเปิดร่าง Issue สาธารณะที่ยังไม่ได้ส่ง โปรดตรวจสอบก่อนส่งด้วยตนเอง และต้องมีบัญชี GitHub

ระบุหัวข้อ เนื้อหาที่คาดหวังและเนื้อหาปัจจุบัน สภาพแวดล้อมที่จำเป็น และหลักฐานสาธารณะ ลบคีย์ API ข้อมูลบัญชี เส้นทางส่วนตัว ข้อมูลลูกค้า และบันทึกที่ยังไม่ได้ปกปิดข้อมูล ร่างนี้ไม่เก็บข้อมูลจากงานและไม่มี query string ของหน้า

หากไม่มีบัญชี GitHub ให้คัดลอกเส้นทางหน้าและคำอธิบายปัญหาไว้ในบันทึกภายในเครื่อง แล้วขอให้ผู้ร่วมงานที่มีสิทธิ์ส่งให้ ไม่มีการรับประกันเวลาตอบกลับและไม่มีการส่งข้อความโดยอัตโนมัติ

## วิธีที่ผู้ดูแลจัดการ

หลังทำซ้ำปัญหาหรือตรวจแหล่งข้อมูล ให้บันทึกเหตุผลว่า ยอมรับ แก้ไข หรือยังยืนยันไม่ได้ เมื่อแก้ข้อเท็จจริงของผลิตภัณฑ์ ให้อัปเดตเนื้อหาและหลักฐานที่เกี่ยวข้องโดยไม่ทำเครื่องหมายหน้าที่ไม่เกี่ยวข้องว่าอัปเดตแล้ว เมื่อแก้แบบฝึกหัด ให้อัปเดตสื่อต้นทาง แพ็กเกจดาวน์โหลด และเนื้อหาพร้อมกัน หากข้อสรุปเดิมใช้ไม่ได้แล้ว ให้อธิบายผลกระทบของวิธีเดิมและขั้นตอนย้าย ไม่ใช่เขียนเพียงว่า “ปรับปรุงเนื้อหา”

เมื่ออัปเดตหน้านี้ ให้ลิงก์ไปยังหน้าที่ได้รับผลกระทบและแหล่งข้อมูลสาธารณะ พร้อมระบุส่วนที่ยังไม่ได้ทดสอบ นี่คือบันทึกการเปลี่ยนแปลงของคู่มือชุมชน ไม่ใช่บันทึกการอัปเดตทางการของ OpenAI
