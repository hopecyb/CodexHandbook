CLI เหมาะกับผู้ใช้เทอร์มินัลและการเชื่อมต่อกับสคริปต์หรือ CI

หากเพิ่งเห็นคำว่า “CLI” ให้เข้าใจว่าเป็นจุดที่ใช้ทำงานร่วมกับ Codex โดยตรงในเทอร์มินัลโดยไม่ผ่าน UI แบบกราฟิก

เหมาะกับสถานการณ์เหล่านี้มากกว่า:

- ผู้ที่คุ้นเคยกับบรรทัดคำสั่ง
- ผู้ที่ต้องการใช้ร่วมกับสคริปต์
- ผู้ที่ต้องเชื่อมต่อ CI/ระบบอัตโนมัติ

สำหรับผู้เริ่มต้นที่ไม่คุ้นเคยกับเทอร์มินัลเลย CLI ไม่จำเป็นต้องเป็นจุดแรกที่เรียน แต่ถ้าใช้ `cd`, `ls` และรันคำสั่งในไดเรกทอรีโปรเจกต์พื้นฐานได้แล้ว CLI จะมีประสิทธิภาพมาก

## สิ่งที่ต้องแยกให้ออกเมื่อใช้ครั้งแรก

ในช่วงแรก ให้แยกสองโหมดนี้:

1. **โหมดโต้ตอบ**: สนทนากับ Codex โดยตรงในเทอร์มินัล
2. **โหมดไม่โต้ตอบ**: ใช้ Codex เป็นคำสั่งในสคริปต์หรือ CI

หากเพิ่งลองใช้ครั้งแรก โดยทั่วไปโหมดโต้ตอบจะสะดวกกว่า เมื่อจำเป็นต้องทำอัตโนมัติ ค่อยศึกษาโหมดไม่โต้ตอบ
