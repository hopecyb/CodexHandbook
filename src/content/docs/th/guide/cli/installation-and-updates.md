เมื่อติดตั้ง CLI ครั้งแรก หลายคนติดอยู่ที่คำถามเหล่านี้:

- ติดตั้งสำเร็จแล้วหรือยัง
- เหตุใดหลังติดตั้ง เทอร์มินัลยังไม่รู้จัก `codex`
- หลังอัปเดตจะยืนยันได้อย่างไรว่ากำลังรันเวอร์ชันใด

การติดตั้ง CLI จะถือว่าเสร็จไม่ใช่เพียงเพราะรันคำสั่งติดตั้งหนึ่งครั้ง แต่เทอร์มินัลปัจจุบันต้องค้นพบ CLI ได้อย่างเสถียร

## หลังติดตั้งต้องตรวจอย่างน้อย 3 เรื่อง

1. รันคำสั่งได้โดยตรง
2. เทอร์มินัลปัจจุบันค้นพบคำสั่งใน `PATH`
3. ยืนยันตัวตนเสร็จแล้ว ไม่ใช่เพียงติดตั้งไฟล์ปฏิบัติการ

## ความเข้าใจผิดที่พบบ่อย

### 1. สคริปต์ติดตั้งทำงานจบแปลว่าติดตั้งเสร็จแล้ว

สคริปต์ทำงานจบแปลเพียงว่า “ขั้นตอนติดตั้งถูกเรียกใช้แล้ว”  
ต่อไปต้องตรวจว่าเทอร์มินัลที่เปิดอยู่รู้จักคำสั่งนี้หรือไม่

### 2. เปลี่ยนหน้าต่างเทอร์มินัลแล้วจะหายเอง

บางครั้งใช่ บางครั้งไม่ใช่  
หาก `PATH` ยังไม่อัปเดต แม้เปลี่ยนหน้าต่างก็อาจยังค้นไม่พบ

### 3. การอัปเดตคือการติดตั้งใหม่อีกรอบ

หลายครั้งควรยืนยันก่อนว่า:

- เวอร์ชันปัจจุบันเก่าจริงหรือไม่
- คุณกำลังอัปเดตการติดตั้งชุดใด

## ตรวจตามลำดับนี้

หลังติดตั้ง ให้ตรวจดังนี้:

1. ยืนยันว่ารันคำสั่ง `codex` ได้โดยตรง
2. ยืนยันว่า `PATH` ของ shell ปัจจุบันมีตำแหน่งติดตั้ง
3. ลงชื่อเข้าใช้หรือยืนยันตัวตนให้เสร็จ
4. ยืนยันข้อมูลเวอร์ชันเป็นขั้นสุดท้าย

เกณฑ์ที่ใช้ได้จริงคือเทอร์มินัลปัจจุบันค้นพบ CLI และคุณยืนยันตัวตนสำเร็จแล้ว

ดูเทียบได้ที่: [ติดตั้ง CLI](/th/guide/getting-started/install-cli/)
ดูคำอธิบายการติดตั้งและอัปเกรดอย่างเป็นทางการที่ [Codex CLI](https://learn.chatgpt.com/docs/codex/cli) ตัวติดตั้งแบบ standalone อย่างเป็นทางการสำหรับ macOS/Linux ใช้คำสั่งเดียวกันทั้งติดตั้งและอัปเดต ส่วน Windows, npm และ Homebrew ให้ยึดแท็บที่เกี่ยวข้องบนหน้าอย่างเป็นทางการ
