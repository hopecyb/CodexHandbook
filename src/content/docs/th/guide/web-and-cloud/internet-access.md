Cloud มีช่วงเชื่อมต่อเครือข่ายสองช่วงที่ต่างกัน:

| ช่วง | พฤติกรรมเริ่มต้น | การใช้งานหลัก |
|---|---|---|
| setup script | เชื่อมต่อได้ | ติดตั้ง dependency และเครื่องมือ |
| Agent phase | ปิดโดยค่าเริ่มต้น | เข้าถึงทรัพยากรภายนอกระหว่างที่ Agent ทำงาน |

ดังนั้น `pnpm install` สำเร็จใน setup ไม่ได้หมายความว่า Agent จะใช้ `curl` ไปยังเว็บไซต์ใดก็ได้ในภายหลัง

## เหตุใดจึงปิดโดยค่าเริ่มต้น

การให้ Agent เข้าถึงอินเทอร์เน็ตเพิ่มความเสี่ยงจาก Prompt injection การส่งโค้ดหรือข้อมูลออก ระบบ dependency อันตราย และเนื้อหาที่มี license ไม่เข้ากันถูกนำเข้า repository issue, หน้าเว็บ หรือ README ของ dependency ที่ไม่น่าเชื่อถืออาจมีคำสั่งชักจูงให้ Agent ส่งข้อมูลออก

หลักการคือเปิดเฉพาะเป้าหมายและการดำเนินการที่งานจำเป็น แล้วตรวจ log การทำงาน

## ตัวเลือกการกำหนดค่า

การเข้าถึงอินเทอร์เน็ตของ Agent กำหนดแยกตามสภาพแวดล้อม:

- **Off**: ปิดการเชื่อมต่ออินเทอร์เน็ตของ Agent ทั้งหมด
- **On**: อนุญาตการเชื่อมต่อ และจำกัดโดเมนกับ HTTP method ได้

รายการโดเมนเริ่มจากรายการว่าง ใช้ค่าที่กำหนดไว้ล่วงหน้า Common dependencies หรือเลือก All (unrestricted) ได้ repository production ไม่ควรใช้ unrestricted เป็นทางลัดในการแก้ปัญหา

หากงานต้องการเพียงอ่านเอกสารหรือดาวน์โหลดเนื้อหา ให้จำกัด HTTP method เป็น `GET`, `HEAD` และ `OPTIONS` วิธีนี้จะบล็อก `POST`, `PUT`, `PATCH` และ `DELETE` ที่อาจส่งข้อมูลออกหรือแก้ข้อมูล

## ตัวอย่างเปิดสิทธิ์ขั้นต่ำ

เมื่องานต้องค้นเอกสาร API สาธารณะหนึ่งแห่ง:

1. คงค่า Off ไว้ก่อน และยืนยันว่าความล้มเหลวเกิดจากเครือข่ายจริง
2. เปิด Agent access
3. เพิ่มเฉพาะโดเมนทางการนั้นใน allowlist
4. อนุญาตเฉพาะ `GET`, `HEAD` และ `OPTIONS`
5. รันใหม่แล้วตรวจคำขอขาออกทั้งหมดใน log
6. เมื่องานเสร็จ ประเมินว่าควรกลับไปใช้ Off หรือไม่

## ความสัมพันธ์สำคัญกับ Secret

Cloud Secret จะถูกนำออกก่อนขั้น Agent ช่วยลดความเสี่ยงที่ Agent ส่ง setup Secret ออกโดยตรง แต่ตัวแปรสภาพแวดล้อมทั่วไป เนื้อหา repository และข้อมูลที่งานสร้างยังส่งออกได้ อย่าปลอมค่าที่อ่อนไหวเป็นตัวแปรทั่วไปเพื่อหลีกเลี่ยงวงจรชีวิตของ Secret

## เช็กลิสต์ตรวจรับ

- [ ] อธิบายแล้วว่าเหตุใดขั้น Agent จึงต้องใช้อินเทอร์เน็ต
- [ ] allowlist มีเฉพาะโดเมนที่จำเป็น
- [ ] จำกัด HTTP method ไว้ที่ชุดขั้นต่ำ
- [ ] แหล่งอินพุตเชื่อถือได้ หรือพิจารณา Prompt injection แล้ว
- [ ] ไม่มีคำสั่งอัปโหลด repository สภาพแวดล้อม หรือข้อมูลประจำตัวใน log
- [ ] ตรวจแหล่งที่มา เวอร์ชัน และ license ของ dependency ใหม่แล้ว
