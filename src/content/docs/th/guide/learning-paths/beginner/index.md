ใช้ชุดข้อมูลกิจกรรมสมมติเพื่อฝึกตั้งแต่การอ่านไฟล์จนส่งมอบประกาศที่ตรวจสอบได้ คุณไม่จำเป็นต้องรู้ Git การเขียนโปรแกรม หรือการติดตั้ง dependency ก่อน

[ดาวน์โหลดชุดฝึกฉบับเต็ม](/downloads/first-project/first-project-1.0.0.zip) · [คำอธิบายสื่อ](/downloads/first-project/README.md)

เมื่อแตกไฟล์แล้ว ให้คัดลอก starter เป็นโฟลเดอร์ work ใหม่ แล้วเปิด work ด้วย Codex เก็บต้นฉบับและเอกสารอ้างอิงของผู้เขียนไว้ ทำแบบฝึกให้เสร็จก่อนจึงเทียบคำตอบ หากมีปัญหาติดตั้งหรือลงชื่อเข้าใช้ไคลเอนต์ ให้ดู [เริ่มต้นอย่างรวดเร็ว](/th/guide/getting-started/) และ [การแก้ปัญหา](/th/guide/reference/troubleshooting/) ก่อน

| ขั้น | ทำอะไร | หลักฐานว่าเสร็จ |
|---|---|---|
| [1. สนทนากับ Codex](/th/guide/learning-paths/beginner/01-talk-to-codex/) | อ่านสามไฟล์อย่างเดียว แล้วอธิบายหน้าที่และสิ่งที่ยังไม่ทราบ | พบว่าวิธีลงทะเบียนรอยืนยัน และไฟล์ไม่เปลี่ยน |
| [2. ทำงานกับไฟล์](/th/guide/learning-paths/beginner/02-work-with-files/) | เพิ่ม comment สถานะในประกาศเท่านั้น | มีเพียงไฟล์เดียวเพิ่มหนึ่งบรรทัด |
| [3. มอบหมายงานให้ชัดเจน](/th/guide/learning-paths/beginner/03-give-clear-tasks/) | เรียบเรียงประกาศจากข้อเท็จจริง | ข้อเท็จจริงตรงกัน เก็บสิ่งที่ยังไม่ทราบ และขอบเขตถูกต้อง |
| [4. ตรวจทานผลลัพธ์](/th/guide/learning-paths/beginner/04-review-results/) | หาข้อผิดพลาดในตัวอย่างผิดและตรวจอาร์ติแฟกต์ของตนเอง | ระบุข้อผิดพลาดสี่ข้อและมีบันทึกการตรวจจริง |
| [5. ทำโปรเจกต์เล็กแรกให้เสร็จ](/th/guide/learning-paths/beginner/05-complete-first-project/) | ฝึกกู้คืนในสำเนาและเขียนเอกสารส่งต่อ | ไฟล์หลังคืนค่าตรงกันและเอกสารส่งต่อตรวจย้อนหลังได้ |

## ในชุดฝึกมีอะไร

starter มีข้อเท็จจริง ร่างประกาศ และบันทึกสังเคราะห์ที่ห้ามแก้; references มีเอกสารอ้างอิงของผู้เขียนและตัวอย่างผิดที่ออกแบบไว้; templates มีเทมเพลตตรวจทานและส่งต่อ; validation มีสคริปต์ทำซ้ำแบบเลือกใช้และบันทึกการทำงานกับไฟล์จริง

กิจกรรมและสถานที่ทั้งหมดเป็นเรื่องสมมติ สื่อใช้สัญญาอนุญาต CC0-1.0 แบบฝึกทำงานกับไฟล์ในเครื่องเท่านั้น ไม่มีการลงทะเบียน เผยแพร่ หรือส่งข้อความจริง

## ตรวจสอบถึงขั้นใดแล้ว

ผู้เขียนเรียกการคัดลอกเริ่มต้น การแก้ไฟล์เดียว การป้องกันต้นฉบับ การสร้างความผิดพลาด และการตรวจการกู้คืนในไดเรกทอรีชั่วคราวแล้ว สคริปต์ไม่ได้เรียกโมเดล และประกาศอ้างอิงเขียนโดยผู้เขียน เว็บไซต์นี้ยังไม่มีผลวัดอัตราสำเร็จของโมเดล เวลาเรียน หรือการทำจนจบของผู้อ่านอิสระ ความสำเร็จของคุณต้องพิสูจน์ด้วยไฟล์และบันทึกการตรวจของคุณเอง
