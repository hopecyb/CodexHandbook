## ข้อกำหนดเบื้องต้น

ทำขั้นแรกเสร็จแล้ว และใน `work` ยังมีไฟล์ต้นฉบับสามไฟล์ เก็บ `starter` ที่อยู่นอกไดเรกทอรีทำงานไว้เป็น baseline

## แก้ไขหนึ่งครั้งที่ตรวจสอบได้

```text
เพิ่มหมายเหตุสถานะต่อไปนี้ที่บรรทัดแรกของ notice.md เท่านั้น:
<!-- สถานะ: ร่างฝึกหัด ยังไม่เผยแพร่ -->
เก็บเนื้อหาเดิมทุกคำ ห้ามแก้ไฟล์อื่นและห้ามเพิ่มไฟล์
เมื่อเสร็จ ให้อธิบายตำแหน่งที่แก้ และห้ามเผยแพร่หรือส่งประกาศ
```

ใช้มุมมอง diff ของไคลเอนต์ปัจจุบันหรือเอดิเตอร์เทียบกับต้นฉบับทีละบรรทัด ที่นี่ต้องการการแก้เล็กเพียงครั้งเดียว ไม่ต้องเพิ่มกระบวนการ “วางแผนก่อนแล้วค่อยยืนยันทีละขั้น”

## เงื่อนไขว่าเสร็จ

เปลี่ยนเฉพาะ notice.md และเพิ่มเพียง comment หนึ่งบรรทัดตรงตามข้อความ ไฟล์อีกสองไฟล์คงเดิม ดู [ผลลัพธ์ขั้นที่สอง](/downloads/first-project/references/step-2-notice.md) comment อาจไม่แสดงเมื่อ render Markdown จึงต้องดูซอร์สของไฟล์

หากโมเดลแก้เนื้อหาหลัก ให้คืน notice.md เป็นต้นฉบับจาก starter แล้วทำขั้นนี้ใหม่ การคืนค่าใช้เฉพาะไฟล์ฝึกนี้ อย่ารีเซ็ตทั้งโปรเจกต์ ดูวิธีที่เกี่ยวข้องใน [เลิกทำและกู้คืน](/th/guide/getting-started/undo-and-recover/)
