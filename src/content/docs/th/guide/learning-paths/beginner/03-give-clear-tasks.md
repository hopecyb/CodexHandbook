## ข้อกำหนดเบื้องต้น

ทำขั้นที่สองเสร็จแล้ว `facts.md` มีข้อเท็จจริงที่มีหมายเลขเจ็ดข้อ และ `notice.md` มี comment สถานะว่ายังไม่เผยแพร่

## จัดประกาศด้วยเกณฑ์ที่ชัดเจน

```text
ใช้เฉพาะ facts.md ในไดเรกทอรีนี้เป็นแหล่งข้อมูล แล้วเรียบเรียง notice.md เป็นประกาศกิจกรรม
เก็บ comment สถานะ “ร่างฝึกหัด ยังไม่เผยแพร่” ไว้
ใส่เวลา สถานที่ จำนวนที่รับ ค่าใช้จ่าย สิ่งที่ต้องเตรียม และส่วน “รอยืนยัน”
กำกับข้อเท็จจริงแต่ละข้อด้วยหมายเลข F ที่ตรงกัน; เก็บข้อมูลที่ไม่แน่ใจเป็นไม่ทราบ
ห้ามเพิ่ม QR code หมายเลขโทรศัพท์ หรือลิงก์ลงทะเบียน
แก้เฉพาะ notice.md ห้ามแก้ facts.md และ private-note.md ห้ามเพิ่มไฟล์
ห้ามเชื่อมต่ออินเทอร์เน็ต และห้ามเผยแพร่หรือส่งเนื้อหา
เมื่อเสร็จ ให้แสดงรายการที่แก้และหลักฐานที่ตรงกัน; หากข้อมูลขัดแย้ง ให้ระบุความขัดแย้งและคงไว้เป็นรอยืนยัน
```

เป้าหมายคือประกาศที่ตรวจสอบได้ บริบทคือกิจกรรมสมมติเพื่อการสอน อินพุตคือ facts.md และขอบเขตคือแก้เฉพาะ notice.md เกณฑ์ยอมรับเจาะจงทั้งเนื้อหาและไฟล์ ไม่ใช้คำว่า “เขียนให้เป็นมืออาชีพขึ้น” แทน

## เงื่อนไขว่าเสร็จ

เวลาคือ 2026-10-17 14:00—15:30 สถานที่คือห้องอ่านหนังสือสมมติในข้อมูล รับ 18 คน ไม่มีค่าใช้จ่าย และนำหนังสือมาได้โดยสมัครใจ ส่วนวิธีลงทะเบียนต้องคงเป็นรอยืนยัน ตรวจทีละข้อว่าหมายเลขอ้างอิงรองรับประโยคนั้นจริง

ตรวจด้วยตัวเองก่อน แล้วดู [ประกาศอ้างอิงของผู้เขียน](/downloads/first-project/references/notice.md) สำนวนไม่ต้องเหมือนกัน แต่ข้อเท็จจริง เรื่องที่ยังไม่ตัดสิน และขอบเขตการเปลี่ยนแปลงต้องตรงกัน หากผิด ให้แก้เฉพาะปัญหา อย่าให้โมเดลเขียนไฟล์ข้อเท็จจริงใหม่เพื่อให้ตรงกับผลลัพธ์
