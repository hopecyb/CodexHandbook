## เตรียมสื่อ

[ดาวน์โหลดชุดฝึกฉบับเต็ม](/downloads/first-project/first-project-1.0.0.zip) เมื่อแตกไฟล์แล้ว ให้คัดลอก `starter` ทั้งโฟลเดอร์เป็นโฟลเดอร์ `work` ใหม่ แล้วให้ Codex เปิด `work` ภายในมีเพียง `facts.md`, `notice.md` และ `private-note.md` ซึ่งทั้งหมดเป็นข้อมูลสังเคราะห์เพื่อการสอน

เก็บ `starter` ต้นฉบับไว้ และอย่าใช้ `references` ที่มีคำตอบของผู้เขียนเป็นอินพุตในขั้นนี้ ยังไม่ต้องใช้ Git เทอร์มินัล หรือ dependency เพิ่มเติม เปิดไฟล์ด้วยเอดิเตอร์ก็พอ

## มอบหมายงานแรก

```text
อ่านเฉพาะ facts.md, notice.md และ private-note.md ในไดเรกทอรีปัจจุบัน
อธิบายหน้าที่ของแต่ละไฟล์รวมสามประโยค แล้วระบุข้อมูลกิจกรรมที่ยังไม่ยืนยัน
ห้ามเพิ่ม แก้ หรือลบไฟล์ ห้ามเชื่อมต่ออินเทอร์เน็ต และห้ามเผยแพร่หรือส่งเนื้อหา
```

แบบฝึกนี้กำหนดให้อ่านอย่างเดียวอย่างชัดเจน จึงต้องระบุขอบเขตการอ่านเขียน งานอื่นควรให้สิทธิ์ตามเจตนาจริง ไม่ต้องเติมประโยคนี้กับทุกคำขอโดยอัตโนมัติ

## เงื่อนไขว่าเสร็จ

คำตอบแยกได้ถูกต้องว่าไฟล์ใดเป็นข้อเท็จจริง ไฟล์ใดเป็นประกาศที่ต้องแก้ และไฟล์ใดเป็นบันทึกที่ต้องเก็บไว้ พร้อมระบุว่ายังไม่ทราบวิธีลงทะเบียน ทั้งสามไฟล์ต้องเหมือนต้นฉบับใน starter โดยไม่มีไฟล์เพิ่มหรือลบ

หากไม่แน่ใจ ให้เปิดไฟล์ตรวจโดยตรง แล้วดู [คำอธิบายไฟล์จากผู้เขียน](/downloads/first-project/references/folder-map.md) ถ้อยคำต่างกันได้ แต่ห้ามแต่งหน้าที่ของไฟล์หรือวิธีลงทะเบียน
