**Agent** จะเดินหน้าตามเป้าหมายอย่างต่อเนื่อง: เข้าใจเป้าหมาย → เลือกเครื่องมือ → สังเกตผล → ปรับขั้นถัดไป จนเสร็จหรือต้องให้คุณเข้ามาช่วย

AI ทั่วไปคล้ายคนที่ตอบคำถาม ส่วน Agent คล้ายคนที่รับงานแล้วทำต่อทีละขั้น

![ภาพประกอบ: ด้านซ้ายเป็นแชตทั่วไปแบบถามตอบ ด้านขวาเป็นวงจร Agent ที่อ่านไฟล์ ใช้เครื่องมือ ตรวจผล และแก้ output](/illustrations/agent-basics.webp)

## Agent ต่างจากแชตทั่วไปอย่างไร

| | แชตทั่วไป | Agent |
|---|---|---|
| Output | ส่วนใหญ่เป็นคำแนะนำข้อความ | อ่านเขียนไฟล์ รันคำสั่ง และแก้ repository ได้ |
| กระบวนการ | ตอบครั้งเดียว | เรียกเครื่องมือหลายขั้น |
| ความเสี่ยง | คำแนะนำที่ทำให้เข้าใจผิด | อาจทำไฟล์เสียหรือรันคำสั่งอันตราย |
| บทบาทของคุณ | อ่าน | กำหนดขอบเขต อนุมัติ และตรวจรับ |

## คำเปรียบเทียบที่เข้าใจง่าย

เปรียบเทียบได้ดังนี้:

- **แชตทั่วไป**: คล้ายถามเพื่อนว่า “ข้อนี้ทำอย่างไร”
- **Agent**: คล้ายขอให้เพื่อนร่วมงานทำ draft ก่อน แล้วตรวจร่วมกัน

ดังนั้นในโหมด Agent คุณต้องใส่ใจมากขึ้นว่า:

- Agent เข้าถึงอะไรได้
- ควรให้วางแผนก่อนหรือไม่
- จะตรวจรับอย่างไรเมื่อเสร็จ

## ทำไมต้องแยกความต่างนี้

การใช้ผิดจำนวนมากมาจากความเข้าใจเดียวกัน:

> คิดว่าระบบเพียง “พูดเท่านั้น”

เมื่อระบบเริ่มอ่านไฟล์ แก้ไฟล์ และรันคำสั่ง มันไม่ใช่เพียงคำแนะนำในหน้าต่างแชต แต่กำลังเข้าร่วมงานจริง

เมื่อเริ่มใช้ ควรอ่านพร้อมกัน:

1. [สิทธิ์และการอนุมัติ](/th/guide/foundations/permissions-and-approvals/)
2. [รันงานแรก](/th/guide/getting-started/run-your-first-task/)
3. [ตรวจผลลัพธ์](/th/guide/getting-started/review-the-result/)
