ดูคำศัพท์ฉบับเต็มที่ [อภิธานศัพท์](/th/guide/reference/glossary/) ส่วนหน้านี้รวมคำที่พบบ่อยและมีผลต่อการอ่านมากที่สุดก่อน

เมื่อเริ่มอ่านคู่มือ Codex สิ่งที่ทำให้สะดุดง่ายที่สุดมักเป็นศัพท์ที่หนาแน่น แต่ละคำดูเข้าใจได้ แต่เมื่ออยู่รวมกันกลับทำให้งง

สถานการณ์ที่พบบ่อยมีสองแบบ:

- อ่านคำได้ทุกคำ แต่ไม่รู้ว่าหมายถึงอะไรในการใช้งานจริง
- ไม่รู้ว่าคำใดต้องเข้าใจตอนนี้ และคำใดเรียนทีหลังได้

อย่ามองเป็นข้อสอบคำศัพท์ เพียงรู้คร่าว ๆ ว่าหมายถึงอะไรเพื่ออ่านเนื้อหาต่อได้ก็พอ

## คำที่ควรรู้ก่อน

หากเป้าหมายตอนนี้คือทำงานแรกให้สำเร็จ ให้เข้าใจ 6 คำนี้ก่อน:

| คำศัพท์ | เหตุผลที่ควรรู้ก่อน |
|---|---|
| **พรอมต์** | วิธีอธิบายงานให้ชัด |
| **บริบท** | ข้อมูลที่ Codex มองเห็นอยู่ |
| **Agent** | เหตุใดจึงไม่ใช่แค่ตอบข้อความ |
| **การอนุมัติ** | เหตุใดบางครั้งจึงหยุดถามคุณ |
| **ความแตกต่าง (diff)** | วิธีตรวจว่าเปลี่ยนอะไรไปจริง |
| **งาน** | หน่วยพื้นฐานของงานหนึ่งรอบ |

| คำศัพท์ | คำอธิบายอย่างง่าย |
|---|---|
| **พรอมต์ (prompt)** | เป้าหมาย ภูมิหลัง และข้อกำหนดที่คุณให้ Codex |
| **บริบท (context)** | ข้อมูลโปรเจกต์ ไฟล์ และบทสนทนาที่โมเดลเห็นในขณะนั้น |
| **Agent** | รูปแบบการทำงานที่เรียกเครื่องมือและเดินหน้าซ้ำตามเป้าหมายได้ |
| **เครื่องมือ (tool)** | ความสามารถที่เรียกใช้ได้ เช่น อ่านไฟล์ รันคำสั่ง และค้นหา |
| **Sandbox** | สภาพแวดล้อมทำงานที่จำกัดผลกระทบต่อระบบไฟล์และเครือข่าย |
| **การอนุมัติ (approval)** | การกระทำบางอย่างต้องได้รับความยินยอมชัดเจนจากคุณก่อนดำเนินต่อ |
| **ความแตกต่าง (diff)** | การเทียบเนื้อหาก่อนและหลังเปลี่ยนเพื่อให้ตรวจทาน |
| **เธรด / เซสชัน** | บทสนทนาต่อเนื่องและบริบทที่สะสมอยู่ |
| **งาน** | หน่วยงานที่มีเป้าหมายหนึ่งชุด ซึ่งอาจเรียกเครื่องมือหลายขั้น |
| **Skill** | คำสั่งและทรัพยากรเฉพาะทางที่นำกลับมาใช้ซ้ำได้ (ขั้นสูง) |
| **MCP** | โปรโตคอลเชื่อมเครื่องมือและแหล่งข้อมูลภายนอก (ขั้นสูง) |
| **งาน Cloud** | งานที่รันในสภาพแวดล้อม Cloud ไม่ใช่ Sandbox บนเครื่อง |

## พูดให้ตรงไปตรงมา

- **พรอมต์**: สิ่งที่คุณพูดเมื่อต้องการมอบหมายงาน
- **บริบท**: เอกสารที่มีอยู่ในมือตอนนี้
- **Agent**: ไม่เพียงตอบข้อความ แต่เดินหน้าทำงานจริง
- **การอนุมัติ**: บางอย่างทำเองไม่ได้ ต้องให้คุณยืนยัน
- **diff**: การเทียบก่อนและหลังแก้
- **Skill**: แพ็กวิธีทำงานชุดหนึ่งเพื่อนำกลับมาใช้

## วิธีใช้หน้านี้

เมื่อพบคำเหล่านี้ในหน้าอื่น ไม่ต้องหยุดค้นนิยามทุกครั้ง:

- ถ้าพอเข้าใจ ก็อ่านต่อ
- ถ้าเห็นซ้ำแล้วยังไม่ชัด ให้กลับมาที่นี่
- ถ้าเริ่มกระทบความเข้าใจเวิร์กโฟลว์ ให้ไปอ่านหน้าหัวข้อนั้น

## แบ่งเป็นกลุ่มได้

ถ้าไม่อยากจำมากเกินไป ให้แบ่งดังนี้:

- คุณพูดอะไร: พรอมต์
- มันเห็นอะไร: บริบท
- มันทำอย่างไร: Agent, เครื่องมือ
- มันทำได้หรือไม่: การอนุมัติ, Sandbox
- คุณตรวจอย่างไร: diff, ผลลัพธ์ของงาน

## คำที่เรียนทีหลังได้

รายการต่อไปนี้ส่วนใหญ่เป็นเนื้อหาขั้นสูง ไม่ต้องรีบเข้าใจทั้งหมดในครั้งแรก:

- Skill
- MCP
- Hook
- Plugin
- รายละเอียดสภาพแวดล้อม Cloud

ทำ [งานแรก](/th/guide/getting-started/run-your-first-task/) ให้เสร็จก่อน แล้วค่อยกลับมาอ่านคำเหล่านี้ มักเข้าใจได้ราบรื่นกว่า

เมื่อพบคำใหม่ ให้กลับมาตรวจแล้วอ่านต่อ

ในการอ่านคู่มือครั้งแรก มองศัพท์เหล่านี้เป็นเพียงป้ายบอกทาง การรู้คร่าว ๆ ว่าหมายถึงอะไรมีประโยชน์กว่าท่องจำทั้งหมดตั้งแต่แรก
