## อัปเดตต่อเนื่อง

คู่มือนี้ไม่ได้ผูกไว้กับ Codex เวอร์ชันเดียวในระยะยาว ผลิตภัณฑ์เปลี่ยนแปลงต่อเนื่อง ดังนั้นวิธีติดตั้ง การเข้าสู่ระบบ สิทธิ์ โมเดล การตั้งค่า และพฤติกรรมของ Cloud อาจเปลี่ยนไปตามเวลา

## ควรยึดข้อมูลใด

สำหรับพฤติกรรมปัจจุบันของผลิตภัณฑ์ ให้ยึด [เอกสาร Codex อย่างเป็นทางการของ OpenAI](https://developers.openai.com/codex) คู่มือนี้ใช้เพื่ออธิบายแนวคิด จัดลำดับเส้นทาง และเสนอวิธีทำงานเชิงปฏิบัติ หากข้อมูลขัดแย้งกัน ให้ยึดเอกสารทางการและแจ้งปัญหาผ่านลิงก์แก้ไขที่ด้านล่างของหน้า

## วิธีประเมินว่าเนื้อหายังใช้ได้หรือไม่

เมื่ออ่านข้อมูลที่อาจเปลี่ยนแปลง ให้พิจารณาสามเรื่อง:

1. หัวข้อนั้นเปลี่ยนบ่อยหรือไม่ เช่น การติดตั้ง การตั้งค่า สิทธิ์ หรือช่องทางเข้าสู่ผลิตภัณฑ์
2. วันที่อัปเดตเนื้อหาที่แสดงอยู่ห่างจากปัจจุบันมากหรือไม่
3. แหล่งข้อมูลทางการที่อ้างถึงยังตรงกับพฤติกรรมปัจจุบันของผลิตภัณฑ์หรือไม่

แนวคิด วิธีการ และหลักการตรวจรับมักคงที่กว่าปุ่ม พารามิเตอร์ และเส้นทางในหน้าจอ สำหรับพฤติกรรม พารามิเตอร์ ราคา หรือกฎล่าสุด ให้ตรวจสอบแหล่งข้อมูลทางการอีกครั้ง

## การอัปเดตและแก้ไขเนื้อหา

[การอัปเดตและแก้ไขเนื้อหา](/th/guide/updates/) บันทึกการเปลี่ยนแปลงสำคัญและผลกระทบ ส่วนท้ายหน้าสามารถเปิดร่าง Issue บน GitHub ที่มีชื่อและเส้นทางของหน้าปัจจุบัน โปรดตรวจสอบและลบข้อมูลอ่อนไหวก่อนส่ง

## เนื้อหาที่เปลี่ยนบ่อย

- วิธีติดตั้งและข้อกำหนดของระบบ
- การเข้าสู่ระบบ บัญชี และขั้นตอนสิทธิ์
- โมเดล ตัวเลือกการตั้งค่า และรูปแบบพารามิเตอร์
- พฤติกรรมของ Cloud ไคลเอนต์ และช่องทางเข้าสู่ผลิตภัณฑ์
- ราคา โควตา และข้อจำกัดของบริการ
