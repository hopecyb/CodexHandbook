## อัปเดตต่อเนื่อง

คู่มือนี้จะไม่ผูกกับ Codex เวอร์ชันเดียวแล้วหยุดนิ่งระยะยาว ผลิตภัณฑ์เปลี่ยนได้ แต่ละหน้าจึงใช้สถานะ วันที่ตรวจสอบ และหลักฐานเฉพาะเพื่อบอกขอบเขตที่ตรวจแล้ว วันที่เพียงอย่างเดียวไม่ใช่คะแนนความน่าเชื่อถือ

## เนื้อหา

- เหตุใดคู่มือนี้จึงถือว่าไม่เปลี่ยนแปลงตลอดไปไม่ได้
- ควรอ่านสถานะและวันที่ตรวจสอบด้านบนหน้าอย่างไร
- เมื่อขัดแย้งกับข้อมูลทางการควรเชื่อแหล่งใด

## สถานะหน้า

| สถานะ | ความหมาย |
|---|---|
| planned | วางแผนแล้ว ยังไม่ได้เขียน |
| draft | กำลังเขียน |
| review | เนื้อหาเสร็จ รอตรวจทาน |
| verified | ตรวจสอบตามหลักฐานที่ระบุแล้ว |
| outdated | ต้องอัปเดตหลังผลิตภัณฑ์เปลี่ยน |
| archived | เก็บเป็นประวัติ ไม่อยู่ในเมนูหลัก |

## วิธีอ่านสถานะหน้า

- `planned`: ยังไม่ได้เขียน
- `draft`: กำลังเขียนและยังไม่นิ่ง
- `review`: เนื้อหาหลักเป็นรูปเป็นร่างแล้ว แต่ยังต้องตรวจทาน
- `verified`: ตรวจสอบตามหลักฐานที่ระบุแล้ว
- `outdated`: อาจเคยถูกต้อง แต่ตอนนี้ต้องระวังข้อมูลล้าสมัย
- `archived`: เก็บไว้อ้างอิง ไม่ใช่เนื้อหาหลักปัจจุบัน

## บันทึกการตรวจสอบและการอัปเดตเนื้อหา

ส่วนบนของหน้าแสดงสถานะบรรณาธิการ วิธีตรวจสอบ วันที่ตรวจ และหลักฐานที่ใช้แยกกัน `editorial` คือการตรวจโดยบรรณาธิการ `source-checked` คือการตรวจแหล่งข้อมูล และ `run-tested` คือการทดลองรันตัวอย่างในสภาพแวดล้อมที่บันทึกไว้ ทั้งสามแทนกันไม่ได้ คำอธิบายในอดีตจะเก็บแยกและไม่ถูกยกระดับเป็นการทดสอบปัจจุบันโดยอัตโนมัติ

[การอัปเดตและแก้ไขเนื้อหา](/th/guide/updates/) อธิบายการเปลี่ยนแปลงและผลกระทบโดยละเอียด ที่ท้ายหน้าภาษาจีนสามารถเปิดร่างแก้ไขบน GitHub ซึ่งแนบข้อมูลหน้าปัจจุบันไว้ได้ แต่ต้องตรวจและลบข้อมูลอ่อนไหวด้วยตนเองก่อนส่ง

## แหล่งข้อมูลทางการ

ให้ยึดพฤติกรรมผลิตภัณฑ์ตามเอกสาร OpenAI: [https://developers.openai.com/codex](https://developers.openai.com/codex) Repository นี้เป็นคู่มือชุมชน หากขัดแย้งกับข้อมูลทางการ ให้ยึดข้อมูลทางการและยินดีรับ issue

## ความเข้าใจผิดที่พบบ่อย

### 1. เมื่อเขียนไว้ในคู่มือแล้ว แปลว่าจะไม่เปลี่ยนระยะยาว

เนื้อหาต่อไปนี้เปลี่ยนได้ง่ายเป็นพิเศษ:

- วิธีติดตั้ง
- ขั้นตอนเข้าสู่ระบบและบัญชี
- สิทธิ์ โมเดล และตัวเลือกการตั้งค่า
- พฤติกรรมของ Cloud และช่องทางผลิตภัณฑ์

### 2. `review` ไม่ได้แปลว่าอ่านไม่ได้

`review` หมายถึงมีเนื้อหาหลักแล้ว แต่ยังไม่ถึงระดับยืนยันสูงสุด ไม่ได้หมายความว่าใช้อ้างอิงไม่ได้

### 3. เมื่อคู่มือชุมชนขัดแย้งกับเอกสารทางการ ไม่ควรเชื่ออย่างละครึ่ง

ให้แยกดังนี้:

- ใช้คู่มือเพื่อเข้าใจแนวคิดและเส้นทาง
- ใช้เอกสารทางการสำหรับพฤติกรรมล่าสุดและรูปแบบพารามิเตอร์เฉพาะ

## วิธีประเมินว่าหน้าน่าเชื่อถือหรือไม่

หากกังวลว่าหน้าหนึ่งล้าสมัย ให้ดูสามเรื่อง:

1. สถานะบรรณาธิการด้านบนเป็น `review`, `verified` หรือ `outdated`
2. วันที่ตรวจล่าสุดห่างจากปัจจุบันเพียงใด
3. เนื้อหาเป็นแนวคิด หรือเป็นเรื่องที่เปลี่ยนง่ายอย่างการติดตั้ง การตั้งค่า และสิทธิ์

เรื่องพฤติกรรม พารามิเตอร์ และกฎล่าสุดทุกอย่าง ให้ยึดเอกสารทางการปัจจุบันเป็นข้อสรุปสุดท้าย
