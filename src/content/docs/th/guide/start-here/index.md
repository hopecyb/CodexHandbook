คู่มือนี้เขียนขึ้นสำหรับ **ผู้เริ่มต้นด้าน AI** เป็นหลัก โดยไม่สมมติว่าคุณใช้เทอร์มินัล Git หรือ Agent เป็น แต่จะค่อย ๆ อธิบายความสามารถที่ต้องใช้ต่อไป

![ภาพประกอบ: ป้ายบอกทางหลายเส้นตั้งอยู่ที่จุดเริ่มต้น มีคู่มือเปิดอยู่ข้าง ๆ และผู้ช่วยตัวเล็กโบกมือต้อนรับผู้อ่าน](/illustrations/start-here.webp)

## เนื้อหา

- เข้าใจว่า Codex ทำอะไรได้และทำอะไรไม่ได้
- เลือกเส้นทางอ่านตามบทบาทและงาน
- ทำงานแรกที่ตรวจสอบได้ในโปรเจกต์ฝึกที่ปลอดภัย
- เรียนรู้การเขียนพรอมต์ด้วย “เป้าหมาย ข้อจำกัด เกณฑ์ยอมรับ” และสร้างนิสัยตรวจทาน

## ลำดับการอ่านที่แนะนำ

1. [Codex คืออะไร](/th/guide/start-here/what-is-codex/) — เข้าใจว่าทำอะไรได้และไม่ได้
2. [เลือกไคลเอนต์](/th/guide/choose-your-client/) — เลือกระหว่าง App, CLI, IDE และ Cloud
3. [ทำงานแรกให้เสร็จ](/th/cases/first-task/) — ใช้พรอมต์ชัดเจนทำการแก้ไขเล็ก ๆ และตรวจผล
4. [สิทธิ์และ Sandbox](/th/guide/permissions-and-sandbox/) — เข้าใจการอนุมัติ การแยก และขอบเขตเครือข่าย
5. [บริบทและไฟล์](/th/guide/context/) — เรียนรู้การให้อินพุตที่มีประโยชน์
6. [ตรวจสอบผลลัพธ์](/th/guide/quality/) — สร้างนิสัยตรวจทานและทดสอบ

## ความเข้าใจผิดที่พบบ่อย

### 1. บท “เริ่มต้นที่นี่” จะไม่อธิบายทุกอย่างในครั้งเดียว

บทนี้เน้นทำให้ทางเข้าและลำดับชัดเจน ไม่ยัดทุกอย่างให้คุณในครั้งเดียว

### 2. แม้ยังไม่เข้าใจหลายคำ ก็อ่านต่อได้

ตอนแรกเพียงรู้เรื่องต่อไปนี้ก็พอ:

- Codex ทำงานร่วมกับคุณอย่างไร
- เริ่มงานอย่างไร
- ตรวจผลอย่างไร

รายละเอียดอื่นเรียนรู้เพิ่มระหว่างใช้งานได้

### 3. เข้าใจแนวคิดอย่างเดียวยังไม่พอให้เริ่มใช้จริง

ยังไม่พอ ต้องเข้าใจ ทดลองในขอบเขตเล็ก และตรวจผลไปพร้อมกัน

## เส้นทาง 30 นาทีแรก

| เวลา | ทำอะไร |
|---|---|
| 0–5 นาที | อ่านประเด็นความปลอดภัยใน [สิทธิ์และ Sandbox](/th/guide/permissions-and-sandbox/) |
| 5–10 นาที | ติดตั้งและเข้าสู่ระบบไคลเอนต์ที่เลือก (เช่น [Desktop App](/th/guide/desktop-app/)) |
| 10–25 นาที | ทำแบบฝึกตาม [กรณีงานแรก](/th/cases/first-task/) |
| 25–30 นาที | อ่าน [พื้นฐานพรอมต์](/th/prompts/basics/) เพื่อเตรียมเขียนงานให้ชัดขึ้น |

หากติดขัด ดู [การแก้ไขปัญหา](/th/guide/reference/troubleshooting/)
