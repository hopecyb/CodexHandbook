ปัจจุบัน Codex ใช้งานได้ผ่าน **แพ็กเกจ ChatGPT** หรือ **API key แบบคิดตามการใช้งาน** แต่ทั้งสองแบบไม่ได้ให้ช่องทางเข้าใช้และขอบเขตการกำกับดูแลเหมือนกันทั้งหมด

## เลือกวิธีเข้าถึงก่อน

| วิธี | เหมาะกับ | ขอบเขตการใช้งาน |
|---|---|---|
| ลงชื่อเข้าใช้ด้วย ChatGPT | การโต้ตอบส่วนบุคคล เดสก์ท็อป Cloud และเวิร์กสเปซองค์กร | ทำงานภายใต้โควตาของแพ็กเกจ ChatGPT บทบาทในเวิร์กสเปซ และนโยบายผู้ดูแลระบบ |
| ใช้ API key | Codex ในเครื่อง สคริปต์ และ CI | คิดค่าบริการตามการใช้ API; ความสามารถบางอย่างที่พึ่งพาเวิร์กสเปซ ChatGPT หรือ Cloud จะใช้ไม่ได้ |

หน้า Pricing ทางการปัจจุบันรวม ChatGPT Work และ Codex ไว้ในแพ็กเกจ Free, Go, Plus, Pro, Business, Edu และ Enterprise แต่ราคา โควตา โมเดล และฟีเจอร์ที่รวมอาจเปลี่ยนแปลงได้ หน้านี้จึงไม่จัดทำตารางราคา โปรดดู [ตัวเลือกแพ็กเกจและแหล่งข้อมูลราคาของเว็บไซต์นี้](/chatgpt-pricing/) และตรวจสอบ [หน้า Pricing ทางการแบบเรียลไทม์](https://learn.chatgpt.com/docs/pricing)

## ทำไมมีบัญชีแล้วจึงอาจยังใช้ไม่ได้

การลงชื่อเข้าใช้เป็นเพียงด่านแรก การเข้าถึงจริงยังขึ้นอยู่กับ:

1. แพ็กเกจปัจจุบันครอบคลุมช่องทางหรือฟีเจอร์ที่ต้องการหรือไม่
2. ผลิตภัณฑ์นั้นพร้อมให้บริการในภูมิภาคของคุณหรือไม่
3. องค์กรจัดสรรที่นั่ง บทบาท และสิทธิ์เวิร์กสเปซให้แล้วหรือไม่
4. ผู้ดูแลระบบจำกัดวิธีลงชื่อเข้าใช้ โมเดล หรือความสามารถในเครื่องผ่านการกำหนดค่าแบบจัดการหรือไม่
5. การใช้งานของคุณถึงขีดจำกัดของช่วงเวลาปัจจุบันหรือขีดจำกัดรายสัปดาห์แล้วหรือไม่

## เช็กลิสต์สำหรับผู้ใช้ส่วนบุคคล

- ลงชื่อเข้าใช้บัญชี ChatGPT ที่ถูกต้องบนหน้าทางการได้
- รู้ว่ากำลังใช้โควตาจากแพ็กเกจหรือคิดค่าบริการ API ตามการใช้งาน
- เห็นข้อมูลประจำตัวที่ถูกต้องในไคลเอนต์เป้าหมาย
- เมื่อพบข้อความเรื่องโควตา ให้ตรวจการใช้งานแบบเรียลไทม์ แทนการติดตั้งไคลเอนต์ซ้ำ

## เช็กลิสต์สำหรับทีมและองค์กร

- เลือกเวิร์กสเปซที่ถูกต้อง ไม่ใช่พื้นที่ส่วนตัวภายใต้อีเมลเดียวกัน
- ผู้ดูแลระบบตั้งค่าสมาชิก ที่นั่ง และบทบาทเรียบร้อยแล้ว
- SSO, MFA, การเก็บรักษาข้อมูล และนโยบายภูมิภาคตรงตามข้อกำหนดขององค์กร
- การกำหนดค่าแบบจัดการไม่ได้บังคับให้ใช้วิธีลงชื่อเข้าใช้ในเครื่องแบบอื่น
- API key อยู่ใน API organization ที่ถูกต้อง และไม่ปะปนกับนโยบายเวิร์กสเปซ ChatGPT

## ตัวอย่างการวินิจฉัย

หาก CLI ลงชื่อเข้าใช้ด้วย API key ได้ แต่ปุ่ม Cloud ใช้ไม่ได้ สาเหตุอาจไม่ใช่การติดตั้งผิดพลาด Cloud ต้องลงชื่อเข้าใช้ด้วย ChatGPT และอยู่ภายใต้แพ็กเกจ ChatGPT กับสิทธิ์เวิร์กสเปซ ส่วน API key ครอบคลุมงานในเครื่องและเวิร์กโฟลว์แบบโปรแกรมเป็นหลัก
