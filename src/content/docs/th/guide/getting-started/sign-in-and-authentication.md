Codex มีวิธีลงชื่อเข้าใช้ส่วนบุคคลสองแบบเมื่อใช้โมเดล OpenAI:

- **ลงชื่อเข้าใช้ด้วย ChatGPT**: ใช้โควตาการสมัครสมาชิก และสืบทอดสิทธิ์เวิร์กสเปซกับนโยบายข้อมูลของ ChatGPT
- **ลงชื่อเข้าใช้ด้วย API key**: คิดค่าบริการตามการใช้ API และสืบทอดนโยบายข้อมูลกับการจัดการของ API organization

งานในเครื่องของเดสก์ท็อป App ของ ChatGPT, Codex CLI และการผสานกับ IDE รองรับทั้งสองวิธี แต่ **Codex Cloud ต้องลงชื่อเข้าใช้ด้วย ChatGPT**

## ลงชื่อเข้าใช้ด้วย ChatGPT

ไคลเอนต์ในเครื่องจะเปิดเบราว์เซอร์เพื่ออนุญาต แล้วส่งข้อมูลประจำตัวกลับไปยังไคลเอนต์:

- เดสก์ท็อป App: เลือกดำเนินการลงชื่อเข้าใช้ต่อในหน้าที่ออกจากระบบอยู่
- CLI: เรียก `codex login`
- IDE: เลือกลงชื่อเข้าใช้ด้วย ChatGPT ในหน้าที่ออกจากระบบอยู่

หลังลงชื่อเข้าใช้ ให้ตรวจบัญชีและเวิร์กสเปซที่ใช้งานอยู่ โดยเฉพาะเมื่อมีทั้งพื้นที่ส่วนตัวและเวิร์กสเปซบริษัท

## ลงชื่อเข้าใช้ด้วย API key

หลังสร้าง key ใน OpenAI Platform อย่าเขียนลงในประวัติคำสั่งโดยตรง CLI รับค่าผ่านอินพุตมาตรฐาน:

```bash
printenv OPENAI_API_KEY | codex login --with-api-key
```

ในเดสก์ท็อป App ให้เข้าผ่าน “ใช้วิธีอื่นในการลงชื่อเข้าใช้” ส่วน IDE ให้เข้าผ่าน “Use API Key” API key เหมาะกับงานในเครื่องและ CI ที่เชื่อถือได้ แต่ไม่ให้ความสามารถที่พึ่งพาเวิร์กสเปซ ChatGPT หรือ Cloud

## ตรวจและออกจากระบบใน CLI

```bash
codex login status
codex logout
```

CLI กับ IDE แชร์ข้อมูลลงชื่อเข้าใช้ที่แคชไว้ หลังออกจากระบบในเครื่องมือหนึ่ง อีกเครื่องมืออาจต้องลงชื่อเข้าใช้อีกครั้งเมื่อเริ่มครั้งถัดไป

## ความปลอดภัยของข้อมูลประจำตัว

- อย่า commit `~/.codex/auth.json` หรือวางลงในทิกเก็ต แชต หรือ log
- ควรใช้ที่เก็บข้อมูลประจำตัวของระบบปฏิบัติการ token ที่เก็บในไฟล์ต้องได้รับการปฏิบัติเหมือนรหัสผ่าน
- CI ควรใช้ข้อมูลประจำตัวเฉพาะที่เพิกถอนได้ ไม่ใช้ key ส่วนบุคคลระยะยาวซ้ำ
- Codex Cloud เข้าถึงรีโพซิทอรีโค้ดโดยตรง จึงควรเปิด MFA ให้บัญชี และผู้ดูแลระบบควรบังคับ MFA สำหรับ SSO ขององค์กร
- อย่าเปลี่ยนไปใช้ key ส่วนตัวเพื่อเลี่ยงข้อจำกัดขององค์กร ให้ตรวจเวิร์กสเปซและนโยบายแบบจัดการก่อน

## ลงชื่อเข้าใช้สำเร็จแต่ยังใช้งานไม่ได้

ตรวจตามลำดับนี้:

1. ใช้บัญชีหรือ API organization ที่ถูกต้องหรือไม่
2. เข้าเวิร์กสเปซ ChatGPT ที่ถูกต้องหรือไม่
3. ความสามารถเป้าหมายต้องใช้การลงชื่อเข้าใช้ด้วย ChatGPT แทน API key หรือไม่
4. แพ็กเกจ ที่นั่ง บทบาท หรือนโยบายผู้ดูแลระบบจำกัดการเข้าถึงหรือไม่
5. จากนั้นจึงตรวจแคชไคลเอนต์ เครือข่าย และเวอร์ชัน

CLI มี log เฉพาะสำหรับการลงชื่อเข้าใช้ ซึ่งใช้ได้เมื่อต้องขอความช่วยเหลือทางการหรือแก้ปัญหาการเข้าสู่ระบบ แต่ต้องตรวจข้อมูลละเอียดอ่อนใน log ก่อนเสมอ
