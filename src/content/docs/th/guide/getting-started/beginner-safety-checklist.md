ก่อนใช้ครั้งแรก ลองถามตัวเองว่า “ถ้ามันทำผิด ฉันจะเสียหายมากเกินไปหรือไม่”

เช็กลิสต์นี้ช่วยลดความเสี่ยงของการใช้งานครั้งแรก

ตรวจให้ครบก่อนเริ่ม:

- [ ] ฉันใช้ไดเรกทอรีฝึกที่ทิ้งได้ ไม่ใช่รีโพซิทอรีโปรดักชัน
- [ ] ในไดเรกทอรีไม่มีคีย์จริง รหัสผ่าน หรือข้อมูลส่วนตัวของลูกค้า
- [ ] ฉันเข้าใจว่าการดำเนินการความเสี่ยงสูงต้องได้รับอนุมัติจากฉัน
- [ ] ฉันจะไม่อนุมัติคำสั่งหรือคำขอออกเครือข่ายที่อ่านไม่เข้าใจ
- [ ] ฉันจะตรวจ diff ก่อนยอมรับผลลัพธ์
- [ ] ฉันรู้วิธี [เลิกทำ](/th/guide/getting-started/undo-and-recover/)

## ความเข้าใจผิดที่พบบ่อย

### 1. เช็กลิสต์ความปลอดภัยมีไว้สำหรับคนที่ระวังมากเป็นพิเศษเท่านั้น

เช็กลิสต์นี้ทำมาเพื่อผู้ใช้ครั้งแรกโดยเฉพาะ เพราะครั้งแรกเรามักประเมินสูงเกินไปว่าตัวเอง “ควรเข้าใจทุกอย่าง”

### 2. แค่ไม่กดคำสั่งอันตรายก็ปลอดภัยพอแล้ว

ปัญหาที่พบบ่อยกว่าในการใช้ครั้งแรกคือ:

- ใช้ผิดโปรเจกต์
- มีไฟล์ละเอียดอ่อนติดมาด้วย
- ไม่ตรวจ diff
- ไม่ได้คิดว่าจะย้อนกลับอย่างไร

### 3. เรียนไประหว่างใช้ก็ได้ ไม่ต้องตรวจเรื่องเหล่านี้ล่วงหน้า

คุณเรียนไประหว่างใช้ได้ แต่ตรวจรายการเหล่านี้สักรอบก่อนเริ่มจะปลอดภัยกว่า

ก่อนใช้ Codex ครั้งแรก ให้ลดต้นทุนของความผิดพลาดไว้ก่อน แล้วขั้นต่อไปจะง่ายขึ้นมาก
