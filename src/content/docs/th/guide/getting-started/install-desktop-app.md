“เดสก์ท็อป App” ในคู่มือนี้หมายถึง **เวิร์กสเปซ Codex ภายในเดสก์ท็อป App ของ ChatGPT** ซึ่งมีเวอร์ชันทางการสำหรับ macOS, Windows และ Linux

## ขั้นตอนติดตั้ง

1. เปิด [คำแนะนำทางการของเดสก์ท็อป App ของ ChatGPT](https://learn.chatgpt.com/docs/app)
2. ดาวน์โหลดแพ็กเกจติดตั้งที่ตรงกับระบบปฏิบัติการจากช่องทางทางการ
3. ติดตั้งและเปิด ChatGPT แล้วลงชื่อเข้าใช้ด้วยบัญชี ChatGPT หรือวิธีอื่นที่รองรับ
4. สร้างแชตหรือโปรเจกต์ใหม่ หรือเปิดโฟลเดอร์ฝึก
5. เข้า Codex สร้างงานใหม่ และอธิบายผลลัพธ์ที่ต้องการ

อย่าดาวน์โหลดแพ็กเกจติดตั้งจากเว็บไซต์บุคคลที่สามในผลการค้นหา หากอุปกรณ์บริษัทติดตั้งโดยผู้ดูแลระบบ ให้ปฏิบัติตามนโยบายแจกจ่ายและอัปเดตซอฟต์แวร์ขององค์กร

## ตรวจขั้นต่ำหนึ่งครั้งหลังติดตั้ง

เตรียมไดเรกทอรีฝึกที่ไม่มีคีย์ แล้วตรวจว่า:

- App เปิดได้ตามปกติและแสดงบัญชีหรือเวิร์กสเปซปัจจุบัน
- เปิดไดเรกทอรีนั้นหรือเพิ่มไฟล์ลงในโปรเจกต์ได้
- สร้างงาน Codex และได้รับคำตอบ
- สิทธิ์เข้าถึงไฟล์ครอบคลุมเฉพาะขอบเขตที่งานนี้ต้องใช้
- หาผลลัพธ์งาน การเปลี่ยนแปลงไฟล์ และจุดอนุมัติได้

ใช้คำสั่งแบบอ่านอย่างเดียวนี้เป็น smoke test ได้:

```text
อ่านไดเรกทอรีนี้อย่างเดียว ห้ามแก้ไฟล์ บอกว่ามีไฟล์อะไรบ้าง น่าจะเป็นโปรเจกต์ประเภทใด และคุณอ้างอิงจากชื่อไฟล์ใด
```

## ปัญหาที่พบบ่อย

### เปิด App ได้ แต่ไม่เห็น Codex

ยืนยันบัญชี เวิร์กสเปซ และสิทธิ์เข้าถึงตามแพ็กเกจก่อน แล้วตรวจว่าองค์กรปิดความสามารถนี้ไว้หรือไม่ อย่าติดตั้งซ้ำไปมาเพื่อเลี่ยงนโยบายบัญชีหรือผู้ดูแลระบบ

### ระบบขอสิทธิ์ไฟล์ การช่วยการเข้าถึง หรือการควบคุมแอป

ตรวจว่างานปัจจุบันจำเป็นต้องใช้จริงหรือไม่ หากเพียงเปิดไดเรกทอรีฝึก ไม่ต้องอนุญาตดิสก์หรือความสามารถระบบที่ไม่เกี่ยวข้อง ดูวิธีตัดสินใจที่ [สิทธิ์และแซนด์บ็อกซ์](/th/guide/permissions-and-sandbox/)

### UI หลังติดตั้งไม่เหมือนภาพหน้าจอ

เดสก์ท็อป App อัปเดตเร็ว ให้ถือว่า “ลงชื่อเข้าใช้ได้ เลือกตำแหน่งทำงานได้ เริ่มงานได้ และตรวจผลลัพธ์ได้” คือเกณฑ์สำเร็จ อย่ายึดตำแหน่งปุ่มใดปุ่มหนึ่ง

ดูรายละเอียด UI ที่ [การติดตั้งและ UI](/th/guide/desktop-app/installation-and-interface/) หากล้มเหลวดู [การแก้ปัญหาเดสก์ท็อป App](/th/guide/desktop-app/troubleshooting/)
