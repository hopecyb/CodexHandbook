Codex CLI เหมาะกับการทำงานสำรวจ แก้ไข ทดสอบ และตรวจทานทั้งหมดในเทอร์มินัล หน้าติดตั้งทางการมีตัวเลือก macOS/Linux, Windows, npm และ Homebrew ให้เลือกวิธีที่ตรงกับระบบและตัวจัดการซอฟต์แวร์ของคุณ

## ตัวติดตั้งเดี่ยวทางการสำหรับ macOS / Linux

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

เมื่อต้องการอัปเดต CLI ให้เรียกคำสั่งติดตั้งทางการเดิมอีกครั้ง ผู้ใช้ Windows, npm หรือ Homebrew ควรเลือกแท็บติดตั้งที่ตรงกันใน [หน้าทางการของ Codex CLI](https://learn.chatgpt.com/docs/codex/cli) อย่านำคำสั่ง macOS/Linux ไปใช้กับทุกระบบโดยตรง

## ตรวจหลังติดตั้ง

เปิดหน้าต่างเทอร์มินัลใหม่ แล้วเรียกคำสั่งต่อไปนี้ในรีโพซิทอรีฝึก:

```bash
codex --version
codex login status
```

หากยังไม่ได้ลงชื่อเข้าใช้:

```bash
codex login
```

หลังอนุญาตผ่านเบราว์เซอร์แล้ว ให้เริ่มเซสชันแบบโต้ตอบในไดเรกทอรีรีโพซิทอรี:

```bash
codex
```

งานแรกควรเป็นแบบอ่านอย่างเดียว:

```text
ยังไม่ต้องแก้ไฟล์ อธิบายวิธีติดตั้ง ทดสอบ และ build โปรเจกต์นี้ พร้อมระบุพาธของไฟล์ที่คุณอ่าน
```

## หากเกิดข้อผิดพลาด ให้ตรวจตามลำดับ

1. `codex --version` หาไม่พบ: เปิดเทอร์มินัลใหม่ แล้วตรวจ `PATH` ของ shell ปัจจุบัน
2. เรียกคำสั่งได้แต่ใช้งานไม่ได้: เรียก `codex login status` เพื่อแยกปัญหาการติดตั้งออกจากปัญหาการยืนยันตัวตน
3. ใช้ข้อมูลประจำตัวผิด: เรียก `codex logout` แล้วลงชื่อเข้าใช้อีกครั้ง
4. ถูกปฏิเสธในสภาพแวดล้อมบริษัท: ตรวจเวิร์กสเปซ วิธีลงชื่อเข้าใช้ หรือการกำหนดค่าแบบจัดการ อย่าใช้ข้อมูลประจำตัวส่วนตัวเพื่อเลี่ยงนโยบาย

อย่าวาง API key ลงในประวัติ shell ทิกเก็ต หรือแชต เมื่อต้องลงชื่อเข้าใช้ด้วย API key ให้ส่งผ่านอินพุตมาตรฐานตาม [การลงชื่อเข้าใช้และการยืนยันตัวตน](/th/guide/getting-started/sign-in-and-authentication/)
