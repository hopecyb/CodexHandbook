ปัจจุบัน Codex เข้าสู่เอดิเตอร์หลักด้วยวิธีต่างกัน: ตระกูล VS Code ใช้ส่วนขยาย Codex ส่วน Xcode และ JetBrains IDE ใช้ช่องทางผสานของตนเอง

## วิธีที่รองรับในปัจจุบัน

| เอดิเตอร์ | ช่องทาง Codex | วิธีเปิด |
|---|---|---|
| Visual Studio Code | ส่วนขยาย Codex | ไอคอน Codex หรือ `Codex: Open Codex Sidebar` |
| Cursor | ส่วนขยายที่เข้ากันได้กับ Codex | ไอคอน Codex หรือ Command Palette |
| Windsurf | ส่วนขยายที่เข้ากันได้กับ Codex | ไอคอน Codex หรือ Command Palette |
| Visual Studio Code Insiders | ส่วนขยาย Codex | แผงส่วนขยายและแถบด้านข้าง Codex |
| Xcode | การผสานกับ Xcode coding assistant | สร้างแชตใหม่แล้วเลือก Codex Agent |
| JetBrains IDEs | การผสานกับ JetBrains AI Chat | เปิด AI Chat แล้วเลือก Codex |

ช่องทางติดตั้งและเวอร์ชันขั้นต่ำอาจเปลี่ยนแปลง ให้เข้าผ่าน [หน้า Codex IDE ทางการ](https://learn.chatgpt.com/docs/codex/ide) เสมอ อย่าตัดสินว่าเป็นทางการเพียงเพราะส่วนขยายบุคคลที่สามมีชื่อคล้ายกัน

## ช่องทาง IDE เหมาะกับอะไรที่สุด

- เพิ่มไฟล์ที่เปิดอยู่หรือส่วนที่เลือกลงในคำถามโดยตรง
- อธิบาย แก้ไข และติดตามโค้ดเฉพาะจุด
- ตรวจสรุปและการเปลี่ยนแปลงข้างซอร์สโค้ด
- เก็บงานเล็กไว้ในเครื่อง แล้วมอบหมายไปยังเวิร์กโฟลว์ที่ยาวกว่าเมื่องานใหญ่ขึ้น

ตัวอย่าง:

```text
ตรวจลูป retry ในส่วนที่เลือกอยู่
อธิบายเงื่อนไขสิ้นสุดก่อน แล้วจึงแก้ให้น้อยที่สุด; แก้เฉพาะไฟล์ปัจจุบันและการทดสอบที่เกี่ยวข้อง
เมื่อเสร็จให้รายงาน diff กับคำสั่งทดสอบ และห้ามอัปเกรด dependency
```

## ทำให้ทีมที่ใช้หลายเอดิเตอร์สอดคล้องกันอย่างไร

1. เขียนคำสั่ง build ทดสอบ และฟอร์แมตไว้ใน `AGENTS.md` ของรีโพซิทอรีหรือเอกสารการมีส่วนร่วม
2. กำหนดขอบเขตไฟล์ในพรอมต์ อย่าพึ่งปุ่มเฉพาะของ IDE ใด
3. การยอมรับขั้นสุดท้ายให้ดู Git diff กับชุดการทดสอบเดียวกัน ไม่ใช่ “รันได้ใน IDE ของฉัน”
4. แยกคำแนะนำตาม IDE เฉพาะเมื่อต้องชี้ UI อย่างแม่นยำ

## เอดิเตอร์ที่ไม่อยู่ในรายการ

เลือกใช้ [Codex CLI](/th/guide/cli/) หรือ [เดสก์ท็อป App](/th/guide/desktop-app/) ก่อน อย่าฝืนติดตั้งแพ็กเกจส่วนขยาย VS Code ในเอดิเตอร์ที่ไม่เข้ากัน และอย่าถือว่าการผสานบุคคลที่สามเป็นความสามารถทางการของ OpenAI โดยอัตโนมัติ

ดูขั้นตอนติดตั้งที่ [ติดตั้งการผสานกับ IDE](/th/guide/getting-started/install-ide-extension/) และวิธีใช้บริบทที่ [บริบทของเอดิเตอร์](/th/guide/ide/editor-context/)
