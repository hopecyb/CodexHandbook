ส่วนขยาย IDE เหมาะกับการ **เขียนไปดู diff ไป**: เปิดไฟล์ เลือกโค้ด แล้วอธิบายงานในแถบด้านข้าง บทนี้ครอบคลุมเส้นทางทั้งหมดตั้งแต่การเลือกเครื่องมือจนถึงการตรวจทาน

หากปกติคุณเขียนโค้ดหรือแก้เอกสารในเอดิเตอร์ IDE มักเป็นช่องทางที่เป็นธรรมชาติที่สุด

Codex จะนำไฟล์ที่เปิดอยู่และส่วนที่เลือกมาเป็นบริบทโดยตรง จึงควบคุมขอบเขตงาน “แก้เฉพาะจุด” ได้ง่ายกว่า

## เรื่องที่ควรสังเกตก่อน

เมื่อใช้ครั้งแรก ให้สังเกตสามเรื่องนี้:

1. Codex จะอ้างอิงไฟล์ที่คุณเปิดอยู่
2. คุณใช้ส่วนที่เลือกเพื่อกำหนดขอบเขตได้แม่นขึ้น
3. หลังแก้เสร็จ คุณยังต้องตรวจ diff ด้วยตัวเอง

ส่วนขยาย IDE เหมาะกับงาน “ขอบเขตเล็ก ดูไปแก้ไป” แต่ยังต้องควบคุมขอบเขตและตรวจทานเสมอ
