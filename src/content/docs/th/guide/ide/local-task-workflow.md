งานในเครื่องของ IDE เป็นวงจร “**เปิด → เลือก → อธิบาย → ตรวจทาน → ทดสอบ**” เหมาะกับการแก้ทีละน้อยอย่างถี่ ๆ หน้านี้ให้เส้นทางปฏิบัติที่พบบ่อยที่สุด ดูรายละเอียดบริบทที่ [ส่วนที่เลือกและไฟล์ที่เปิดอยู่](/th/guide/ide/selected-code-and-open-files/)

## เวิร์กโฟลว์ที่แนะนำ

1. **เปิดรากเวิร์กสเปซ** ของทั้งรีโพซิทอรี ไม่ใช่ไฟล์เดียว
2. เปิดไฟล์ที่เกี่ยวข้อง และ [เลือกส่วนโค้ด](/th/guide/ide/selected-code-and-open-files/) เมื่อจำเป็น
3. ระบุในแผง Codex ให้ชัด: เป้าหมาย ข้อจำกัด และ [นิยามของคำว่าเสร็จ](/th/prompts/define-done/)
4. หากงานซับซ้อน ให้ [ขอแผน](/th/prompts/ask-for-a-plan/) ก่อนดำเนินการ
5. [ตรวจการเปลี่ยนแปลง](/th/guide/ide/reviewing-changes/) ในมุมมอง diff / inline
6. เรียกคำสั่งทดสอบของโปรเจกต์ในเทอร์มินัล IDE
7. คุณเป็นผู้ `git commit` เอง เว้นแต่ทีมอนุญาตให้ Agent commit อย่างชัดเจน

## ตัวอย่าง prompt

```text
แก้เฉพาะ src/auth/login.ts และการทดสอบที่เกี่ยวข้อง
เป้าหมาย: แก้ข้อผิดพลาด 500 เมื่อส่งอีเมลว่าง ให้เป็น 400 พร้อมข้อความผิดพลาด
ห้าม: แก้ package-lock, git push
เสร็จเมื่อ: เรียก npm test -- auth และแสดงสรุปการเปลี่ยนแปลง
```

## เมื่อใดควรเปลี่ยนไปใช้ช่องทางอื่น

| สถานการณ์ | คำแนะนำ |
|---|---|
| หลายงานพร้อมกันและหลาย worktree | [เดสก์ท็อป App](/th/guide/desktop-app/) |
| สคริปต์ / CI | [CLI แบบไม่โต้ตอบ](/th/guide/cli/non-interactive-mode/) |
| สภาพแวดล้อมมาตรฐานระยะไกลและเปิด PR | [งานบนคลาวด์จาก IDE](/th/guide/ide/cloud-task-workflow/) |

## ข้อผิดพลาดที่พบบ่อย

- ไม่เปิดเวิร์กสเปซ ทำให้อ่าน `AGENTS.md` ไม่ได้
- ยอมรับคำแนะนำ inline ทั้งหมดด้วยคลิกเดียว
- commit โดยยังไม่เรียกการทดสอบ

## คำถามที่พบบ่อย

### 1. ทำไมจึงย้ำให้ “เปิดรากเวิร์กสเปซ” เสมอ

เพราะบริบทจำนวนมากของส่วนขยาย IDE ขึ้นอยู่กับการเปิดทั้งโปรเจกต์ ไม่ใช่ไฟล์เดี่ยว

### 2. แก้ใน IDE สะดวกแล้ว ลดการตรวจทานได้หรือไม่

ไม่ได้

ยิ่งสะดวกก็ยิ่งเผลอกดยอมรับได้ง่าย จึงต้องรักษานิสัยตรวจเสมอ

### 3. งานแบบใดเหมาะกับครั้งแรก

งานลักษณะนี้เหมาะกว่า:

- แก้เพียง 1–2 ไฟล์
- เห็นผลแล้วเข้าใจได้ทันที
- ทดสอบหรือดูตัวอย่างหลังแก้ได้ง่าย

งานในเครื่องของ IDE เหมาะกับการเดินหน้าเร็วทีละก้าว แต่ “สะดวก” ไม่ได้แปลว่าข้ามการตรวจทานและการตรวจสอบได้
