การแก้ปัญหา IDE ต่างจาก CLI อย่างหนึ่ง:  
หลายปัญหาดูเหมือน “ปลั๊กอินไม่ทำงาน” แต่สาเหตุจริงมักเป็น **เวิร์กสเปซ สถานะลงชื่อเข้าใช้ หรือบริบทของเอดิเตอร์เอง** ไม่ถูกต้อง

เมื่อ IDE มีปัญหา ให้แยกก่อนว่า “ส่วนขยายไม่เริ่ม” หรือ “ส่วนขยายเริ่มแล้ว แต่ได้บริบทผิด”

| อาการ | ลองก่อน |
|---|---|
| ส่วนขยายไม่ตอบสนอง | อัปเดตส่วนขยายและเอดิเตอร์; ดู log ของ extension host |
| สถานะลงชื่อเข้าใช้หาย | ยืนยันตัวตนใหม่ |
| บริบทไม่ถูกต้อง | ยืนยันรากเวิร์กสเปซที่เปิดอยู่ |

## แยกเป็น 3 ประเภทก่อน

- **ไม่ตอบสนองเลย**: ส่วนใหญ่มาจากปัญหาการโหลดส่วนขยาย
- **เปิดได้แต่ใช้ไม่ได้**: ส่วนใหญ่มาจากปัญหาลงชื่อเข้าใช้หรือยืนยันตัวตน
- **ตอบผิดหรือแก้ผิดจุด**: ส่วนใหญ่มาจากปัญหาเวิร์กสเปซหรือบริบท

## ความเข้าใจผิดที่พบบ่อย

### 1. ไอคอนปลั๊กอินยังอยู่ แสดงว่าส่วนขยายไม่มีปัญหา

ไอคอนที่อยู่บอกได้เพียงว่าติดตั้งแล้ว ไม่ได้แปลว่าเซสชันปัจจุบันทำงานตามปกติ

### 2. บริบทผิดแปลว่าโมเดลเข้าใจไม่ดี

หลายครั้งไม่ใช่ปัญหาความเข้าใจ แต่เป็นเพราะเปิดรากไดเรกทอรีผิด เลือกขอบเขตไฟล์ผิด หรือใช้เวิร์กสเปซผิด

### 3. ติดตั้งปลั๊กอินใหม่ต้องเป็นขั้นแรกเสมอหรือไม่

ไม่ต้องเริ่มแบบนั้น

ยืนยันสิ่งเหล่านี้ก่อน:

- เวอร์ชันเอดิเตอร์
- เวอร์ชันส่วนขยาย
- สถานะลงชื่อเข้าใช้
- เวิร์กสเปซปัจจุบัน

หลายปัญหาระบุสาเหตุได้ในขั้นนี้

## ลำดับการตรวจ

1. ดูว่าส่วนขยายตอบสนองหรือไม่
2. ยืนยันสถานะลงชื่อเข้าใช้
3. ยืนยันรากเวิร์กสเปซและไฟล์ที่เปิดอยู่
4. หากยังไม่ได้ จึงดู log ของส่วนขยาย

ต้นเหตุที่พบบ่อยที่สุดของปัญหา IDE คือเวิร์กสเปซ สถานะลงชื่อเข้าใช้ หรือแหล่งบริบทผิด ไม่จำเป็นว่าปลั๊กอินเสียจริง
