หลักการหลายอย่างดูเหมือนเข้าใจง่ายเมื่ออ่านแยกกัน แต่พอจะนำมาใช้กับ repository ของตัวเองกลับไม่รู้ว่าควรเริ่มตรงไหน

ชุดนี้มีไว้ให้คุณเห็นว่า “คนอื่นเขียนกันอย่างไร” เพื่อช่วยเปลี่ยนกฎเชิงนามธรรมให้เป็นแนวทางการเขียนที่นำไปใช้ได้จริงยิ่งขึ้น

## ทางเข้าของชุดนี้

- [AGENTS.md ใน Monorepo](/th/guide/customization/examples/monorepo-agents-md/)

## ควรอ่านชุดนี้เมื่อใด

- คุณเข้าใจแล้วว่า AGENTS.md คืออะไร แต่ยังไม่รู้ว่าจะเริ่มเขียนอย่างไร
- คุณรู้ว่าต้องกำหนดกฎ แต่ยังไม่แน่ใจว่าจะเขียนลำดับชั้นของไดเรกทอรีและขอบเขตการมีผลอย่างไร
- คุณอยากดูตัวอย่างจริงก่อน แล้วค่อยปรับให้เป็นเวอร์ชันสำหรับโปรเจกต์ของตัวเอง

หน้าตัวอย่างเหมาะสำหรับใช้อ้างอิงแนวคิด ไม่ควรคัดลอกไปใช้ทั้งชุดโดยไม่ปรับแก้
