หมวดกฎนี้มักทำให้ผู้เริ่มต้นเข้าใจผิดได้ง่ายที่สุดว่าเป็นเพียง “การเขียนคำเตือนให้ Codex เพิ่มอีกเล็กน้อย”

ความเข้าใจที่แม่นยำกว่าคือ กฎมีไว้แก้โจทย์ว่า “การกระทำใดอนุญาตโดยค่าเริ่มต้น การกระทำใดต้องบล็อก และการกระทำใดต้องใช้มาตรฐานเดียวกันทั้งทีม”

## หัวข้อชุดนี้ช่วยแก้ปัญหาอะไร

- การกระทำใดควรถูกหยุดทันที
- ข้อจำกัดใดเหมาะจะเขียนเป็นกฎที่ชัดเจน แทนการเตือนกันด้วยวาจา
- จะทำให้ทุกคนในทีมใช้ขอบเขตชุดเดียวกันเมื่อต้องรับมือกับความเสี่ยงประเภทเดียวกันได้อย่างไร

กฎมีไว้กำหนดขอบเขตให้เด็ดขาด และให้ระบบบังคับใช้ตามขอบเขตนั้น
