เมื่อเห็นหมวด “การตั้งค่า” เป็นครั้งแรก คุณอาจคิดได้ง่ายว่าหมวดนี้มีไว้พูดถึงชื่อพารามิเตอร์จำนวนมากเท่านั้น

แต่สิ่งสำคัญที่หมวดนี้ต้องการแก้มีเพียงเรื่องเดียว: กำหนดให้ Codex ทำงานแบบใดเป็นค่าเริ่มต้น เพื่อไม่ต้องบอกซ้ำใหม่ทุกครั้ง

## ลำดับที่แนะนำ

1. [พื้นฐานการตั้งค่า](/th/guide/customization/configuration/config-basics/)
2. [Profiles](/th/guide/customization/configuration/profiles/)

## หมวดนี้แก้ปัญหาอะไร

- ความชอบใดเหมาะจะเขียนไว้ในไฟล์การตั้งค่า
- เมื่อใดควรแยกเป็นหลาย Profile
- เหตุใดข้อจำกัดบางอย่างควรให้กฎหรือการอนุมัติเป็นผู้ควบคุม แทนที่จะพึ่งเพียงหมายเหตุในการตั้งค่า

การตั้งค่าเหมาะสำหรับพฤติกรรมเริ่มต้นและความชอบที่เสถียร ไม่เหมาะใช้แทนการอนุมัติ กฎ และคำอธิบายโปรเจกต์
