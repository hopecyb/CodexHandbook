Agent ใช้ **เครื่องมือ** เพื่ออ่านไฟล์ รันคำสั่ง ค้นเว็บ และเปิดเบราว์เซอร์ การเลือกเครื่องมือให้เหมาะและระบุขอบเขตชัดช่วยลดการเชื่อมต่อภายนอกหรือแก้ไขเกินจำเป็น

“เครื่องมือ” ในที่นี้หมายถึงความสามารถที่ Codex เรียกใช้เมื่อลงมือทำงานจริง ไม่ใช่ทุกงานจะเสร็จด้วยบทสนทนาเพียงอย่างเดียว บางงานต้องอ่านไฟล์ บางงานต้องรันคำสั่ง บางงานต้องค้นเว็บ และบางงานต้องดูหน้าจริง

![ภาพประกอบ: ชุดเครื่องมือวางเรียงบนโต๊ะ—เทอร์มินัล เบราว์เซอร์ แว่นขยายค้นหา ภาพ ไมโครโฟน และตัวชี้เมาส์ โดยผู้ช่วยตัวเล็กกำลังเลือกชิ้นที่เหมาะ](/illustrations/tools-overview.webp)

## ทำไมควรรู้จักเครื่องมือก่อน

ตอนเริ่มใช้ มักมอง Codex เป็นผู้ช่วยสนทนาเท่านั้น แต่เมื่อคุณอนุญาต มันอาจ:

- อ่านไฟล์โปรเจกต์
- แก้เอกสารหรือโค้ด
- รันคำสั่งเทอร์มินัล
- ค้นหน้าเว็บสาธารณะ
- เปิดหน้าในเครื่องเพื่อตรวจผล

เครื่องมือไม่ใช่ความรู้เสริม แต่เป็นพื้นฐานด้านความปลอดภัยและประสิทธิภาพ

## ลำดับการอ่านที่แนะนำ

หากอ่านบทนี้ครั้งแรก ให้เรียงดังนี้:

1. [การเลือกเครื่องมือ](/th/guide/tools/tool-selection/) เพื่อดูก่อนว่างานต่าง ๆ ควรใช้เครื่องมือใด
2. [Shell และเทอร์มินัล](/th/guide/tools/shell-and-terminal/) เพื่อเข้าใจความเสี่ยงจากการรันคำสั่ง
3. อ่านหน้า Search เบราว์เซอร์ หรือเครื่องมืออื่นตามงานปัจจุบัน

เครื่องมือกำหนดว่า Codex ลงมือได้อย่างไร ส่วนคุณต้องระบุว่าเครื่องมือใดใช้ได้และเครื่องมือใดห้ามใช้
