หากเริ่มอ่านกลุ่มความปลอดภัยจากหน้ารายละเอียดทันที คุณอาจจำได้เพียงคำศัพท์กระจัดกระจาย แต่ไม่รู้ว่ามาตรการเหล่านั้นป้องกันอะไร

อ่านตามลำดับ “ความเสี่ยงมาจากไหน แล้วควรกั้นหรือทบทวนที่ชั้นใด” จะเข้าใจชัดกว่า

## ลำดับที่แนะนำ

1. [โมเดลภัยคุกคาม](/th/guide/team-enterprise/security/threat-model/)
2. [ความเสี่ยงของ Plugin และ MCP](/th/guide/team-enterprise/security/plugin-and-mcp-risk/)
3. [Prompt injection](/th/guide/team-enterprise/security/prompt-injection/)

## ใครควรอ่านก่อน

- ทีมกำลังเตรียมขยายขอบเขตการใช้งาน
- คุณเริ่มเชื่อมส่วนขยายของบุคคลที่สาม เครื่องมือภายนอก หรือกฎที่ใช้ร่วมกัน
- คุณต้องการรู้ว่าความเสี่ยงใดแก้ไม่ได้ด้วยการ “เตือนทุกคนให้ระวัง” เพียงอย่างเดียว

จุดสำคัญของหน้าความปลอดภัยคือช่วยระบุว่าความเสี่ยงใดต้องควบคุมด้วยขอบเขตของระบบ
