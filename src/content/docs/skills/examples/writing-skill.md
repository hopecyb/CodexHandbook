# 示例：写作 Skill

## SKILL.md 骨架

```md
---
name: article-writer
description: 按大纲撰写技术文章，含研究、成稿与润色。在用户要写博客、教程、公众号文章时使用。
---

## 流程
1. 确认受众、长度、语气与禁止项
2. 若缺资料，先列提纲并标待补充点
3. 按节撰写，每节后暂停等我确认方向
4. 全文完成后做事实与链接检查
5. 输出最终稿到指定路径

## 禁止
- 不要编造引用或数据
- 不要未经批准发布到外部平台
```
