# 示例：研究 Skill

## SKILL.md 骨架

```md
---
name: source-backed-research
description: 做带 URL/文件路径引用的技术调研与对比表。在用户要做选型、竞品分析、文献综述时使用。
---

## 流程
1. 明确研究问题与排除项
2. 列出评估维度（3–5 项）
3. 每个结论附来源；无法核验标「待确认」
4. 输出对比表 + 推荐 + 开放问题
5. 不要改代码
```
