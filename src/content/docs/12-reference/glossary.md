---
title: 术语表
description: 手册常用术语的短定义。
---


| 术语 | 定义 |
|---|---|
| Agent | 围绕目标调用工具并迭代推进的执行方式 |
| 审批 | 高风险操作前的人工确认 |
| 差异 / diff | 变更前后的对比视图 |
| Cloud 任务 | 在云端环境执行的任务 |
| 上下文 | 模型当前可利用的信息集合 |
| 压缩 | 长上下文被摘要以节省窗口的过程 |
| Hook | 在生命周期节点运行的自定义逻辑（进阶） |
| MCP | 连接外部工具与数据的协议（进阶） |
| 提示词 | 给 Agent 的目标与要求文本 |
| 沙箱 | 限制影响范围的执行隔离 |
| Skill | 可复用的专项说明与资源包（进阶） |
| 线程 | 连续对话及其累积上下文 |
| Token | 模型处理文本的计量单位 |
| 工作树 | 隔离的工作目录，用于并行试验 |
