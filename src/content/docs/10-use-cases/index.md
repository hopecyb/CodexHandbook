案例库回答：「**在这种真实目标下，完整走一遍 Codex 是什么体验？**」与单篇产品说明互补。

## 案例 vs 教程

| | 入门教程 | 案例库 |
|---|---|---|
| 目标 | 学会某个按钮/概念 | 交付某类真实成果 |
| 结构 | 按产品功能 | 按任务类型 |
| 失败处理 | 常省略 | 必须包含 |

## 如何使用

1. 选与你目标最接近的案例（或只用其「准备清单」）
2. 对照 [探索—计划—执行—验证](/09-workflows/explore-plan-execute-verify/)
3. 完成后用 [案例模板](/10-use-cases/case-study-template/) 复盘，决定是否沉淀为 Skill

## 贡献方向

- 可复现步骤（仓库、分支、命令）
- 标注适用客户端与核验日期
- 不写无法验证的「一次成功」叙事
