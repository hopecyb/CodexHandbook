# 理解模板

很多任务卡住，是因为还没建立起最基本的共同理解。

理解模板适合用在“先搞懂，再决定下一步”的任务里。

## 模板

```text
目标：理解【主题/模块/代码库区域】，为后续【实现/修改/评审】做准备。
背景：【项目类型、技术栈、相关 issue】
输入：【@文件路径、文档链接、截图】
约束：只读分析，不要修改任何文件；不要运行破坏性命令。
输出：
1. 用 5–8 条说明核心概念或模块职责
2. 标出与【目标】最相关的 3 个文件/目录及原因
3. 列出 3 个待确认问题
验收：我能根据输出决定下一步任务范围。
```

## 什么时候适合用这个模板

- 新接手代码库
- 看一块陌生模块
- 准备改之前，先摸清关联范围

## 常见误区

### 1. 理解任务不只是“让它总结一下”

还要让它指出：

- 哪几个文件最相关
- 还有哪些地方没搞清
- 下一步应该从哪下手

### 2. 理解阶段不是越详细越好

先把主线理清，比一下子把所有细节都挖完更重要。

理解模板的价值，就是帮你把下一步任务范围先收清楚。
