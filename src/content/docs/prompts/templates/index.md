# 提示词模板

以下模板覆盖常见任务类型。使用时请替换 `【】` 中的占位内容，并补充约束与验收标准。

| 模板 | 适用场景 |
|---|---|
| [理解](/prompts/templates/understand/) | 读代码库、文档或资料，先建立认知 |
| [创建](/prompts/templates/create/) | 从零实现功能、文稿或产物 |
| [修改](/prompts/templates/change/) | 在现有基础上迭代改动 |
| [诊断](/prompts/templates/diagnose/) | 定位问题根因，先不改代码 |
| [审查](/prompts/templates/review/) | 审查 diff、PR 或文档变更 |
| [研究](/prompts/templates/research/) | 带引用的调研与对比 |
| [自动化](/prompts/templates/automate/) | 重复任务、脚本与无人值守流程 |

写作原则见 [提示词基础](/prompts/basics/) 与 [任务结构](/prompts/task-anatomy/)。
