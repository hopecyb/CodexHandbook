# 研究模板

研究类任务和普通问答的差别，在于你要的不只是答案，还要答案从哪里来。

## 模板

```text
研究问题：【一句话】
评估维度：【列出 3–5 项】
约束：
- 每个结论附来源 URL 或 @仓库内路径
- 无法核验的标为「待确认」
- 不要改代码
输出：对比表 + 推荐 + 开放问题
```

## 什么时候适合用这个模板

- 做产品/方案对比
- 查最新能力、规则或差异
- 需要结论能回头复核

## 常见误区

### 1. 研究就是让它总结得像样一点

研究里更看重的是来源、边界和待确认项。

### 2. 没查到也要给一个确定答案

研究类任务里，明确标出“待确认”，比假装确定更有价值。

研究模板里有一条关键限制：每个关键结论都要能追到来源，不能只看格式是不是完整。
