# 诊断模板

## 模板

```text
现象：【错误信息、失败测试、用户报告】
背景：【最近变更、环境、复现步骤】
输入：@【日志/测试/相关代码】
约束：先不要改代码；列出 2–3 个可能根因及验证方法。
输出：
1. 最可能根因（附证据）
2. 建议的验证步骤（命令或检查点）
3. 若验证通过，修复计划草案（等我确认再执行）
```
