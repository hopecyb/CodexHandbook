手册中命令、权限、价格、产品功能会随版本变化。**核验**确保读者按文档操作时结果可预期。

## 本页内容

很多人第一次参与文档维护，会把“我看起来没发现问题”当成“已经核验过了”。

但对技术手册来说，这两件事差很多：

- 前者只是主观觉得像真的
- 后者意味着你已经拿当前版本、当前环境、当前步骤真正试过

这里要解决的是，怎么把“看起来对”升级成“有证据证明它现在还是对”。

## “核验”在检查什么

“核验技术内容”可以理解成：不只检查文字通不通顺，而是确认读者按它做，今天真的还能做出来。

这件事尤其重要，因为很多内容不是永远稳定的，比如：

- 命令会改
- 菜单位置会变
- 权限默认值会调整
- 产品能力和可用范围会更新

所以核验不是编辑洁癖，而是避免读者照着旧文档踩坑。

## 状态含义

| 状态 | 含义 |
|---|---|
| `planned` | 已规划，尚未编写 |
| `draft` | 编写中，尚未完整定稿 |
| `review` | 内容完成，待复核 |
| `verified` | 已按标注依据核验 |
| `outdated` | 产品变化后需更新 |
| `archived` | 历史保留，不进主导航 |

## 常见误会

### 编辑状态与验证方式是两个字段

`editorialStatus` 记录编写和复核进度。`verification.kind` 记录实际做过哪一种检查；读者不能由 `verified` 推断示例已经运行。

| 验证方式 | 可支持的结论 | 必填证据 |
|---|---|---|
| `editorial` | 结构、表述或站内引用已审阅 | 检查摘要和日期 |
| `source-checked` | 标明范围内的事实与来源一致 | 具体来源链接、摘要和日期 |
| `run-tested` | 示例在记录环境中运行过 | 环境、执行与复核记录、摘要和日期 |

`run-tested` 不保证所有平台通用。记录摘要必须说明验证了什么、没有验证什么；独立计算自检也不能称为第二位作者复核。没有证据的旧记录保存在 `legacyVerification`，不自动推导为任一种新验证状态。

```yaml
editorialStatus: review
verification:
  kind: editorial
  checkedAt: "2026-09-18"
  summary: 已检查结构与站内链接，示例尚未实跑。
```

来源核对和实跑使用 `evidence` 列表，每项包含 `label` 和 `href`。实跑另填 `environment`，明确系统、相关客户端版本和依赖版本。构建会拒绝缺少环境或证据链接的实跑记录。链接本身存在仍不等于证据充分，维护者必须阅读记录。

### 社区文章可以帮你理解，但不能替代事实核验

社区文章或其他社区资料，很适合帮助你发现应该补哪些主题。

但一旦涉及：

- 命令名
- 权限行为
- 产品入口
- 价格、配额、地区差异

还是要回到官方文档或当前实际运行结果。

### 核验不是只看单个句子

有时每一句单看都没问题，但连起来就不成立，比如：

- 适用产品和实际页面不一致
- 步骤顺序不对
- 默认前提没写出来
- 标题承诺的内容比正文实际验证范围更大

所以要按“整条操作链路”来验，而不是只扫字面。

## 核验清单

1. **标明范围**：产品（App/CLI/IDE/Cloud）、OS、CLI 版本号
2. **逐步复现**：从零或干净 worktree 跟做一遍
3. **官方依据**：产品事实附具体官方来源；稳定的方法练习使用实际输入和检查记录，不伪造官方背书
4. **社区来源**：若借鉴社区资料，只作主题参考，事实以官方为准
5. **更新日期**：`verification.checkedAt` 只写实际检查日期，不能批量刷新旧日期冒充复核
6. **独立复核**：`verified` 建议非作者第二人确认

## 核验顺序

按下面的顺序最容易不漏：

1. 先确认页面讲的是哪个产品、哪个入口、哪个场景
2. 再从头走一遍文中的步骤
3. 对照官方文档核实易变信息
4. 把不确定、没复现到的地方降级处理
5. 最后再更新状态和日期

宁可先保持 `review`，也不要在证据还不够时提前写成 `verified`。

## 易变信息

以下必须每季度或随 major 发布重核：

- 命令与子命令名、flags
- 权限默认与沙盒行为
- 套餐、模型名、地区可用性
- MCP/Hook 事件名

## 失败时

- 按实际情况降级为 `review`、`draft` 或 `outdated`
- 在 PR 中说明哪一步与官方不一致
- 大偏差开 issue 标 `outdated`
