# Codex 指南

这里帮助你理解 Codex 是什么、适合做什么，以及怎么从第一次使用逐步过渡到稳定工作流。

如果你是第一次打开这份手册，不必把它当成一本要从头读到尾的书。把它当成一张“从第一次上手，到逐步用顺”的路线图会更自然。

你不需要先懂完所有术语、产品和工作流。先找到你当前所在阶段，再按顺序往前走就行。

## 这一部分会讲什么

- 我第一次接触 Codex，应该看哪里
- 我该先选哪个客户端
- 我做完第一个任务后，下一步该补什么能力
- 出现权限、上下文、验证问题时该回哪一章

## 常见误会

### 1. 我应该把整份手册都读完，再开始用

对大多数人来说，更合适的节奏是：

- 先理解最基础的安全和协作方式
- 先跑通一个小任务
- 再带着真实问题回来补读

### 2. 这些章节看起来很多，说明我现在还不适合开始

章节多是为了让你后面有地方回查，不代表你一开始就要全部掌握。

### 3. 我只要选一个客户端，后面其他内容就都和我无关

客户端只是入口不同，很多核心概念像权限、上下文、验证，在各端都会反复出现。
