桌面 App 是初学者默认入口：可视化项目、任务、差异与审批。

对不熟命令行或 IDE 插件的人来说，这也是比较容易上手的入口。

它不只是“能聊天”，还把项目、改动、审批和验证放进了同一个可见界面。

## 本章内容

- 桌面 App 里优先该学会的几个动作是什么
- 哪些功能适合初学者先用，哪些可以以后再补
- 遇到改动、审批和排障时该看哪里

## 先认出这三件事

不用一口气学会所有功能。  
先认出这三类核心动作：

1. 在哪里输入任务
2. 在哪里看改动
3. 在哪里批准或拒绝操作

这三步走通后，就已经能完成一次基础任务闭环。

## 常见误会

### 1. 桌面 App 只是 CLI 的图形壳？

它会把协作过程中几个关键环节都摊开给你看：

- 当前任务
- 计划和工具调用
- 文件改动
- 审批动作
- 结果审查

### 2. 要把所有按钮都弄懂才能开始吗？

一开始先认得：

- 输入任务的位置
- 看 diff 的位置
- 批准/拒绝的位置

就够用了。

### 3. 桌面 App 适合新手，是不是就不适合正式工作？

很多正式工作同样可以在桌面 App 里完成，尤其是你很在意可视化审查和过程透明的时候。

## 上手顺序

第一次用桌面 App 时，可以按这个顺序：

1. 先装好并认界面
2. 选对项目
3. 开一个小任务
4. 看它的改动
5. 学会批准和拒绝
6. 最后再学并行 Agent、工作树、云端任务这些进阶能力

这样通常比一上来就研究所有功能更轻松。
