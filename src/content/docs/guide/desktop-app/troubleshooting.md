排障时，按最可能、最容易处理的顺序排查。

| 症状 | 先试 |
|---|---|
| 无法安装/打开 | 核对系统要求与官方安装包；重启后再试 |
| 无法登录 | 检查网络、账号权限、SSO；清会话后重登 |
| 看不到项目文件 | 确认已添加正确文件夹与系统文件权限 |
| 任务一直等待审批 | 回到任务视图处理待批准请求 |
| 改动不符合预期 | 收紧约束、新开线程、检查上下文 |

仍失败：[https://developers.openai.com/codex](https://developers.openai.com/codex) 与 [故障排查索引](/guide/reference/troubleshooting/)。

## 常见误会

### 1. 一出问题，是不是说明哪里用错得很严重？

很多问题只是：

- 路径没选对
- 权限没批
- 任务在等你确认
- 上下文已经聊乱了

### 2. “看不到文件”先该怀疑什么？

优先怀疑项目目录和权限，不用先怀疑模型能力。

### 3. “改动不符合预期”怎么救？

先把问题范围收窄：

- 重新说明范围
- 明确哪些地方不对
- 必要时新开线程

排障先排最常见、最容易修的原因，不必一开始就把问题想得太复杂。
