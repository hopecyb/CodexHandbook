安装步骤见 [安装桌面 App](/guide/getting-started/install-desktop-app/) 与 [https://developers.openai.com/codex](https://developers.openai.com/codex)。

刚打开桌面 App 时，界面里会同时出现不少信息。

不用一上来就把所有区域摸透，先认出最关键的几个位置就行。

## 界面区域（逻辑划分）

具体标签名随版本变化，请对照你屏幕上的实际文案：

1. **项目 / 工作区选择**：当前绑定的文件夹
2. **对话 / 任务区**：输入提示词、查看 Agent 进度
3. **变更 / 差异视图**：审查拟议改动
4. **终端或日志**（若启用）：查看命令输出
5. **设置与账户**：模型、权限、通知等

开始时先找到“在哪里输入任务”和“在哪里批准文件改动”。

## 常见误会

### 1. 一开始不用把所有面板都弄懂

先认出这三块就够：

- 在哪里输入任务
- 在哪里看改动
- 在哪里做批准或拒绝

### 2. 终端、差异、设置这些以后再学可以吗？

可以分阶段学。  
但差异视图最好尽早熟悉，因为它直接关系到你能不能看懂改动范围。

### 3. 如果界面和文档截图不完全一样怎么办？

以你当前版本的实际文案为准。  
这里说的是逻辑区域，不是具体按钮名字。

先把“输入任务”“看改动”“做批准”这三件事找到，后面边用边熟悉就行。
