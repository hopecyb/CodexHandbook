## 界面区域（逻辑划分）

具体标签名随版本变化，请对照你屏幕上的实际文案：

1. **项目 / 工作区选择**：当前绑定的文件夹
2. **对话 / 任务区**：输入提示词、查看 Agent 进度
3. **变更 / 差异视图**：审查拟议改动
4. **终端或日志**（若启用）：查看命令输出
5. **设置与账户**：模型、权限、通知等

第一次使用：先认出「把提示词打在哪里」和「在哪里批准文件改动」。
