IDE 扩展适合**边写边看 diff**：打开文件、选中代码、在侧边栏描述任务。本章覆盖从选型到审查的完整路径。

如果平时就在编辑器里写代码或改文档，IDE 往往就是最自然的入口。

它会直接带上你当前打开的文件和选区，所以很多“小范围修改”任务更容易收住范围。

## 先留意这几件事

第一次用时，可以留意这三件事：

1. 它会参考你当前打开的文件
2. 你可以用选区把范围卡得更准
3. 改完后仍然要自己审查 diff

IDE 扩展适合“小范围、边看边改”的任务，但范围控制和审查还是少不了。
