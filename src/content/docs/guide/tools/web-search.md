Web 搜索适合补事实，不适合替你直接下最终结论。

适合：查公开文档、错误码、版本说明。不适合：把搜索结果当最终法律/医疗结论。

要求附来源，并人工点开核对。与 [核验来源](/guide/quality/validate-sources/) 联用。

## 搜索适合做什么

搜索主要是帮你定位这些东西：

- 去哪里看
- 哪几条信息值得进一步核对
- 有没有更权威的来源

它的作用是把资料先找出来，后面再回到原文核对。

## 常见误会

### 1. 它能搜到结果，是不是就说明答案可靠？

不能这么看。搜到，不等于可信；摘要顺畅，也不等于准确。

### 2. 什么情况下适合用搜索？

常见的场景有：

- 查官方文档
- 查错误信息
- 查版本变化
- 查公开网页上的事实

### 3. 搜索结果里的摘要能不能直接引用？

先别直接引用。可以按下面的方式处理：

1. 先看搜索结果里有哪些来源
2. 再点开原页面
3. 用自己的话总结

### 4. 什么时候不要只靠搜索？

当问题是：

- 高风险法律/医疗/财务判断
- 你需要确认真实页面行为
- 你需要核对项目本地文件而不是公网资料

这时还要配合别的工具或人工核验。

## 搜索顺序

可以按这个顺序处理：

1. 先搜最接近问题的关键词
2. 优先找官方文档或一手来源
3. 点开原文确认细节
4. 再决定要不要把结论写进结果里

## 可直接使用的提示语

可以直接补一句：

```text
请先搜索并优先使用官方来源；给结论时附上可点击的来源链接，不要只给搜索摘要。
```

搜索给你线索和来源，最后还是要回到原文核对。
