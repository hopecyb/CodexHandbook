只要结论依赖外部事实，就不要只收结论，来源也要一起拿到。

要求 Agent：

```text
每个关键事实附上来源 URL 或文献；不确定的明确标注「未核验」。
```

拿到结果后，再点开链接核对。搜索能力见 [Web 搜索](/guide/tools/web-search/)。

## 常见误会

### 1. 表达自信，不等于来源可靠

表达流畅、自信，和事实是否可靠，原本就是两回事。

### 2. 每句话都要查来源吗？

但下面这些内容尤其值得要求来源：

- 关键事实
- 会影响判断的数字
- 时间、政策、产品差异
- 你准备拿去对外使用的说法

### 3. 给了链接，仍然要自己核对

至少点开确认这几件事：

- 链接是否真对应这条结论
- 是否是你信任的来源
- 是否已经过时

在研究类任务里，来源本身就是结论可信度的一部分。
