第一次装 CLI，很多人会卡在这些地方：

- 我到底有没有装成功
- 装完以后为什么终端还是不认识 `codex`
- 更新之后怎么确认自己现在跑的是哪个版本

CLI 安装完成，不是命令跑过一次就算，而是你当前终端能稳定找到它。

## 安装后至少检查这 3 件事

1. 命令能直接运行
2. 当前终端能在 `PATH` 里找到它
3. 认证已经完成，不是只装了可执行文件

## 常见误会

### 1. 安装脚本跑完就说明完成了

安装脚本跑完，只说明“安装步骤执行了”。  
接下来要看的是：你当前开的终端能不能认出这个命令。

### 2. 换个终端窗口就会自动好

有时会，有时不会。  
如果 `PATH` 没更新，换窗口也可能还是一样找不到。

### 3. 更新就是重新装一次

很多时候你更需要先确认：

- 现在这个版本是不是旧的
- 你到底在更新哪一份安装

## 可以按这个顺序检查

刚装完的话，可以这样查：

1. 先确认 `codex` 命令能否直接执行
2. 再确认当前 shell 的 `PATH` 是否包含安装位置
3. 然后完成登录或认证
4. 最后再确认版本信息

更实际的判断标准是：当前终端能找到它，而且你已经能完成认证。
