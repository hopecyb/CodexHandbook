## 常见误会

### 1. 功能多，不代表更适合先上手

先看你现在最需要哪种使用方式，不用一直盯着功能多少。

### 2. 不需要一开始就把四种入口都学会

先选一个能用起来的入口就行。

### 3. 按你现在的工作方式选

照平时的工作习惯选就行：

- 想要最直观、最好审查 -> 桌面 App
- 已经习惯终端 -> CLI
- 平时就一直在编辑器里工作 -> IDE
- 更偏远程仓库、长任务 -> Cloud

### 4. 入口没选准，后面还能调整

不用把这件事想得太重。  
先挑一个能开始用的入口，后面再换也来得及。

## 不知道怎么选时

如果一时拿不准，就先看这几件事：

1. 你最常在哪工作：桌面、终端、编辑器还是浏览器
2. 你现在最在意的是看得清楚，还是接脚本、接代码、接远程环境
3. 你是先学会用，还是已经准备进入持续工作流

很多人会这样走：

- 先用桌面 App 熟悉基本节奏
- 再根据习惯补 CLI 或 IDE
- 真需要远程长任务时再加 Cloud

## 速选表

| 当前需求 | 更适合先用哪个 |
|---|---|
| 先看清它在做什么 | 桌面 App |
| 我已经习惯命令行和脚本 | CLI |
| 我主要时间都在写代码 | IDE |
| 我想让任务在远端跑、更标准化 | Cloud |

按使用场景来选，通常比只盯着功能多少更靠谱。
