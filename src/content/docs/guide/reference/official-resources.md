本手册是社区开源指南。产品行为、安装包与套餐以官方为准：

- Codex 开发者文档：[https://developers.openai.com/codex](https://developers.openai.com/codex)
- OpenAI 平台与账号相关页面：以 OpenAI 官网当前入口为准

官方文档和这本手册分工不同：

- 这本手册负责解释概念和使用思路
- 官方文档负责确认当前版本和最新写法

若官方 URL 变更，以 OpenAI 站点导航为准，并欢迎 PR 更新本页。

## 什么时候优先看官方

遇到下面这些问题时，直接回官方文档更直接：

- 安装与登录
- 当前功能是否支持
- 配置项或命令最新写法
- 套餐、权限、产品行为变化

## 常见误会

### 1. 官方最权威，不代表社区手册没必要看

很多人卡住，是因为看完官方说明之后，还是不知道该从哪里开始。

### 2. 手册里写过，不代表现在一定还是这样

下面这些内容变化会更快：

- 命令参数
- 配置键名
- 支持的产品能力
- 套餐和权限范围

### 3. 遇到冲突时，优先级要分清

简单分的话，概念和背景看手册；涉及当前行为和最新写法时看官方。

## 使用方式

下面这类问题，可以先看手册：

- 我不懂这个概念在讲什么
- 我不知道该怎么开始
- 我想知道推荐的入门顺序

下面这类问题，看官方更可靠：

- 现在最新支持什么
- 这个参数今天到底叫什么
- 这个功能当前版本有没有
- 产品规则最近是否变了

## 不确定先看哪边时

1. 用手册理解概念和大方向
2. 真要开始配置、安装、执行前，再去官方确认最新写法
3. 如果两边冲突，以官方为准

这样方向会更清楚，也能少踩到过期信息。
