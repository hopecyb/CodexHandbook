未运行项留空或标记未运行，不填零耗时、通过或推测版本。公开记录应使用脱敏路径与测试画面，避免包含真实任务内容。

## 宠物检查

先验证 JSON 与资源路径，再在客户端检查选择、加载、透明背景、动作切换和窗口缩放。若图集带版本字段，确认字段与行列契约一致；图片能打开不代表客户端按正确版本解析。

停用时先切回内置资源或关闭宠物。将自定义包移到扫描目录之外的备份位置，然后刷新或重启，确认它不再出现；要恢复时放回同一包，再检查加载。不要只在扫描目录内改名，也不要删除整个配置目录。

## 主题检查

记录启用前后相同页面的外观与交互。至少覆盖首页、任务、输入框、搜索、错误信息和可获得的审批界面。无法触发的界面标记未测试，不制造真实高风险动作来测试按钮。

恢复后重新打开正常客户端，确认外观与操作正常，且没有主题自动重启或再次注入。界面恢复与调试连接关闭应分别核对；无法确认其中一项时保留未决记录。

## 何时需要重新验证

客户端、系统、主题引擎、宠物格式或资源包发生变化后，复用原测试步骤。保留旧记录并新增版本组合，不能只刷新核验日期。失败时优先恢复已知配置，再单独定位新变化。
