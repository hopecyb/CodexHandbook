## 不知道问题属于哪类时

如果一时说不清问题属于哪类，可以先按下面几种情况分：

1. 是“进不去”？
2. 是“跑不起来”？
3. 是“跑了但结果不对”？
4. 是“我不知道该怎么选工具或入口”？

这样通常能更快落到对应页面。
