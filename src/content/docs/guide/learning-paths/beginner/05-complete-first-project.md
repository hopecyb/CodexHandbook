## 本步目标

在练习目录交付一个小而完整的产物，例如一页 `practice-report.md`：

- 说明你用了哪个客户端
- 列出三次成功任务
- 写下一次想学的能力（提示词 / 上下文 / 质量）

这一步不是做一个“像作业”的文档，而是把前面几步串起来，完成一次独立的小闭环。

## 完成后

- 复习 [能力地图](/guide/start-here/codex-capability-map/)
- 深入 [桌面 App](/guide/desktop-app/) 或 [提示词](/prompts/)

## 练习重点

这里主要看三件事：

- 不只会发一个请求
- 还会控制范围、检查结果、总结经验

做到这一步，通常就能独立完成一个小项目。

## 常见误会

### 1. 第一个小项目必须看起来很厉害

小而完整，比大而失控更有价值。

### 2. 只要生成了一个产物，就算完成

更重要的是你能说清楚：

- 你怎么让它做
- 你怎么判断它做对了
- 你下一步还想补什么能力

第一个小项目的价值，不在于作品多大，而在于你已经走完一次完整协作闭环。
