## 本步目标

用完整句子说明 **你要什么** 和 **不要什么**，不要只丢几个词。

第一次和 Codex 对话时，很多人会把它当成搜索框，只丢几个关键词。这一步用来改掉这个习惯。

## 练习

对练习项目说：

```text
请用三句话解释当前文件夹里有哪些文件，以及每个文件大概做什么。
不要修改任何文件。
```

## 这一步在练什么

这里练的是两件最基本的事，不是把 prompt 写得更漂亮：

- 把目标说完整
- 把边界说清楚

哪怕只是只读任务，也最好明确写上“不要修改任何文件”。

## 学到什么

- 只读任务也要写清「不要修改」
- 含糊请求会得到含糊答案

## 常见误会

### 1. 这种练习太简单，没必要做

如果连只读任务都不说清楚，后面一上来做改动任务更容易跑偏。

### 2. 只有改文件时才需要写限制

只读、解释、总结这类任务，同样需要边界。
