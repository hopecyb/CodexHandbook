用一套虚构活动资料，练习从读取文件到交付一份可核对的通知。你不需要先学会 Git、编程或安装依赖。

[下载完整练习包](/downloads/first-project/first-project-1.0.0.zip) · [材料说明](/downloads/first-project/README.md)

解压后把 starter 复制成新的 work 文件夹，再用 Codex 打开 work。保留原件与作者参考，先完成练习，再对照答案。遇到客户端安装或登录问题，先看[快速上手](/guide/getting-started/)与[故障排查](/guide/reference/troubleshooting/)。

| 步骤 | 做什么 | 完成证据 |
|---|---|---|
| [1. 与 Codex 对话](/guide/learning-paths/beginner/01-talk-to-codex/) | 只读三个文件，说明用途与未知 | 找出报名方式待确认，文件未变 |
| [2. 处理文件](/guide/learning-paths/beginner/02-work-with-files/) | 只给通知增加状态注释 | 只有一个文件增加一行 |
| [3. 给出清晰任务](/guide/learning-paths/beginner/03-give-clear-tasks/) | 根据事实整理通知 | 事实对应、未知保留、范围正确 |
| [4. 审查结果](/guide/learning-paths/beginner/04-review-results/) | 找出坏样本错误并复核自己的产物 | 四项错误定位与实际复核记录 |
| [5. 完成第一个小项目](/guide/learning-paths/beginner/05-complete-first-project/) | 在副本演练恢复并写交接 | 文件恢复一致、交接可回查 |

## 包里有什么

starter 提供事实、通知草稿和不得修改的合成便条；references 提供作者参考和故意设计的错误样本；templates 提供复核、交接模板；validation 保存可选复现脚本及真实文件操作记录。

所有活动、地点均为虚构，材料采用 CC0-1.0。练习只处理本地文件，不进行实际报名、发布或消息发送。

## 验证到哪一步

作者已在临时目录运行初始复制、单文件修改、原件保护、故障制造和恢复核对。脚本没有调用模型，参考通知是作者编写；本站尚未测得模型成功率、学习耗时或独立读者通关情况。你的完成情况应由自己的文件和复核记录证明。
