Codex 通过 **工具** 作用于真实世界：

- 读/写项目文件
- 在终端运行命令（需权限与沙箱策略允许）
- 搜索网页、打开浏览器等（视产品能力与策略）

## 使用原则

1. **最小必要范围**：指明目录与文件，避免「随便改整个仓库」
2. **危险命令需审批**：删除、推送、改系统配置等
3. **工具选择有方法**：见 [工具选择](/guide/tools/tool-selection/)

产品入口不同，工具面板与确认方式也不同，细节见各产品手册。
