## 持续更新

本手册不会绑定单一 Codex 版本长期冻结。产品会持续变化，因此安装、登录、权限、模型、配置和 Cloud 行为等内容可能随时间调整。

## 应该信任什么

产品的当前行为以 [OpenAI Codex 官方文档](https://developers.openai.com/codex) 为准。本手册用于解释概念、梳理路径和提供实践方法；如果两者冲突，应以官方文档为准，并欢迎通过页面底部的纠错入口反馈。

## 怎么判断内容是否仍然适用

阅读可能变化的内容时，重点看三件事：

1. 主题本身是否容易变化，例如安装、配置、权限和产品入口。
2. 页面显示的最近内容更新时间是否距今较久。
3. 文中引用的官方资料和当前产品行为是否一致。

概念、方法和验收思路通常比具体按钮、参数和界面路径稳定。涉及最新行为、参数、价格或规则时，请再次查阅官方资料。

## 内容更新与纠错

[内容更新与纠错](/guide/updates/)记录重要改动及其影响。页面底部可以打开已带入当前页面标题和路径的 GitHub 纠错草稿；提交前请检查内容并删除敏感信息。

## 经常变化的内容

- 安装方式与系统要求
- 登录、账号和权限流程
- 模型、配置项与参数写法
- Cloud、客户端和产品入口行为
- 价格、配额与服务限制
