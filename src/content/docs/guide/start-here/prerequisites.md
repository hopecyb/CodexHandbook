大多数人刚开始用 Codex，卡住的地方不在技术背景，而是第一步怎么开始。

## 必备

1. **可用的 OpenAI / Codex 访问权限**（账号与套餐以官方说明为准）
2. **一台可安装桌面 App、CLI 或 IDE 扩展的电脑**
3. **一个可丢弃的练习目录**（不要直接在生产仓库上做首次尝试）
4. **愿意检查结果**：接受、修改或撤销，而不是盲目合并

这四项里，第 3 和第 4 项最容易被忽略。

- 练习目录能让试错时压力小很多
- 愿意检查结果，决定了这次尝试是不是可控

## 你不需要先具备什么

下面这些，**不是开始前的硬门槛**：

- 不必先精通 Git
- 不必先会写很多代码
- 不必一开始就理解所有模型、上下文、沙箱、审批细节
- 不必一次装齐所有客户端

把第一个任务跑通，再慢慢补这些概念，压力会小很多。

## 常见误会

### 1. 不用把文档全看完再开始

可以边看边学，很多人会这样开始：

1. 完成一个很小的任务
2. 再回来看相关概念
3. 遇到问题时再回来查文档

### 2. 不建议一开始就拿正式项目试

刚开始可以这样做：

- 一个可丢弃的小目录
- 一个你能看懂结果的小任务
- 一个出错也不会造成损失的环境

### 3. 不用一次把 CLI、IDE、App 全学完

对大多数新手来说，从 **桌面 App** 开始会轻松一些，因为界面更直观，也更容易看到项目、任务和改动。

## 建议

- 先阅读 [初学者安全清单](/guide/getting-started/beginner-safety-checklist/)
- 了解 [权限与审批](/guide/foundations/permissions-and-approvals/) 与 [沙箱与网络](/guide/foundations/sandbox-and-network/)
- 官方安装与产品变更以 [https://developers.openai.com/codex](https://developers.openai.com/codex) 为准

## 一个常见起步顺序

可以按这个顺序来：

1. 确认自己有访问权限
2. 安装一个客户端
3. 准备一个练习目录
4. 跑一个很小的任务
5. 检查结果，再决定下一步

开始前，在安全、小范围、可撤回的环境里跑通第一个任务，比先补一大堆概念更省劲。
