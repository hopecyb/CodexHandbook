这份手册主要写给刚开始认真接触 Codex 的人。

它不假设你已经懂这些东西：

- 终端
- Git
- Agent
- 提示词工程
- 云端环境

本来就懂这些的话，会读得更快；如果还不熟，正文也尽量写得容易跟上。

## 四类读者

| 读者 | 你会怎样用这本手册 |
|---|---|
| AI 初学者 | 从「是什么」到首个安全任务；术语都有解释 |
| 创作者 | 研究、写作、演示与原型；可先读概览，再进入能力专题 |
| 开发者 | 代码理解、实现、测试、评审与自动化 |
| 团队 | 共享说明、权限、质量与治理（深度内容在后续里程碑） |

## 这四类人不用分得太细

很多人实际会同时落在两三类之间，比如：

- 会写一点代码，但刚开始认真用 Agent
- 本来是内容创作者，后来也开始让 Codex 帮忙改站点
- 团队负责人自己也会先以个人身份试用

所以这四类读者更接近四种**使用场景**，并不是互斥身份。

## 主要面向

正文主要写给 **不熟悉终端与 Agent 的读者**。开发者和团队相关内容不会因此变浅，只是会按学习路径逐步展开。

## 常见误会

### 1. 这本手册不只适合程序员

工作里如果有下面这些内容，这本手册也适合你：

- 写作与整理内容
- 研究与信息比对
- 文档维护
- 原型与页面修改
- 团队流程梳理

### 2. 已经有些基础，也可以先读前面几页

前面的“开始前”“基础概念”“第一次任务”不只是在给零基础铺路，也能帮你快速校准：

- Codex 到底怎么工作
- 任务应该怎么提
- 哪些风险要提前避开

### 3. 不用从头读到尾

很多人会这样读：

1. 读起步页
2. 跑通第一个小任务
3. 再按你自己的角色往下跳读

## 不适合把手册当成什么

- 单一产品的完整官方 changelog
- 不经核验即可上生产的脚本仓库
- 替代你们组织内部的安全与合规政策

## 适合哪些人

有下面这些需求的话，这本手册就值得看：

- 你想安全地把 Codex 用起来
- 你已经会一点，但总觉得任务提不稳
- 你想把个人用法整理成团队可复用流程
- 你不是做开发出身，但想把 AI 真正接到日常工作里
