Codex 是 OpenAI 提供的 **AI 编程与工作 Agent**：你可以给它目标，它会结合项目文件、工具与你的批准，去阅读、修改、运行命令、生成产物，并让你检查结果。

官方产品文档以 [OpenAI Codex](https://developers.openai.com/codex) 为准；本手册是社区开源指南，用于系统学习与实践，**不是** OpenAI 官方文档的替代品。

## 能做什么

- **理解**：总结仓库、文档、表格与截图中的信息
- **创建与修改**：写文稿、改代码、生成页面与配置
- **执行**：在你授权下运行终端命令、搜索与浏览
- **协作**：在 App、CLI、IDE、Cloud 等入口之间延续任务
- **扩展**：通过 Skills、Plugins、MCP、Hooks 等接入重复流程与外部系统（进阶章节后续补齐）

## 不能做什么（重要）

- 不能替代你对事实、安全与业务决策的最终责任
- 不能保证一次生成就完全正确；结果必须可检查
- 不能在未获授权时突破沙箱、网络或组织策略
- 不应被当作「无需验收的自动发布流水线」

## 主要使用入口

| 入口 | 适合 |
|---|---|
| 桌面 App | 初学者默认；可视化项目、任务、差异审查 |
| CLI | 终端用户、脚本与自动化 |
| IDE 扩展 | 在编辑器内结合打开文件与选区工作 |
| Web / Cloud | 连接仓库、云端环境与长任务 |
| 移动与远程 | 监控、审批与轻量跟进 |
