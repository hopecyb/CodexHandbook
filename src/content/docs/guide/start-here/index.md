# 从这里开始

欢迎来到 Codex 指南模块。若你第一次使用 Codex，按下面顺序阅读即可建立安全、可验证的基础习惯。

## 建议阅读顺序

1. [Codex 是什么](/guide/start-here/what-is-codex/) — 弄清能做什么、不能做什么
2. [选择客户端](/guide/choose-your-client/) — 在 App、CLI、IDE、Cloud 之间做第一次选择
3. [完成第一个任务](/cases/first-task/) — 用清晰提示词完成小改动并检查结果
4. [权限与沙箱](/guide/permissions-and-sandbox/) — 理解审批、隔离与网络边界
5. [上下文与文件](/guide/context-and-files/) — 学会提供有效输入
6. [验证结果](/guide/verification/) — 养成审查与测试习惯

## 前三十分钟路线

| 时间 | 做什么 |
|---|---|
| 0–5 分 | 读 [权限与沙箱](/guide/permissions-and-sandbox/) 中的安全要点 |
| 5–10 分 | 安装并登录所选客户端（见 [桌面 App](/guide/desktop-app/) 等） |
| 10–25 分 | 按 [第一个任务案例](/cases/first-task/) 完成练习 |
| 25–30 分 | 浏览 [提示词基础](/prompts/basics/)，准备写更清楚的任务 |

卡住了？查看 [故障排查](/guide/troubleshooting/)。
