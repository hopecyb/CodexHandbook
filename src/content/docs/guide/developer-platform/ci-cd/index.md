把 Codex 接进 CI/CD 时，最常见的问题通常出在这里：

一上来就想让它自动改、自动推、自动合并。

更常见的做法，是先让它只读、只提建议、只产出报告。

## 本组入口

- [代码审查自动化](/guide/developer-platform/ci-cd/code-review-automation/)

## 本组内容

- 在 PR 阶段做结构化审查
- 让自动化先做“发现问题”和“给建议”
- 把高风险动作继续留给人工审批

CI/CD 里接 Codex，一般先做低风险辅助，再决定哪些动作值得放权。
