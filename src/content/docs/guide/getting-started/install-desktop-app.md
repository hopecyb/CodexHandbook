1. 打开官方 Codex 文档的桌面应用下载说明：[https://developers.openai.com/codex](https://developers.openai.com/codex)
2. 选择你的操作系统安装包并安装
3. 启动应用，确认能看到登录或项目入口

第一次用 Codex，又不想先折腾终端的话，桌面 App 是比较直接的入口。
这里更关心的是装完以后，什么状态才算已经可以开始用。

## 安装后检查

- 应用能正常打开
- 系统权限（如文件访问）按需授予，不要一次性给无关磁盘权限
- 界面总览见 [安装与界面](/guide/desktop-app/installation-and-interface/)

## 常见误会

### 1. App 能启动，就说明没问题

更值得确认的是下面这几项：

- 能不能正常登录
- 能不能看到项目或任务入口
- 权限是不是给对了

### 2. 系统一弹权限框，就全都点允许

稳妥一点的做法是按需授予，而不是一次把无关磁盘或系统能力都打开。

### 3. 装完以后马上就该开始做大任务

第一次可以先确认几件小事：

- 登录没问题
- 页面能正常打开
- 你知道项目入口和基本界面在哪

桌面 App 装好以后，先确认能正常打开、登录、看到入口，再去做第一个任务。

若失败：见 [桌面 App 排障](/guide/desktop-app/troubleshooting/)。
