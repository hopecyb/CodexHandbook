本手册所说的“桌面 App”，指当前 **ChatGPT 桌面 App 中的 Codex 工作区**。官方提供 macOS、Windows 和 Linux 版本。

## 安装步骤

1. 打开 [ChatGPT 桌面 App 官方说明](https://learn.chatgpt.com/docs/app)。
2. 从官方入口下载与你操作系统匹配的安装包。
3. 安装并打开 ChatGPT，使用 ChatGPT 账号或其他可用方式登录。
4. 新建聊天、创建项目或打开一个练习文件夹。
5. 进入 Codex，新建任务并描述你要得到的结果。

不要从搜索结果中的第三方下载站获取安装包。公司设备如由管理员统一部署，应遵循组织的软件分发与更新策略。

## 安装后做一次最小检查

准备一个不含密钥的练习目录，然后确认：

- App 能正常打开并显示当前账号或工作区
- 能打开该目录或在项目中添加文件
- 能创建 Codex 任务并收到回复
- 文件访问权限只覆盖本次工作需要的范围
- 你能找到任务结果、文件变化和审批入口

可以用这条只读任务做烟雾测试：

```text
只读这个目录，不要修改文件。告诉我它包含哪些文件、可能是什么项目，并说明你依据了哪些文件名。
```

## 常见问题

### App 能打开，但看不到 Codex

先确认当前账号、工作区和计划访问权限，再检查组织是否禁用了相关能力。不要通过反复重装来绕过账号或管理员策略。

### 系统请求文件、辅助功能或应用控制权限

先看当前任务是否真的需要。只打开练习目录时，不必顺手授权无关磁盘或系统能力。判断方法见 [权限与沙箱](/guide/permissions-and-sandbox/)。

### 安装后界面和截图不一样

桌面 App 更新较快，以“能登录、能选择工作位置、能发起任务、能审查结果”为成功标准，不要依赖某个按钮的固定位置。

详细界面见 [安装与界面](/guide/desktop-app/installation-and-interface/)，失败时见 [桌面 App 排障](/guide/desktop-app/troubleshooting/)。
