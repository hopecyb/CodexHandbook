第一次使用前，可以先问自己一句：“如果它做错了，我会不会付出太大代价？”

这份清单是为了把第一次使用的风险压低。


开始前勾选：

- [ ] 我使用的是可丢弃的练习目录，不是生产仓库
- [ ] 目录内没有真实密钥、密码、客户隐私
- [ ] 我理解高风险操作需要我审批
- [ ] 我不会批准看不懂的命令或出网请求
- [ ] 我打算检查差异后再接受结果
- [ ] 我知道如何 [撤销](/guide/getting-started/undo-and-recover/)

概念补充：[权限与审批](/guide/foundations/permissions-and-approvals/) · [沙箱与网络](/guide/foundations/sandbox-and-network/)。

## 常见误会

### 1. 安全清单只是给特别谨慎的人看的

它就是给第一次上手的人准备的，因为第一次很容易高估自己“应该能看懂一切”。

### 2. 只要我不点危险命令，就已经足够安全

第一次更常见的问题是：

- 用错项目
- 带了敏感文件
- 没检查 diff
- 没想好怎么撤回

### 3. 我一边用一边学，也不用提前确认这些

可以边用边学，但这张清单里的几项，开始前过一遍会更稳妥。

第一次使用 Codex，先把出错成本压低，后面会轻松很多。
