很多人第一次卡住，问题出在安装之前：

- 我明明有 OpenAI 账号，为什么还是进不去
- 我能登录，是不是就代表所有客户端都能用
- 公司环境下为什么同事能用、我不能用

常见误解是，以为“能登录账号”就等于“当前一定有对应产品的访问权限”。

使用 Codex 前需要有效的 OpenAI 账号，以及当前地区/组织策略允许的 **产品访问权限**。套餐名称、额度与是否包含 App/CLI/Cloud 以官方说明为准。

## 需要确认的三件事

1. 能登录 [OpenAI / Codex 相关入口](https://developers.openai.com/codex)
2. 你的计划包含打算使用的客户端
3. 若在公司环境：是否有 SSO、设备管理或禁用策略

## 常见误会

### 1. 有账号就等于 App / CLI / IDE / Cloud 都能用

不同入口可能对应不同的可用范围、套餐能力或组织策略。

### 2. 登录失败一定是密码错了

也可能是：

- 组织 SSO 限制
- 当前地区或设备策略限制
- 产品本身没有对你的账号开放

### 3. 公司环境和个人环境是一回事

在公司环境里，账号能不能用、能用哪些入口，经常会受额外的安全和设备策略影响。

## 排查顺序

如果暂时不确定问题出在哪，可以按这个顺序检查：

1. 我能不能登录相关入口
2. 我当前计划是否包含目标客户端
3. 我所在组织有没有额外限制

账号可用只是第一步，后面还要看套餐和组织访问策略。
