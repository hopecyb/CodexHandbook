扩展机制多，容易混淆。本页是**选型地图**，不是安装教程。

## 关系示意

```text
                    ┌─────────────────┐
                    │   你的任务目标   │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         ▼                   ▼                   ▼
   ┌───────────┐      ┌─────────────┐     ┌──────────────┐
   │ AGENTS.md │      │  提示词/模板  │     │ 斜杠命令      │
   │ 持久规则   │      │  本次任务     │     │ 你主动触发    │
   └───────────┘      └─────────────┘     └──────────────┘
         │                   │                   │
         └───────────────────┼───────────────────┘
                             ▼
                    ┌─────────────────┐
                    │      Skill       │
                    │ 可复用工作流包    │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌──────────┐  ┌──────────┐  ┌─────────────┐
        │   MCP    │  │  Hooks   │  │  Scripts    │
        │ 外部工具  │  │ 审计校验  │  │ Skill 内脚本 │
        └──────────┘  └──────────┘  └─────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │     Plugin       │
                    │ 分发与组合打包    │
                    └────────┬────────┘
                             ▼
                    ┌─────────────────┐
                    │  Automations     │
                    │ 无人值守/定时     │
                    └─────────────────┘
```

## 对比表

| | 谁触发 | 持久性 | 连外部系统 | 团队分发 |
|---|---|---|---|---|
| AGENTS.md | 自动加载 | 高（Git） | 易 |
| 提示词 | 你 | 低 | 难 |
| 斜杠命令 | 你 | 中 | 视产品 |
| Skill | 你或模型匹配 | 高 | 易（目录/Git） |
| MCP | 模型调用工具 | 配置级 | 需治理 |
| Plugin | 安装后综合生效 | 高 | 官方/团队渠道 |
| Hooks | 系统事件 | 配置级 | 企业常见 |
| Automations | 时间/事件 | 配置级 | 需审批流 |

## 决策速查

| 你想… | 优先选 |
|---|---|
| 统一代码风格和测试命令 | AGENTS.md |
| 把「审查 PR」流程标准化 | Skill |
| 读 Jira/Linear 工单 | MCP |
| 给全团队装一套集成 | Plugin |
| 每次提交前扫描密钥 | Hooks |
| 每周一自动生成周报草稿 | Automations（+ 人工发布） |

详细分支逻辑：[如何选择扩展方式](/07-extensions-automation/choosing-an-extension-method/)。

## 与产品入口无关

上述机制**不绑定**单一界面：CLI、桌面 App、IDE 对 Skill/MCP 的支持程度可能不同，以 [功能对照](/12-reference/feature-comparison/) 与官方说明为准。
