## Общая информация

| Поле | Значение |
|---|---|
| Для кого | Разработчики / команды |
| Клиент | CLI / IDE / Cloud |
| Расчётное время | 20–40 минут |

## 1. Цель и контекст

**Цель:** до объединения обнаружить выход за рамки задачи, риски безопасности и пробелы в тестах.

**Критерий успеха:** каждый вывод проверки привязан к конкретному файлу или строке, а проблемы уровня P0 устранены либо блокируют объединение.

## 2. Рекомендуемый промпт

```text
Сравни diff текущей ветки с main, пока не изменяя код:
1. Есть ли изменения за рамками issue
2. Есть ли очевидные риски безопасности: секреты, инъекции, права доступа
3. Не хватает ли тестов или документации
Выведи контрольный список с отметками P0/P1 и путями к файлам.
```
