## Общая информация

| Поле | Значение |
|---|---|
| Для кого | Команда |
| Клиент | CLI |
| Расчётное время | 1–2 часа для первой версии |

## 1. Цель и контекст

**Цель:** ежедневно автоматически формировать сводку изменений, результаты тестов и список задач.

**Критерий успеха:** одна команда или Skill создаёт Markdown фиксированного формата; при сбое возвращается однозначный код завершения.

## 2. Рекомендуемый промпт

```text
Цель: сформировать ежедневный отчёт в Markdown за период со вчерашнего дня по текущий момент.
Содержание: сводка git log, статус CI (если доступен для чтения), список открытых PR.
Результат: reports/daily-YYYY-MM-DD.md
Ограничения: работай с git только на чтение; не выполняй push; создай scripts/generate-daily.sh для повторных запусков.
```
