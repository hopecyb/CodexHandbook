| Поле | Значение |

## 1. Цель и контекст

**Цель:** распределить независимые подзадачи между несколькими Agent, а затем вручную объединить выводы.

**Критерий успеха:** для каждого Agent задано отдельное определение завершения, и они не перезаписывают один и тот же файл.

## 2. Рекомендуемые схемы

### Параллельное исследование и ручной выбор решения

```text
Agent 1: преимущества, недостатки и объём работы для варианта A
Agent 2: преимущества, недостатки и объём работы для варианта B
(после вашего выбора реализацию выполняет один Agent)
```

### Изоляция с помощью рабочих деревьев

Разные Agent изменяют разные ветки в отдельных [git worktree](/ru/guide/desktop-app/worktrees/), после чего результаты объединяются вручную.

## 3. Правила координации — рекомендуем добавить в AGENTS.md

- Задайте каждому Agent чёткие границы каталогов.
- Запретите параллельный `git push`.
- Перед объединением запустите единый набор проверок CI.
