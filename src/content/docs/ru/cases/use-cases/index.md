Библиотека примеров отвечает на вопрос: **«Как выглядит полный цикл работы с Codex для такой реальной цели?»** Она дополняет отдельные страницы с описанием продукта.

## Пример и учебное руководство

| | Вводное руководство | Библиотека примеров |
|---|---|---|
| Цель | Освоить определённую кнопку или понятие | Получить реальный результат определённого типа |
| Структура | По функциям продукта | По типам задач |
| Работа со сбоями | Часто опускается | Обязательна |

## Как пользоваться

1. Выберите пример, наиболее близкий к вашей цели, — либо возьмите только его контрольный список подготовки.
2. Сопоставьте работу со схемой [Исследование — планирование — выполнение — проверка](/ru/cases/workflows/explore-plan-execute-verify/).
3. После завершения проведите ретроспективу по [шаблону примера](/ru/cases/use-cases/case-study-template/) и решите, стоит ли оформить процесс как Skill.

## Как можно помочь

- Добавляйте воспроизводимые шаги — репозиторий, ветку и команды.
- Указывайте подходящие клиенты и дату проверки.
- Не описывайте непроверенный сценарий «всё получилось с первого раза».
