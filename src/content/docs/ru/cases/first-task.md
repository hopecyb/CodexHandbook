В примере ниже по умолчанию используется **настольный App**; тот же промпт подходит для CLI и IDE.

## Общая информация

| Поле | Значение |
|---|---|
| Для кого | Начинающие |
| Клиент | Настольный App — рекомендуется |
| Расчётное время | 15–20 минут |

## 1. Цель и контекст

**Цель:** безопасно изменить один файл в учебном проекте.

**Критерий успеха:** изменён только указанный файл, результат соответствует условиям приёмки, а вы понимаете diff.

## 2. Подготовка

- Клиент установлен, вход выполнен.
- Создан учебный проект с файлом `hello.md` или аналогичным.

## 3. Рекомендуемый промпт

```text
Цель: добавь в конец hello.md раздел «Сегодняшнее упражнение» со списком ровно из трёх пунктов.
Ограничения: изменяй только hello.md; не удаляй существующее содержимое; не выполняй сетевые запросы.
Приёмка: в конце файла появился этот заголовок и ровно три пункта списка.
Если информации недостаточно, сначала задай вопрос и не делай предположений.
```

## 4. Выполнение и проверка

1. Сначала попросите краткий план — либо дождитесь, пока Codex предложит его сам.
2. При подтверждении записи файла убедитесь, что указан верный путь.
3. После завершения проверьте diff по каждому критерию приёмки.
