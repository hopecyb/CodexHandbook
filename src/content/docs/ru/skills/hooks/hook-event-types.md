При выборе Hook сначала спросите не «как написать скрипт», а «обрабатывать событие до или после побочного эффекта?». Если выбрать неправильный момент, даже идеальный скрипт сможет лишь сообщить о проблеме задним числом.

![Жизненный цикл Hook в Codex и ключевые события](/illustrations/flow-hook-lifecycle.webp)

## Текущий список событий

| Событие | Когда происходит | Что фильтрует matcher | Типичное применение |
|---|---|---|---|
| `SessionStart` | При начале или возобновлении сеанса | `startup`, `resume`, `clear`, `compact` | Описание среды, восстановление контекста |
| `SubagentStart` | При запуске дочернего Agent | Тип дочернего Agent | Добавление ограничений для дочернего Agent |
| `UserPromptSubmit` | При отправке пользовательского промпта | Не поддерживается, настройка игнорируется | Поиск секретов, добавление контекста разработки |
| `PreToolUse` | До выполнения поддерживаемого локального инструмента | Имя инструмента | Отклонение или изменение вызова |
| `PermissionRequest` | Когда Codex готовится запросить подтверждение | Имя инструмента | Разрешение, запрет или передача обычному процессу подтверждения |
| `PostToolUse` | После возврата результата поддерживаемым локальным инструментом | Имя инструмента | Запись результата, обратная связь для дальнейших рассуждений |
| `PreCompact` | До сжатия контекста | `manual` / `auto` | Сохранение состояния перед сжатием |
| `PostCompact` | После сжатия контекста | `manual` / `auto` | Возврат необходимого контекста |
| `SubagentStop` | Когда дочерний Agent готовится завершить работу | Тип дочернего Agent | Запрос ещё одного цикла проверки |
| `Stop` | Когда раунд основной задачи готовится завершиться | Не поддерживается, настройка игнорируется | Запрос продолжения проверки в основном потоке |
| `SessionEnd` | При завершении основного потока | Сейчас — `other` | Быстрый завершающий журнал; не выполняется для дочернего Agent |

## Matcher инструментов

Типичные значения:

```text
Bash
^apply_patch$
Edit|Write
mcp__filesystem__read_file
mcp__filesystem__.*
```

Shell и унифицированное выполнение команд совпадают с `Bash`. Для `apply_patch` также подходят псевдонимы `Edit` и `Write`. MCP и другие локальные функциональные инструменты сопоставляются по фактическому имени.

## Три события, которые путают чаще всего

### PreToolUse

Входные данные содержат `tool_name`, `tool_use_id` и специфичный для инструмента `tool_input`. Событие позволяет:

- `permissionDecision: "deny"`: заблокировать поддерживаемый вызов инструмента
- `permissionDecision: "allow"` + `updatedInput`: изменить входные данные поддерживаемого инструмента
- `additionalContext`: не блокировать, а только добавить контекст для модели

Обычный текст stdout игнорируется; следует выводить JSON, определённый официальной документацией. Код завершения `2` вместе со stderr также позволяет заблокировать вызов и указать причину.

### PermissionRequest

Событие возникает только тогда, когда Codex и без Hook собирается запросить подтверждение повышения разрешений shell, доступа к управляемой сети или аналогичного действия. Hook может разрешить, запретить или не принимать решения, чтобы продолжился обычный UI подтверждения. Не используйте его вместо `PreToolUse` для общих политик инструментов.

### PostToolUse

Инструмент уже выполнен; событие возникает даже при ненулевом коде завершения Bash. Возврат block или завершение с кодом `2` может лишь заменить обратную связь и предложить модели обработать её, но не отменит команду, запись файла или внешнее действие.

## Stop — не кнопка «запретить завершение»

Для `Stop` значение `decision: "block"` автоматически создаёт по указанной причине промпт продолжения, чтобы Codex выполнил ещё один цикл. Уже возникшие побочные эффекты инструментов не откатываются. Скрипт обязан проверять `stop_hook_active`, чтобы избежать бесконечного продолжения.

## Упражнение по выбору события

| Потребность | Выбор | Причина |
|---|---|---|
| Не допустить запись похожего на токен значения в файл | `PreToolUse` с matcher `apply_patch|Edit|Write` | Обработка должна произойти до записи |
| Рассчитать долю сбоев shell | `PostToolUse` с matcher `Bash` | Нужен результат выполнения |
| Сохранить ключевое решение перед автоматическим сжатием контекста | `PreCompact` | Возникает до сжатия |
| Не завершать задачу, пока не выполнены тесты | `Stop` | Необходимо продолжить текущий раунд задачи |
| Выполнить 30-секундный сетевой запрос при завершении основного потока | `SessionEnd` не подходит | Максимум 3 секунды; долгую задачу нельзя помещать в завершающее событие |
