Plugin — единица объединения и распространения возможностей. Он может включать Skills, коннекторы, серверы MCP, расширения браузера, Hooks и шаблоны Scheduled task; непосредственную работу выполняют именно эти компоненты.

## Для кого подходит

- Для пользователей, которые хотят установить готовый набор возможностей из публичного каталога
- Для сопровождающих, которым нужно распространять командные процессы, инструменты и защитные механизмы как единую версионируемую единицу
- Для администраторов, проверяющих источники, разрешения внешних сервисов и Hook из Plugin

## Поддерживаемые среды

| Среда | Просмотр и установка | Использование |
|---|---|---|
| ChatGPT Web и настольное App | Вкладка Plugins | Chat и Work |
| ChatGPT Mobile | Не является основным интерфейсом управления | Использование Plugin, уже добавленных к аккаунту |
| Codex в настольном App ChatGPT | Вкладка Plugins | Задачи Codex |
| Codex CLI | Каталог `/plugins`; после установки нужно открыть новый сеанс | Среда Codex |
| Расширение IDE | **Plugin не поддерживается** | Можно отдельно использовать MCP, Skill и другие возможности, поддерживаемые IDE |
