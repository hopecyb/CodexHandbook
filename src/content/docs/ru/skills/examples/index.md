Сначала проверьте состояние материалов, затем выберите пример. Полные пакеты содержат входные данные, справочные материалы и проверочные скрипты; каркасы требуют дополнить ресурсы и реальные проверки, поэтому их нельзя считать готовыми проверенными процессами.

| Пример | Состояние материалов | Проверенный охват |
|---|---|---|
| [Skill для написания текстов](/ru/skills/examples/writing-skill/) | Полный пакет source-backed-writer для загрузки | Пройдены восемь регрессионных проверок структуры; факты и стиль проверены автором, качество модели не измерялось |
| [Skill для Review](/ru/skills/examples/review-skill/) | Полный пакет scoped-review для загрузки | Пройдены семь регрессионных проверок области diff; маршрутизация модели и доля обнаруженных дефектов не измерялись |
| [Skill для исследований](/ru/skills/examples/research-skill/) | Полный пакет evidence-research для загрузки | Пройдены восемь регрессионных проверок источников и структуры доказательств; качество исследования моделью не измерялось |
| [Skill для автоматизации](/ru/skills/examples/automation-skill/) | Полный пакет quiet-link-monitor для загрузки | Пройдены восемь тестов состояния; настоящее расписание и доставка не проверялись |

Связанный материал: [создание первого Skill](/ru/skills/create-your-first-skill/).

С помощью [методики оценки рабочих процессов](/ru/guide/quality/workflow-evaluation/) отдельно регистрируйте запуск, границы, формат, качество и длительность. Успех скриптов из примера не означает успех модели в целом.
