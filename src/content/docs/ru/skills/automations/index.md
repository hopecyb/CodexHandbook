Scheduled task (задача по расписанию) позволяет ChatGPT повторять работу в фоновом режиме по заданному графику. Этот механизм подходит для регулярных отчётов, постоянного наблюдения и повторяющегося обслуживания, но не заменяет произвольные webhook, события репозитория или автоматизацию CI.

## Сначала проверьте, подходит ли механизм

| Подходит | Не подходит |
|---|---|
| Источники входных данных стабильны, результат можно проверить | Проблему нужно заново определять при каждом запуске |
| Запуск зависит от времени или интервала | Требуется точный запуск по событию вроде Git push или открытия PR |
| Проверки только для чтения, сводки, черновики | Автономное слияние в основную ветку или массовое удаление |
| Ясно определены состояние «без изменений» и условия остановки | После сбоя выполняются бесконечные повторы |

## Текущие точки управления

- Создавайте задачи по расписанию и управляйте ими в ChatGPT Web или настольном App.
- В Codex CLI и расширении IDE нет интерфейса управления Scheduled; там удобно предварительно тестировать промпты, Skill или скрипты.
- В настольном App задача может использовать локальный проект или изолированный Worktree, однако компьютер должен быть включён, App — работать, а проект — по-прежнему находиться на диске.
- Задачи по расписанию в Web могут использовать загруженный контекст, подключённые инструменты, Skills и Plugins, но не имеют прямого доступа к локальным папкам компьютера.
