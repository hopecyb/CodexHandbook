Codex CLI позволяет выполнять исследование, изменения, тестирование и Review непосредственно в терминале. На официальной странице установки доступны варианты для macOS/Linux, Windows, npm и Homebrew; выберите способ, соответствующий вашей системе и менеджеру программ.

## Официальный автономный установщик для macOS / Linux

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Чтобы обновить CLI, снова выполните ту же официальную команду установки. Пользователям Windows, npm или Homebrew следует открыть соответствующую вкладку на [официальной странице Codex CLI](https://learn.chatgpt.com/docs/codex/cli), а не применять команду для macOS/Linux ко всем системам.

## Проверка после установки

Откройте новое окно терминала и в учебном репозитории выполните:

```bash
codex --version
codex login status
```

Если вход ещё не выполнен:

```bash
codex login
```

Завершив авторизацию в браузере, запустите интерактивный сеанс в каталоге репозитория:

```bash
codex
```

Первая задача может быть доступна только для чтения:

```text
Пока не изменяй файлы. Объясни, как установить, протестировать и собрать этот проект, и перечисли пути прочитанных файлов.
```

## Порядок устранения неполадок

1. `codex --version` не находит команду: повторно откройте терминал и проверьте `PATH` текущего shell.
2. Команда запускается, но продукт недоступен: выполните `codex login status`, чтобы отделить проблему установки от проблемы аутентификации.
3. Выполнен вход не в ту учётную запись: запустите `codex logout` и войдите снова.
4. Доступ отклонён в корпоративной среде: проверьте рабочую область, способ входа и управляемую конфигурацию; не обходите политику с помощью личных учётных данных.

Не вставляйте API key в историю shell, тикеты или чаты. Если требуется вход с API key, передайте его через стандартный ввод, как описано в разделе [Вход и аутентификация](/ru/guide/getting-started/sign-in-and-authentication/).

Далее изучите [Интерактивный режим CLI](/ru/guide/cli/interactive-mode/); остальные проблемы рассмотрены в разделе [Устранение неполадок CLI](/ru/guide/cli/troubleshooting/).
