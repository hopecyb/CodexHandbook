Под «настольным приложением» в этом руководстве понимается **рабочая область Codex в актуальном настольном приложении ChatGPT**. Официально доступны версии для macOS, Windows и Linux.

## Шаги установки

1. Откройте [официальную документацию по настольному приложению ChatGPT](https://learn.chatgpt.com/docs/app).
2. Через официальную точку входа загрузите установочный пакет для своей операционной системы.
3. Установите и откройте ChatGPT, затем войдите с учётной записью ChatGPT или другим доступным способом.
4. Создайте чат или проект либо откройте учебную папку.
5. Перейдите в Codex, создайте задачу и опишите требуемый результат.

Не загружайте установочный пакет со сторонних сайтов из поисковой выдачи. Если корпоративное устройство централизованно управляется администратором, соблюдайте правила организации по распространению и обновлению ПО.

## Минимальная проверка после установки

Подготовьте учебный каталог без ключей и убедитесь, что:

- App нормально открывается и показывает текущую учётную запись или рабочую область;
- каталог можно открыть или добавить его файлы в проект;
- можно создать задачу Codex и получить ответ;
- разрешения на доступ к файлам охватывают только необходимую для задачи область;
- вы можете найти результат задачи, изменения файлов и точку согласования.

Для дымового теста используйте задачу только для чтения:

```text
Только прочитай этот каталог и не изменяй файлы. Перечисли содержащиеся в нём файлы, предположи тип проекта и укажи, на какие имена файлов ты опирался.
```

## Распространённые проблемы

### App открывается, но Codex не отображается

Сначала проверьте текущую учётную запись, рабочую область и доступ плана, затем убедитесь, что функция не отключена организацией. Не пытайтесь обойти правила учётной записи или администратора многократной переустановкой.

### Система запрашивает доступ к файлам, специальным возможностям или управлению приложениями

Сначала определите, действительно ли это нужно текущей задаче. Чтобы открыть только учебный каталог, необязательно заодно предоставлять доступ к посторонним дискам или системным возможностям. Способ оценки описан в разделе [Разрешения и песочница](/ru/guide/permissions-and-sandbox/).

### Интерфейс после установки отличается от снимков экрана

Настольное приложение обновляется быстро. Критерием успеха служит возможность войти в систему, выбрать место работы, запустить задачу и провести Review результата, а не фиксированное положение кнопки.

Подробности интерфейса см. в разделе [Установка и интерфейс](/ru/guide/desktop-app/installation-and-interface/), а при ошибке — в разделе [Устранение неполадок настольного приложения](/ru/guide/desktop-app/troubleshooting/).
