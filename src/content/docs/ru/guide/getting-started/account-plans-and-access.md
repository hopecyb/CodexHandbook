Сейчас Codex можно использовать через **план ChatGPT** или с **API key и оплатой по объёму использования**, но эти способы не предоставляют одинаковые точки входа и границы управления.

## Сначала выберите способ доступа

| Способ | Подходит для | Границы доступности |
|---|---|---|
| Вход через ChatGPT | Индивидуального взаимодействия, настольного приложения, Cloud и рабочих областей организаций | Работа в пределах лимитов плана ChatGPT, роли в рабочей области и политик администратора |
| Вход с API key | Локального Codex, скриптов и CI | Оплата по использованию API; функции, зависящие от рабочей области ChatGPT или Cloud, могут быть недоступны |

На актуальной официальной странице Pricing сервисы ChatGPT Work и Codex включены в планы Free, Go, Plus, Pro, Business, Edu и Enterprise, однако цены, лимиты, модели и набор функций меняются. На этой странице нет таблицы цен. Смотрите [выбор плана и источники цен на этом сайте](/chatgpt-pricing/) и сверяйтесь с [официальной актуальной страницей Pricing](https://learn.chatgpt.com/docs/pricing).

## Почему доступ может отсутствовать даже при наличии учётной записи

Вход — лишь первый уровень. Итоговый доступ также зависит от следующих условий:

1. Включает ли текущий план нужную точку входа или функцию.
2. Доступны ли текущий продукт и функция в вашем регионе.
3. Назначила ли организация вам лицензию, роль и разрешения рабочей области.
4. Ограничил ли администратор способ входа, модели или локальные возможности через управляемую конфигурацию.
5. Не достигнут ли лимит текущего временного окна или недели.

## Контрольный список для индивидуального пользователя

- Вы можете войти в нужную учётную запись ChatGPT на официальной странице.
- Вы знаете, используете ли лимит плана или оплату API по объёму.
- В выбранном клиенте отображается правильная учётная запись.
- При сообщении о лимите вы проверяете фактическое использование, а не многократно переустанавливаете клиент.

## Контрольный список для команд и предприятий

- Выбрана правильная рабочая область, а не личное пространство с тем же адресом электронной почты.
- Администратор настроил участников, лицензии и роли.
- SSO, MFA, хранение данных и региональные политики соответствуют требованиям организации.
- Управляемая конфигурация не требует другого способа локального входа.
- API key относится к правильной API organization, а её политики не смешиваются с политиками рабочей области ChatGPT.

## Пример диагностики

Если CLI принимает вход с API key, но кнопка Cloud недоступна, причина необязательно в установке. Cloud требует входа через ChatGPT и регулируется планом ChatGPT и разрешениями рабочей области; API key прежде всего предназначен для локальных и программных процессов.
