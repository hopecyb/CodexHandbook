Сейчас IDE поддерживаются несколькими способами:

| IDE | Способ установки или включения |
|---|---|
| Visual Studio Code, Cursor, Windsurf, VS Code Insiders | Установить или включить расширение Codex |
| Xcode | Выбрать Codex Agent в coding assistant Xcode |
| IDE JetBrains | Выбрать Codex в AI Chat |

На [официальной странице Codex для IDE](https://learn.chatgpt.com/docs/codex/ide) выберите точку входа для своей IDE. Не пытайтесь определить расположение кнопок по снимку экрана другой IDE.

## Редакторы, совместимые с VS Code

1. Установите расширение Codex через официальную точку входа Marketplace.
2. Откройте корень рабочей области настоящего проекта.
3. Выберите значок Codex. Если его не видно, откройте Command Palette и выполните `Codex: Open Codex Sidebar`.
4. Войдите через ChatGPT или с API key.

## Xcode и JetBrains

- Xcode: откройте coding assistant, создайте чат и выберите Codex в качестве Agent.
- JetBrains: откройте AI Chat и выберите Codex.

Эти точки входа предоставляются соответствующими IDE, поэтому интерфейс не будет полностью совпадать с расширением VS Code.

## Проверка контекста после установки

Откройте исходный файл, выделите небольшой фрагмент кода и спросите:

```text
Только объясни входные данные, выходные данные и пути ошибок текущего выделенного фрагмента, не изменяя файлы. Укажи имена связанных функций.
```

Если ответ явно не связан с выделенным фрагментом, сначала проверьте:

- открыт ли корень правильного проекта;
- прикреплены ли файл или выделение к composer;
- выбраны ли правильные учётная запись и рабочая область;
- не включены ли одновременно конфликтующие расширения AI или сочетания клавиш.

Затем изучите [Рабочий процесс локальных задач в IDE](/ru/guide/ide/local-task-workflow/); полный список поддержки приведён в разделе [Поддерживаемые редакторы](/ru/guide/ide/supported-editors/).
