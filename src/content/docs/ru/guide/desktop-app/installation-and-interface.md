Эта глава предназначена для тех, кто впервые открыл настольное приложение ChatGPT. Цель — не запомнить все кнопки, а выполнить небольшую задачу, результат которой **можно просмотреть и проверить**.

Процесс установки и входа описан в разделе [Установка Desktop App](/ru/guide/getting-started/install-desktop-app/). Сейчас официальные версии доступны для macOS, Windows и Linux. После входа можно начать новый чат, создать проект или открыть локальную папку.

## Три основных объекта

| Объект | Для чего нужен | С чего начать новичку |
|---|---|---|
| Проект или папка | Предоставляет чату файлы и рабочий каталог | Откройте учебный репозиторий, а не производственный каталог |
| Чат | Хранит цель, контекст, ход работы и результат | Используйте отдельный чат для каждой чёткой цели |
| Codex | Читает, изменяет и проверяет содержимое проекта | Начните с небольшого, легко проверяемого изменения с низким риском |

Интерфейс приложения постоянно обновляется, но эти три объекта стабильнее расположения любой конкретной кнопки.

## Выполните первую реальную задачу

Подготовьте существующий репозиторий Git и убедитесь, что в нём нет незаписанных изменений, которые нужно сохранить. Затем откройте папку в приложении и создайте чат Codex.

Введите:

```text
Сначала прочитай README.md. Измени только раздел «Локальный запуск»:
1. исправь устаревшую команду запуска;
2. оставь остальные разделы без изменений;
3. после изменения покажи diff и выполни доступные команды проверки из документации;
4. если проверить результат нельзя, прямо укажи причину и не заявляй о завершении задачи.
```

После завершения не ограничивайтесь сводкой в чате. Проверьте:

1. В панели Review отображаются только ожидаемые файлы
2. Удалённое содержимое действительно следовало убрать
3. Вывод терминала действительно подтверждает вывод об успешной проверке
4. `git diff` соответствует области задачи

## Когда выбирать Chat, Work или Codex

- Чтобы задать вопрос или обсудить идею, используйте Chat.
- Для общей работы с несколькими файлами и инструментами используйте Work.
- Чтобы понять, изменить и протестировать репозиторий, используйте Codex.

Для разового вопроса, которому не нужен долговременный контекст, подойдёт Quick chat. Работу, которую нужно отслеживать в течение длительного времени, оставляйте в обычном чате или проекте.

## Что проверить при неудаче

- **Файлы не видны**: убедитесь, что открыта правильная папка и разрешение на выполнение задачи не отклонено.
- **Команда не запускается**: проверьте установку зависимостей, затем найдите первую реальную ошибку в терминале.
- **К изменениям примешано старое содержимое**: с помощью `git status` отделите изменения, существовавшие до задачи, от новых.
- **Интерфейс приложения отличается от описанного**: ищите логические объекты «проект/папка», «чат», «Review» и «терминал», а не фиксированное место на снимке экрана.

Далее изучите [Diff, комментарии и проверку](/ru/guide/desktop-app/diffs-comments-and-review/) и [Встроенный терминал](/ru/guide/desktop-app/integrated-terminal/).
