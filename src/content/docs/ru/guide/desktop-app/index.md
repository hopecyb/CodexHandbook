Desktop App — рекомендуемая точка входа для начинающих: проекты, задачи, diff и одобрения представлены наглядно.

Этот вариант особенно прост для тех, кто ещё не знаком с командной строкой или расширениями IDE.

Приложение предназначено не только для чата: проекты, изменения, одобрения и проверка результата собраны в одном видимом интерфейсе.

## Сначала найдите три основных элемента

Не нужно осваивать все функции сразу.  
Начните с трёх основных действий:

1. Найдите, где вводить задачу
2. Найдите, где просматривать изменения
3. Найдите, где одобрять или отклонять операции

Этого достаточно, чтобы впервые пройти полный базовый цикл задачи.

## Распространённые заблуждения

### 1. Desktop App — лишь графическая оболочка CLI?

Приложение наглядно показывает несколько ключевых частей совместной работы:

- текущую задачу;
- план и вызовы инструментов;
- изменения файлов;
- действия одобрения;
- проверку результата.

### 2. Нужно разобраться во всех кнопках до начала работы?

Для старта достаточно знать:

- где вводится задача;
- где находится diff;
- где одобрять и отклонять действия.

### 3. Если Desktop App подходит новичкам, значит, для серьёзной работы он не годится?

В Desktop App можно выполнять и полноценные рабочие задачи — особенно когда важны наглядная проверка и прозрачность процесса.

## Порядок знакомства

При первом запуске Desktop App действуйте так:

1. Установите приложение и познакомьтесь с интерфейсом
2. Выберите правильный проект
3. Начните с небольшой задачи
4. Просмотрите изменения
5. Научитесь одобрять и отклонять действия
6. Затем переходите к более сложным возможностям: параллельным Agent, Worktree и облачным задачам

Так освоить приложение проще, чем пытаться сразу изучить все функции.
