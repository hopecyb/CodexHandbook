Более полный список приведён в [глоссарии](/ru/guide/reference/glossary/). Здесь собраны самые частые термины, которые сильнее всего влияют на понимание остальных материалов.

При первом знакомстве с руководством по Codex больше всего мешает высокая плотность новых названий. Каждое слово по отдельности может казаться понятным, но их сочетание легко сбивает с толку.

Обычно возникают две ситуации:

- вы понимаете слова, но не знаете, что они означают на практике;
- вы не знаете, какие термины нужны уже сейчас, а какие можно отложить.

Не воспринимайте это как экзамен по терминологии. Достаточно в общих чертах понимать смысл слов, чтобы не останавливаться на каждом из них при чтении.

## Первые термины, которые стоит знать

Если ваша текущая цель — просто выполнить первую задачу, начните с этих шести понятий:

| Термин | Почему важно знать его сначала |
|---|---|
| **Промпт** | Как ясно описать задачу |
| **Контекст** | Какая информация сейчас доступна Codex |
| **Agent** | Почему Codex не ограничивается текстовым ответом |
| **Согласование** | Почему иногда Codex останавливается и спрашивает вас |
| **Различия (diff)** | Как проверить, что именно изменилось |
| **Задача** | Основная единица законченной работы |

| Термин | Простое объяснение |
|---|---|
| **Промпт (prompt)** | Цель, исходные сведения и требования, которые вы передаёте Codex |
| **Контекст (context)** | Доступная модели информация о проекте, файлах и диалоге |
| **Agent** | Способ выполнения, при котором для достижения цели вызываются инструменты, а работа итеративно продвигается вперёд |
| **Инструмент (tool)** | Доступная возможность: чтение файлов, выполнение команд, поиск и другие действия |
| **Песочница (sandbox)** | Среда выполнения, ограничивающая воздействие на файловую систему и сеть |
| **Согласование (approval)** | Явное разрешение, необходимое для продолжения некоторых действий |
| **Различия (diff)** | Сравнение содержимого до и после изменения для вашего Review |
| **Тред / сеанс** | Непрерывный диалог вместе с накопленным контекстом |
| **Задача** | Единица работы с определённой целью, которая может включать несколько вызовов инструментов |
| **Skill** | Повторно используемый набор специальных инструкций и ресурсов; продвинутый уровень |
| **MCP** | Протокол подключения внешних инструментов и источников данных; продвинутый уровень |
| **Задача Cloud** | Задача, выполняемая в облачной среде, а не в локальной песочнице |

## Ещё проще

- **Промпт**: слова, которыми вы ставите задачу.
- **Контекст**: материалы, доступные Codex в данный момент.
- **Agent**: Codex не просто отвечает текстом, а действительно продвигает работу к результату.
- **Согласование**: некоторые действия Codex не может выполнить без вашего разрешения.
- **diff**: сравнение до и после изменения.
- **Skill**: упакованный способ повторно применять один и тот же процесс.

## Как пользоваться этим списком

Встретив эти слова на других страницах, не нужно каждый раз останавливаться и искать определение:

- если общий смысл понятен, продолжайте чтение;
- если термин встречается постоянно, но остаётся неясным, вернитесь сюда;
- если он мешает понять процесс, откройте соответствующий тематический раздел.

## Удобные группы

Если не хочется запоминать всё сразу, сгруппируйте понятия так:

- что вы говорите: промпт;
- что видит Codex: контекст;
- как Codex действует: Agent и инструменты;
- что Codex разрешено: согласования и песочница;
- как вы проверяете: diff и результат задачи.

## Эти термины можно изучить позже

Следующие понятия в основном относятся к продвинутому уровню, и в начале разбираться в них необязательно:

- Skill
- MCP
- Hook
- Plugin
- подробности среды Cloud

Сначала [выполните первую задачу](/ru/guide/getting-started/run-your-first-task/), а затем вернитесь к этим терминам — обычно тогда они становятся понятнее.

Если встретите незнакомое слово, найдите его здесь и продолжайте чтение.

При первом знакомстве с руководством воспринимайте термины как подсказки. Понимать их общий смысл гораздо практичнее, чем пытаться сразу выучить всё наизусть.
