| Термин | Определение |
|---|---|
| Agent | Способ двигаться к цели, вызывая инструменты и повторяя шаги |
| Подтверждение | Подтверждение человеком перед высокорисковым действием |
| Diff | Представление, сравнивающее состояние до и после изменения |
| Задача Cloud | Задача, выполняемая в облачной среде |
| Контекст | Информация, доступная модели в данный момент |
| Компактизация | Сводка длинного контекста для освобождения места в окне |
| Hook | Пользовательская логика, выполняемая в точке жизненного цикла (продвинутый уровень) |
| MCP | Протокол для подключения внешних инструментов и данных (продвинутый уровень) |
| Промпт | Текст, описывающий для Agent цель и требования |
| Песочница | Изоляция выполнения, ограничивающая область возможных последствий |
| Skill | Повторно используемый пакет специализированных инструкций и ресурсов (продвинутый уровень) |
| Поток | Продолжающийся диалог и накопленный в нём контекст |
| Токен | Единица измерения текста, обрабатываемого моделью |
| Worktree | Изолированный рабочий каталог для параллельных экспериментов |

Версия для новичков приведена в разделе [«Термины для начинающих»](/ru/guide/start-here/terminology-for-beginners/).

## Как пользоваться

Это краткий словарь, а не полный учебник. Если на другой странице встретился непонятный термин, найдите его здесь и вернитесь к чтению.

Если большинство терминов незнакомы, начните с раздела [«Термины для начинающих»](/ru/guide/start-here/terminology-for-beginners/).

## Распространённые заблуждения

### 1. Не нужно запоминать всё от начала до конца

Обычно вы встречаете слово в другом месте, находите его здесь и продолжаете читать исходную страницу.

### 2. Понять краткое определение — ещё не значит научиться применять понятие

Глоссарий помогает распознать идею. Для практического применения прочитайте тематическую главу и примеры.

### 3. Множество новых терминов не мешает продолжать обучение

В Codex есть непривычная лексика. Сначала усвойте общее значение, а подробности добавляйте постепенно.

## Что делать с незнакомым термином

1. Найдите краткое определение.
2. Определите общий тип понятия.
3. Откройте соответствующую тематическую страницу с полным объяснением.

Так одно слово не прервёт чтение надолго.
