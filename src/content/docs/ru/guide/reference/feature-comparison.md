В этой таблице сравниваются только **стабильные основные процессы**. Быстро меняющиеся небольшие функции не превращаются в постоянные обещания. Сначала выберите вариант по [схеме выбора клиента](/ru/guide/choose-your-client/), затем уточните различия здесь.

## Основное сравнение

| Точка входа | Где выполняется работа | Наиболее полный контекст | Основной способ Review | Типичные задачи |
|---|---|---|---|---|
| ChatGPT Desktop App | Локальные проекты, чаты и файлы | Открытые папки, проекты и задачи | Сводка задачи, файлы, diff и интерфейс подтверждения | Координация нескольких проектов, длительные задачи, операции с файлами и компьютером |
| Codex CLI | Текущий терминал и локальный репозиторий | Рабочий каталог, вывод команд и состояние Git | Команды терминала, diff и сводка результата | Исследование, редактирование, тестирование, скрипты и CI |
| Интеграция с IDE | Текущий редактор | Открытые файлы, выделение и недавний диалог | Сводка изменений и diff рядом с кодом | Локальные объяснения, пошаговые правки и Review в редакторе |
| Codex Cloud | Изолированная удалённая среда | Подключённый репозиторий и конфигурация окружения | Журналы Cloud, сводка, diff и PR | Длительные фоновые задачи, параллельные попытки и удалённая совместная работа |

## Установка и идентификация

| Пункт | Desktop App | CLI | IDE | Cloud |
|---|---|---|---|---|
| Точка входа | Desktop App для macOS / Windows / Linux | Локальная командная строка | Расширение для редакторов, совместимых с VS Code; отдельные интеграции Xcode и JetBrains | Веб и поддерживаемые удалённые интеграции |
| Вход через ChatGPT | Поддерживается | Поддерживается | Поддерживается | Обязателен |
| Локальный вход по API-ключу | Поддерживается | Поддерживается | Поддерживается | Не поддерживается |
| Основная тарификация | План ChatGPT или использование API | План ChatGPT или использование API | План ChatGPT или использование API | План ChatGPT и разрешения рабочей области |

Локальная работа с входом по API-ключу подчиняется другим правилам тарификации, администрирования и обработки данных, чем вход через ChatGPT. API-ключи также не дают возможностей рабочей области ChatGPT или Cloud. Актуальные планы и лимиты проверяйте на официальных страницах.

## Распространённые сочетания

### Личный цикл разработки

```text
IDE находит локальную проблему → CLI запускает точный тест → Desktop App проверяет длительную работу и diff
```

### Удалённый командный цикл

```text
Начало в GitHub / GitLab / Linear / Slack → выполнение в изолированной Cloud
→ человек проверяет сводку и diff → создаётся PR
```

### Учебный цикл для начинающих

```text
Открыть учебную папку в Desktop App → запросить небольшую задачу
→ изучить запрос разрешения → изучить diff → выполнить проверку
```

## Не заменяйте матрицей проверку реальности

Plugin, Scheduled tasks, уведомления, модели и политики организации быстро развиваются. В текущем клиенте и официальной документации проверьте:

- доступна ли функция этой учётной записи;
- не ограничена ли она планом, регионом или политикой администратора;
- актуальные имена команд, сочетаний клавиш и элементов интерфейса;
- поддерживает ли вход по API-ключу конкретную функцию ChatGPT или Cloud.

Сохраняйте простое правило: **IDE — для локального кода, CLI — для циклов в терминале, Desktop App — для координации локальных задач, Cloud — для изолированного удалённого выполнения.**
