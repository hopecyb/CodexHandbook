В Cloud есть два разных этапа сетевого доступа:

| Этап | Поведение по умолчанию | Основное назначение |
|---|---|---|
| setup script | Сеть доступна | Установка зависимостей и инструментов |
| Agent phase | Отключена | Доступ Agent к внешним ресурсам во время задачи |

Поэтому успешный `pnpm install` на этапе setup не означает, что Agent затем сможет выполнить `curl` для произвольного сайта.

## Почему доступ по умолчанию отключён

Сетевой доступ Agent повышает риск инъекции в промпт, утечки кода или данных, вредоносных зависимостей и добавления в репозиторий содержимого с несовместимой лицензией. Недоверенный issue, веб-страница или README зависимости могут содержать инструкции, побуждающие Agent выполнить команду утечки данных.

Основной принцип: открывайте только необходимые задаче адреса и действия и проверяйте рабочий журнал.

## Настройки

Доступ Agent к интернету настраивается для каждой среды:

- **Off**: полностью запретить Agent доступ к сети;
- **On**: разрешить сеть с возможностью ограничить домены и методы HTTP.

Список доменов можно начать пустым, применить предустановку Common dependencies или выбрать All (unrestricted). В производственном репозитории не используйте unrestricted как быстрый способ устранения неполадок.

Если задача требует только чтения документации или загрузки содержимого, разрешите лишь методы HTTP `GET`, `HEAD` и `OPTIONS`. Это блокирует `POST`, `PUT`, `PATCH`, `DELETE` и другие методы, с помощью которых можно отправить или изменить данные.

## Пример минимального доступа

Задаче нужно обратиться к документации публичного API:

1. Оставьте Off и убедитесь, что ошибка действительно вызвана сетью;
2. Включите Agent access;
3. Добавьте в allowlist только официальный домен этого API;
4. Разрешите лишь `GET`, `HEAD` и `OPTIONS`;
5. Повторите запуск и проверьте в журнале все исходящие запросы;
6. После задачи решите, следует ли вернуть Off.

## Важная связь с Secret

Secret Cloud удаляется до этапа Agent, что снижает риск его прямой отправки из setup. Однако обычные переменные среды, содержимое репозитория и данные, созданные задачей, всё ещё могут быть отправлены наружу. Не маскируйте чувствительные значения под обычные переменные ради обхода жизненного цикла Secret.

## Контрольный список приёмки

- [ ] Объяснено, почему этапу Agent необходим сетевой доступ
- [ ] Allowlist содержит только необходимые домены
- [ ] Методы HTTP ограничены минимальным набором
- [ ] Источники входных данных доверенные или риск инъекции в промпт учтён
- [ ] В журнале нет команд отправки репозитория, среды или учётных данных
- [ ] Проверены источник, версия и лицензия новых зависимостей
