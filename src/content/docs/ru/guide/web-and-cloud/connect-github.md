Чтобы создать среду для репозитория в Codex Cloud, сначала подключите GitHub или GitLab (Beta). Область подключения GitHub определяет, какие репозитории доступны Codex; локальный clone и неотправленные изменения в неё не входят.

## Подключение

1. Откройте Codex Cloud и войдите с учётной записью ChatGPT;
2. Подключите GitHub по подсказке;
3. На странице авторизации GitHub выберите организацию и **только необходимые репозитории**;
4. Вернитесь в Codex, выберите репозиторий и создайте среду Cloud;
5. Проверьте clone, ветку и diff с помощью задачи только для чтения или небольшого изменения;
6. Если требуется PR review, включите Code review для репозитория в Codex Settings.

Предоставляйте доступ только к репозиториям, необходимым для текущей работы. Для командного репозитория также убедитесь, что организация разрешает установить интеграцию, у текущей учётной записи есть нужные полномочия, а защита веток остаётся включённой.

## Проверки до и после подключения

- [ ] Выбран целевой репозиторий, а не одноимённый fork
- [ ] Подтверждены ветка по умолчанию и начальная точка задачи
- [ ] Необходимые локальные изменения отправлены через push или явно исключены из задачи
- [ ] Прямая непроверенная запись в основную ветку запрещена
- [ ] В среде нет производственных учётных данных с полным доступом
- [ ] Первая задача меняет только низкорисковые файлы

## Два способа работы с GitHub

### Реализация задачи в Cloud

Выберите в Codex Cloud среду репозитория и начальную ветку, затем опишите цель. После завершения проверьте diff и создайте PR.

### Review PR с помощью Codex

После включения Code review для репозитория оставьте комментарий в PR:

```text
@codex review
```

Codex опубликует стандартный GitHub review. Автоматический Review включается отдельно в Codex Settings; команда может записать специальные правила репозитория в разделе `## Code Review Rules` файла `AGENTS.md`.

## Как диагностировать проблемы разрешений

- Репозитория нет в списке: проверьте область репозиториев в авторизации GitHub;
- Для репозитория организации возвращается 403: проверьте политику организации, SSO и разрешение на установку;
- Автоматический Review нельзя включить: убедитесь, что у вас есть необходимые разрешения GitHub push или admin;
- Cloud не видит локальный commit: checkout выполняется только из удалённого репозитория, поэтому сначала отправьте commit в явно указанную ветку.

Не предоставляйте доступ ко всем частным репозиториям ради устранения одной ошибки 403. Сначала установите целевой репозиторий и конкретное недостающее разрешение.
