Основным результатом работы Codex часто становятся **изменения файлов в репозитории** или **новые артефакты** — документы, изображения и конфигурация. В этом разделе приведены рекомендации для разных типов файлов, чтобы избежать ситуации «файл создан, но использовать его нельзя».

К разным типам файлов нужны разные требования и способы приёмки.

«Изменить код», «обработать таблицу», «сделать снимок экрана» и «экспортировать PPT» — всё это файловые задачи, но ошибки в них возникают в разных местах.

## О чём эта глава

Здесь рассматриваются три основных вопроса:

- Как ясно поставить задачу
- Где Codex чаще всего может незаметно ошибиться
- Как выполнить окончательную приёмку

Поэтому это скорее набор практических инструкций для разных типов файлов, чем простой перечень функций.

## Общие принципы

1. **Точный путь**: укажите в промпте путь вывода и правила именования
2. **Согласованный формат**: расширение, кодировка (UTF-8) и окончания строк должны соответствовать проекту
3. **Контроль размера**: не помещайте крупные двоичные файлы в Git либо используйте LFS/CDN
4. **Ручная приёмка**: создание ≠ завершение; сверяйтесь с [критериями завершения](/ru/guide/quality/definition-of-done/)
5. **Конфиденциальные данные**: см. [Конфиденциальный контекст](/ru/guide/context/sensitive-context/)

## Распространённые заблуждения

### 1. Созданный файл ещё не означает завершённую задачу

Проблема файловых задач часто не в том, создан ли файл, а в следующем:

- Верен ли формат
- Точно ли содержимое
- Правильно ли выбран путь
- Можно ли использовать файл на следующем этапе

### 2. Для всех типов файлов требования примерно одинаковы?

Нет. Например:

- Для кода важнее область, логика и тесты
- Для таблиц — столбцы, типы и правила агрегации
- Для изображений — визуальное содержимое и размеры
- Для документов — структура, тон и факты

### 3. Если файл открывается, значит всё в порядке?

Нет.  
Открытие — только самый базовый уровень проверки. Оно не доказывает, что файл готов к коммиту, публикации или передаче.

## Рекомендуемый порядок чтения

Если вы впервые поручаете Codex работу с файлами:

1. Найдите тип файла, наиболее близкий к текущей задаче
2. Изучите типичные ошибки для этого формата
3. Затем прочитайте о соответствующем способе приёмки

Так вам не придётся сразу разбираться со всей главой целиком.
