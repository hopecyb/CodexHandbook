**Agent** непрерывно движется к цели: понимает её → выбирает инструмент → наблюдает результат → корректирует следующий шаг, пока не завершит работу или не потребуется ваше участие.

Обычный AI больше похож на человека, который отвечает на вопросы, а Agent — на человека, который получает задачу и выполняет её шаг за шагом.

![Иллюстрация: слева обычный чат с вопросом и ответом, справа цикл работы Agent — чтение файла, применение инструмента, проверка результата и изменение материала](/illustrations/agent-basics.webp)

## Различия между Agent и обычным чатом

| | Обычный чат | Agent |
|---|---|---|
| Результат | В основном текстовые рекомендации | Может читать и записывать файлы, выполнять команды и изменять репозиторий |
| Процесс | Один ответ | Несколько вызовов инструментов |
| Риски | Ошибочные рекомендации | Может также повредить файлы или выполнить опасную команду |
| Ваша роль | Читать | Задавать границы, согласовывать действия и принимать результат |

## Простая аналогия

Сравнить их можно так:

- **Обычный чат**: вы спрашиваете друга, как решить задачу.
- **Agent**: вы просите коллегу подготовить первый вариант, а затем проверяете его вместе.

Поэтому в режиме Agent особенно важно понимать:

- к чему он имеет доступ;
- должен ли он сначала предложить план;
- как вы проверите работу после завершения.

## Почему важно различать эти режимы

Многие ошибки начинаются с одного заблуждения:

> Кажется, будто Codex «только говорит».

Как только он начинает читать и изменять файлы или выполнять команды, это уже не просто рекомендация в окне чата, а участие в реальной работе.
