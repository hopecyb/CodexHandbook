При первом знакомстве с разделом конфигурации легко решить, что он посвящён лишь множеству имён параметров.

На самом деле он решает один основной вопрос: как Codex должен работать по умолчанию, чтобы не повторять настройки в каждом сеансе.

## Рекомендуемый порядок

1. [Основы конфигурации](/ru/guide/customization/configuration/config-basics/)
2. [Profile](/ru/guide/customization/configuration/profiles/)

## Какие вопросы решает раздел

- Какие предпочтения следует записывать в файл конфигурации
- Когда создавать несколько Profile
- Почему некоторые ограничения должны обеспечиваться правилами или подтверждениями, а не только пояснением в конфигурации

Конфигурация лучше подходит для поведения по умолчанию и стабильных предпочтений. Она не заменяет подтверждения, правила и инструкции проекта.
