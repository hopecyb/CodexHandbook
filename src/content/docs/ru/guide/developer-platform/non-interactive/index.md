Услышав выражение «неинтерактивный режим», многие сначала представляют себе «Codex без чата».

Неинтерактивный режим позволяет включать Codex в скрипты, CI и пакетные задания, чтобы одна команда выполняла одну стабильную задачу.

## Рекомендуемый порядок

1. [`codex exec`](/ru/guide/developer-platform/non-interactive/codex-exec/)
2. [Скрипты и конвейеры](/ru/guide/developer-platform/non-interactive/scripts-and-pipelines/)
3. [Структурированный вывод](/ru/guide/developer-platform/non-interactive/structured-output/)
4. [Коды завершения и повторные попытки](/ru/guide/developer-platform/non-interactive/exit-codes-and-retries/)

## Какие задачи решает этот раздел

- Превращение отдельной задачи в шаг CLI
- Определение успеха, сбоя и необходимости повтора в CI
- Подготовка вывода, удобного для последующих скриптов

Этот режим подходит, когда скриптам и конвейерам нужна стабильная передача результата, а не диалог с уточнениями.
