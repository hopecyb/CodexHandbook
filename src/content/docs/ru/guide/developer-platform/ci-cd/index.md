При подключении Codex к CI/CD чаще всего ошибаются, пытаясь с первого дня поручить ему автоматическое редактирование, отправку изменений и слияние.

Обычно лучше начать с режима только для чтения: исключительно рекомендации и отчёты.

## Страница раздела

- [Автоматизация Code Review](/ru/guide/developer-platform/ci-cd/code-review-automation/)

## О чём этот раздел

- Структурированная проверка на этапе PR
- Сначала автоматический поиск проблем и предложения исправлений
- Подтверждение человеком для действий с высоким риском

Подключение Codex к CI/CD обычно начинается с низкорисковой помощи. Затем команда решает, какие действия действительно стоит делегировать.
