Есть два типа точек входа в IDE, и способы установки для них не взаимозаменяемы:

| Редактор | Текущая точка входа | Как открыть |
|---|---|---|
| Visual Studio Code, Cursor, Windsurf, VS Code Insiders | Расширение Codex | Нажать значок Codex или выполнить `Codex: Open Codex Sidebar` |
| Xcode | Встроенная интеграция coding assistant в Xcode | Создать чат и выбрать Codex agent |
| JetBrains IDEs | Интеграция JetBrains AI Chat | Открыть AI Chat и выбрать Codex |

Полный список поддерживаемых вариантов и официальные точки входа приведены в разделе [Поддерживаемые редакторы](/ru/guide/ide/supported-editors/).

## Установка и проверка в редакторах на основе VS Code

1. Установите расширение Codex по официальной ссылке Marketplace;
2. Откройте учебный проект, а не пустое окно;
3. Нажмите значок Codex; если его нет, выполните `Codex: Open Codex Sidebar` из палитры команд;
4. Выполните аутентификацию с учётной записью ChatGPT или API key;
5. Создайте чат, добавьте ссылку на открытый файл и задайте вопрос только для чтения.

Минимальный промпт для проверки:

```text
Только прочитай открытый сейчас файл, не изменяя код.
В трёх пунктах опиши его назначение, входные и выходные данные; в каждом пункте приведи конкретное имя символа.
```

Если ответ соответствует текущему файлу и символам, контекст редактора передаётся правильно. Перед первой задачей с записью создайте контрольную точку Git.

## Частые проблемы

- **Боковая панель не находится**: выполните `Codex: Open Codex Sidebar` из палитры команд.
- **Неверный контекст**: убедитесь, что окно проекта, текущий файл и выделение относятся к ожидаемому репозиторию.
- **Вход запрашивается снова и снова**: CLI и IDE используют общий кеш аутентификации; проверьте текущую учётную запись и войдите повторно.
- **Инструменты Windows находятся в WSL**: при необходимости включите `chatgpt.runCodexInWindowsSubsystemForLinux`; изменение настройки перезагрузит VS Code.
- **Сторонний редактор ведёт себя иначе**: сначала проверьте совместимость его версии с расширением VS Code и не переносите напрямую инструкции для Xcode или JetBrains.

Более подробные шаги для начинающих см. в разделе [Установка расширения IDE](/ru/guide/getting-started/install-ide-extension/).
