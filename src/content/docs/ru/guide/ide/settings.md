В IDE есть два уровня настроек:

| Уровень | Где хранится | За что отвечает |
|---|---|---|
| Настройки Codex Agent | `config.toml` | Модель, интенсивность рассуждений, разрешения, песочница, MCP и персонализация; используются совместно с CLI |
| Настройки редактора | `chatgpt.*` в системе настроек VS Code | Боковая панель, очередь сообщений, клавиша отправки, отображение Review, язык и шрифты |

Правила репозитория по-прежнему следует хранить в `AGENTS.md`, а не в личных настройках редактора.

## Как открыть настройки

Нажмите шестерёнку на боковой панели Codex и выберите **Codex Settings**. Часто используемые параметры Agent можно изменить прямо на панели или выбрать **Open config.toml**, чтобы отредактировать активный уровень конфигурации.

Для настроек поведения редактора найдите в Settings значение `@ext:openai.chatgpt`, `Codex` или конкретное имя ключа.

## Настройки, которые стоит понять в первую очередь

| Ключ | Значение по умолчанию | Когда менять |
|---|---:|---|
| `chatgpt.openOnStartup` | `false` | Если при запуске расширения нужно автоматически переводить фокус на боковую панель |
| `chatgpt.followUpQueueMode` | `queue` | При значении `steer` новое сообщение направляет текущий запуск |
| `chatgpt.composerEnterBehavior` | `enter` | Если многострочные промпты часто отправляются случайно |
| `chatgpt.reviewDelivery` | `inline` | Задайте `detached`, чтобы выводить `/review` в отдельном чате |
| `chatgpt.localeOverride` | Автоматически | Если нужно зафиксировать язык интерфейса |
| `chatgpt.runCodexInWindowsSubsystemForLinux` | `false` | Включите, если репозиторий и инструменты находятся в WSL2 |

`chatgpt.cliExecutable` предназначен только для разработки Codex CLI. Обычным пользователям не следует вручную заменять встроенный исполняемый файл расширения, иначе часть функций может перестать работать.

## Как понимать приоритет конфигурации

- Политика организации задаёт предел, который нельзя превысить;
- `config.toml` определяет поведение Agent по умолчанию;
- `AGENTS.md` содержит правила репозитория и каталогов;
- Настройки редактора меняют только работу в IDE;
- Однократный промпт добавляет цель и границы текущей задачи.

Если настройка «не применяется», сначала определите, какой уровень вы изменили, а затем проверьте, не ограничен ли он политикой более высокого уровня. Подробности см. в разделе [Область действия и приоритет](/ru/guide/customization/agents-md/scope-and-precedence/).

## Проверка после изменения

Меняйте по одному параметру. Например, после установки `chatgpt.reviewDelivery` в `detached` выполните `/review` в репозитории Git и убедитесь, что открылся отдельный чат Review. Запишите исходное значение; если результат отличается от ожидаемого, восстановите его и перезагрузите редактор.
