Сейчас Codex подключается к популярным редакторам по-разному: семейство VS Code использует расширение Codex, а Xcode и JetBrains IDE — собственные точки интеграции.

## Поддерживаемые варианты

| Редактор | Точка входа Codex | Как открыть |
|---|---|---|
| Visual Studio Code | Расширение Codex | Значок Codex или `Codex: Open Codex Sidebar` |
| Cursor | Совместимое расширение Codex | Значок Codex или Command Palette |
| Windsurf | Совместимое расширение Codex | Значок Codex или Command Palette |
| Visual Studio Code Insiders | Расширение Codex | Панель расширений и боковая панель Codex |
| Xcode | Интеграция Xcode coding assistant | Создать чат и выбрать Codex Agent |
| JetBrains IDEs | Интеграция JetBrains AI Chat | Открыть AI Chat и выбрать Codex |

Точки установки и минимальные версии могут меняться. Всегда переходите с [официальной страницы Codex IDE](https://learn.chatgpt.com/docs/codex/ide) и не считайте стороннее расширение официально поддерживаемым только из-за похожего названия.

## Для чего лучше всего подходит IDE

- Непосредственно добавлять в вопрос открытый файл или выделение
- Объяснять и изменять локальный код с последующими уточнениями
- Проверять сводку и изменения рядом с исходным кодом
- Выполнять небольшие задачи локально, а разросшиеся делегировать более длительному процессу

Пример:

```text
Проверь цикл повторных попыток в текущем выделении.
Сначала объясни условие завершения, затем внеси минимальное изменение; меняй только текущий файл и соответствующие тесты.
После завершения сообщи diff и команды тестирования, не обновляя зависимости.
```

## Как сохранить единообразие в команде с разными редакторами

1. Запишите команды сборки, тестирования и форматирования в `AGENTS.md` репозитория или в руководство для участников.
2. Ограничивайте область файлов в промпте, не полагаясь на уникальную кнопку конкретной IDE.
3. Для итоговой приёмки проверяйте Git diff и один и тот же набор тестов, а не только то, что «в моей IDE всё запускается».
4. Создавайте отдельные инструкции для каждой IDE, только когда нужны точные указания по интерфейсу.

## Редакторы вне списка

Используйте [Codex CLI](/ru/guide/cli/) или [Desktop App](/ru/guide/desktop-app/). Не устанавливайте пакет расширения VS Code в несовместимый редактор и не воспринимайте стороннюю интеграцию как официальную возможность OpenAI по умолчанию.

Инструкции по установке см. в разделе [Установка интеграции с IDE](/ru/guide/getting-started/install-ide-extension/), а работу с контекстом — в разделе [Контекст редактора](/ru/guide/ide/editor-context/).
