Веб-поиск подходит для уточнения фактов, но не должен принимать окончательное решение вместо вас.

Подходящие задачи: поиск публичной документации, кодов ошибок и примечаний к версиям. Неподходящая задача: принимать результаты поиска за окончательное юридическое или медицинское заключение.

Требуйте указывать источники и самостоятельно открывайте их для проверки. Используйте поиск вместе с [проверкой источников](/ru/guide/quality/validate-sources/).

## Для чего подходит поиск

Поиск прежде всего помогает определить:

- Где искать сведения
- Какие данные стоит проверить подробнее
- Есть ли более авторитетный источник

Его задача — найти материалы, после чего нужно открыть и проверить оригинал.

## Распространённые заблуждения

### 1. Если результат найден, ответ надёжен?

Нет. Наличие результата не гарантирует достоверность, а гладко написанная сводка — точность.

### 2. Когда стоит использовать поиск?

Типичные сценарии:

- Найти официальную документацию
- Проверить сообщение об ошибке
- Узнать об изменениях между версиями
- Проверить факт на общедоступной веб-странице

### 3. Можно ли сразу цитировать сводку из результатов поиска?

Не спешите. Действуйте так:

1. Посмотрите, какие источники представлены в результатах
2. Откройте исходные страницы
3. Изложите сведения своими словами

### 4. Когда одного поиска недостаточно?

Не полагайтесь только на поиск, если:

- Требуется высокорисковое юридическое, медицинское или финансовое решение
- Необходимо проверить фактическое поведение страницы
- Нужно изучить локальные файлы проекта, а не сведения в интернете

В таких случаях используйте другие инструменты или ручную проверку.

## Порядок поиска

Работайте в следующей последовательности:

1. Найдите ключевые слова, наиболее близкие к вопросу
2. Отдавайте предпочтение официальной документации и первичным источникам
3. Откройте оригинал и проверьте подробности
4. Только затем решайте, включать ли вывод в результат

## Готовый промпт

Можно добавить такую строку:

```text
Сначала выполни поиск, отдавая приоритет официальным источникам. Вместе с выводом приведи кликабельные ссылки на источники, а не только поисковую сводку.
```

Поиск предоставляет ориентиры и источники, но окончательные сведения всё равно нужно сверять с оригиналом.
