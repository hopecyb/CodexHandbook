## Предварительные условия

Второй шаг завершён. В `facts.md` перечислено семь пронумерованных фактов, а в `notice.md` уже есть комментарий о неопубликованном состоянии.

## Подготовка уведомления по ясным критериям

```text
Используя только facts.md из этого каталога, приведи notice.md к виду уведомления о мероприятии.
Сохрани комментарий о состоянии «учебный черновик, не опубликовано».
Укажи время, место, число участников, стоимость, необходимые приготовления и раздел «Требует уточнения».
Для каждого факта укажи соответствующий номер F; неизвестную информацию оставь неизвестной,
не добавляй QR-код, телефон или ссылку для регистрации.
Изменяй только notice.md; не меняй facts.md и private-note.md, не создавай файлы,
не подключайся к сети, ничего не публикуй и не отправляй.
После завершения перечисли изменения и основания для них; если материалы противоречат друг другу, опиши противоречие и оставь вопрос открытым.
```

Цель — проверяемое уведомление, контекст — вымышленное учебное мероприятие, входные данные — facts.md, а граница — изменение только notice.md. Критерии приёмки конкретно описывают содержимое и файлы вместо расплывчатой просьбы «сделать профессиональнее».

## Критерии завершения

Время — 17 октября 2026 года с 14:00 до 15:30, место — вымышленный читальный зал из материалов, число участников — 18, участие бесплатное, книгу можно принести по желанию; способ регистрации остаётся неизвестным. По очереди проверьте, действительно ли каждый номер источника подтверждает соответствующее предложение.

Сначала проведите собственную проверку, затем посмотрите [авторское эталонное уведомление](/downloads/first-project/references/notice.md). Стиль может отличаться, но факты, открытые вопросы и область изменений должны совпадать. Если найдена ошибка, исправьте только конкретную проблему и не позволяйте модели переписывать файл фактов под готовый результат.
