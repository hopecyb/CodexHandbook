## Предварительные условия

Первый шаг завершён, а в `work` по-прежнему находятся три исходных файла. Папка `starter` за пределами рабочего каталога сохранена как базовая версия.

## Проверяемое изменение

```text
Только в первой строке notice.md добавь следующий комментарий о состоянии:
<!-- Статус: учебный черновик, не опубликовано -->
Сохрани исходный основной текст дословно. Не меняй другие файлы и не создавай новые.
После завершения укажи место изменения, не публикуй и не отправляй уведомление.
```

С помощью представления различий текущего клиента или редактора построчно сравните файл с оригиналом. Здесь требуется только одно небольшое изменение; дополнительный процесс «сначала спланировать, затем подтверждать каждый шаг» не нужен.

## Критерии завершения

Изменён только notice.md, и добавлена ровно одна строка комментария; два других файла остались прежними. Сверьтесь с [результатом второго шага](/downloads/first-project/references/step-2-notice.md). Комментарий может быть скрыт при отображении Markdown, поэтому просмотрите исходный текст файла.

Если модель изменила основной текст, восстановите notice.md из оригинала в starter и повторите этот шаг. Восстанавливайте только учебный файл, не сбрасывая весь проект. Связанные приёмы описаны в разделе [Отмена и восстановление](/ru/guide/getting-started/undo-and-recover/).
