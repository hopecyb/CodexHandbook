Маршруты обучения **только задают порядок** и не копируют большие материалы из руководства по продукту или тематических разделов.

При первом знакомстве глава «Маршруты обучения» может показаться ещё одним уровнем каталога. На самом деле она отвечает на два вопроса: на какую группу пользователей вы сейчас больше всего похожи и в каком порядке читать материалы дальше.

Новых знаний эта глава почти не добавляет — её задача помочь вам избежать лишних шагов.

![Иллюстрация: от одной книги расходятся четыре дороги — для начинающих, авторов, разработчиков и команд — и снова сходятся на вершине горы](/illustrations/learning-paths.webp)

## Для чего нужна эта глава

- Какой маршрут выбрать: начинающего, автора, разработчика или руководителя внедрения в команде
- Чем различается порядок чтения для разных ролей
- Какие материалы нужны сейчас, а какие можно изучить позже

## Единый практический маршрут для начинающих

[Загрузите общий набор материалов с уведомлением о мероприятии](/downloads/first-project/first-project-1.0.0.zip) и за пять шагов подготовьте уведомление, проведите Review и запишите восстановление. Программирование не требуется; независимые читатели пока не проходили маршрут целиком.

## Практический маршрут для авторов

[Маршрут для авторов](/ru/guide/learning-paths/creator/) состоит из четырёх последовательных этапов: материалы и таблица фактов → статья с источниками → редактируемая презентация из восьми слайдов → повторно используемое описание задачи. Для статьи и презентации доступны отдельные материалы, а у каждого шага есть критерии завершения; независимые читатели пока не проходили весь маршрут.

## Практический маршрут для разработчиков

[Маршрут для разработчиков](/ru/guide/learning-paths/developer/) использует учебную ошибку корзины покупок и последовательно проводит через чтение кода → исправление и тестирование → Review различий → организацию передачи. Доступны три заполняемых шаблона и авторская справка. Эталонные тесты выполнены повторно, но прохождение независимым читателем ещё не проверялось.

## Маршрут для команд: двухнедельный пилот и решение о развёртывании

- [Команда](/ru/guide/learning-paths/team/): устав → ручная проверка → выборочный контроль → учебный откат → решение о развёртывании, продолжении или остановке; включены шесть шаблонов.

## Маршрут для продвинутых пользователей

Если вы уже умеете выполнять небольшие задачи, следующий шаг — не запоминать больше команд, а научиться объединять возможности в устойчивый рабочий процесс:

| Шаг | Тема | Сначала прочитайте |
|---|---|---|
| 1 | Быстрые точки входа | [Команды с косой чертой и быстрые действия](/ru/guide/reference/slash-commands/) |
| 2 | Постоянный контекст | [AGENTS.md](/ru/guide/customization/agents-md/) и [Память и постоянный контекст](/ru/guide/customization/memories-and-persistent-context/) |
| 3 | Повторно используемые процессы | [Обзор Skills](/ru/skills/overview/) и [Структура Skill](/ru/skills/skill-anatomy/) |
| 4 | Независимые подзадачи | [Дочерний Agent](/ru/guide/agent-work/subagents/) и [Координация нескольких Agent](/ru/cases/workflows/multi-agent-coordination/) |
| 5 | Внешние системы | [Обзор MCP](/ru/skills/mcp/mcp-overview/) |
| 6 | Автоматические защитные механизмы | [Обзор Hooks](/ru/skills/hooks/hooks-overview/) |
| 7 | Распространение в команде | [Обзор Plugins](/ru/skills/plugins/plugins-overview/) |
| 8 | Откат и Review | [Отмена и восстановление](/ru/guide/getting-started/undo-and-recover/) и [Review diff](/ru/guide/quality/review-diffs/) |

Этот маршрут помогает перейти от «иногда просить Codex о помощи» к «небольшой системе, которую команда может воспроизводить». Инструкции проекта задают долгосрочные правила, Skill — способ работы, MCP предоставляет внешние инструменты, дочерний Agent выполняет подзадачи с ясными границами, Hook защищает ключевые точки, а Plugin распространяет этот набор возможностей среди других пользователей.

## Распространённые заблуждения

### 1. Маршруты обучения и основной текст руководства дублируют друг друга

Основной текст объясняет тему, а маршрут подсказывает, какие материалы читать сейчас.

### 2. Сначала нужно отнести себя к одной неизменной роли

Достаточно ответить на один вопрос:  
**Какую главную проблему вы хотите решить прямо сейчас?**

### 3. Выбранный маршрут нужно пройти от начала до конца без переходов

Маршрут — рекомендуемый порядок, а не обязательный процесс. Во время работы можно возвращаться к другим главам с конкретными вопросами.

## Что выбрать, если вы сомневаетесь

- Ещё не завершили первую задачу от начала до конца: выберите [маршрут для начинающих](/ru/guide/learning-paths/beginner/).
- Хотите прежде всего писать, создавать визуальные материалы и презентации: откройте [маршрут для авторов](/ru/guide/learning-paths/creator/).
- Хотите изменять код, исправлять ошибки и работать с проектами: откройте [маршрут для разработчиков](/ru/guide/learning-paths/developer/).
- Продумываете командное внедрение и управление риском: выберите [маршрут для команд](/ru/guide/learning-paths/team/).

Маршрут обучения определяет, что читать дальше, исходя из самой важной текущей задачи.
