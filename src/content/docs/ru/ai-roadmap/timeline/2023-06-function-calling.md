## Проверяемое событие и его границы

**Дата: 2023-06-13 · Тип: выпуск продукта.** OpenAI объявила о добавлении Function Calling в существовавший на тот момент Chat Completions API. Эта дата относится к выпуску API конкретного поставщика, а не к появлению всех видов вызова инструментов.

Источник: [объявление о выпуске Function Calling](https://openai.com/index/function-calling-and-other-api-updates/). Дата проверки — 2026-09-18; дата публикации источника и дата проверки этой страницы обозначают разные события.

## Какую проблему это решает

Модель может вывести имя функции, которую предполагается вызвать, и структурированные аргументы, после чего приложение проверяет их и решает, выполнять ли вызов. Формирование аргументов, получение разрешения и фактическое выполнение — три разных этапа.
