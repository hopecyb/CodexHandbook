# 写作简报

读者：有本地 Markdown 笔记、准备首次尝试整理工具的个人作者。写一篇能帮助读者决定“如何小范围试用、需要检查什么”的中文短文，不写广告，也不评价不存在的真实产品。

固定输入：sources 中三份合成资料及来源索引。不要联网补充拾页信息。全篇明确虚构教学情境，资料中没有的价格、速度、准确率和隐私结论不自行补齐。

交付到 `my-output/`：大纲、文章、claim-map.csv、未决问题清单。关键事实分别标为原文支持、作者推断或未确认。每条原文支持附来源 ID 与小节定位；冲突不得投票或按日期强行解决。

允许一次大纲选择后连续成稿，不默认逐段等待。交付停在本地文件，不发布、不发送。参考初稿是作者设计的错误示例，不能当作真实模型生成日志。
