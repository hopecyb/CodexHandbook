# 三组提示词对照：12 次实际运行记录

2026-09-18，结果包 v1.0.0。与固定输入材料包分开版本管理。本包保留销售周报、合成来源文章、Bug 修复各 A/B 两次的任务、输入、输出、工具记录、耗时和逐项复核。教学材料与生成产物采用 CC0-1.0；产品、人物和销售数据均为合成。

## 先看这些文件

- [review.md](review.md)：逐项分数、依据、观察与限制。
- [runs.json](runs.json)：实际起止时间、耗时、工具错误与交付路径。
- [scores.json](scores.json)：五维评分及证据定位，不计算总排名。
- [plan.json](plan.json)：运行前冻结的次序、输入哈希、任务哈希和停止条件；其中 prepared 为冻结时状态，实际状态见 runs.json。
- [common-wrapper.md](common-wrapper.md)：所有运行共用的任务包装。
- [file-manifest.json](file-manifest.json)：每个原始文件与公开副本的 SHA-256。
- [reviewer-checks.json](reviewer-checks.json)：后续复核脚本执行记录，不能冒充实验 Agent 自己做过的检查。

## 采样条件

每组次序为 A1 → B1 → B2 → A2，每一轮同时执行三个不同任务。共 12 个全新 Agent 上下文，各自使用独立目录，不共享前次对话；通过指令限制目录访问，未使用操作系统沙箱来隔离彼此目录。所有运行继承相同工具范围，不传模型和推理覆盖值。实际模型标签、推理设置不可确认，保留 null；不能声称已完成可复现的固定模型基准。

主任务宿主：Darwin arm64，Codex 应用本地 Info.plist 记录版本 26.911.61220 / build 9647；不据此推断后台模型。评分由主 Agent 对照预先保存的 rubric 和 review-guides 完成，非盲审、无人类独立复核。原任务每次最多 900 秒；没有为替换不佳结果重新运行实验，原运行内部的命令错误和恢复保留。

耗时从 Agent 保存 start.json 到保存 end.json，包含读取、写作、执行工具、记录日志和等待；不含分派前排队，也不等于纯模型推理时间。三个任务并行可能互相影响。没有人工基线、人工返工计时、Token 或费用测量，相应值未知。每种任务每个变体只有两次，不能估计普遍成功率或因果效应。

## 文件保留与限制

run-01 到 run-12 下保留当次输入、task.md、output 和 telemetry，以及 Agent 额外保存的脚本。仅将当前仓库、实验根目录和用户主目录的绝对路径替换成 `<REPOSITORY_ROOT>`、`<EXPERIMENT_ROOT>`、`<USER_HOME>`；不修正输出中的数字、措辞或漏项。复跑日志中的命令前，应将这些占位符替换成解压位置。原件保留于仓库规划目录，公开副本哈希单独列出。

日志来自 Agent 自行保存，并非执行平台自动导出的完整审计轨迹。run-07 明确报告只保留部分 Python 命令摘要，未保存完整 heredoc 源码；该缺口保留并影响可复现性评分。不能把本包描述为每条命令均完整可重放。

A/B 同一量表包含事实表、红绿测试和运行环境等交付检查，B 恰好显式提醒其中一部分。因此分数反映指定交付完整性，不是对模型通用能力的无偏评估；更长提示词也没有保证日志完整。

## 自行复核产物

需要 Python 3.10+ 和 Node.js（记录中的复核版本见 reviewer-checks.json）：

```sh
python3 scripts/check_results.py
```

脚本校验 12 次输入和任务哈希；销售任务从原始行重新计算并比较全部 CSV 字段；文章检查相对来源文件存在；Bug 任务使用临时目录、原测试和交付代码重新执行。它会更新 reviewer-checks.json，包含本次的真实时间和测试耗时。文章事实支持、冲突处理、正文数字与日志完整性仍需阅读复核。

这个命令不会调用模型，也不改变实验输出。重跑模型必须另建记录，不能覆盖本次 12 个样本。
