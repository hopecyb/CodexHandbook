# 两周团队试点包

v1.0.0，CC0。用于设计和记录小范围团队试点，不是已完成的真实团队研究。按十个工作日安排；节假日或任务量不足时延长，不以日历到期替代证据。

先填写 templates/01-charter.md，再选择任务并登记到 02-tasks.csv；运行与复核分别写 03-review.csv。异常使用 04-incident.md，第十个工作日用 05-decision.md 决定有限推广、继续观察或停止。06-schedule.md 指明每阶段产物与退出条件。

开始前先完成本站 Issue 分流或链接检查的本地练习，确认知道如何检查结果、保存证据和恢复。下载对应案例包；本包不重复分发它们，也不创建实际调度或外部权限。

负责人、执行者、复核者和系统管理员可以兼任，但涉及外部写入或安全事件的决定应有独立复核；暂时找不到复核者时限制为合成输入、本地草稿和作者自检，不能写成独立审查。

所有模板的空字段都是待团队填写的项目，不代表已有观测。示意决策见 references/tabletop-review.md，仅为作者桌面推演，无真实人员、效率数据或成功率。
