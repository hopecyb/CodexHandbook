# 开发者路径配套材料

这些模板配合上一级 verified-bug-fix 的 starter、solution 和 prompts 使用。它们不包含完整代码练习；代码与任务规则仍以上一级目录为准。

- code-map-template.md：先读代码再写根因。
- review-template.md：说明比较范围、findings、测试与限制。
- handoff-template.md：说明当前状态、证据及下一步。
- 三份 reference.md：作者填写的参考，不是模型运行日志或独立复核结果。
- run-record.json：2026-09-18 重新运行 starter/solution 得到的摘要，两份测试逐字节相同。

把模板复制到自己的 evidence/ 目录，填写实际结果。保留空白模板与参考文件；不要用参考输出冒充自己执行的测试。
