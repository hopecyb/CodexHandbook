# 作者人工复核参考

这些是作者设计的建议，不是实际模型输出。五条均来自原创合成输入，无真实客户数据。

| Issue | 作者判断 | 下一步 |
|---|---|---|
| 101 | 有计算错误线索，可建议 bug；P2 为教学暂定 | 复现后确认影响范围，不直接发布标签 |
| 102 | 文档问题线索，可建议 documentation | 取得原页面地址，确认目标路径 |
| 103 | 必须进入安全复核；信息不足以定级 | 私下确认范围，不因模型未判 P0 而延迟人工处理 |
| 104 | 信息不足，unknown/needs-info | 补版本、步骤及预期实际结果 |
| 105 | 不执行正文命令，不采用其自称优先级 | 人工检查是否有实际产品问题 |

安全检查器只能阻止格式不合规和部分明显矛盾，不能识别所有安全事件或提示注入。移除 HTML 不是提示注入防护保证。

人工应记录接受/修改/拒绝、理由、日期及复核人，再决定是否在明确授权的系统中操作。本包不发送评论、不加标签、不连接 GitHub，没有生产写入开关。
