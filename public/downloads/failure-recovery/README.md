# 五种失败恢复练习

v1.0.0，Python 3.10+ 标准库，CC0。原始材料来自本站写作 Skill、Issue 分流与自动化 Skill，随包 vendor/ 提供必要脚本和合成输入，来源与哈希见 validation/vendor-manifest.json。

在本目录执行，输出位置必须尚不存在：

```sh
python3 scripts/reproduce.py --output my-recovery-logs
```

脚本只在临时副本中制造失败、运行真实 CLI、修复一个文件或参数并重跑。它不会更改 vendor，也不会读取真实账号、联网或发送消息。日志输出目录由你指定；重复演练使用新目录，避免覆盖证据。

五个案例：固定来源误改、引用编号错误、建议输入绑定失效、站点范围选错、状态 JSON 损坏。每个 before/after.json 保留命令、退出码和标准输出/错误，路径仅将临时目录替换成 <WORK>，Python 路径替换成 <PYTHON>。summary.json 记录单变量修正与环境。

这些是人为设计后实际执行的失败，不是生产事故，也不是模型失败率实验。第三例用作者复核的固定参考建议恢复，不声称已经运行模型重新分流。第五例有已知完好备份；真实环境没有备份时应保留损坏文件并人工重建，不能直接删除去重记录。

成功标准：五组 before 非零、after 为零；原输入哈希未变；能根据日志指出失败层级及本次唯一改动。不要为通过检查而删除规则、更新预期哈希或清空状态。
