> Vom ersten Öffnen von Codex bis zur Nutzung in echten Projekten, Workflows und langfristiger Wissensaufbau.  
> Dies ist keine verstreute Tippsammlung, sondern ein systematisches Praxis-Handbuch, organisiert um `Leitfaden / Prompts / Skills / Fälle`.

## Was das ist

**Codex Handbook** ist eine systematische Wissensbasis zum Lernen und Praktizieren mit Codex. Es versucht nicht, die breite Frage „Was kann Codex?“ zu beantworten. Stattdessen fokussiert es drei praktische Fragen:

- Wo sollte man anfangen, wenn man Codex zum ersten Mal nutzt?
- Wie beschreibt man Aufgaben, organisiert Kontext und verifiziert Ergebnisse bei der Nutzung von Codex in echten Projekten?
- Nach einer erfolgreichen Zusammenarbeit: Wie verwandelt man diese Erfahrung in Prompts, Skills, Regeln, Fälle und Team-Assets?

Wenn du gerade mit Codex startest, sind dieses Repository und die Website dein erster Anlaufpunkt.

## Was du lernen wirst

### Leitfaden

Verstehen, wie du den Codex-Einstieg wählst, grundlegende Nutzungspfade folgst, Kontext organisierst, Berechtigungsgrenzen einhältst und Ergebnisse verifizierst.

### Prompts

Lernen, Aufgaben klar zu beschreiben, Einschränkungen, Ziele, Eingaben und Akzeptanzkriterien zu definieren, damit Codex zuverlässig prüfbare Ergebnisse liefert.

### Skills

Lernen, Skills zu entwerfen, nutzen, warten und zu verwalten — eine erfolgreiche Zusammenarbeit in eine langfristig wiederverwendbare Fähigkeit zu verwandeln.

### Praxis-Fälle

End-to-End-Workflows durch echte Aufgaben verstehen: Code lesen, Bugs beheben, Dokumentation schreiben, recherchieren, automatisieren und Liefer-Zusammenarbeit.

## Für wen

- Einsteiger, die Codex zum ersten Mal entdecken
- Entwickler, die Codex in echten Projekten nutzen wollen
- Teams, die Prompts, Regeln, Vorlagen und Fälle festhalten müssen
- Wissensarbeiter, die Codex für Schreiben, Recherche, Dokumentation und Präsentationen nutzen

## Lokale Entwicklung

Dieses Projekt nutzt [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/) für die Dokumentations-Website. Der deutsche Inhalt liegt in `src/content/docs/de/`.

Anforderungen:

- Node.js `>=22.12.0`
- `pnpm`

Entwicklungsumgebung starten:

```bash
pnpm install
pnpm dev
```

Statische Website bauen:

```bash
pnpm build
```

Fortschritt der deutschen Übersetzung prüfen:

```bash
pnpm i18n:status -- --locale de
```

Der deutsche Inhalt liegt in `src/content/docs/de/` (Spiegel der Quelle in vereinfachtem Chinesisch). Glossar: [`glossary/de.md`](./glossary/de.md). Stand 2026-07-28: deutsche Seitenabdeckung **100%** (alle `translation_status: draft`; sprachliche/technische Review ausstehend).

## Prinzipien

- **Offiziell zuerst**: Bei Produktfähigkeiten, Regeln und Grenzen offizielle Quellen bevorzugen.
- **Einsteigerfreundlich**: Keine Vorkenntnisse in Terminal, Git, Agent oder Automatisierung vorausgesetzt.
- **Aufgabenorientiert**: Wiederverwendbare Workflows, Fälle und Vorlagen — keine abstrakten Konzeptstapel.
- **Klare Sicherheitsgrenzen**: Berechtigungen, Dateischreibvorgänge, Netzwerk, Automatisierung und Erweiterungen müssen Risiken erklären.
- **Kontinuierliche Festhaltung**: Eine erfolgreiche Aufgabe in Prompts, Skills, Regeln, Fälle und Team-Assets verwandeln.

## Mitwirken

Wir freuen uns über:

- Einsteigerfreundliche Tutorial-Überarbeitungen
