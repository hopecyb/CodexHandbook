# 本教学包的风格样本

受众是准备试用工具的个人作者。先写输入、动作和可检查的限制，用自然中文；不写宣传保证。用户自己的风格要求优先于这份样本。

## 设计反例与修改

反例：“拾页是全能神器，轻松处理任何格式，让你的工作效率翻倍。”

修改：“说明只列出 Markdown 与纯文本。先复制少量笔记试用，再回查摘要指向的原文。”

理由：去掉无来源的能力与效果承诺，写出实际边界和下一步。第二句是作者建议，仍应在事实表中单独标明。

另一种修改：“资料对诊断默认设置的说法相反，目前无法确认。”比“隐私表现非常优秀”更符合现有证据。

## 人工检查

- 每段是否服务受众的问题，而非重复“非常重要”？
- 是否用具体动作替换了空泛效果词？
- 精简后是否丢掉“仅限”“合成”“未确认”等必要限定？
- 保留了用户要求的语气和结构吗？

不要用禁词计数代替判断；出现某个形容词并不自动构成错误。
