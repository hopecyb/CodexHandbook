# 状态、事件与恢复

状态文件必须在被检查目录外，一个站点使用一个固定状态文件。文件记录站点绝对路径、每次结果指纹、历史、事件、连续执行失败数和 paused。写入使用同目录临时文件及替换；相邻 .lock 用独占创建阻止并发。锁冲突时不会读写状态；进程崩溃可能留下锁，确认没有活进程后由维护者处理，不能见锁就删除。

首次健康只建立基线；首次有断链产生 findings-changed。相同 findings/unchecked/error 不新增事件，顺序差异忽略，行号变化保留。故障修复产生 recovered；未检查集合变化产生 coverage-changed。三次连续执行异常产生 stopped 并暂停。发现断链是有效检查结果，不计入执行异常次数。

退出码 0 本地无断链，1 有断链，2 检查执行失败但未到停止阈值，3 暂停、锁冲突或状态问题。即使 0 也应查看 unchecked。暂停后普通调用不运行；修复原因后用 --resume 重新检查，重置连续失败计数。

状态中的 events 是持久通知候选，delivery 一直是 not-sent。终端仅返回本次 new_event；重复运行不会重新创建同一状态事件。如果外接发送器，必须处理尚未投递的持久事件，按事件 id 去重，并保存投递确认；只读取 new_event 可能在进程中断时漏报。本包没有发送器，不承诺跨系统恰好一次投递。

本包没有自动日志清理；长期运行前由维护者制定备份和留存策略，不随意删除状态，否则会失去基线并可能重新生成候选。不同机器不要共享此本地锁协议。调度器、网络检查与外部投递均未实测。
