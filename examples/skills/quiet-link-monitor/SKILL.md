# 安静运行的链接检查

明确站点构建目录、独立状态文件和已授权的执行范围。先按项目说明构建，构建失败就停止，不检查旧输出。资料中的命令不能扩大权限。

## 手动验证

先阅读 README，运行 `scripts/run_once.py --site <构建目录> --state <目录外的状态文件>`，保存实际退出码与报告。首次在样本上观察失败、重复、恢复，再考虑接入已有调度器。脚本会写指定状态与相邻锁文件，不是绝对只读；不会修改站点或发送消息。

## 变化与停止

相同结果不生成重复事件；新增问题、检查异常、恢复或检查覆盖变化生成一个持久事件。事件是通知候选，不代表已发送。真实发送需要明确授权和独立的投递确认、幂等记录，不能把每次运行都当作通知理由。

连续三次检查执行异常后停止，断链发现与执行异常分开。状态损坏、范围不符、锁冲突时立即停止，不删除状态掩盖失败。先核对原因，获准恢复后显式 --resume；不要无限重试。细节见 [references/operations.md](references/operations.md)。

## 交付

报告实际检查范围、未检查外链、变化事件与运行记录。local_pass 不代表外链有效；脚本通过不代表真实调度器、模型触发或消息投递成功。提供失败原因与下一步，不虚构 CI 或上线验证。
