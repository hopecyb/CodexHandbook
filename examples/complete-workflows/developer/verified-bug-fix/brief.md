# 任务简报

购物车函数 `calculateTotal(lines, discountPercent)` 接收商品行和折扣百分比。

业务规则：

- 每行金额是 `price * quantity`。
- `discountPercent = 10` 表示减免小计的 10%。
- 空购物车总额为 `0`。
- `discountPercent = 0` 时不打折。

已知现象：无折扣测试通过，10% 折扣测试得到负数。

约束：

- 不改变函数名、参数或返回类型。
- 不修改测试期望来迎合错误实现。
- 不增加第三方依赖。
- 不处理货币精度、税费和非法输入，这些不在本案例范围。

完成标准：

- 起始失败可以稳定复现。
- 只修改百分比换算根因。
- 3 个测试全部通过。
- 能提供失败断言、最小 diff 和通过摘要。
