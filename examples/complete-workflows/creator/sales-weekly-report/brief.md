# 任务简报

你为虚构的文具商店整理周报。负责人需要比较 2026-09-07—09-13 与 2026-08-31—09-06 两个完整自然周，找出各地区净额与本期 Top 3 产品，并知道哪些数据尚未纳入。

允许读取本练习包，在 `my-output/` 新建文件。保留 starter、solution 和 validation 不变，不联网、不外发、不写入其他目录。

完成标准：

- 四个约定产物齐全；金额按人民币元、精确到分。
- 报告每个关键数字说明字段、筛选口径或对应汇总文件。
- 重复、缺日期、退款、零基数逐项有处理决定。
- 独立核对总额、华东分组和缺日期金额；确认输入哈希不变。
- 分析仅描述数据，不编造增长原因、利润或客户画像。

若发现同一订单 ID 的内容不同，停止汇总并列出冲突，不自行保留第一条。其他口径已经在数据字典明确，可以连续完成，不必每一步等待确认。
