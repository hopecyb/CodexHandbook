# 用量与耗时记录

v1.0.0，CC0。两份空白 CSV，不读取账号、不调用模型、不计算订阅余量的美元价值。

runs.csv 每次运行一行，包括失败、中断和重试。billing_route 写 subscription/api/unknown；actual_api_charge 仅填已核对账单或用量明细，estimated_api_charge 是估算，两者不能混称。未知字段留空并写原因，不填零。

allowance-snapshots.csv 记录界面显示的额度快照和重置时间。account_scope 使用脱敏别名，不填账号或凭证。多个任务可能共享额度，两个快照的差不能直接归因到一个任务；窗口重置、并行工作与显示精度都要记录。

等待用 elapsed_seconds，人工复核与返工分别以分钟记录。总墙钟与人的投入不能简单相加：人可能在模型运行时同时做别的事。没有匹配人工基线时，不计算节省比例。

## 采样条件

任务输入和难度、模型/客户端/推理设置、工具范围、是否缓存或重试、服务模式、日期与价格来源都需记录。当前包没有实测样本，不提供模型速度或成本排序。

## 教学估算（虚构费率，不是产品报价）

假设一个只含文本、无工具费用、无缓存、无长上下文附加条件的演算：输入10000 token，输出2000 token；虚构单价分别为每百万2美元和10美元。估算为10000/1000000×2 + 2000/1000000×10 = 0.04美元。

此算式只示范单位转换。真实API需核对对应模型、输入/缓存/输出及适用附加计费项，按当次用量与价格计算。推理 token 属于输出计费时，不能在已包含它的输出总数之外重复加算。不得用订阅使用百分比代入这个公式。
