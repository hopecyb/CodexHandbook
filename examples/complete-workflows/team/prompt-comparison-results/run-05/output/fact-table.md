# 逐项事实表

“资料支持”仅表示合成资料明确记载，不表示对真实产品的验证。P、I、C 分别链接至[产品说明](../input/01-product.md)、[合成访谈](../input/02-interview.md)、[版本摘要](../input/03-changelog.md)。

| 编号 | 陈述 | 来源 | 判定与使用边界 |
| --- | --- | --- | --- |
| F01 | 拾页为虚构产品，不代表实际软件。 | P 文首；C 文首 | 明确的合成身份，介绍中必须保留。 |
| F02 | 三份资料均为原创或自制教学材料，标注 CC0 1.0。 | P、I、C 文首 | 资料支持。 |
| F03 | 拾页帮助个人整理指定本地文件夹里的 Markdown 和纯文本笔记。 | P1 | 资料支持；未承诺跨设备同步。 |
| F04 | 1.2 仅接受 `.md` 和 `.txt`。 | P1 | 资料支持；不得扩大为任意文档格式。 |
| F05 | 不支持 PDF、网页抓取或图片识别。 | P1 | 明确限制；C1 也未提及新增 PDF 或图片支持。 |
| F06 | 用户可以生成主题索引。 | P2 | 资料支持。 |
| F07 | 用户可以生成带源文件路径的摘要。 | P2；C1 | 两份资料相符；C1 将路径列为 1.2 新增。 |
| F08 | 摘要不是原文，使用前应回到源文件核对。 | P2 | 明确的使用要求。 |
| F09 | 产品说明没有承诺摘要完全准确。 | P2 | 不得写成准确性保证。 |
| F10 | 文件索引在本机完成。 | P3 | 仅适用于文件索引，不能外推为全部功能离线。 |
| F11 | 产品说明称“诊断上传默认关闭”。 | P3，2026-09-10 | 与 F12 冲突，尚不能作为无条件产品结论。 |
| F12 | 版本摘要称“新安装的 1.2 默认开启诊断上传”。 | C2，2026-09-12 | 与 F11 并列保留；是否仅针对测试版或正式版未说明。 |
| F13 | 维护者尚未提供上述冲突的修正说明；较晚日期不能证明另一份失效。 | C3 | 冲突未决；不得按日期择一。 |
| F14 | 开启诊断选项后的发送内容与网络行为需查阅相应设置说明。 | P3 | 当前资料未附该说明，无法进一步确认。 |
| F15 | 产品说明与版本摘要均未列出诊断上传字段。 | P3；C2 | 信息缺口；不能断言不上传笔记或敏感内容，也不能断言一定上传。 |
| F16 | 小林是虚构角色，访谈不能作为真实用户证言或效果统计。 | I 文首；I3 | 引用观察时必须保留这个限定。 |
| F17 | 小林希望从散落的读书笔记中找到主题相关原文，再自行选择写入文章的段落。 | I1 | 虚构角色的目标，不代表全部作者。 |
| F18 | 小林在情境中试了十二份 Markdown 笔记，索引帮助其回到源文件。 | I2 | 合成情境观察；不是评估样本或实测效果。 |
| F19 | 情境中有一次摘要把两个相似项目当成同一件事，小林对照原文改正。 | I2 | 不得据此推算错误率、准确率或普遍表现。 |
| F20 | 访谈没有计时，也没有固定评估样本。 | I3 | 无法支持时间节省或整体准确率结论。 |
| F21 | 1.2 增加摘要中的源文件路径。 | C1 | 版本摘要明确记载。 |
| F22 | 1.2 修复重新扫描时重复索引同一文件的问题。 | C1 | 版本摘要明确记载；无独立验证或量化改善数据。 |
| F23 | 资料没有给出处理速度、节省时间或准确率数据。 | P4；I3 | 效果数据缺失，不填入估计值。 |
| F24 | 资料没有给出付费方案或跨设备同步承诺。 | P4 | 未提供不等于免费，也不等于明确不支持同步。 |
