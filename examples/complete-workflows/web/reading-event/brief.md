# 固定需求：阅读分享会页面

事实只来自 facts.md（复用新手包的 CC0 合成资料）。输出是一页本地静态 HTML：活动介绍、时间、地点、名额、费用、自愿带书与待确认报名方式。不得编造报名链接、二维码、电话号码或真实活动信息。

使用原生 HTML 和内联 CSS，无第三方字体、图片、脚本或依赖。不联网，不收集数据，不部署，不发送。允许改动范围只有工作副本的 index.html。保留语义结构、一个 H1、viewport 设置和可见键盘焦点。

主按钮仅跳转到本页参与说明，不能伪装成已提供报名功能。桌面和手机窄屏可读，不能横向溢出，按钮目的地真实存在。

验收：逐项核对 F1—F7；375×812 和桌面浏览器检查；Tab 到按钮并用 Enter 激活；本地链接检查通过；原始事实和需求未改。
