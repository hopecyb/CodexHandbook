# 价格快照来源记录

核对日期：2026-09-18。范围：美国 App Store 的 ChatGPT 应用详情页，Information → In-App Purchases。

来源：https://apps.apple.com/us/app/chatgpt/id6448311069

该页开发者为 OpenAI OpCo, LLC，地区为 United States。本站仅摘录公开内购项目名称及 USD 标价，共 8 条，存于 `src/data/chatgptPriceQuotes.json`；每条记录独立包含来源、渠道、地区、币种和核对日期。

重要边界：公开清单未提供每条项目的订阅周期、税费处理或账号购买资格。Plus 同名项目出现两个价格，无法仅凭金额判定哪条是年付。因此 `period` 和 `tax` 保持 null，页面说明两者未核验。不把本快照视为实时结账报价。

旧实现中的 32 地区参考值没有逐条一手来源；本轮移除这些未核验金额、固定汇率、套餐倍数推算和相应最低价/最高价/节省比例排名。其他地区或渠道明确显示暂无核验数据。以后新增记录须逐条核对，不能从美国价格或其他套餐外推。

验证：数据契约测试检查来源、币种、地区、渠道、日期及未知周期/税费；事实准确性依据上述来源人工核对，测试本身不能证明价格仍未变化。
