## 原型怎么用

直接打开 `prototype.html`。页面使用同目录 CSS/JS 与本地 Logo，无框架、字体或 CDN 依赖。若浏览器限制本地资源，可在仓库根目录运行 `python3 -m http.server 4177 --bind 127.0.0.1`，访问 `http://127.0.0.1:4177/docs/planning/next-content/prototype.html`。

顶部设计栏切换「任务优先 / 路径优先 / 查阅优先」，比较的是入口与布局，不只是换颜色。进入案例库可筛选；进入周报案例可看步骤、核对样本、复制提示词和下载 CSV；学习路径可切换角色；内容排期可切换批次。

原型中的新增内容均标为规划，不把设计数据当作已上线实测成果。CSV 仅为 6 行合成设计样本，不替代规划中的完整教学包。

## 推荐决策

1. 保留四模块的内容资产和 URL，增加任务入口与明确的学习顺序。
2. 第一批同时交付可信度修正和一个完整周报案例；没有完成素材包前，不宣传「完整实战」。
3. 第二批补文章与演示稿，并串成创作者路径。
4. 第三批再扩大 Skill 包、评估与失败恢复内容。
5. 暂不增加独立新闻、榜单或作品展一级栏目。作品预览嵌在案例内，直接服务学习。

此轮设计基于现有网站和仓库，是可评审的主方案与两种变体；尚未经过真实读者可用性访谈，不能视为已验证的增长策略。
