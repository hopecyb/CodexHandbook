# 页面设计说明

## 设计取舍

延续书本 Logo 和蓝色品牌，减少通用封面，给任务产物、输入材料和验收说明让出空间。正文 17px、行高约 1.8；标题与正文用现有中文系统字体，避免引入整套中文网络字体。底色采用现站书本纸张的暖色作为浅色阅读方案，深色作为可切换方案。

三种首页方向使用相同内容资产：

| 方向 | 布局与主动作 | 适合 | 代价 |
|---|---|---|---|
| A 任务优先（推荐） | 大标题+成果预览；三类任务入口 | 有具体需求、想立刻动手的人 | 需要真实素材包支撑 |
| B 路径优先 | 分步路线作为视觉主体；先选角色 | 从零开始系统学习的人 | 需要清楚的课程完成条件 |
| C 查阅优先 | 搜索和主题索引靠前；紧凑列表 | 回访者和熟练用户 | 对首次访问者的成果感较弱 |

原型顶部方向切换只用于设计评审；正式网站不必让读者选择信息架构。建议 A 为首页，B 的路径模块与 C 的检索入口融合到主方案。

## 五个视图的责任

### 首页

顺序：站点导航 → 一句具体价值主张 → 一个成果预览与直接行动 → 三个任务入口 → 学习/查阅入口。文案建议：「从一个小任务，做出一份能用的成果。」

主 CTA 为「开始周报练习」，次 CTA 为「浏览实战案例」。GitHub 保留页脚与贡献区，首次读者不必先离站。

### 案例库

可按任务分类和关键词筛选；卡片包含任务、产物、难度、内容状态。已存在案例与规划案例严格区分。原型只展示精选样本，条目数不是全站案例总量。

无结果状态说明当前筛选，并提供重置。正式搜索需保留筛选参数到 URL；原型为本地交互，不实现全站 Pagefind 替换。

### 案例详情

首屏说明结果、材料和适用条件。桌面左侧步骤导航、中央任务正文、右侧验收摘要；移动端依次堆叠，步骤按钮可换行，不依赖横向滚动寻找下一步。

步骤：准备材料、说明任务、核对结果、失败恢复。每步必须有完成条件。参考结果明确写「参考」，读者勾选检查项只是自检，不生成认证徽章。

原型提供真实可下载的六行合成 CSV 和可复制提示词；这两项仅验证交互，不代表首批完整案例已写完。复制失败时回退为选择文本，给出明确反馈。

### 学习路径

四角色切换；每一节点有动作、预期产物、前置依赖和状态。不用进度环或虚构完成率。正式若保存进度，优先本地状态，清楚说明只在当前设备生效；本轮原型不保存学习进度。

### 内容排期

用于维护者评审，正式网站不必发布。按四个批次显示内容、依赖和发布门槛，与 content-plan 中的 T01—T24 对应。避免把相对优先级伪装为承诺发布日期。

## 状态与交互

- 页面级设计提示始终可见：规划预览，不是已经发布的新课程。
- 当前导航 `aria-current`；方向和筛选按钮 `aria-pressed`；步骤页切换后将焦点移到正文标题。
- 复制提示使用 `aria-live`；下载指向真实本地 CSV 文件，不出现虚假成功提示。
- 所有非原型页面的入口明确标为打开现站，不做死按钮。
- 空结果有解释和恢复按钮；未知 URL hash 回到首页。
- 键盘可到达所有按钮，焦点明显；避免仅靠颜色区分状态。
- 375px 与 1440px 检查无整页横向溢出；宽代码块只在自身容器内滚动。
- 尊重 `prefers-reduced-motion`。默认无自动播放、浮层遮挡或追踪请求。

## 正式实施映射

| 原型能力 | 建议接入现有文件 | 边界 |
|---|---|---|
| 任务优先首页 | `src/content/docs/index.mdx` | 保留 i18n、SEO 与现有路由 |
| 主导航分组 | `Header.astro`、`MobileMainNav.astro`、`siteNav.ts` | 桌面和移动共用数据源 |
| 单标题与封面减重 | `PageTitle.astro`、`DocIllustration.astro` | 先处理 61 个正文 H1 条件页 |
| 案例目录卡片 | 新建 CaseCard/CaseFilters，接 `/cases/` | 数据来自内容集合，避免手工复制状态 |
| 案例步骤与材料 | MDX 组件、案例 frontmatter | 无文件不渲染下载按钮 |
| 内容验证徽标 | 新建 VerificationMeta，扩展 schema | 不自动把旧 verified 映射为实跑 |
| 路径节点 | PathStep 组件与路径内容 | 正文不重复产品教程 |
| 上下篇 | 入口页/路径页明确 pagination | 参考目录排序不等于教学顺序 |

## 设计验证与未覆盖事项

原型需验证入口切换、筛选/空结果、详情步骤、下载/复制、角色路径、排期切换、主题、窄屏布局及浏览器控制台。结果写入 validation.md。

本轮不完成生产端迁移、全站产品事实核验、实时价格数据接入或真实读者访谈。这些是实施计划内的后续工作，不是本次规划设计的隐含交付。
