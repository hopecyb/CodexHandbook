## 已有资产

- 品牌：Codex 指南手册，社区网站；不冒充 OpenAI 官方。
- Logo：复制仓库 `public/brand/logo.png` 到本目录 `assets/logo.png`，原样引用，不重画。
- UI 依据：2026-09-18 对线上中文首页、指南、案例和价格页的浏览器观察，以及 `src/components`、`src/styles/custom.css`。原有深色界面、书本 Logo、蓝色强调保持可识别。
- 色板：原站书脊蓝 `#3d68ff`、纸张色 `#f3e6d3`、纸张边缘 `#d9c4a6`。原型将纸张色调淡作为阅读底色，深色配色沿用已观察的炭灰视觉；属于设计调整，不是新的官方品牌规范。
- 字体：中文系统字体优先，与仓库写作规范一致；不加载外部字体。无额外商业素材依赖。
- 非实体产品，不需要产品渲染图。原型的成果预览是结构化文档示例，不是伪造产品截图。

## 设计假设

优先提高首次完成任务的机会；保留查阅效率；先做三个完整非编程练习。尚无站点分析数据支持用户数量、转化率或收益判断，原型不展示这些数字。

「30 分钟」「8 页」分别是规划的练习规模与目标交付页数。不是当前产品速度保证。新增案例标签统一标「规划」；已存在 Bug 练习标「现有材料」，不虚构本轮重新实跑。
