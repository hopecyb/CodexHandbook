## 2. 宠物：先登记资源，再测完整生命周期

本机未找到已提供的可测试自定义宠物包；资源名称、版本、作者许可、来源和SHA-256都待登记。选择一个已有合法来源的包，不用内置宠物的播放结果冒充自定义包安装验证。

按[兼容记录模板](../../../src/content/docs/guide/reference/resource-compatibility.md)执行：记录原选项 → 备份 → 复制完整资源包 → 选择并验证加载 → 观察透明背景、动作与窗口缩放 → 切回原选项 → 将该包移出扫描目录 → 刷新确认不再出现 → 放回同一包确认恢复 → 最后恢复测试前状态。无法观察的动作单独标未知；不删除整个配置目录。
