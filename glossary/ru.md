# Глоссарий (русский)

Рекомендуемые русские термины для перевода и подготовки материалов Codex Handbook. Стабильные идентификаторы терминов перечислены в [`terms.yml`](./terms.yml). Исходный язык — упрощённый китайский (`zh-CN`).

## Принципы

- Названия продуктов, механизмов, протоколов и файлов не переводятся: Codex, ChatGPT, AGENTS.md, Skill, MCP, Hook, Plugin, Cloud, Agent, Worktree, Profile, Review.
- Естественная русская техническая лексика предпочтительнее буквальных калек с китайского или английского.
- Для одного понятия следует использовать один и тот же термин на странице и во всём руководстве, кроме случаев, когда в интерфейсе продукта закреплена другая формулировка.
- При первом упоминании редкого термина можно привести английский вариант в скобках: сжатие контекста (compaction).

## Не рекомендуется

| Избегать | Предпочитать | Почему |
|---|---|---|
| Переводить Skill как «навык» или подменять им Plugin | Skill / Plugin | Это разные механизмы продукта |
| Смешивать ветку и задачу | ветка / задача | Ветка хранит непрерывный контекст, задача описывает единицу работы |
| Переводить AGENTS.md | AGENTS.md | Это имя файла |
| Чередовать «песочницу», «sandbox» и «изолятор» без причины | песочница | Единый термин руководства |
| Переводить Worktree как «рабочее дерево» в названиях функций | Worktree | В документации продукта сохраняется исходное название |
