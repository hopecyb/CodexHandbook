# 术语表（简体中文）

手册翻译与写作时使用的推荐译法。稳定术语 ID 见 [`terms.yml`](./terms.yml)。

## 原则

- 官方产品名、协议名、文件名不翻译：Codex、MCP、Skill、Hook、Plugin、AGENTS.md、Token。
- 同一语言中不得混用容易混淆的译法（例如「任务 / 线程」各有固定含义）。
- 首次出现生僻术语时，可在括号中附英文：提示词（prompt）。

## 不推荐

| 避免 | 原因 |
|---|---|
| 把 Thread 译成「对话」并与 Task 混用 | 线程强调连续上下文，任务强调目标单元 |
| 把 Skill 译成「技能包」且与 Plugin 互换 | 产品机制不同 |
| 把 Sandbox 译成「沙盒」与「沙箱」混用 | 本手册统一用「沙箱」 |
