# อภิธานศัพท์ (ภาษาไทย)

คำแปลแนะนำสำหรับการแปลและเขียน Codex Handbook ดู Term ID ที่คงที่ได้ใน [`terms.yml`](./terms.yml) ภาษาต้นฉบับคือภาษาจีนตัวย่อ (`zh-CN`)

## หลักการ

- ไม่แปลชื่อผลิตภัณฑ์ โปรโตคอล กลไกทางการ หรือชื่อไฟล์: Codex, ChatGPT, AGENTS.md, Skill, MCP, Hook, Plugin, Cloud, Agent, Worktree, Profile และ Review
- ให้ความสำคัญกับภาษาไทยเชิงเทคนิคที่เป็นธรรมชาติ มากกว่าการแปลตามคำแบบกลไก
- ใช้คำเดียวกันให้สม่ำเสมอทั้งภายในหน้าและตลอดคู่มือ เว้นแต่ UI ของผลิตภัณฑ์จะใช้ป้ายกำกับต่างออกไป

## คำที่ควรหลีกเลี่ยง

| หลีกเลี่ยง | ควรใช้ | เหตุผล |
|---|---|---|
| แปล Skill เป็นเพียง “ทักษะ” หรือใช้ปะปนกับ Plugin | Skill / Plugin | เป็นกลไกผลิตภัณฑ์คนละแบบ |
| ใช้เธรดกับงานแทนกัน | เธรด / งาน | เธรดเน้นบริบทต่อเนื่อง แต่งานเน้นเป้าหมาย |
| แปล AGENTS.md | AGENTS.md | เป็นชื่อไฟล์ |
| ใช้คำแปลหลายแบบสำหรับแซนด์บ็อกซ์ | แซนด์บ็อกซ์ | ทำให้คำศัพท์ทางเทคนิคไม่สม่ำเสมอ |
